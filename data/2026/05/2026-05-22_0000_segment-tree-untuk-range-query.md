## ⚡ Competitive Programming Concept: Segment Tree untuk Range Query

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data pohon yang memungkinkan query pada range (jangkauan) dan update pada elemen individual atau range dalam waktu logaritma.

Segment Tree adalah struktur data berbasis pohon biner yang digunakan untuk menyimpan informasi tentang interval atau segmen. Setiap node dalam Segment Tree mewakili suatu interval dari array asli, dan node root mewakili seluruh array. Node internal lainnya mewakili sub-interval, dan node daun mewakili elemen individual dari array. Struktur ini sangat efisien untuk memproses query pada range, seperti mencari jumlah, minimum, maksimum, atau operasi lain yang bersifat asosiatif dan dapat digabungkan secara efisien.

Pembangunan Segment Tree biasanya dimulai dari array input. Node root mencakup seluruh array `[0, N-1]`. Untuk setiap node `[L, R]`, ia memiliki dua anak: anak kiri mencakup `[L, (L+R)/2]` dan anak kanan mencakup `[(L+R)/2 + 1, R]`. Informasi di node parent (misalnya, jumlah) digabungkan dari informasi di kedua anak-anaknya. Query pada range `[queryL, queryR]` akan memecah range ini menjadi beberapa interval yang sesuai dengan node-node di pohon. Jika sebuah node interval `[nodeL, nodeR]` sepenuhnya berada di dalam `[queryL, queryR]`, nilai node tersebut langsung digunakan. Jika tidak, query diteruskan ke anak-anaknya. Operasi update elemen tunggal juga serupa, dengan menelusuri pohon hingga node daun yang sesuai dan memperbarui nilai pada jalur kembali ke root.

Pembangunan Segment Tree membutuhkan waktu `O(N)`, di mana `N` adalah ukuran array asli, karena setiap node dikunjungi sekali. Baik operasi query maupun update elemen tunggal membutuhkan waktu `O(log N)`, karena dalam setiap langkah kita membagi interval menjadi dua, sehingga kedalaman pohon adalah `log N`. Total ruang yang dibutuhkan adalah `O(N)`, biasanya sekitar `4N` untuk array 1-dimensi.

```
const int N = 1e5;
int arr[N];
int tree[4 * N]; // Ukuran pohon biasanya 4*N

void build(int node, int start, int end) {
    if (start == end) {
        tree[node] = arr[start];
    } else {
        int mid = (start + end) / 2;
        build(2 * node, start, mid);
        build(2 * node + 1, mid + 1, end);
        tree[node] = tree[2 * node] + tree[2 * node + 1]; // Contoh: sum query
    }
}

int query(int node, int start, int end, int l, int r) {
    if (r < start || end < l) return 0; // Tidak ada tumpang tindih
    if (l <= start && end <= r) return tree[node]; // Tumpang tindih penuh
    int mid = (start + end) / 2;
    int p1 = query(2 * node, start, mid, l, r);
    int p2 = query(2 * node + 1, mid + 1, end, l, r);
    return p1 + p2;
}
```

💡 **Fun Fact:** Segment Tree seringkali digunakan untuk masalah yang sekilas terlihat membutuhkan `O(N)` waktu per query (seperti mencari sum di range), namun dengan Segment Tree bisa diselesaikan lebih cepat. Konsep ini bisa diperluas menjadi 2D Segment Tree atau dengan lazy propagation untuk update range yang lebih kompleks.
