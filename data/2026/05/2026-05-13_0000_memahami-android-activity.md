## 🤖 Android Concept: Memahami Android Activity

**Category:** UI
**TL;DR:** Activity adalah komponen inti aplikasi Android yang menyediakan satu layar antarmuka pengguna, tempat pengguna berinteraksi langsung.

Di dunia Android, aplikasi dibangun dari berbagai komponen, dan `Activity` adalah salah satu yang paling fundamental. Bayangkan `Activity` sebagai satu layar tunggal dalam aplikasi Anda. Misalnya, saat Anda membuka aplikasi email, daftar email adalah satu `Activity`, dan saat Anda mengeklik salah satu email untuk membacanya, itu mungkin `Activity` lain. Ini adalah titik masuk utama bagi pengguna untuk berinteraksi dengan antarmuka pengguna (UI) aplikasi Anda.

Setiap `Activity` memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, yang diatur oleh sistem Android. Beberapa tahapan penting termasuk `onCreate()`, tempat Anda melakukan inisialisasi awal seperti mengatur tata letak (layout) UI; `onStart()`, saat `Activity` menjadi terlihat; `onResume()`, saat `Activity` berada di latar depan dan siap berinteraksi; `onPause()` dan `onStop()` saat `Activity` tidak lagi di latar depan; dan `onDestroy()` saat `Activity` dihancurkan. Memahami lifecycle ini sangat krusial untuk mengelola sumber daya dan perilaku aplikasi dengan benar.

Untuk membuat `Activity` baru, Anda cukup membuat class Kotlin yang mewarisi dari `AppCompatActivity` (atau `Activity`). Anda perlu mendeklarasikan `Activity` ini di file `AndroidManifest.xml` agar sistem Android dapat menemukannya dan meluncurkannya. Peluncuran `Activity` biasanya dilakukan menggunakan `Intent`, yang bertindak sebagai pesan untuk meminta sistem Android memulai komponen tertentu, misalnya `startActivity(Intent(this, DetailActivity::class.java))`.

`Activity` adalah jantung dari navigasi dan interaksi pengguna di sebagian besar aplikasi Android. Pengguna berpindah antar layar dengan meluncurkan `Activity` yang berbeda. Dengan memahami bagaimana `Activity` bekerja, bagaimana mengelola siklus hidupnya, dan bagaimana berpindah antar `Activity`, Anda akan memiliki dasar yang kuat untuk membangun aplikasi Android yang interaktif dan responsif.

```
import androidx.appcompat.app.AppCompatActivity
import android.os.Bundle

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan layout UI
    }
}
```

💡 **Fun Fact:** Setiap kali Anda meluncurkan Activity baru, ia ditempatkan di atas Activity sebelumnya dalam tumpukan yang disebut 'back stack'. Menekan tombol kembali (back button) akan mengeluarkan Activity teratas dari tumpukan tersebut.
