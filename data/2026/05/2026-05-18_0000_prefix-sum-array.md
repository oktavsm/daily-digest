## ⚡ Competitive Programming Concept: Prefix Sum Array

**Category:** Data Structure
**TL;DR:** Sebuah teknik untuk menghitung jumlah elemen dalam rentang (range sum) dari sebuah array dengan cepat dalam waktu O(1) setelah prekomputasi O(N).

Konsep Prefix Sum Array (juga dikenal sebagai cumulative sum) adalah sebuah teknik fundamental dalam competitive programming yang digunakan untuk mempercepat perhitungan jumlah elemen dalam suatu rentang (sub-array) dari array asli. Ide dasarnya adalah menyimpan jumlah akumulatif elemen hingga setiap indeks dalam array baru, sehingga setiap pertanyaan mengenai jumlah rentang dapat dijawab dengan operasi sederhana.

Untuk membangun Prefix Sum Array `P` dari array asli `A` yang berukuran `N`, kita membuat array `P` berukuran `N+1` (jika menggunakan 0-indexed array `A`, maka `P[0]` biasanya 0). Kemudian, `P[i]` menyimpan jumlah semua elemen `A[0]` hingga `A[i-1]`. Ini dapat dihitung dengan iterasi: `P[i] = P[i-1] + A[i-1]` untuk `i` dari 1 hingga `N`. Proses prekomputasi ini membutuhkan waktu `O(N)`.

Setelah Prefix Sum Array `P` terbentuk, jumlah elemen dalam rentang `A[L]` hingga `A[R]` (inclusive, 0-indexed) dapat dihitung dengan rumus `P[R+1] - P[L]`. Sebagai contoh, untuk mencari jumlah `A[2]...A[5]`, kita cukup menghitung `P[6] - P[2]`. Setiap query range sum dapat dijawab dalam waktu `O(1)`, menjadikannya sangat efisien untuk kasus di mana ada banyak query pada array yang sama.

Teknik ini sangat serbaguna dan dapat diperluas ke dimensi yang lebih tinggi, seperti Prefix Sum 2D untuk matriks, di mana jumlah sub-matriks dapat dihitung dengan cepat. Aplikasi umum meliputi masalah di mana kita perlu mencari sub-array dengan jumlah tertentu, memecahkan masalah sliding window, atau sebagai komponen dalam algoritma yang lebih kompleks.

```
std::vector<long long> build_prefix_sum(const std::vector<int>& arr) {
    int n = arr.size();
    std::vector<long long> p_sum(n + 1, 0); // p_sum[0]=0
    for (int i = 0; i < n; ++i) {
        p_sum[i+1] = p_sum[i] + arr[i];
    }
    // Untuk query jumlah arr[l...r] (inclusive, 0-indexed): p_sum[r+1] - p_sum[l]
    return p_sum;
}
```

💡 **Fun Fact:** Konsep prefix sum sering kali menjadi fondasi bagi algoritma yang lebih kompleks seperti Segment Tree atau Fenwick Tree (BIT), yang juga bertujuan untuk query range secara efisien tetapi dengan dukungan update.
