## ⚡ Competitive Programming Concept: Segment Tree (Pohon Segmen)

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data pohon biner yang efisien untuk melakukan query dan update pada rentang (range) dalam sebuah array.

Segment Tree adalah struktur data pohon biner yang digunakan untuk menyimpan informasi tentang interval atau segmen. Konsep utamanya adalah membagi array menjadi sub-segmen yang direpresentasikan oleh node-node dalam pohon. Setiap node non-leaf merepresentasikan gabungan dari interval yang direpresentasikan oleh kedua anak-anaknya. Ini memungkinkan operasi query pada rentang tertentu dan update pada elemen tertentu dilakukan dengan sangat efisien.

Pembangunan Segment Tree (build) biasanya dilakukan secara rekursif. Node daun (leaf node) akan merepresentasikan satu elemen dari array asli. Node internal akan merepresentasikan agregasi dari nilai yang ada di rentang yang dicakup oleh node tersebut. Agregasi ini bisa berupa jumlah, minimum, maksimum, atau operasi lain yang bersifat asosiatif dan dapat digabungkan. Proses build ini membutuhkan waktu O(N), di mana N adalah ukuran array.

Ada dua operasi utama: query dan update. Operasi query, misalnya mencari jumlah elemen dalam rentang [L, R], juga dilakukan secara rekursif. Pohon akan "melintasi" cabangnya dan menggabungkan informasi dari node-node yang rentangnya sepenuhnya tercakup dalam [L, R] atau sebagian. Operasi update untuk mengubah nilai elemen tunggal pada indeks `i` akan memperbarui leaf node yang sesuai dan kemudian memperbarui semua node leluhurnya hingga ke root. Baik query maupun update memerlukan waktu O(log N) karena tinggi pohon adalah O(log N).

Segment Tree sangat serbaguna dan dapat dimodifikasi untuk mendukung berbagai jenis query (sum, min, max, gcd) dan bahkan update pada rentang tertentu (range update) menggunakan teknik Lazy Propagation. Efisiensi logaritmik ini membuatnya menjadi pilihan populer untuk masalah competitive programming yang melibatkan operasi pada rentang array.

```
std::vector<int> tree;
// ... diasumsikan tree sudah dibangun
int query(int node, int L, int R, int qL, int qR) {
    if (qR < L || R < qL) return 0; // Tidak ada overlap
    if (qL <= L && R <= qR) return tree[node]; // Overlap penuh
    int mid = L + (R - L) / 2;
    int p1 = query(2 * node, L, mid, qL, qR);
    int p2 = query(2 * node + 1, mid + 1, R, qL, qR);
    return p1 + p2;
}
```

💡 **Fun Fact:** Segment Tree bisa diperluas dengan teknik Lazy Propagation untuk melakukan update pada seluruh rentang (range update) dengan kompleksitas waktu O(log N) juga, menjadikannya solusi yang sangat kuat untuk berbagai masalah yang melibatkan query dan update range.
