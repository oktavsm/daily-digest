## ⚡ Competitive Programming Concept: 0/1 Knapsack Problem

**Category:** DP
**TL;DR:** Masalah ini bertujuan untuk memilih subset item dengan bobot dan nilai tertentu agar total nilai maksimal tanpa melebihi kapasitas bobot yang tersedia.

Masalah 0/1 Knapsack adalah salah satu masalah dasar dalam pemrograman dinamis (Dynamic Programming - DP). Diberikan sejumlah N item, di mana setiap item memiliki bobot (weight) `w_i` dan nilai (value) `v_i`, serta sebuah "knapsack" (ransel) dengan kapasitas bobot maksimum `W`. Tujuannya adalah memilih item-item mana yang akan dimasukkan ke dalam ransel sehingga total nilai item yang dipilih menjadi maksimal, tanpa melebihi total kapasitas bobot ransel. Nama "0/1" mengacu pada fakta bahwa setiap item hanya bisa diambil seluruhnya (1) atau tidak sama sekali (0).

Solusi untuk 0/1 Knapsack menggunakan DP dibangun di atas prinsip optimal substructure dan overlapping subproblems. Kita dapat mendefinisikan `dp[i][j]` sebagai nilai maksimum yang bisa diperoleh dari `i` item pertama dengan kapasitas ransel `j`. Untuk setiap item `i` dan kapasitas `j`, ada dua pilihan:
1. Tidak memasukkan item ke-`i`: Nilai maksimumnya sama dengan `dp[i-1][j]`.
2. Memasukkan item ke-`i`: Ini hanya mungkin jika `w_i <= j`. Jika iya, nilai maksimumnya adalah `v_i + dp[i-1][j - w_i]`.
Kita kemudian mengambil nilai maksimum dari kedua pilihan ini.

Basis kasus DP biasanya adalah `dp[0][j] = 0` (tidak ada item, nilai 0) dan `dp[i][0] = 0` (kapasitas 0, nilai 0). Iterasi DP akan mengisi tabel dari `i=1` hingga `N` dan `j=1` hingga `W`. Kompleksitas waktu algoritma ini adalah O(N*W), di mana N adalah jumlah item dan W adalah kapasitas maksimum ransel.

```
int solveKnapsack(int W, const std::vector<int>& w, const std::vector<int>& v) {
    int N = w.size();
    std::vector<std::vector<int>> dp(N + 1, std::vector<int>(W + 1, 0));
    for (int i = 1; i <= N; ++i) {
        for (int cap = 1; cap <= W; ++cap) {
            if (w[i-1] <= cap) dp[i][cap] = std::max(v[i-1] + dp[i-1][cap - w[i-1]], dp[i-1][cap]);
            else dp[i][cap] = dp[i-1][cap];
        }
    }
    return dp[N][W];
}
```

💡 **Fun Fact:** Masalah Knapsack pertama kali diformulasikan pada akhir abad ke-19 dan memiliki banyak aplikasi praktis, mulai dari alokasi sumber daya di bidang industri, perencanaan produksi, hingga pemilihan portofolio investasi. Ini adalah salah satu masalah NP-hard yang paling terkenal.
