## ☕ Java Concept: Penanganan Exception dengan try-catch

**Category:** Exception
**TL;DR:** Exception Handling menggunakan blok `try-catch` adalah mekanisme Java untuk mengelola error runtime secara graceful agar program tidak crash dan dapat memberikan feedback yang informatif.

Di dunia pemrograman, tidak semua hal berjalan sesuai rencana. Terkadang, selama program berjalan (runtime), bisa terjadi peristiwa yang tidak diharapkan dan mengganggu alur normal program, inilah yang kita sebut "exception" atau "pengecualian". Bayangkan mencoba membagi angka dengan nol, atau mencoba mengkonversi teks yang bukan angka menjadi angka; ini adalah contoh-contoh sederhana di mana Java akan "melempar" sebuah exception. Jika tidak ditangani, exception ini dapat menyebabkan program Anda berhenti mendadak (crash) dan seringkali menampilkan pesan error yang kurang informatif bagi pengguna.

Untuk mengatasi masalah ini, Java menyediakan mekanisme "exception handling" menggunakan blok `try-catch`. Blok `try` digunakan untuk membungkus kode yang berpotensi menyebabkan exception. Jika sebuah exception benar-benar terjadi di dalam blok `try`, maka eksekusi kode di dalam `try` akan dihentikan di titik terjadinya exception tersebut, dan kontrol akan dialihkan ke blok `catch` yang sesuai. Blok `catch` sendiri berisi kode yang akan dieksekusi untuk "menangkap" dan menangani exception tersebut, misalnya dengan mencetak pesan error, mencatatnya ke dalam log, atau melakukan tindakan pemulihan yang diperlukan.

Denga menggunakan `try-catch`, kita dapat membuat program yang lebih tangguh dan "user-friendly". Daripada membiarkan program crash, kita bisa memberikan pesan error yang jelas kepada pengguna, mencatat kesalahan untuk tujuan debugging, atau bahkan mencoba memperbaiki situasi dan melanjutkan eksekusi program. Ini sangat penting dalam aplikasi dunia nyata di mana keandalan dan pengalaman pengguna menjadi prioritas utama. Ada juga blok `finally` yang bersifat opsional, yang kodenya akan selalu dieksekusi, terlepas dari apakah exception terjadi atau tidak, sering digunakan untuk membersihkan sumber daya seperti menutup file atau koneksi database.

```
public class ExceptionDemo {
    public static void main(String[] args) {
        try {
            int numerator = 10;
            int denominator = 0; // Ini akan menyebabkan ArithmeticException
            int result = numerator / denominator;
            System.out.println("Hasil pembagian: " + result);
        } catch (ArithmeticException e) {
            System.out.println("Terjadi kesalahan aritmatika: " + e.getMessage());
        } finally {
            System.out.println("Blok finally selalu dieksekusi.");
        }
        System.out.println("Program berlanjut setelah penanganan exception.");
    }
}
```

💡 **Fun Fact:** Salah satu fitur utama Java ketika pertama kali dirilis adalah model exception handling-nya yang robust, terutama konsep 'checked exceptions' yang memaksa programmer untuk secara eksplisit menangani potensi kesalahan pada saat kompilasi, membuat kode lebih handal sejak awal.
