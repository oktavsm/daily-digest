## ☕ Java Concept: Menggunakan ArrayList

**Category:** Collections
**TL;DR:** ArrayList adalah struktur data dinamis yang sangat fleksibel untuk menyimpan dan mengelola daftar objek di Java.

Mengapa kita butuh ArrayList? Array biasa punya ukuran tetap, tapi seringkali kita butuh daftar objek yang ukurannya bisa berubah-ubah selama program berjalan. Di sinilah `ArrayList` dari Java Collections Framework menjadi penyelamat. `ArrayList` adalah implementasi dari antarmuka `List` yang memungkinkan Anda menyimpan objek dalam urutan tertentu dan bisa bertambah atau berkurang ukurannya secara otomatis, menjadikannya pilihan utama untuk mengelola koleksi data yang dinamis.

Cara kerja `ArrayList` mirip dengan array, tetapi lebih canggih dan mudah digunakan. Untuk membuat `ArrayList`, kita perlu mendeklarasikannya dengan tipe data objek yang akan disimpan di dalamnya (misalnya `ArrayList<String>`). Kita bisa menambahkan elemen baru menggunakan metode `add()`, mengakses elemen berdasarkan indeks menggunakan `get()`, dan mengubah elemen yang sudah ada pada indeks tertentu dengan `set()`. Metode-metode ini membuat manipulasi data di dalam daftar menjadi sangat intuitif dan efisien.

Selain itu, `ArrayList` juga menyediakan metode praktis lain seperti `remove()` untuk menghapus elemen pada indeks tertentu atau menghapus objek spesifik, serta `size()` untuk mengetahui jumlah elemen yang ada di dalamnya saat ini. Fleksibilitas dan kemudahan penggunaan ini membuat `ArrayList` menjadi salah satu struktur data yang paling sering dan paling praktis digunakan dalam pengembangan aplikasi Java, dari proyek kecil hingga sistem berskala besar. Ini adalah alat fundamental yang harus dikuasai oleh setiap programmer Java.

```
import java.util.ArrayList;

public class DaftarMahasiswa {
    public static void main(String[] args) {
        ArrayList<String> daftarNama = new ArrayList<>(); // Membuat ArrayList
        daftarNama.add("Budi Santoso"); // Menambah elemen
        daftarNama.add("Siti Aminah");
        daftarNama.add("Joko Susanto");

        System.out.println("Mahasiswa pertama: " + daftarNama.get(0)); // Mengakses elemen
        daftarNama.remove(1); // Menghapus elemen (Siti Aminah)

        System.out.println("Jumlah mahasiswa sekarang: " + daftarNama.size()); // Ukuran
    }
}
```

💡 **Fun Fact:** `ArrayList` diimplementasikan menggunakan array biasa di balik layarnya. Saat kapasitas array internal penuh, `ArrayList` akan secara otomatis membuat array baru yang lebih besar dan menyalin semua elemen lama ke array baru tersebut untuk mengakomodasi penambahan elemen.
