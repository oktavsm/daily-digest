## ⚡ Competitive Programming Concept: Segment Tree untuk Range Queries

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data berbentuk pohon biner yang efisien untuk melakukan operasi query dan update pada rentang (range) indeks dalam sebuah array.

Segment Tree adalah struktur data powerful yang sangat sering muncul dalam problem competitive programming, terutama yang melibatkan operasi query dan update pada rentang indeks. Bayangkan Anda memiliki sebuah array dan perlu berulang kali mencari jumlah elemen dalam sebuah sub-array (range sum), nilai minimum (range minimum query), atau bahkan nilai maksimum dalam rentang tertentu. Secara naif, ini bisa membutuhkan waktu O(N) untuk setiap query. Dengan teknik prefix sums, query bisa O(1), tetapi update satu elemen akan butuh O(N). Segment Tree mengatasi keterbatasan ini dengan menyediakan kompleksitas logaritmik untuk kedua operasi.

Cara kerja Segment Tree didasarkan pada prinsip "divide and conquer". Segment Tree adalah pohon biner di mana setiap node merepresentasikan sebuah 'segmen' atau rentang dari array asli. Node root mencakup seluruh array. Setiap node internal memiliki dua anak, masing-masing merepresentasikan setengah dari rentang induknya. Proses ini berlanjut hingga node daun, yang masing-masing merepresentasikan satu elemen tunggal dari array asli. Informasi yang disimpan di setiap node (misalnya, jumlah, minimum, maksimum) adalah hasil penggabungan dari informasi anak-anaknya.

Operasi utama pada Segment Tree adalah: **Build** (membangun pohon dari array awal), **Query** (melakukan operasi pada rentang tertentu), dan **Update** (mengubah nilai satu elemen dan memperbarui node-node yang terpengaruh). Membangun Segment Tree membutuhkan waktu O(N). Baik operasi query maupun update (untuk satu titik) dapat diselesaikan dalam waktu O(log N). Untuk operasi update pada rentang (range update), Segment Tree dapat diperluas dengan teknik yang disebut Lazy Propagation, yang juga mempertahankan kompleksitas O(log N).

```
int tree[4 * MAXN]; // Asumsikan MAXN adalah ukuran maksimum array

// Fungsi query untuk mencari sum di rentang [L, R]
// node: indeks node saat ini di array tree
// start, end: rentang yang direpresentasikan oleh node saat ini
// L, R: rentang query yang diinginkan
int query(int node, int start, int end, int L, int R) {
    if (R < start || end < L) return 0; // Tidak ada overlap antara rentang node dan rentang query
    if (L <= start && end <= R) return tree[node]; // Rentang node sepenuhnya tercakup dalam rentang query
    
    int mid = (start + end) / 2;
    // Gabungkan hasil dari anak kiri dan kanan
    int p1 = query(2 * node, start, mid, L, R);
    int p2 = query(2 * node + 1, mid + 1, end, L, R);
    return p1 + p2; // Contoh: operasi sum
}
```

💡 **Fun Fact:** Nama 'Segment Tree' berasal dari fakta bahwa setiap node di pohon merepresentasikan sebuah 'segmen' atau rentang dari array. Meskipun Segment Tree adalah pohon logis, ia sering diimplementasikan menggunakan array tunggal (mirip heap biner) untuk efisiensi memori dan cache.
