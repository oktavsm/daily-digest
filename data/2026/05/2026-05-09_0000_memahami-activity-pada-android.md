## 🤖 Android Concept: Memahami Activity pada Android

**Category:** UI
**TL;DR:** Activity adalah komponen dasar yang menyediakan layar interaktif untuk pengguna, mengelola tampilan antarmuka (UI), dan merespons interaksi.

Dalam pengembangan aplikasi Android, Activity adalah salah satu blok bangunan yang paling fundamental. Bayangkan Activity sebagai satu "layar" tunggal yang dilihat dan diinteraksikan oleh pengguna. Setiap kali Anda membuka aplikasi, melihat daftar email, atau mengetik pesan, kemungkinan besar Anda sedang berinteraksi dengan sebuah Activity. Ia bertanggung jawab untuk menyediakan jendela visual tempat antarmuka pengguna (UI) Anda digambar, dan juga menjadi tempat kode Anda merespons berbagai kejadian seperti sentuhan tombol atau input teks.

Secara teknis, sebuah Activity adalah subclass dari `android.app.Activity` dan biasanya mengelola tampilan UI melalui file layout XML yang terhubung. Metode `onCreate()` adalah titik masuk utama saat Activity pertama kali dibuat. Di sinilah Anda biasanya mengatur tampilan layout dengan memanggil `setContentView()`, menginisialisasi komponen UI seperti `Button` atau `TextView`, dan menyiapkan logika awal yang dibutuhkan oleh layar tersebut. Setiap aplikasi Android setidaknya memiliki satu Activity, seringkali disebut `MainActivity`, yang menjadi titik awal aplikasi.

Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, mulai dari saat ia dibuat (`onCreate`), terlihat oleh pengguna (`onStart`), berinteraksi secara aktif (`onResume`), hingga saat ia dihentikan (`onStop`) atau dihancurkan (`onDestroy`). Memahami lifecycle ini sangat penting untuk mengelola sumber daya, menyimpan data saat aplikasi beralih fokus, dan memastikan pengalaman pengguna yang mulus. Misalnya, Anda mungkin ingin menghentikan pemutaran video saat Activity tidak lagi terlihat, atau menyimpan data yang belum disimpan saat pengguna meninggalkan aplikasi.

Ketika Anda ingin berpindah dari satu layar ke layar lain dalam aplikasi, Anda akan menggunakan mekanisme yang disebut Intent untuk memulai Activity baru. Ini memungkinkan Anda untuk memecah fungsionalitas aplikasi menjadi beberapa Activity yang lebih kecil dan spesifik, meningkatkan modularitas dan keterbacaan kode. Activity bekerja sama untuk membentuk alur navigasi lengkap dalam sebuah aplikasi, menciptakan pengalaman yang kaya dan interaktif bagi pengguna.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        // Menghubungkan Activity ini dengan layout XML: activity_main.xml
        setContentView(R.layout.activity_main)
    }
}
```

💡 **Fun Fact:** Activity pertama di Android, "Hello, World!", secara teknis merupakan Activity dan sejak awal sudah menjadi pondasi dari setiap aplikasi yang dibuat.
