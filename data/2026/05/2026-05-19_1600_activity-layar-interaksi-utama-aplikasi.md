## 🤖 Android Concept: Activity: Layar Interaksi Utama Aplikasi

**Category:** UI
**TL;DR:** Activity adalah komponen fundamental yang merepresentasikan satu layar dalam aplikasi Android, menyediakan antarmuka pengguna untuk berinteraksi dengan pengguna.

Activity adalah salah satu dari empat komponen aplikasi Android inti (bersama Service, Broadcast Receiver, dan Content Provider). Sederhananya, setiap kali Anda melihat layar di aplikasi, kemungkinan besar itu adalah sebuah Activity. Ia bertugas menyediakan jendela tempat UI (User Interface) aplikasi Anda digambar dan tempat pengguna dapat berinteraksi. Setiap aplikasi memiliki setidaknya satu Activity, yang sering disebut sebagai "main activity" atau "launcher activity".

Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, mulai dari dibuat, berjalan, hingga dihancurkan. Beberapa metode penting dalam siklus hidup ini meliputi `onCreate()`, yang dipanggil saat Activity pertama kali dibuat untuk inisialisasi awal; `onStart()`, saat Activity menjadi terlihat oleh pengguna; `onResume()`, saat Activity siap berinteraksi dengan pengguna; `onPause()`, saat Activity sebagian tersembunyi; `onStop()`, saat Activity tidak lagi terlihat; dan `onDestroy()`, saat Activity dihancurkan. Memahami siklus hidup ini sangat krusial untuk mengelola sumber daya dan perilaku aplikasi dengan benar.

Untuk membuat Activity, Anda perlu membuat kelas Kotlin yang mewarisi dari `AppCompatActivity` dan mengimplementasikan metode `onCreate()`. Di dalam `onCreate()`, Anda biasanya memanggil `setContentView()` untuk menentukan layout XML mana yang akan digunakan sebagai UI. Untuk meluncurkan Activity lain, Anda menggunakan `Intent`, yang merupakan objek untuk melakukan operasi "maksud" (seperti memulai Activity lain, Service, atau mengirim broadcast). Intent dapat membawa data dari satu Activity ke Activity lainnya, memungkinkan komunikasi antar komponen.

Activity adalah fondasi pengalaman pengguna di Android. Dengan menggabungkan beberapa Activity dan menavigasi di antaranya, kita dapat membangun alur kerja yang kompleks dan intuitif. Misalnya, satu Activity menampilkan daftar produk, Activity lain menampilkan detail produk yang dipilih, dan Activity ketiga mungkin menangani proses checkout. Memahami bagaimana Activity bekerja, siklus hidupnya, dan cara berinteraksi adalah langkah pertama yang paling penting dalam menjadi seorang developer Android.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan layout XML
    }
}
```

💡 **Fun Fact:** Setiap Activity beroperasi dalam sebuah 'task stack', yang mengelola urutan Activity dan memungkinkan pengguna untuk menavigasi 'mundur' melalui aplikasi menggunakan tombol kembali.
