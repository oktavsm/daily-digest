## ⚡ Competitive Programming Concept: Segment Tree (Pohon Segmen)

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data pohon yang memungkinkan query dan update efisien pada range (rentang) tertentu di sebuah array, umumnya untuk operasi asosiatif seperti sum, min, atau max.

Segment Tree adalah struktur data pohon biner yang digunakan untuk menyimpan informasi tentang interval atau segmen. Tujuan utamanya adalah untuk melakukan operasi query (misalnya mencari sum, minimum, atau maksimum dalam sebuah rentang) dan operasi update (mengubah nilai pada indeks tertentu atau rentang tertentu) dengan sangat efisien. Konsep dasar Segment Tree adalah memecah array asli menjadi segmen-segmen yang lebih kecil dan menyimpan hasil agregat (misal: jumlah, min, max) untuk segmen-segmen tersebut di node-node pohon.

Pohon ini dibangun secara rekursif. Setiap node pada Segment Tree merepresentasikan sebuah rentang dalam array asli. Node daun (leaf nodes) merepresentasikan elemen tunggal dari array asli. Node internal merepresentasikan gabungan dari rentang anak-anaknya. Misalnya, jika sebuah node merepresentasikan rentang `[L, R]`, maka anak kirinya akan merepresentasikan `[L, (L+R)/2]` dan anak kanannya `[(L+R)/2 + 1, R]`. Proses pembangunan pohon (building) membutuhkan waktu O(N) di mana N adalah ukuran array asli.

Ketika melakukan query untuk rentang `[Q_L, Q_R]`, Segment Tree akan menelusuri pohon secara rekursif. Jika rentang node saat ini sepenuhnya berada di dalam `[Q_L, Q_R]`, maka nilai agregat node tersebut langsung dikembalikan. Jika tidak, pencarian dilanjutkan ke anak-anaknya. Hasil dari anak-anak kemudian digabungkan untuk mendapatkan jawaban akhir. Untuk operasi update, misalnya mengubah nilai pada indeks `idx`, Segment Tree juga menelusuri pohon dari root hingga node daun yang merepresentasikan `idx`, memperbarui nilainya, lalu memperbarui nilai agregat pada semua node leluhurnya (ancestors) hingga ke root.

Baik operasi query maupun update pada Segment Tree memiliki kompleksitas waktu O(log N). Hal ini karena pada setiap langkah rekursif, kita membagi rentang menjadi dua, mirip dengan binary search. Dengan kompleksitas yang efisien ini, Segment Tree sangat cocok untuk masalah-masalah di competitive programming yang melibatkan banyak query dan update pada array besar, di mana solusi O(N) per query akan terlalu lambat.

```
/* Asumsi tree[] sudah dibangun dengan build(1, 0, N-1) */
int query(int node, int start, int end, int l, int r) {
    if (r < start || end < l) { /* Rentang node di luar rentang query */
        return 0; /* Atau nilai identitas lain seperti INT_MAX/MIN */
    }
    if (l <= start && end <= r) { /* Rentang node sepenuhnya di dalam rentang query */
        return tree[node];
    }
    /* Sebagian rentang node tumpang tindih, rekursi ke anak */
    int mid = (start + end) / 2;
    int p1 = query(2 * node, start, mid, l, r);
    int p2 = query(2 * node + 1, mid + 1, end, l, r);
    return p1 + p2; /* Gabungkan hasil dari anak */
}
```

💡 **Fun Fact:** Segment Tree adalah fondasi untuk banyak struktur data yang lebih kompleks, seperti 2D Segment Tree atau Segment Tree dengan Lazy Propagation, yang dapat menangani operasi update pada rentang secara efisien.
