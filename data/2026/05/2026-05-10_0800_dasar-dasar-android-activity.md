## 🤖 Android Concept: Dasar-dasar Android Activity

**Category:** Architecture
**TL;DR:** Activity adalah blok bangunan utama aplikasi Android yang merepresentasikan satu layar antarmuka pengguna (UI) dan mengelola daur hidupnya.

Activity adalah salah satu komponen fundamental dalam setiap aplikasi Android. Secara sederhana, Activity merepresentasikan satu layar tunggal dengan antarmuka pengguna (UI) di mana pengguna dapat berinteraksi. Ketika Anda melihat layar utama, layar pengaturan, atau layar detail produk di sebuah aplikasi, kemungkinan besar masing-masing layar tersebut diimplementasikan sebagai sebuah Activity. Activity menyediakan jendela tempat Anda dapat menempatkan elemen UI seperti tombol, teks, gambar, dan widget lainnya.

Setiap Activity memiliki "daur hidup" (lifecycle) yang terdefinisi dengan baik, mulai dari dibuat (`onCreate`), terlihat oleh pengguna (`onStart`), siap berinteraksi (`onResume`), hingga dihancurkan (`onDestroy`). Memahami daur hidup ini sangat krusial. Misalnya, Anda perlu memuat data atau menginisialisasi komponen UI di `onCreate` dan membersihkan sumber daya yang tidak lagi diperlukan di `onPause` atau `onDestroy` untuk mencegah kebocoran memori dan memastikan aplikasi berjalan efisien.

Untuk berpindah dari satu Activity ke Activity lain, kita menggunakan objek `Intent`. `Intent` berfungsi sebagai pesan yang memberitahu sistem Android untuk melakukan suatu tindakan, seperti memulai Activity baru. Ini memungkinkan alur navigasi yang mulus di dalam aplikasi Anda dan juga memungkinkan aplikasi Anda berinteraksi dengan komponen lain, baik di aplikasi Anda sendiri maupun aplikasi lain di perangkat pengguna. Misalnya, Anda dapat menggunakan `Intent` untuk membuka kamera atau galeri foto.

Setiap Activity yang Anda buat harus dideklarasikan dalam file `AndroidManifest.xml` aplikasi Anda. File manifest ini adalah seperti peta jalan aplikasi yang memberitahu sistem Android tentang komponen-komponen apa saja yang ada di aplikasi Anda (termasuk Activity), izin apa yang dibutuhkan, dan bagaimana cara meluncurkannya. Tanpa deklarasi yang benar di manifest, sistem tidak akan mengetahui Activity Anda dan aplikasi bisa mengalami crash saat mencoba meluncurkannya.

```
package com.example.myapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        // Menentukan layout XML untuk Activity ini
        setContentView(R.layout.activity_main)
    }
}
```

💡 **Fun Fact:** Tahukah Anda bahwa Android Activity telah ada sejak versi pertama Android 1.0 pada tahun 2008, menjadikannya salah satu fondasi paling tua dan penting dalam pengembangan aplikasi Android hingga saat ini!
