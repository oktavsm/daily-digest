## 🌐 Networking Concept: Redundansi Gateway dengan HSRP

**Category:** Routing
**TL;DR:** Memastikan ketersediaan gateway default yang tinggi dengan dua atau lebih router yang bertindak sebagai satu gateway virtual.

Pada jaringan komputer modern, ketersediaan layanan adalah kunci. Salah satu titik kegagalan yang sering diabaikan adalah default gateway. Jika router yang berfungsi sebagai default gateway untuk sebuah subnet mengalami masalah, seluruh perangkat di subnet tersebut akan kehilangan konektivitas ke luar jaringan. Di sinilah Hot Standby Router Protocol (HSRP) berperan penting. HSRP adalah protokol redundansi gateway pertama kali yang dikembangkan oleh Cisco, dirancang untuk memberikan failover transparan dalam kasus kegagalan router pertama hop.

HSRP bekerja dengan mengkonfigurasi dua atau lebih router untuk berbagi satu alamat IP virtual dan alamat MAC virtual. Router-router ini akan membentuk sebuah grup HSRP. Dalam grup ini, satu router akan berperan sebagai "Active" router, yang bertanggung jawab untuk meneruskan lalu lintas yang ditujukan ke alamat IP virtual. Router lainnya akan menjadi "Standby" router, siap mengambil alih peran Active jika router Active mengalami kegagalan. Jika router Active down, router Standby akan segera mengambil alih peran Active dan terus meneruskan lalu lintas, tanpa gangguan yang signifikan bagi pengguna akhir.

Konfigurasi HSRP melibatkan penetapan grup HSRP, alamat IP virtual, dan seringkali prioritas untuk menentukan router mana yang akan menjadi Active atau Standby. Router dengan prioritas tertinggi akan menjadi Active. Fitur preemption juga bisa diaktifkan, yang memungkinkan router dengan prioritas lebih tinggi untuk mengambil kembali peran Active setelah pulih dari kegagalan. Dengan HSRP, alamat IP default gateway yang diberikan kepada perangkat-perangkat di jaringan adalah alamat IP virtual, bukan alamat IP fisik salah satu router. Ini memastikan bahwa meskipun ada pergantian router Active, alamat gateway tidak berubah.

Implementasi HSRP di Cisco Packet Tracer memungkinkan kita untuk mempraktikkan konsep vital ini. Mahasiswa dapat mensimulasikan kegagalan router Active dengan mematikan interface-nya atau menghapus kabelnya, kemudian mengamati bagaimana router Standby secara otomatis mengambil alih, menjaga konektivitas jaringan tetap berjalan mulus. Ini adalah keterampilan penting untuk setiap administrator jaringan yang ingin membangun infrastruktur yang tangguh dan selalu tersedia.

```
standby 1 ip 192.168.1.254
```

💡 **Fun Fact:** Meskipun HSRP adalah protokol proprietary Cisco, ada standar terbuka yang fungsinya serupa yaitu VRRP (Virtual Router Redundancy Protocol) yang dapat diimplementasikan pada perangkat dari berbagai vendor.
