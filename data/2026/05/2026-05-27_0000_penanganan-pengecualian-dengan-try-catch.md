## ☕ Java Concept: Penanganan Pengecualian dengan try-catch

**Category:** Exception
**TL;DR:** Penanganan pengecualian menggunakan blok `try-catch` memungkinkan program Java untuk gracefully mengatasi kesalahan tak terduga saat runtime tanpa mengalami crash.

Dalam pengembangan perangkat lunak, program seringkali dihadapkan pada situasi tak terduga yang dapat menyebabkan kesalahan atau 'pengecualian' (exceptions). Contohnya termasuk pembagian dengan nol, mencoba mengakses indeks di luar batas array, atau gagal membaca file. Jika pengecualian ini tidak ditangani, program Anda akan berhenti secara paksa atau 'crash', yang tentu saja memberikan pengalaman buruk bagi pengguna dan menunjukkan kurangnya ketangguhan program.

Java menyediakan mekanisme yang kuat untuk menangani situasi ini melalui blok `try-catch`. Konsep dasarnya adalah Anda 'mencoba' menjalankan blok kode yang berpotensi menimbulkan pengecualian. Jika pengecualian memang terjadi di dalam blok `try` tersebut, Java akan 'melemparkan' objek pengecualian, dan eksekusi blok `try` akan segera berhenti. Kontrol kemudian beralih ke blok `catch` yang relevan, yang tugasnya adalah 'menangkap' dan memproses pengecualian tersebut.

Blok `catch` memungkinkan Anda untuk menentukan tipe pengecualian apa yang ingin Anda tangani. Misalnya, Anda bisa memiliki blok `catch` untuk `NumberFormatException` jika Anda mencoba mengkonversi string non-angka menjadi integer, atau `IOException` jika ada masalah dengan operasi input/output. Di dalam blok `catch`, Anda bisa menulis kode untuk merespons kesalahan, seperti mencetak pesan error yang informatif ke konsol, mencoba tindakan alternatif, atau meminta input ulang dari pengguna. Ini memberikan kontrol penuh kepada developer untuk menentukan bagaimana program harus bereaksi terhadap berbagai skenario kesalahan.

Dengan menggunakan `try-catch`, Anda tidak hanya mencegah program Anda dari crash, tetapi juga membuatnya lebih tangguh dan ramah pengguna. Pengguna akan menerima pesan yang jelas daripada program yang tiba-tiba berhenti, dan program Anda dapat melanjutkan eksekusi dengan cara yang terkontrol setelah mengatasi masalah. Ini adalah praktik fundamental yang harus dikuasai untuk membangun aplikasi Java yang solid dan andal.

```
public class ExceptionDemo {
    public static void main(String[] args) {
        String inputAngka = "abc"; // Ini akan menyebabkan NumberFormatException
        try {
            int angka = Integer.parseInt(inputAngka);
            System.out.println("Angka yang Anda masukkan: " + angka);
        } catch (NumberFormatException e) {
            // Blok ini menangani jika konversi string ke int gagal
            System.err.println("Kesalahan: Input tidak valid. Harap masukkan angka.");
            System.err.println("Detail error: " + e.getMessage());
        }
        System.out.println("Program selesai dieksekusi.");
    }
}
```

💡 **Fun Fact:** Semua pengecualian di Java adalah objek dan merupakan bagian dari hierarki kelas yang berakar dari `java.lang.Throwable`. Ini berarti Anda bisa membuat pengecualian kustom Anda sendiri dengan memperluas kelas `Exception` atau `RuntimeException`.
