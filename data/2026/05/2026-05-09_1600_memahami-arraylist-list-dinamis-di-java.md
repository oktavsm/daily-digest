## ☕ Java Concept: Memahami ArrayList: List Dinamis di Java

**Category:** Collections
**TL;DR:** ArrayList adalah implementasi List yang fleksibel dan dinamis di Java, memungkinkan kita menyimpan dan mengelola kumpulan objek yang ukurannya dapat berubah saat program berjalan.

Bayangkan Anda perlu menyimpan daftar nama mahasiswa, tetapi Anda tidak tahu persis berapa banyak nama yang akan ada. Jika Anda menggunakan array biasa, Anda harus menentukan ukurannya di awal, dan jika daftar bertambah, Anda akan kesulitan. Di sinilah `ArrayList` datang membantu. `ArrayList` adalah bagian dari Java Collections Framework yang menyediakan "list" (daftar) yang ukurannya bisa bertambah atau berkurang secara otomatis. Ini sangat kontras dengan array tradisional yang ukurannya tetap (fixed-size) setelah dibuat.

Secara internal, `ArrayList` sebenarnya menggunakan array biasa, tetapi Java mengelola kompleksitas penambahan ukuran array tersebut untuk Anda. Saat Anda menambahkan elemen dan `ArrayList` mencapai kapasitas maksimum array internalnya, ia akan secara otomatis membuat array internal yang baru dengan ukuran lebih besar dan menyalin semua elemen lama ke array yang baru. Untuk menggunakannya, Anda cukup mengimpor `java.util.ArrayList` dan mendeklarasikannya, seringkali dengan Generics (misalnya, `ArrayList<String>`) untuk memastikan tipe data yang disimpan konsisten dan aman.

`ArrayList` menyediakan berbagai metode yang praktis untuk memanipulasi data. Anda bisa menambahkan elemen baru dengan `add()`, mengambil elemen pada indeks tertentu dengan `get()`, menghapus elemen dengan `remove()`, atau mengetahui jumlah elemen saat ini dengan `size()`. Karena sifatnya yang dinamis, `ArrayList` sangat sering digunakan dalam aplikasi Java untuk menyimpan kumpulan data yang tidak memiliki ukuran tetap, seperti daftar belanja, hasil query database, atau antrean tugas, menjadikannya salah satu struktur data yang paling fundamental dan serbaguna yang akan Anda temui.

```
import java.util.ArrayList;

public class ContohArrayList {
    public static void main(String[] args) {
        ArrayList<String> namaProduk = new ArrayList<>();
        namaProduk.add("Laptop");
        namaProduk.add("Mouse");
        System.out.println("Produk pertama: " + namaProduk.get(0)); // Output: Laptop
        namaProduk.add("Keyboard"); // Menambah elemen baru
        System.out.println("Total produk: " + namaProduk.size()); // Output: 3
        namaProduk.remove("Mouse");
        System.out.println("Produk tersisa: " + namaProduk); // Output: [Laptop, Keyboard]
    }
}
```

💡 **Fun Fact:** Tahukah kamu? `ArrayList` di Java secara internal sebenarnya menggunakan array biasa. Ketika `ArrayList` 'penuh' dan kamu menambahkan elemen baru, ia akan secara otomatis membuat array internal yang baru dengan ukuran lebih besar (biasanya 1.5 kali ukuran semula) dan menyalin semua elemen lama ke array yang baru itu secara efisien!
