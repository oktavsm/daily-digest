## 🌐 Networking Concept: Redundansi Gateway dengan HSRP

**Category:** Routing
**TL;DR:** Pelajari cara kerja Hot Standby Router Protocol (HSRP) untuk menyediakan ketersediaan gateway default yang tinggi, mencegah downtime jaringan saat router utama gagal.

Di jaringan lokal, default gateway adalah titik krusial. Jika router yang berfungsi sebagai gateway utama mati, seluruh subnet akan kehilangan konektivitas ke luar. Hot Standby Router Protocol (HSRP) hadir untuk mengatasi masalah single point of failure ini. HSRP memungkinkan dua atau lebih router bekerja sama untuk membagikan satu alamat IP dan MAC address virtual sebagai default gateway. Ini berarti host di jaringan tidak perlu tahu router fisik mana yang sedang aktif; mereka hanya berkomunikasi dengan gateway virtual.

Dalam grup HSRP, satu router menjadi router "Aktif" yang meneruskan semua trafik untuk gateway virtual, sementara router lain menjadi router "Standby" yang siap mengambil alih jika router Aktif gagal. Router-router ini secara teratur bertukar pesan "hello" untuk memantau status satu sama lain. Jika router Aktif tidak mengirim pesan hello dalam interval waktu tertentu, router Standby akan secara otomatis mengambil alih peran Aktif, memastikan layanan jaringan tetap berlanjut tanpa gangguan. Prioritas dapat dikonfigurasi untuk menentukan router mana yang diinginkan menjadi Aktif, dan preemption dapat diaktifkan agar router dengan prioritas lebih tinggi selalu menjadi Aktif jika pulih dari kegagalan.

Keunggulan utama HSRP adalah kemampuannya menyediakan redundansi dan ketersediaan tinggi secara transparan bagi pengguna akhir. Proses failover berlangsung otomatis dan cepat, sehingga meminimalkan downtime jaringan yang disebabkan oleh kegagalan hardware router. Dalam Cisco Packet Tracer, Anda dapat mensimulasikan skenario ini dengan menempatkan dua router sebagai default gateway untuk sebuah subnet, lalu mengkonfigurasi HSRP pada interface LAN mereka, kemudian mematikan salah satu router untuk melihat failovernya.

Bayangkan sebuah perusahaan dengan puluhan karyawan. Jika router gateway mereka tiba-tiba mati, produktivitas akan terganggu total karena tidak ada akses internet atau jaringan eksternal. Dengan HSRP, meskipun router utama gagal, router cadangan akan langsung mengambil alih peran gateway, dan karyawan mungkin bahkan tidak menyadari adanya masalah karena konektivitas mereka tetap terjaga. Ini adalah fondasi penting untuk desain jaringan yang tangguh dan handal.

```
Router(config-if)# standby 1 ip 192.168.1.254
```

💡 **Fun Fact:** HSRP adalah protokol eksklusif milik Cisco Systems, sementara Virtual Router Redundancy Protocol (VRRP) adalah standar terbuka yang melakukan fungsi serupa. Failover HSRP bisa terjadi dalam waktu kurang dari satu detik.
