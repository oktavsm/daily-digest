## 🤖 Android Concept: Activity: Layar Utama Aplikasi

**Category:** UI
**TL;DR:** Activity adalah komponen dasar Android yang menyediakan satu layar antarmuka pengguna (UI) untuk berinteraksi dengan pengguna.

Setiap aplikasi Android yang Anda lihat terdiri dari satu atau lebih Activity. Bayangkan Activity sebagai satu "layar" dalam aplikasi Anda. Misalnya, ketika Anda membuka aplikasi chat, daftar percakapan adalah satu Activity, dan layar percakapan dengan kontak tertentu adalah Activity lain. Activity bertanggung jawab untuk mengelola antarmuka pengguna (UI) serta berinteraksi dengan pengguna di layar tersebut.

Ketika sebuah Activity diluncurkan, ia melewati serangkaian tahapan dalam "siklus hidup" (lifecycle)-nya. Tahapan yang paling penting untuk pemula adalah `onCreate()`. Ini adalah metode pertama yang dipanggil ketika Activity dibuat, dan di sinilah Anda biasanya melakukan semua inisialisasi awal, seperti mengatur tata letak (layout) UI yang akan ditampilkan di layar menggunakan `setContentView()` dan menemukan tampilan (View) lainnya.

Untuk berpindah dari satu Activity ke Activity lain, kita menggunakan objek `Intent`. Intent bertindak seperti pesan yang memberi tahu sistem Android bahwa kita ingin melakukan suatu tindakan, misalnya meluncurkan komponen aplikasi lain seperti Activity baru. Konsep Activity ini sangat fundamental; tanpa Activity, aplikasi Anda tidak akan memiliki antarmuka yang bisa dilihat dan diinteraksikan oleh pengguna.

Activity juga harus dideklarasikan dalam file `AndroidManifest.xml` aplikasi Anda agar sistem Android dapat menemukannya dan meluncurkannya. Ini seperti daftar isi aplikasi Anda yang memberitahu sistem tentang semua komponen utama yang dimilikinya, termasuk setiap Activity yang akan digunakan.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan layout XML
        // Di sini Anda bisa menambahkan logika UI lainnya
    }
}
```

💡 **Fun Fact:** Tahukah Anda, konsep Activity mirip dengan halaman web di browser, di mana setiap halaman memiliki UI dan fungsionalitasnya sendiri, dan pengguna dapat berpindah di antara halaman-halaman tersebut. Google pernah mempertimbangkan untuk menamai Activity sebagai "Screen" atau "Panel" sebelum akhirnya menetapkan nama Activity.
