## 🤖 Android Concept: Android Activity: Building User Screens

**Category:** Architecture
**TL;DR:** Activity adalah komponen fundamental yang menyediakan satu layar untuk interaksi pengguna, bertindak sebagai pintu masuk utama aplikasi Anda.

Dalam pengembangan Android, `Activity` adalah komponen dasar yang berfungsi sebagai satu layar antarmuka pengguna (UI) di aplikasi Anda. Setiap kali Anda membuka aplikasi dan melihat satu layar, kemungkinan besar itu dikelola oleh sebuah `Activity`. Ini adalah titik masuk utama untuk sebagian besar interaksi pengguna dengan aplikasi Anda, tempat di mana pengguna melihat dan berinteraksi dengan elemen UI seperti tombol, teks, dan gambar.

`Activity` memiliki siklus hidup yang terdefinisi dengan baik, mencakup berbagai status seperti `Created`, `Started`, `Resumed`, `Paused`, dan `Destroyed`. Memahami siklus hidup ini sangat penting untuk mengelola sumber daya, menyimpan status aplikasi, dan memastikan aplikasi berjalan efisien serta responsif. Metode `onCreate()` adalah tempat utama untuk melakukan inisialisasi awal, seperti mengatur tata letak UI, mengikat data, dan menyiapkan View.

Setiap `Activity` biasanya terhubung dengan satu atau lebih file layout XML yang mendefinisikan tampilan antarmukanya. Anda menautkan layout ini ke `Activity` menggunakan metode `setContentView()` di dalam `onCreate()`. Ini memungkinkan Anda untuk mendesain UI secara deklaratif menggunakan XML dan kemudian mengontrol logikanya, seperti merespons klik tombol, dari kode Kotlin Anda yang terhubung dengan Activity tersebut.

Untuk berpindah dari satu layar (Activity) ke layar lainnya, Anda menggunakan `Intent`. `Intent` adalah objek yang menjelaskan operasi yang ingin Anda lakukan, seperti meluncurkan Activity lain atau mengirimkan data. Ini adalah mekanisme utama untuk navigasi dalam aplikasi Android dan memungkinkan modularitas antar komponen, menjadikannya kunci untuk membangun alur aplikasi yang kompleks.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan Activity ke layout XML
        // Di sini Anda bisa menemukan dan menginisialisasi View seperti Button atau TextView
    }
}
```

💡 **Fun Fact:** Faktanya, `Activity` telah menjadi tulang punggung setiap aplikasi Android sejak versi pertamanya dirilis. Meskipun Jetpack Compose kini menjadi cara modern untuk membangun UI, konsep dasar dan manajemen lifecycle dari Activity tetap sangat relevan dan penting untuk dipahami bahkan di era Compose.
