## 🌐 Networking Concept: Redundansi Gateway dengan HSRP

**Category:** Routing
**TL;DR:** Memastikan ketersediaan gateway jaringan dengan dua atau lebih router yang beroperasi sebagai satu gateway virtual.

Dalam setiap jaringan, ketersediaan gateway default adalah krusial. Jika router yang berfungsi sebagai gateway tunggal mengalami kegagalan, seluruh subnet akan kehilangan konektivitas ke luar jaringan. Konsep Hot Standby Router Protocol (HSRP) dirancang untuk mengatasi masalah single point of failure ini, memastikan bahwa perangkat akhir (end-devices) selalu memiliki jalur menuju gateway mereka, bahkan jika salah satu router fisik gagal.

HSRP bekerja dengan mengelompokkan dua atau lebih router ke dalam sebuah grup standby, yang kemudian bertindak sebagai satu gateway virtual. Grup ini memiliki alamat IP virtual dan alamat MAC virtual yang sama, yang dikonfigurasi sebagai default gateway pada perangkat-perangkat dalam subnet. Dalam grup HSRP, satu router akan berperan sebagai router "Aktif" (Active) yang menangani semua lalu lintas, sementara router lain akan berperan sebagai router "Standby" (Standby) yang siap mengambil alih peran aktif jika router aktif gagal. Router lainnya akan berada dalam keadaan "Listen" atau "Speak".

Komunikasi antara router-router dalam grup HSRP terjadi melalui pengiriman pesan hello secara periodik. Jika router aktif gagal mengirimkan pesan hello dalam waktu tertentu (hold time), router standby akan secara otomatis beralih menjadi router aktif. Proses failover ini berlangsung mulus dan transparan bagi perangkat akhir, karena mereka tetap menggunakan alamat IP dan MAC virtual yang sama tanpa perlu mengubah konfigurasi mereka. Ini secara signifikan meningkatkan ketersediaan dan keandalan jaringan.

Untuk konfigurasi yang lebih optimal, HSRP mendukung fitur preemption (preempt) yang memungkinkan router dengan prioritas lebih tinggi untuk mengambil alih peran aktif setelah pulih dari kegagalan. Selain itu, fitur tracking dapat digunakan untuk memantau interface lain atau objek di router. Jika interface atau objek yang dipantau tersebut gagal, prioritas HSRP router dapat diturunkan, memicu failover meskipun interface HSRP-nya sendiri masih up.

```
standby 1 ip 192.168.1.254
```

💡 **Fun Fact:** HSRP adalah protokol first-hop redundancy proprietary milik Cisco. Meskipun demikian, karena popularitasnya, protokol ini menjadi salah satu solusi standar industri untuk menjaga ketersediaan gateway.
