## ⚡ Competitive Programming Concept: Segment Tree

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data pohon biner yang efisien untuk melakukan query rentang (range query) dan update titik (point update) pada sebuah array.

Segment Tree adalah struktur data pohon biner yang digunakan untuk menyimpan informasi tentang rentang atau segmen dari sebuah array. Setiap node dalam pohon merepresentasikan suatu rentang dari array asli. Node daun (leaf node) merepresentasikan elemen tunggal dari array, sedangkan node internal menyimpan hasil agregasi (misalnya, jumlah, minimum, maksimum) dari rentang yang dicakup oleh anak-anaknya. Struktur ini memungkinkan operasi pada rentang data dengan sangat efisien.

Proses pembangunan (building) Segment Tree dilakukan secara rekursif. Dimulai dari root yang mencakup seluruh rentang array, kita membagi rentang menjadi dua sub-rentang yang sama besar untuk setiap anak node. Proses ini berlanjut hingga mencapai node daun yang hanya mencakup satu elemen. Setelah anak-anak dihitung, node induk akan menggabungkan hasil dari anak-anaknya. Kompleksitas waktu untuk membangun sebuah Segment Tree adalah O(N), di mana N adalah ukuran array, karena setiap elemen array dan setiap node di pohon dikunjungi tepat satu kali.

Operasi query rentang (misalnya, mencari jumlah elemen dari indeks L hingga R) juga dilakukan secara rekursif. Dari root, kita memeriksa apakah rentang yang dicakup oleh node saat ini sepenuhnya berada di dalam rentang query, sepenuhnya di luar, atau tumpang tindih sebagian. Jika sepenuhnya di dalam, kita langsung mengembalikan nilai node. Jika tumpang tindih sebagian, kita memanggil query secara rekursif pada anak-anak node dan menggabungkan hasilnya. Mirip dengan query, operasi update titik (mengubah nilai pada indeks tertentu) juga rekursif. Kita menelusuri pohon dari root hingga node daun yang sesuai dengan indeks yang diupdate, kemudian memperbarui nilai node daun dan semua ancestor-nya hingga root. Baik operasi query maupun update memiliki kompleksitas waktu O(log N).

Segment Tree sangat serbaguna dan dapat digunakan untuk berbagai masalah seperti Range Minimum Query (RMQ), Range Sum Query (RSQ), atau mencari nilai maksimum/minimum dalam rentang. Variasi lanjutan dari Segment Tree, seperti Lazy Propagation, memungkinkan update pada seluruh rentang (range update) juga dalam kompleksitas waktu O(log N), memperluas fungsionalitasnya lebih jauh.

```
int tree[4 * MAXN]; // MAXN adalah ukuran maksimum array

// Contoh: Query Range Sum
int query(int node, int start, int end, int l, int r) {
    if (r < start || end < l) return 0; // Rentang node di luar rentang query
    if (l <= start && end <= r) return tree[node]; // Rentang node di dalam rentang query

    int mid = (start + end) / 2;
    int p1 = query(2 * node, start, mid, l, r);
    int p2 = query(2 * node + 1, mid + 1, end, l, r);
    return p1 + p2; // Gabungkan hasil dari anak-anak
}
```

💡 **Fun Fact:** Nama 'Segment Tree' berasal dari kemampuannya memecah array menjadi segmen-segmen kecil yang direpresentasikan oleh node pohon, memungkinkan operasi cepat pada rentang data.
