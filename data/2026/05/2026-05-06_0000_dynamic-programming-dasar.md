## ⚡ Competitive Programming Concept: Dynamic Programming Dasar

**Category:** DP
**TL;DR:** Teknik memecahkan masalah kompleks dengan memecahnya menjadi sub-masalah yang lebih kecil, menyelesaikan setiap sub-masalah hanya sekali, dan menyimpan hasilnya untuk digunakan kembali.

Dynamic Programming (DP) adalah metode algoritmik untuk menyelesaikan masalah dengan memecahnya menjadi sub-masalah yang lebih kecil dan saling tumpang tindih (overlapping subproblems), serta memiliki sifat optimal substructure (solusi optimal masalah dapat dibangun dari solusi optimal sub-masalahnya). Kunci dari DP adalah menghindari perhitungan berulang untuk sub-masalah yang sama, sehingga secara signifikan meningkatkan efisiensi waktu komputasi.

Tiga komponen utama dalam DP adalah: 1) **State**: Definisi dari sub-masalah. Bagaimana kita merepresentasikan sebuah kondisi atau bagian dari masalah yang perlu diselesaikan? 2) **Transition**: Rumus atau cara untuk membangun solusi dari sebuah state menggunakan solusi dari state-state sebelumnya (yang lebih kecil). 3) **Base Case**: Kondisi paling sederhana dari masalah yang solusinya sudah diketahui tanpa perlu perhitungan lebih lanjut.

Ada dua pendekatan utama DP: **Top-down (Memoization)**, di mana kita mulai dari masalah utama dan secara rekursif memanggil sub-masalah, menyimpan hasilnya dalam tabel (memo) saat pertama kali dihitung untuk menghindari komputasi ulang. Dan **Bottom-up (Tabulation)**, di mana kita mulai dari base case dan secara iteratif membangun solusi untuk state-state yang lebih besar hingga mencapai masalah utama. Kompleksitas waktu DP umumnya adalah O(jumlah state * kompleksitas transisi), sedangkan kompleksitas ruangnya O(jumlah state).

Menguasai DP membutuhkan latihan dalam mengidentifikasi state yang tepat, merumuskan transisi yang benar, dan menentukan base case. Pemahaman yang kuat tentang struktur masalah dan cara memecahnya akan sangat membantu dalam merancang solusi DP yang efisien untuk berbagai soal di competitive programming, mulai dari persoalan knapsack hingga masalah graf pada grid.

```
#include <vector>
// Menghitung Fibonacci ke-n menggunakan DP bottom-up
long long fibonacci(int n) {
    if (n <= 1) return n;
    std::vector<long long> dp(n + 1);
    dp[0] = 0;
    dp[1] = 1;
    for (int i = 2; i <= n; ++i) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

💡 **Fun Fact:** Konsep "Dynamic Programming" diciptakan oleh Richard Bellman pada tahun 1950-an. Ia memilih nama "dynamic" untuk membuatnya terdengar lebih menarik dan "programming" dalam konteks ini berarti "perencanaan" atau "tabelisasi", bukan pemrograman komputer.
