## ⚡ Competitive Programming Concept: Memoization (DP Top-Down)

**Category:** DP
**TL;DR:** Meningkatkan efisiensi rekursi dengan menyimpan hasil subproblem yang sudah dihitung untuk menghindari komputasi ulang.

Dalam pemrograman kompetitif, banyak masalah yang dapat dipecahkan menggunakan pendekatan rekursif di mana sebuah masalah besar dipecah menjadi subproblem yang lebih kecil. Namun, seringkali subproblem yang sama dihitung berulang kali, terutama dalam struktur rekursi seperti pohon, yang dapat menyebabkan kompleksitas waktu eksponensial dan TLE (Time Limit Exceeded). Pendekatan rekursif murni tanpa optimasi semacam itu menjadi tidak praktis untuk input yang besar.

Memoization adalah teknik optimasi di mana kita menyimpan hasil dari pemanggilan fungsi untuk subproblem tertentu. Setiap kali fungsi dipanggil dengan parameter yang sama, kita pertama-tama memeriksa apakah hasilnya sudah pernah dihitung dan disimpan. Jika ya, kita langsung mengembalikan hasil yang tersimpan tanpa perlu melakukan komputasi ulang. Jika belum, kita hitung hasilnya seperti biasa, lalu menyimpannya sebelum mengembalikannya. Ini secara efektif memastikan bahwa setiap subproblem dihitung paling banyak satu kali.

Implementasi memoization umumnya menggunakan sebuah array (misalnya `std::vector` di C++) atau hash map (`std::map` atau `std::unordered_map`) untuk menyimpan hasil. Dimensi dari array atau kunci dari map harus merepresentasikan 'state' dari subproblem, yaitu parameter-parameter unik yang mendefinisikan subproblem tersebut. Inisialisasi array dengan nilai 'sentinel' (misalnya -1 atau 0, tergantung konteks) yang menunjukkan bahwa hasil untuk state tersebut belum dihitung adalah praktik umum.

Dengan memoization, kompleksitas waktu suatu algoritma yang sebelumnya eksponensial dapat berkurang drastis menjadi polinomial. Ini karena setiap subproblem unik hanya dihitung satu kali. Jika ada `N` subproblem unik dan setiap komputasi subproblem membutuhkan waktu `O(K)` (tidak termasuk panggilan rekursif), maka total kompleksitas waktu menjadi `O(N * K)`. Kompleksitas ruang biasanya `O(N)` untuk menyimpan hasil dari `N` subproblem tersebut.

```
std::vector<long long> memo;

long long fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib(n - 1) + fib(n - 2);
}

/* Untuk digunakan di main:
int N = ...;
memo.assign(N + 1, -1); // Inisialisasi dengan nilai sentinel
long long result = fib(N);
*/
```

💡 **Fun Fact:** Meskipun sering dikaitkan dengan 'memory' (memori), istilah 'memoization' sebenarnya berasal dari kata Latin 'memorandum' (yang berarti 'untuk diingat' atau 'catatan'). Tujuannya adalah 'mencatat' hasil untuk masa depan, bukan sekadar menggunakan memori secara umum.
