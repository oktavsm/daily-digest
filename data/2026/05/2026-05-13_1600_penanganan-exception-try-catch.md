## ☕ Java Concept: Penanganan Exception (try-catch)

**Category:** Exception
**TL;DR:** Penanganan exception menggunakan `try-catch` adalah mekanisme Java untuk mengelola error runtime agar program tidak crash dan dapat memberikan respons yang lebih baik kepada pengguna.

Dalam pemrograman Java, 'exception' adalah peristiwa yang mengganggu alur normal eksekusi program. Ini bukan kesalahan sintaksis yang terdeteksi saat kompilasi, melainkan masalah yang muncul saat program sedang berjalan (runtime). Contoh umum meliputi mencoba membagi angka dengan nol, mengakses elemen di luar batas array, atau mencoba membuka file yang tidak ada. Jika exception tidak ditangani, program akan berhenti secara tiba-tiba (crash) dan seringkali menampilkan pesan error yang tidak ramah bagi pengguna.

Untuk mengatasi hal ini, Java menyediakan mekanisme penanganan exception menggunakan blok `try-catch`. Blok `try` digunakan untuk mengelilingi kode yang berpotensi menyebabkan exception. Jika exception terjadi di dalam blok `try`, eksekusi kode di dalam blok `try` segera dihentikan, dan kontrol program dialihkan ke blok `catch` yang sesuai.

Blok `catch` berisi kode yang akan dieksekusi ketika sebuah exception tertangkap. Anda dapat menentukan jenis exception yang ingin ditangkap (misalnya, `ArithmeticException` untuk pembagian dengan nol) di dalam tanda kurung setelah kata kunci `catch`. Ini memungkinkan Anda untuk menangani berbagai jenis kesalahan dengan cara yang spesifik, seperti mencetak pesan error yang jelas, menyimpan log kesalahan, atau mencoba melakukan operasi alternatif.

Penggunaan `try-catch` sangat penting untuk membangun aplikasi Java yang tangguh dan user-friendly. Dengan menangani exception secara efektif, Anda dapat mencegah program crash, memberikan umpan balik yang informatif kepada pengguna, dan memastikan aplikasi dapat melanjutkan operasinya sebisa mungkin meskipun menghadapi kondisi tak terduga.

```
public class ContohException {
    public static void main(String[] args) {
        try {
            int a = 10;
            int b = 0;
            int hasil = a / b;
            System.out.println("Hasil: " + hasil);
        } catch (ArithmeticException e) {
            System.err.println("Error: Tidak bisa membagi dengan nol!");
        }
        System.out.println("Program selesai.");
    }
}
```

💡 **Fun Fact:** Exception handling di Java adalah bagian dari filosofi desainnya yang menekankan 'robustness', membantu pengembang membangun aplikasi yang dapat pulih dengan anggun dari situasi tak terduga. Sebelum Java, banyak bahasa pemrograman mengandalkan kode error atau `goto` untuk penanganan kesalahan, yang seringkali menyebabkan kode sulit dipahami (spaghetti code) dan sulit dipelihara.
