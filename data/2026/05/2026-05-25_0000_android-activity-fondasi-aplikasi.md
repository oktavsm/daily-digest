## 🤖 Android Concept: Android Activity: Fondasi Aplikasi

**Category:** UI
**TL;DR:** Activity adalah komponen fundamental dalam aplikasi Android yang merepresentasikan satu layar antarmuka pengguna (UI) dengan mana pengguna dapat berinteraksi.

Setiap aplikasi Android dibangun dari berbagai komponen, dan `Activity` adalah salah satu yang paling krusial. Bayangkan setiap layar yang Anda lihat di aplikasi sebagai sebuah `Activity` yang terpisah. Misalnya, layar login, layar daftar produk, atau layar detail barang, masing-masing biasanya diwakili oleh sebuah `Activity`. `Activity` bertanggung jawab untuk menampilkan antarmuka pengguna (UI) dan merespons interaksi pengguna, menjadikannya titik masuk utama bagi pengguna untuk berinteraksi dengan aplikasi Anda.

Salah satu aspek terpenting dari `Activity` adalah siklus hidupnya (lifecycle). `Activity` dapat berada dalam beberapa keadaan berbeda (misalnya, dibuat, dimulai, dilanjutkan, dijeda, dihentikan, dihancurkan) tergantung pada interaksi pengguna dan keadaan sistem. Memahami siklus hidup ini sangat vital karena memungkinkan Anda untuk mengelola sumber daya dengan efisien. Misalnya, Anda dapat memulai operasi yang intensif saat `Activity` `onResume()` dan menghentikannya saat `onPause()` untuk menghemat baterai dan performa.

`Activity` juga bekerja sama dengan file layout XML untuk menentukan tampilan UI-nya. Anda akan menggunakan metode `setContentView()` di dalam `Activity` untuk "mengikat" file layout tersebut, sehingga elemen-elemen UI seperti tombol, teks, dan gambar dapat ditampilkan. Ini adalah langkah pertama untuk membuat `Activity` Anda terlihat dan berfungsi.

Navigasi antar `Activity` umumnya dilakukan menggunakan `Intent`, sebuah objek yang digunakan untuk meminta sistem Android melakukan tindakan, termasuk memulai `Activity` baru atau mengirimkan data antar komponen. `Intent` memungkinkan aplikasi untuk berpindah dari satu layar ke layar lainnya dengan mulus, membentuk tumpukan tugas (back stack) yang bisa dinavigasi mundur oleh pengguna.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Mengaitkan layout XML
    }
}
```

💡 **Fun Fact:** Tahukah Anda bahwa Android Activity telah ada sejak versi Android pertama? Konsep ini telah menjadi tulang punggung UI Android selama lebih dari satu dekade, menunjukkan betapa fundamental dan kuatnya desain ini dalam ekosistem Android.
