## 🤖 Android Concept: Android Activity: Layar Interaksi Aplikasi

**Category:** Architecture
**TL;DR:** Activity adalah komponen dasar yang menyediakan satu layar interaksi bagi pengguna dalam aplikasi Android Anda.

Activity adalah salah satu blok bangunan paling fundamental di setiap aplikasi Android. Secara sederhana, Activity merepresentasikan satu layar (screen) di antarmuka pengguna (UI) aplikasi Anda. Misalnya, ketika Anda membuka aplikasi, daftar email yang Anda lihat adalah sebuah Activity, dan ketika Anda mengklik satu email untuk melihat detailnya, itu bisa jadi Activity lain. Activity bertugas menampilkan UI, menerima input pengguna, dan mengelola interaksi mereka dengan aplikasi.

Setiap Activity memiliki siklus hidup (lifecycle) yang dikelola oleh sistem Android. Ini berarti Activity dapat melewati berbagai status seperti dibuat (created), dimulai (started), dilanjutkan (resumed), dijeda (paused), dihentikan (stopped), hingga dihancurkan (destroyed). Metode paling penting untuk pemula adalah `onCreate()`. Metode ini dipanggil saat Activity pertama kali dibuat, dan di sinilah Anda biasanya melakukan semua inisialisasi awal, seperti mengatur tata letak (layout) UI menggunakan `setContentView()` dan mempersiapkan data awal.

Penting untuk memahami `onCreate()` karena ini adalah titik masuk utama untuk menyiapkan Activity Anda. Di sinilah Anda menentukan elemen-elemen visual apa saja yang akan terlihat di layar dan bagaimana Activity akan memulai fungsionalitasnya. Karena Activity dapat dihancurkan dan dibuat ulang oleh sistem Android (misalnya, saat orientasi layar berubah atau karena keterbatasan memori), semua inisialisasi penting harus dilakukan di `onCreate()` agar Activity selalu siap digunakan dalam keadaan yang benar.

Sebuah aplikasi Android biasanya terdiri dari beberapa Activity yang bekerja sama. Anda dapat berpindah dari satu Activity ke Activity lain menggunakan `Intent`. `Intent` bertindak sebagai “niat” atau pesan yang menyatakan keinginan untuk melakukan suatu tindakan, seperti memulai Activity baru. Ini memungkinkan Anda membangun alur pengguna yang kompleks dan mulus di dalam aplikasi Anda, menghubungkan berbagai layar dan fungsionalitas.

```
import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Mengaitkan layout XML yang telah Anda buat
    }
}
```

💡 **Fun Fact:** Tahukah kamu, Activity adalah salah satu komponen Android yang paling lama ada dan esensial, dan telah menjadi tulang punggung setiap aplikasi Android sejak versi pertama Android dirilis pada tahun 2008. Meskipun banyak pola arsitektur baru muncul, Activity tetap menjadi fondasi utama.
