## ☕ Java Concept: Penanganan Exception dengan `try-catch`

**Category:** Exception
**TL;DR:** Pelajari cara menggunakan blok `try-catch` untuk menangani kesalahan atau peristiwa tak terduga (exception) yang terjadi saat program berjalan, agar aplikasi tetap stabil dan tidak berhenti secara tiba-tiba.

Dalam pemrograman Java, seringkali kita menghadapi situasi di mana program bisa mengalami kesalahan tak terduga saat dieksekusi, seperti pembagian dengan nol, mencoba mengakses file yang tidak ada, atau mengakses elemen di luar batas array. Peristiwa-peristiwa ini dikenal sebagai 'exception' (pengecualian). Jika tidak ditangani, exception dapat menyebabkan program kita berhenti bekerja secara tiba-tiba (crash), yang tentu saja bukanlah pengalaman yang baik bagi pengguna.

Untuk mengatasi hal ini, Java menyediakan mekanisme penanganan exception menggunakan blok `try-catch`. Konsepnya sederhana: kode yang berpotensi menimbulkan exception diletakkan di dalam blok `try`. Jika exception benar-benar terjadi di dalam blok `try`, maka eksekusi kode di `try` akan dihentikan dan kontrol program akan langsung berpindah ke blok `catch` yang sesuai. Blok `catch` inilah yang bertanggung jawab untuk 'menangkap' exception tersebut dan berisi instruksi bagaimana program harus merespons kesalahan yang terjadi.

Setiap blok `catch` dapat dikonfigurasi untuk menangani tipe exception tertentu. Misalnya, Anda bisa memiliki satu `catch` untuk `ArithmeticException` dan `catch` lainnya untuk `ArrayIndexOutOfBoundsException`. Dengan penanganan exception, kita bisa memberikan pesan kesalahan yang lebih informatif kepada pengguna, mencatat log kesalahan, atau bahkan mencoba solusi alternatif, sehingga program kita menjadi lebih 'tahan banting' dan user-friendly. Setelah blok `catch` selesai dieksekusi, program akan melanjutkan jalannya dari kode setelah seluruh blok `try-catch`, bukan berhenti total.

```
public class ExceptionHandlerDemo {
    public static void main(String[] args) {
        try {
            int[] numbers = {10, 20, 30};
            System.out.println(numbers[5]); // Baris ini akan menimbulkan ArrayIndexOutOfBoundsException
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Terjadi kesalahan: Anda mencoba mengakses indeks di luar batas array.");
            // System.err.println("Detail error: " + e.getMessage()); // Opsional, untuk debug
        }
        System.out.println("Program tetap berjalan setelah penanganan exception.");
    }
}
```

💡 **Fun Fact:** Konsep `try-catch` untuk penanganan exception adalah salah satu fitur fundamental yang membuat Java menjadi bahasa pemrograman yang kuat dan robust, karena mendorong developer untuk memikirkan skenario kegagalan sejak awal. Banyak bahasa modern lainnya juga mengadopsi pola penanganan kesalahan serupa.
