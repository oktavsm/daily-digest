## ☕ Java Concept: `ArrayList`: Koleksi Data Dinamis Fleksibel

**Category:** Collections
**TL;DR:** `ArrayList` adalah struktur data di Java yang memungkinkan kita menyimpan daftar objek dengan ukuran yang dapat berubah secara dinamis, sangat praktis untuk mengelola kumpulan data.

Saat pertama kali belajar pemrograman, kita mungkin sudah mengenal array, yaitu struktur data untuk menyimpan banyak nilai dengan tipe yang sama. Namun, array memiliki keterbatasan utama: ukurannya sudah tetap sejak awal dibuat. Jika kita perlu menyimpan lebih banyak data daripada kapasitas array yang ditentukan, kita akan kesulitan. Di sinilah `ArrayList` hadir sebagai solusi yang elegan dalam Java Collections Framework. `ArrayList` adalah sebuah kelas yang berperilaku seperti array tetapi dengan kemampuan untuk menambah atau mengurangi elemen tanpa perlu khawatir tentang ukuran awal.

Menggunakan `ArrayList` cukup mudah. Anda perlu mengimpor kelas `java.util.ArrayList` terlebih dahulu. Deklarasinya mirip dengan array, tetapi Anda menggunakan tanda `<>` untuk menentukan tipe data objek yang akan disimpan, contohnya `ArrayList<String> daftarNama = new ArrayList<>();`. Setelah itu, Anda bisa menambahkan objek menggunakan metode `add()`, mengakses objek berdasarkan indeks dengan `get(index)`, atau bahkan menghapus objek dengan `remove()`. `ArrayList` akan secara otomatis mengatur ulang kapasitasnya di balik layar saat Anda menambahkan terlalu banyak elemen.

Keunggulan utama `ArrayList` adalah fleksibilitasnya. Kita tidak perlu memikirkan berapa banyak elemen yang akan kita simpan di awal, karena ia akan beradaptasi sesuai kebutuhan. Ini menjadikannya pilihan yang sangat populer dan sering digunakan dalam banyak aplikasi Java untuk menyimpan daftar nama, angka, atau objek kustom lainnya. Meskipun secara internal ia menggunakan array biasa dan mungkin sedikit kurang efisien untuk operasi tertentu dibandingkan array statis jika ukurannya sering berubah drastis di tengah-tengah, kemudahan penggunaannya seringkali menutupi kekurangan tersebut untuk sebagian besar skenario.

```
import java.util.ArrayList;

public class ContohArrayList {
    public static void main(String[] args) {
        // Membuat ArrayList untuk menyimpan nama-nama (tipe String)
        ArrayList<String> daftarSiswa = new ArrayList<>();

        // Menambahkan elemen ke ArrayList
        daftarSiswa.add("Budi");
        daftarSiswa.add("Ani");
        daftarSiswa.add("Cahyo");

        // Mengakses elemen dan mengetahui ukuran
        System.out.println("Total siswa: " + daftarSiswa.size()); // Output: Total siswa: 3
        System.out.println("Siswa pertama: " + daftarSiswa.get(0)); // Output: Siswa pertama: Budi

        // Menghapus elemen
        daftarSiswa.remove("Ani"); // Menghapus elemen "Ani"
        System.out.println("Daftar siswa setelah Ani dihapus: " + daftarSiswa); // Output: [Budi, Cahyo]
    }
}
```

💡 **Fun Fact:** Secara internal, `ArrayList` sebenarnya menggunakan array biasa. Ketika Anda menambahkan elemen dan array internal penuh, `ArrayList` akan secara otomatis membuat array baru yang lebih besar (biasanya 1.5 kali ukuran lama) dan menyalin semua elemen dari array lama ke array baru tersebut. Proses ini disebut "resizing".
