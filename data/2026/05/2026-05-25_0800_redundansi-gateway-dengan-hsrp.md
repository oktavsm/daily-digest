## 🌐 Networking Concept: Redundansi Gateway dengan HSRP

**Category:** Routing
**TL;DR:** HSRP menyediakan redundansi gateway untuk perangkat di LAN, memastikan konektivitas jaringan tetap berjalan meskipun satu router gagal.

Bayangkan jika default gateway di jaringan lokal Anda mengalami kegagalan. Semua perangkat di LAN akan kehilangan koneksi ke jaringan luar, bahkan jika ada router lain yang berfungsi. Ini adalah masalah 'single point of failure' yang serius, di mana kegagalan satu komponen dapat melumpuhkan seluruh sistem. Untuk mengatasi risiko ini dan memastikan ketersediaan jaringan yang tinggi, kita bisa menggunakan Hot Standby Router Protocol (HSRP).

HSRP adalah protokol redundansi gateway layer 3 yang dikembangkan oleh Cisco. Protokol ini memungkinkan dua atau lebih router untuk berbagi satu alamat IP virtual dan alamat MAC virtual yang bertindak sebagai default gateway untuk perangkat di LAN. Dalam sebuah grup HSRP, satu router akan berperan sebagai 'Active' router yang bertanggung jawab meneruskan lalu lintas, sementara router lainnya menjadi 'Standby' router yang siap mengambil alih peran Active jika router Active mengalami kegagalan.

Ketika router Active tidak lagi responsif (misalnya, karena mati, link utamanya putus, atau mengalami masalah perangkat lunak), router Standby akan secara otomatis mengambil alih peran Active, meneruskan lalu lintas menggunakan IP dan MAC virtual yang sama. Proses transisi ini terjadi secara transparan bagi perangkat-perangkat di LAN, sehingga mereka tidak perlu mengubah konfigurasi default gateway mereka. HSRP menggunakan mekanisme hello message untuk memantau status masing-masing router dalam grup, dan dapat dikonfigurasi dengan prioritas serta preemption untuk mengontrol router mana yang menjadi Active.

Dengan HSRP, kita dapat menciptakan jaringan yang lebih tangguh dan tersedia tinggi. Jika salah satu router mengalami masalah, jaringan tetap dapat berfungsi tanpa interupsi yang signifikan. Ini sangat penting untuk lingkungan bisnis di mana downtime jaringan dapat menyebabkan kerugian besar. Konsep ini sangat menarik untuk dipelajari di Packet Tracer karena Anda bisa mensimulasikan kegagalan router dan melihat bagaimana redundansi HSRP bekerja secara real-time, menggarisbawahi pentingnya desain jaringan yang robust.

```
standby 1 ip 192.168.1.254
```

💡 **Fun Fact:** HSRP adalah protokol Cisco proprietary, sementara Virtual Router Redundancy Protocol (VRRP) adalah standar terbuka yang melakukan fungsi serupa. Kedua protokol ini memungkinkan perangkat di LAN untuk menggunakan satu alamat IP gateway virtual yang tidak pernah berubah.
