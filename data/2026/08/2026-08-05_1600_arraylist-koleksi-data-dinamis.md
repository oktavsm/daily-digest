## ☕ Java Concept: ArrayList: Koleksi Data Dinamis

**Category:** Collections
**TL;DR:** `ArrayList` adalah implementasi antarmuka `List` yang memungkinkan kita menyimpan koleksi objek dengan ukuran yang bisa berubah secara dinamis, sangat cocok untuk daftar item yang jumlahnya tidak tetap.

Dalam pemrograman, seringkali kita perlu menyimpan sekumpulan data yang jumlahnya tidak kita ketahui secara pasti di awal, atau jumlahnya dapat berubah seiring berjalannya program. Di sinilah `ArrayList` hadir sebagai solusi yang sangat praktis dan sering digunakan. `ArrayList` adalah salah satu kelas yang ada di dalam paket `java.util` dan merupakan bagian dari Java Collections Framework. Konsep dasarnya mirip dengan array biasa, namun dengan keunggulan utama: ukurannya dapat bertambah atau berkurang secara otomatis sesuai kebutuhan.

Untuk menggunakan `ArrayList`, kita perlu mendeklarasikannya dan menginisialisasi objeknya. Penting untuk diingat bahwa `ArrayList` hanya dapat menyimpan objek (bukan tipe data primitif seperti `int`, `double`, atau `boolean`). Jika kita ingin menyimpan tipe primitif, Java akan secara otomatis melakukan "autoboxing" (mengubah primitif menjadi objek pembungkusnya, seperti `int` menjadi `Integer`). Beberapa metode dasar yang sangat sering digunakan adalah `add()` untuk menambahkan elemen baru, `get(index)` untuk mengambil elemen pada posisi tertentu, dan `size()` untuk mengetahui berapa banyak elemen yang saat ini tersimpan dalam koleksi.

`ArrayList` memiliki performa yang baik untuk operasi penambahan elemen di akhir list dan pengambilan elemen berdasarkan indeks. Namun, perlu diingat bahwa operasi penghapusan atau penambahan elemen di tengah-tengah list dapat memakan waktu lebih lama karena elemen-elemen setelahnya harus digeser. Dengan fleksibilitas ukurannya dan kemudahan penggunaannya, `ArrayList` menjadi pilihan favorit untuk berbagai skenario, seperti menyimpan daftar nama mahasiswa, keranjang belanja online, atau catatan log.

Sebagai mahasiswa semester awal, memahami `ArrayList` akan sangat membantu Anda dalam mengelola data dinamis dan merupakan langkah penting sebelum menyelami struktur data yang lebih kompleks. Ini adalah salah satu koleksi dasar yang akan Anda temui dan gunakan berulang kali dalam perjalanan Anda di Java.

```
import java.util.ArrayList;
import java.util.List;

public class ContohArrayList {
    public static void main(String[] args) {
        // Deklarasi dan inisialisasi ArrayList untuk menyimpan nama-nama
        List<String> daftarNama = new ArrayList<>();

        // Menambahkan elemen ke ArrayList
        daftarNama.add("Alice");
        daftarNama.add("Bob");
        daftarNama.add("Charlie");

        // Mengakses elemen dan mengetahui ukuran
        System.out.println("Ukuran daftar: " + daftarNama.size()); // Output: 3
        System.out.println("Nama pertama: " + daftarNama.get(0));   // Output: Alice

        // Menghapus elemen
        daftarNama.remove("Bob"); // Menghapus elemen "Bob"

        // Ukuran setelah penghapusan
        System.out.println("Ukuran setelah dihapus: " + daftarNama.size()); // Output: 2
    }
}
```

💡 **Fun Fact:** Meskipun ukurannya dinamis, `ArrayList` di Java secara internal menggunakan array biasa. Ketika `ArrayList` penuh dan kita mencoba menambahkan elemen baru, ia akan secara otomatis membuat array baru yang lebih besar (biasanya 1.5 kali ukuran semula) dan menyalin semua elemen lama ke array baru tersebut.
