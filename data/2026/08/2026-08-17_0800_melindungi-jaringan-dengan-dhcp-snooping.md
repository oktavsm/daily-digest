## 🌐 Networking Concept: Melindungi Jaringan dengan DHCP Snooping

**Category:** Security
**TL;DR:** Mempelajari DHCP Snooping untuk melindungi jaringan dari server DHCP palsu dan serangan spoofing IP/MAC dengan memverifikasi pesan DHCP di switch.

Pada perkuliahan hari ini, kita akan menyelami salah satu fitur keamanan layer 2 yang krusial: DHCP Snooping. Bayangkan skenario di mana seseorang berhasil menghubungkan 'server DHCP' palsu ke jaringan Anda. Server ini bisa memberikan alamat IP yang salah, gateway default yang mengarah ke penyerang, atau bahkan DNS server yang jahat, mengakibatkan serangan Man-in-the-Middle (MITM) atau mengganggu konektivitas seluruh jaringan. Tanpa perlindungan, switch tidak bisa membedakan antara server DHCP yang sah dan yang nakal, sehingga semua klien akan rentan.

DHCP Snooping bekerja dengan mengklasifikasikan port switch menjadi dua jenis: 'trusted' dan 'untrusted'. Port 'trusted' adalah port di mana server DHCP yang sah terhubung, atau port uplink ke switch lain yang terhubung ke server DHCP sah. Switch akan mengizinkan pesan DHCP server (seperti DHCPOFFER, DHCPACK) hanya untuk masuk melalui port trusted ini. Sementara itu, port 'untrusted' adalah port di mana perangkat klien terhubung, dan switch akan memblokir semua pesan DHCP server yang mencoba masuk dari port untrusted. Ini mencegah server DHCP palsu untuk menyebarkan informasi konfigurasi IP ke klien.

Selain itu, DHCP Snooping juga membangun 'DHCP snooping binding database' yang menyimpan informasi tentang alamat MAC, alamat IP, VLAN, dan port yang digunakan oleh setiap klien DHCP. Database ini sangat penting karena berfungsi sebagai dasar untuk fitur keamanan lanjutan lainnya, seperti Dynamic ARP Inspection (DAI) dan IP Source Guard. Dengan database ini, switch memiliki 'daftar putih' (whitelist) klien yang sah, yang memungkinkan identifikasi dan pemblokiran lalu lintas yang mencurigakan, misalnya jika ada perangkat yang mencoba menggunakan alamat IP yang tidak diberikan oleh server DHCP yang sah.

Dengan mengimplementasikan DHCP Snooping di Cisco Packet Tracer, kita dapat mensimulasikan skenario serangan server DHCP palsu dan melihat bagaimana fitur ini secara efektif memblokir upaya tersebut. Kita akan belajar mengaktifkan DHCP Snooping secara global, mengidentifikasi VLAN mana yang perlu dilindungi, dan yang terpenting, mengkonfigurasi port mana yang harus 'trusted' dan 'untrusted' untuk memastikan jaringan kita tetap aman dari ancaman berbasis DHCP.

```
interface GigabitEthernet0/1
 ip dhcp snooping trusted
```

💡 **Fun Fact:** DHCP Snooping seringkali menjadi fondasi keamanan lapisan 2 lainnya. Tanpanya, fitur seperti Dynamic ARP Inspection (DAI) dan IP Source Guard tidak dapat berfungsi dengan efektif karena mereka bergantung pada 'DHCP snooping binding database' untuk memvalidasi identitas perangkat di jaringan.
