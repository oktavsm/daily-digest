## ⚡ Competitive Programming Concept: Segment Tree

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data pohon yang memungkinkan query range (seperti sum, min, max) dan update point/range secara efisien dalam waktu logaritmik.

Segment Tree adalah struktur data pohon biner yang sangat powerful, digunakan untuk secara efisien melakukan operasi query pada rentang (range query) dan update nilai pada titik (point update) atau rentang (range update) pada sebuah array atau list. Setiap node dalam pohon merepresentasikan suatu rentang (segment) dari array asli dan menyimpan informasi agregat (misalnya sum, minimum, maksimum) untuk rentang tersebut. Ini membuatnya ideal untuk masalah yang memerlukan pemrosesan data pada sub-array secara berulang.

Pembangunan Segment Tree dilakukan secara rekursif menggunakan pendekatan divide and conquer. Node root merepresentasikan seluruh array. Node-node internal membagi rentang menjadi dua sub-rentang yang diwakili oleh anak-anaknya, hingga mencapai node leaf yang merepresentasikan elemen tunggal dari array asli. Untuk query rentang (misalnya mencari sum dari indeks L sampai R), algoritma akan melintasi pohon, menggabungkan hasil dari node-node yang rentangnya sepenuhnya tumpang tindih dengan query, atau memecah query ke anak-anak jika hanya sebagian yang tumpang tindih.

Operasi update, misalnya mengubah nilai pada indeks tertentu, juga dilakukan dengan melintasi pohon. Dimulai dari root, algoritma akan bergerak ke bawah menuju node leaf yang merepresentasikan indeks yang diupdate. Setelah leaf diupdate, nilai-nilai pada node-node ancestor di jalur tersebut juga diperbarui (dipropagate) kembali ke atas hingga root, memastikan konsistensi data. Untuk update rentang (misalnya menambah nilai X pada seluruh rentang L-R), teknik Lazy Propagation seringkali digunakan untuk menjaga efisiensi, menunda update pada node anak hingga benar-benar diperlukan.

Segment Tree menawarkan kompleksitas waktu yang sangat efisien. Pembangunan pohon membutuhkan waktu O(N), di mana N adalah ukuran array. Baik operasi query maupun update (point atau range dengan lazy propagation) dapat diselesaikan dalam waktu O(log N). Kebutuhan ruang untuk menyimpan pohon adalah O(N), karena umumnya pohon memiliki sekitar 2N sampai 4N node tergantung implementasinya, sehingga sering dialokasikan 4*N ukuran array untuk menampung pohon.

```
vector<long long> tree_val; // Diasumsikan berukuran 4*N
vector<int> initial_arr;  // Array asli yang akan dibangun Segment Tree di atasnya

void build_segment_tree(int node, int start, int end) {
    if (start == end) {
        tree_val[node] = initial_arr[start];
    } else {
        int mid = (start + end) / 2;
        build_segment_tree(2 * node, start, mid);
        build_segment_tree(2 * node + 1, mid + 1, end);
        tree_val[node] = tree_val[2 * node] + tree_val[2 * node + 1]; // Contoh untuk aggregasi sum
    }
}
```

💡 **Fun Fact:** Segment Tree dinamai karena ia membagi array menjadi 'segmen' dan menyimpannya dalam struktur pohon. Konsepnya pertama kali diperkenalkan oleh Jon Bentley pada tahun 1977, meskipun nama 'Segment Tree' dipopulerkan kemudian oleh algoritma lain di bidang geometri komputasi.
