## ⚡ Competitive Programming Concept: Binary Search

**Category:** Searching
**TL;DR:** Algoritma efisien untuk mencari elemen dalam data terurut atau nilai optimal di rentang tertentu dengan membagi dua ruang pencarian secara berulang.

Binary Search adalah algoritma pencarian yang sangat efisien, dirancang khusus untuk bekerja pada koleksi data yang sudah terurut (misalnya, array atau vector). Ide utamanya adalah secara berulang membagi dua interval pencarian yang mungkin, sehingga pada setiap langkah, setengah dari data yang tersisa dapat diabaikan. Ini memberikan keuntungan kecepatan yang signifikan dibandingkan pencarian linear yang memeriksa setiap elemen satu per satu.

Misalkan kita ingin mencari sebuah nilai `X` dalam array terurut `A`. Kita memulai dengan menetapkan `low` ke indeks pertama dan `high` ke indeks terakhir dari ruang pencarian kita. Di setiap langkah, kita menghitung indeks tengah `mid = low + (high - low) / 2`. Kita kemudian membandingkan `A[mid]` dengan `X`. Jika `A[mid]` sama dengan `X`, kita telah menemukan elemen tersebut. Jika `A[mid]` lebih kecil dari `X`, kita tahu `X` pasti berada di sisi kanan `mid`, jadi kita memperbarui `low = mid + 1`. Sebaliknya, jika `A[mid]` lebih besar dari `X`, `X` pasti berada di sisi kiri `mid`, sehingga kita memperbarui `high = mid - 1`. Proses ini berlanjut sampai `low > high` (menandakan nilai tidak ditemukan) atau `X` ditemukan.

Selain mencari di array, Binary Search juga sering digunakan untuk mencari *jawaban optimal* untuk suatu masalah, yang dikenal sebagai "Binary Search on Answer". Konsepnya adalah jika kita dapat memverifikasi apakah suatu nilai `K` *mungkin* menjadi jawaban (misalnya, "apakah mungkin menyelesaikan masalah ini dengan paling banyak `K` operasi?"), dan fungsi verifikasi ini bersifat monotonik (artinya, jika kita bisa dengan `K`, kita juga bisa dengan `K+1` atau sebaliknya), maka kita bisa melakukan binary search pada rentang nilai yang mungkin untuk `K`. Fungsi verifikasi (`check` function) inilah yang menjadi inti dari metode ini, di mana kita mencari `K` terkecil atau terbesar yang memenuhi kondisi.

Karena setiap langkah secara efektif membagi dua ruang pencarian yang tersisa, Binary Search memiliki kompleksitas waktu logaritmik, yaitu **O(log N)**, di mana N adalah ukuran ruang pencarian (jumlah elemen dalam array atau rentang nilai jawaban yang mungkin). Dalam konteks Binary Search on Answer, kompleksitas totalnya menjadi O(log N * C), di mana C adalah kompleksitas dari fungsi `check` yang digunakan untuk memverifikasi kelayakan sebuah jawaban.

```
int find_first_occurrence(const std::vector<int>& arr, int target) {
    int low = 0;
    int high = arr.size() - 1;
    int ans_idx = -1; // Index of the first element >= target

    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] >= target) {
            ans_idx = mid;
            high = mid - 1;
        } else {
            low = mid + 1;
        }
    }
    return ans_idx;
}
```
