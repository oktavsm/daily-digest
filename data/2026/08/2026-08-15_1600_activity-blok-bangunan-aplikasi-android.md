## 🤖 Android Concept: Activity: Blok Bangunan Aplikasi Android

**Category:** UI
**TL;DR:** Activity adalah komponen dasar dalam aplikasi Android yang menyediakan satu layar antarmuka pengguna (UI) untuk interaksi pengguna.

Activity mewakili satu layar dengan antarmuka pengguna yang dapat berinteraksi dengan pengguna. Bayangkan setiap layar yang Anda lihat di aplikasi, seperti layar login, daftar produk, atau detail item, itu kemungkinan besar diwakili oleh sebuah Activity. Ini adalah pintu gerbang utama aplikasi Anda bagi pengguna, dan sebagian besar aplikasi terdiri dari beberapa Activity yang bekerja sama untuk menyediakan fungsionalitas penuh.

Setiap Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, mulai dari saat dibuat hingga dihancurkan. Metode-metode seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()` dipanggil oleh sistem Android pada tahapan-tahapan ini. Memahami siklus hidup ini sangat penting untuk mengelola sumber daya, menyimpan data saat aplikasi beralih fokus, dan memastikan aplikasi berjalan efisien serta stabil.

Secara default, setiap Activity biasanya terhubung dengan satu file layout XML. File XML ini mendefinisikan tata letak visual elemen-elemen UI seperti tombol, teks, gambar, dan lain-lain. Dengan memisahkan kode logika (Kotlin) dari desain UI (XML), pengembangan menjadi lebih modular dan mudah dikelola. Dalam metode `onCreate()` Activity, kita menggunakan `setContentView()` untuk menghubungkan Activity dengan file layout XML yang akan ditampilkannya.

Setelah layout dihubungkan, Anda dapat menulis logika di dalam Activity Kotlin untuk merespons interaksi pengguna, seperti menangani klik tombol, memperbarui teks, atau menampilkan data dari sumber lain. Ini adalah inti dari bagaimana Anda membangun pengalaman pengguna yang interaktif dan dinamis di aplikasi Android, menggabungkan tampilan visual dengan fungsionalitas di baliknya.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan Activity dengan layout XML
    }
}
```

💡 **Fun Fact:** Setiap kali Anda berpindah antar aplikasi atau kembali ke layar utama, sistem Android mengelola siklus hidup Activity Anda secara cerdas untuk memastikan pengalaman yang mulus, seringkali menyimpannya di 'back stack' agar bisa kembali lagi nanti.
