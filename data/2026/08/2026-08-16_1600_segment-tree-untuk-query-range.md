## ⚡ Competitive Programming Concept: Segment Tree untuk Query Range

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data pohon yang efisien untuk melakukan query (misal: sum, min, max) dan update pada rentang (range) elemen di sebuah array dalam waktu logaritmis.

Segment Tree adalah struktur data berbasis pohon yang digunakan untuk menyelesaikan masalah yang melibatkan query dan update pada rentang (range) sebuah array. Bayangkan Anda memiliki sebuah array dan Anda sering perlu mencari jumlah, nilai minimum, atau maksimum dari sub-array tertentu, serta mengubah nilai elemen tunggal. Menggunakan array biasa, operasi query bisa O(N) dan update O(1), atau dengan prefix sum, query O(1) dan update O(N). Segment Tree memungkinkan kedua operasi ini dilakukan dengan sangat efisien.

Struktur Segment Tree direpresentasikan sebagai sebuah pohon biner. Setiap node dalam pohon merepresentasikan sebuah rentang (segment) dari array asli. Node daun (leaf nodes) merepresentasikan elemen tunggal dari array, sedangkan node internal merepresentasikan gabungan rentang dari anak-anaknya. Biasanya, pohon ini diimplementasikan menggunakan array, di mana node `i` memiliki anak kiri `2*i` dan anak kanan `2*i+1`. Proses pembangunan (build) pohon melibatkan rekursi, memecah rentang menjadi dua hingga mencapai node daun, lalu menggabungkan hasil dari anak-anak kembali ke atas. Kompleksitas waktu untuk membangun Segment Tree adalah O(N) karena setiap elemen array dan setiap node pohon diproses sekali.

Setelah dibangun, Segment Tree mendukung dua operasi utama: query dan update. Operasi query (misal: mencari jumlah dalam rentang [L, R]) dilakukan secara rekursif. Pohon dijelajahi, dan jika rentang query sepenuhnya tertutup oleh rentang sebuah node, nilai node tersebut langsung dikembalikan. Jika tidak, query dipecah dan dilakukan pada anak kiri dan kanan, lalu hasilnya digabungkan. Operasi update (misal: mengubah nilai elemen di indeks `i`) juga rekursif; kita menemukan node daun yang sesuai, mengubah nilainya, lalu memperbarui nilai pada semua node di jalur dari daun tersebut hingga ke akar. Baik operasi query maupun update memiliki kompleksitas waktu O(log N) karena di setiap level pohon, kita hanya perlu menelusuri sebagian kecil cabang. Ruang memori yang dibutuhkan adalah O(N), umumnya sekitar 4N untuk array implementasi.

```
int arr[100005], tree[400005]; // arr: original, tree: segment tree

void build(int node, int start, int end) {
    if(start == end) { tree[node] = arr[start]; return; }
    int mid = (start + end) / 2;
    build(2 * node, start, mid);
    build(2 * node + 1, mid + 1, end);
    tree[node] = tree[2 * node] + tree[2 * node + 1]; // Example: sum
}

int query(int node, int start, int end, int l, int r) {
    if(r < start || end < l) return 0; // No overlap (identity for sum is 0)
    if(l <= start && end <= r) return tree[node]; // Complete overlap
    int mid = (start + end) / 2;
    return query(2 * node, start, mid, l, r) + query(2 * node + 1, mid + 1, end, l, r);
} // Point update operation is similar to query traversal
```

💡 **Fun Fact:** Segment Tree dapat dimodifikasi untuk mendukung operasi yang lebih kompleks seperti 'lazy propagation', yang memungkinkan update pada rentang elemen (range update) dalam waktu O(log N) juga, bukan hanya update titik tunggal.
