## 🤖 Android Concept: Siklus Hidup Activity

**Category:** Architecture
**TL;DR:** Activity Lifecycle menjelaskan berbagai status yang dilewati sebuah Activity dari mulai dibuat, berjalan, hingga dihancurkan oleh sistem Android.

Setiap aplikasi Android terdiri dari satu atau lebih Activity, yang berfungsi sebagai titik masuk bagi pengguna untuk berinteraksi. Namun, sebuah Activity tidak selalu 'hidup' atau 'aktif' sepanjang waktu. Sistem Android mengelola Activity dalam berbagai status, yang dikenal sebagai Siklus Hidup Activity (Activity Lifecycle). Memahami siklus hidup ini sangat krusial agar aplikasi Anda berperilaku benar, efisien, dan tidak mengalami *crash* saat pengguna berpindah antar layar, menerima panggilan telepon, atau beralih aplikasi.

Siklus Hidup Activity dibagi menjadi beberapa tahapan utama. Ketika sebuah Activity pertama kali dibuat, metode `onCreate()` dipanggil—di sinilah Anda biasanya melakukan *setup* awal UI. Setelah itu, `onStart()` dipanggil ketika Activity menjadi terlihat oleh pengguna, diikuti oleh `onResume()` ketika Activity siap untuk berinteraksi penuh. Jika pengguna beralih ke Activity lain atau aplikasi lain, `onPause()` dipanggil (Activity masih terlihat, tapi tidak interaktif), kemudian `onStop()` (Activity tidak lagi terlihat). Akhirnya, `onDestroy()` dipanggil saat Activity akan dihancurkan sepenuhnya.

Memahami kapan setiap metode siklus hidup dipanggil memungkinkan Anda untuk mengelola sumber daya dengan tepat. Misalnya, Anda bisa menginisialisasi kamera atau sensor di `onStart()` dan melepaskannya di `onStop()` untuk menghemat baterai. Anda juga bisa menyimpan data penting yang belum disimpan oleh pengguna menggunakan `onSaveInstanceState()` yang dipanggil sebelum `onStop()`, agar data tersebut tidak hilang jika sistem Android memutuskan untuk menghancurkan dan membuat ulang Activity Anda (misalnya, saat rotasi layar).

Mengabaikan siklus hidup dapat menyebabkan *memory leak*, data tidak tersimpan, atau bahkan *crash* aplikasi. Dengan mengimplementasikan logika yang sesuai pada setiap metode *callback* siklus hidup, Anda memastikan aplikasi Anda responsif, efisien, dan stabil di berbagai skenario penggunaan yang berbeda, memberikan pengalaman pengguna yang mulus dan andal.

```
class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        // Di sini Activity pertama kali dibuat.
        // Lakukan inisialisasi UI dan data awal.
        // Ada juga onStart, onResume, onPause, onStop, onDestroy.
    }
}
```

💡 **Fun Fact:** Android memiliki *task stack* yang mengelola urutan Activity. Saat Anda membuka Activity baru, ia diletakkan di atas stack; ketika Anda menekan tombol 'Back', Activity teratas akan dihancurkan dan Activity di bawahnya akan muncul kembali.
