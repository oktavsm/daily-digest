## ☕ Java Concept: ArrayList: Koleksi Dinamis Data

**Category:** Collections
**TL;DR:** `ArrayList` adalah struktur data dinamis di Java yang memungkinkan kita menyimpan dan mengelola daftar objek yang ukurannya bisa berubah saat program berjalan.

Di Java, ketika kita membutuhkan sebuah daftar atau urutan data, array adalah pilihan yang umum. Namun, array memiliki batasan ukuran yang tetap setelah dibuat. Artinya, kita tidak bisa dengan mudah menambah atau mengurangi jumlah elemennya di tengah jalan eksekusi program. Di sinilah `ArrayList` hadir sebagai solusi yang lebih fleksibel. `ArrayList` adalah implementasi dari antarmuka `List` di Java, yang memungkinkan kita menyimpan koleksi objek dengan kemampuan untuk secara dinamis mengubah ukurannya.

Membuat dan menggunakan `ArrayList` sangatlah mudah. Anda cukup mendeklarasikannya, lalu bisa langsung menambahkan elemen ke dalamnya. Untuk menambahkan elemen, Anda menggunakan metode `add()`. `ArrayList` secara otomatis akan menangani alokasi memori ketika Anda menambahkan lebih banyak elemen daripada kapasitas awalnya, dengan cara membuat array internal yang lebih besar dan menyalin data yang sudah ada. Untuk mengakses elemen, Anda bisa menggunakan metode `get()` dengan indeks (posisi) elemen yang ingin Anda ambil, mirip seperti array biasa namun lebih aman karena ada pengecekan indeks secara otomatis.

Selain menambah dan mengakses, `ArrayList` juga menyediakan berbagai metode praktis lainnya. Anda bisa menghapus elemen menggunakan `remove()` (berdasarkan indeks atau objek), mengetahui jumlah elemen saat ini dengan `size()`, atau bahkan mencari elemen tertentu. `ArrayList` juga mendukung perulangan (looping) menggunakan `for-each loop` yang sangat nyaman untuk memproses setiap elemen dalam koleksi. Penting untuk diingat bahwa `ArrayList` menyimpan objek, sehingga Anda bisa menentukan tipe objek yang akan disimpan menggunakan Generics (misalnya, `ArrayList<String>`).

Singkatnya, `ArrayList` adalah salah satu kelas koleksi paling fundamental dan sering digunakan di Java. Fleksibilitasnya dalam menangani daftar data yang ukurannya tidak tetap membuatnya menjadi pilihan utama untuk banyak skenario, mulai dari menyimpan daftar nama pengguna hingga mengelola daftar item belanja dalam sebuah aplikasi. Memahami `ArrayList` adalah langkah penting untuk dapat menulis program Java yang lebih dinamis dan efisien.

```
import java.util.ArrayList;

public class DaftarMahasiswa {
    public static void main(String[] args) {
        // Membuat ArrayList untuk menyimpan nama mahasiswa (tipe String)
        ArrayList<String> daftarNamaMahasiswa = new ArrayList<>(); 

        // Menambah elemen ke ArrayList
        daftarNamaMahasiswa.add("Budi Santoso");
        daftarNamaMahasiswa.add("Ani Yulia");
        daftarNamaMahasiswa.add("Cici Paramida");

        // Mengakses elemen pertama (indeks 0)
        System.out.println("Mahasiswa pertama: " + daftarNamaMahasiswa.get(0)); 

        // Menampilkan semua mahasiswa menggunakan perulangan
        System.out.println("\nDaftar Lengkap Mahasiswa:");
        for (String nama : daftarNamaMahasiswa) {
            System.out.println("- " + nama);
        }
    }
}
```

💡 **Fun Fact:** Tahukah kamu? Meskipun `ArrayList` terlihat "ajaib" karena ukurannya bisa dinamis, secara internal ia sebenarnya menggunakan array biasa! Ketika kamu menambahkan elemen melebihi kapasitas array internalnya, `ArrayList` akan secara otomatis membuat array baru yang lebih besar dan menyalin semua elemen lama ke dalamnya, sebuah proses yang dikenal sebagai 'resizing'.
