## ☕ Java Concept: Classes dan Objects: Pondasi OOP

**Category:** OOP
**TL;DR:** Classes adalah blueprint untuk membuat Objects, yang merupakan representasi nyata dari data dan perilaku di dunia nyata.

Kelas (Class) di Java adalah sebuah blueprint atau template untuk membuat objek. Ia mendefinisikan struktur objek, termasuk atribut (data atau karakteristik) dan metode (perilaku atau fungsi) yang akan dimiliki oleh setiap objek yang dibuat dari kelas tersebut. Bayangkan sebuah kelas sebagai cetak biru sebuah rumah; ia menentukan berapa banyak kamar, di mana letak pintu, dan desain umum, tetapi bukan rumah yang sebenarnya.

Objek (Object) adalah instance konkret dari sebuah kelas. Jika kelas adalah cetak biru rumah, maka objek adalah rumah yang sudah jadi berdasarkan cetak biru tersebut. Setiap objek memiliki statusnya sendiri (nilai-nilai dari atributnya) dan dapat melakukan tindakan sesuai dengan metode yang didefinisikan dalam kelasnya. Kita bisa membuat banyak objek dari satu kelas yang sama, dan setiap objek bisa memiliki nilai atribut yang berbeda.

Konsep Kelas dan Objek adalah inti dari Pemrograman Berorientasi Objek (OOP) di Java. Dengan menggunakan kelas dan objek, kita dapat memodelkan entitas dunia nyata ke dalam kode program, menjadikannya lebih terstruktur, mudah dikelola, dan dapat digunakan kembali. Ini memungkinkan kita untuk mengorganisir kode ke dalam unit-unit logis yang mandiri, meningkatkan skalabilitas dan pemeliharaan aplikasi.

```
class Mahasiswa {
    String nama;
    String nim;
    int semester;

    void perkenalanDiri() {
        System.out.println("Halo, saya " + nama + ", NIM " + nim + ", semester " + semester);
    }
}

/* Cara menggunakan:
Mahasiswa mhs1 = new Mahasiswa(); // Membuat objek
mhs1.nama = "Budi Santoso";
mhs1.nim = "2024001";
mhs1.semester = 1;
mhs1.perkenalanDiri();
*/
```

💡 **Fun Fact:** Java sering disebut sebagai bahasa yang 'sangat berorientasi objek', di mana hampir semua yang Anda lakukan melibatkan kelas dan objek. Ini adalah salah satu alasan utama mengapa Java sangat kuat untuk membangun aplikasi berskala besar dan kompleks.
