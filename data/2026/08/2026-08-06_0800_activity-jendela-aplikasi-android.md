## 🤖 Android Concept: Activity: Jendela Aplikasi Android

**Category:** Architecture
**TL;DR:** Activity adalah komponen fundamental di aplikasi Android yang merepresentasikan satu layar antarmuka pengguna (UI) tempat pengguna dapat berinteraksi.

Dalam dunia pengembangan Android, Activity adalah salah satu blok bangunan paling dasar dan krusial. Bayangkan aplikasi Anda seperti sebuah buku cerita; setiap halaman dalam buku tersebut bisa diibaratkan sebagai sebuah Activity. Setiap Activity bertanggung jawab untuk menggambar UI dan merespons interaksi pengguna untuk satu layar tunggal. Ini adalah titik masuk utama bagi pengguna untuk berinteraksi dengan fitur-fitur aplikasi Anda.

Setiap Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, yang terdiri dari beberapa tahap seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()`. Metode `onCreate()` adalah tempat utama untuk melakukan inisialisasi awal, seperti menyiapkan layout UI (misalnya, dari file XML) dan menginisialisasi variabel-variabel penting. Memahami lifecycle ini sangat penting agar aplikasi Anda dapat mengelola sumber daya dengan efisien, menyimpan dan memulihkan data dengan benar, serta memberikan pengalaman pengguna yang mulus bahkan saat perangkat berputar atau aplikasi berpindah ke latar belakang.

Ketika Anda membuat Activity baru, biasanya Anda akan mewarisi dari `AppCompatActivity` (sebuah subclass dari `Activity`) dan meng-override metode `onCreate()`. Di sinilah Anda akan memanggil `setContentView()` untuk menghubungkan Activity Anda dengan file layout XML yang mendefinisikan tampilan visual layar tersebut. Setelah layout dimuat, Anda dapat menemukan dan memanipulasi View (seperti tombol, teks, gambar) di layout tersebut menggunakan ID-nya. Ini memungkinkan Anda untuk menambahkan logika bisnis dan fungsionalitas interaktif ke layar aplikasi Anda.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan Activity dengan layout XML
        // Di sini Anda bisa menambahkan logika inisialisasi UI atau data lain
    }
}
```

💡 **Fun Fact:** Meskipun sebuah aplikasi Android bisa memiliki banyak Activity, hanya satu Activity yang bisa berada dalam status 'aktif' (foreground) pada satu waktu. Android mengelola urutan Activity dalam sebuah 'back stack', memungkinkan pengguna untuk menekan tombol kembali dan bernavigasi mundur melalui layar-layar yang sebelumnya mereka kunjungi.
