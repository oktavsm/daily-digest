## 🤖 Android Concept: ViewModel: Data Tetap Aman

**Category:** Jetpack
**TL;DR:** ViewModel adalah komponen Jetpack yang menyimpan dan mengelola data UI secara lifecycle-aware, memastikan data tidak hilang saat perubahan konfigurasi seperti rotasi layar.

Sebagai seorang developer Android, Anda pasti akan menghadapi tantangan di mana data pada layar aplikasi Anda hilang ketika perangkat mengalami perubahan konfigurasi, seperti saat layar diputar dari portrait ke landscape. Ini terjadi karena Activity atau Fragment yang menampilkan UI dihancurkan dan dibuat ulang. ViewModel hadir sebagai solusi untuk masalah ini, berfungsi sebagai tempat penyimpanan data UI yang persisten dan terbebas dari siklus hidup Activity atau Fragment.

ViewModel dirancang untuk menyimpan dan mengelola data yang terkait dengan UI, seperti daftar item, status input pengguna, atau hasil panggilan jaringan. Berbeda dengan Activity/Fragment yang hancur dan dibuat ulang, instance ViewModel akan tetap hidup selama Activity/Fragment tersebut masih ada dalam 'back stack' sistem, bahkan setelah terjadi perubahan konfigurasi. Ini berarti data Anda akan tetap tersedia dan siap digunakan kembali oleh instance Activity/Fragment yang baru dibuat, tanpa perlu mengambilnya ulang atau menyimpannya secara manual.

Prinsip utama di balik ViewModel adalah pemisahan tanggung jawab (separation of concerns). ViewModel bertanggung jawab penuh atas logika bisnis dan pengelolaan data, menjauhkan tugas-tugas ini dari Activity atau Fragment yang seharusnya hanya berfokus pada menampilkan UI dan menangani interaksi pengguna. Dengan demikian, kode Anda menjadi lebih bersih, lebih mudah diuji, dan lebih mudah dipelihara.

Untuk menggunakannya, Anda biasanya membuat kelas yang mewarisi dari `androidx.lifecycle.ViewModel` dan mendapatkan instance-nya melalui `ViewModelProvider` di Activity atau Fragment Anda. Anda kemudian dapat menyimpan `MutableLiveData` atau `StateFlow` di ViewModel Anda dan mengamati perubahannya di UI untuk memperbarui tampilan secara reaktif.

```
import androidx.lifecycle.ViewModel
import androidx.lifecycle.MutableLiveData
import androidx.lifecycle.ViewModelProvider

// MyViewModel.kt
class MyViewModel : ViewModel() {
    val userName = MutableLiveData<String>()
}

// MainActivity.kt
class MainActivity : AppCompatActivity() {
    private lateinit var viewModel: MyViewModel

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        viewModel = ViewModelProvider(this).get(MyViewModel::class.java)

        // Contoh penggunaan data dari ViewModel
        viewModel.userName.observe(this) { name ->
            // Update UI, misalnya: welcomeTextView.text = "Halo, $name!"
        }
        // Mengatur data pertama kali atau saat event terjadi
        if (viewModel.userName.value == null) {
            viewModel.userName.value = "Pengguna Baru"
        }
    }
}
```

💡 **Fun Fact:** Salah satu keunggulan desain ViewModel adalah bahwa ia tidak memiliki referensi langsung ke View, Activity, atau Fragment. Hal ini sengaja dilakukan untuk mencegah kebocoran memori (memory leaks) yang umum terjadi jika ViewModel menyimpan referensi ke objek UI yang memiliki siklus hidup lebih pendek.
