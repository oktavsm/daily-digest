## 🤖 Android Concept: Memahami Siklus Hidup Activity

**Category:** Architecture
**TL;DR:** Siklus hidup Activity adalah serangkaian metode callback yang dipanggil sistem Android saat sebuah Activity melewati berbagai tahapan, dari dibuat hingga dihancurkan.

Sebagai pondasi utama dalam pengembangan aplikasi Android, Activity memiliki siklus hidup yang sangat penting untuk dipahami. Siklus hidup ini merupakan serangkaian tahapan yang dilalui sebuah Activity, dimulai dari saat ia dibuat, terlihat oleh pengguna, berinteraksi, hingga akhirnya dihancurkan. Sistem Android mengelola Activity melalui berbagai callback method seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()`, yang masing-masing dipanggil pada momen-momen spesifik dalam perjalanan Activity.

Memahami kapan dan mengapa setiap metode callback dipanggil sangat krusial untuk membangun aplikasi yang stabil dan efisien. Misalnya, `onCreate()` adalah tempat inisialisasi awal, seperti mengatur tampilan (layout) dan menginisialisasi variabel. `onResume()` adalah tahap di mana Activity berada di latar depan dan siap berinteraksi dengan pengguna. Sebaliknya, `onPause()` dan `onStop()` adalah momen yang tepat untuk menyimpan data yang belum tersimpan, melepaskan sumber daya yang memakan baterai atau memori (misalnya, mematikan kamera atau menghentikan pemutaran video), karena Activity bisa saja dihancurkan kapan saja setelah tahap ini.

Penanganan siklus hidup yang tepat juga sangat penting untuk mengelola perubahan konfigurasi, seperti rotasi layar. Saat layar berputar, Activity secara default akan dihancurkan dan dibuat ulang. Dengan memahami siklus ini, kita dapat menyimpan keadaan UI atau data penting menggunakan `onSaveInstanceState()` agar pengalaman pengguna tidak terganggu, dan data tidak hilang saat Activity dibuat ulang. Ini memastikan aplikasi dapat pulih dengan lancar dari gangguan dan perubahan kondisi.

Dengan menguasai siklus hidup Activity, Anda akan dapat merancang aplikasi yang responsif terhadap interaksi pengguna dan peristiwa sistem, mengelola sumber daya dengan bijak, serta memberikan pengalaman pengguna yang mulus dan bebas dari kehilangan data. Ini adalah salah satu konsep fundamental yang harus dikuasai setiap developer Android pemula untuk membangun aplikasi yang kokoh dan berperforma baik.

```
import android.os.Bundle
import android.util.Log
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    private val TAG = "MyActivity" // Tag untuk logcat

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        Log.d(TAG, "onCreate: Activity dibuat dan mulai berjalan.")
    }

    override fun onPause() {
        super.onPause()
        Log.d(TAG, "onPause: Activity tidak lagi di fokus, siapkan untuk berhenti.")
        // Contoh: Hentikan pemutaran musik atau simpan data yang belum tersimpan.
    }
}
```

💡 **Fun Fact:** Tahukah Anda bahwa Android dirancang untuk secara agresif mengelola sumber daya? Sistem dapat menghancurkan Activity yang tidak sedang digunakan untuk membebaskan memori bagi aplikasi lain, itulah mengapa memahami siklus hidup sangat krusial agar aplikasi Anda dapat bertahan dalam berbagai skenario tanpa kehilangan data atau status.
