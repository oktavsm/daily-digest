## ☕ Java Concept: Menggunakan ArrayList untuk Koleksi Data

**Category:** Collections
**TL;DR:** ArrayList adalah salah satu struktur data dinamis paling umum di Java yang memungkinkan kita menyimpan daftar objek yang ukurannya bisa berubah.

Sebagai programmer, kita seringkali perlu menyimpan banyak data yang sejenis, seperti daftar nama siswa, produk dalam keranjang belanja, atau nilai-nilai tertentu. Array tradisional memiliki batasan utama: ukurannya tetap setelah dibuat. Ini menyulitkan jika kita tidak tahu berapa banyak data yang akan kita tangani sejak awal. Di sinilah `ArrayList` hadir sebagai solusi yang elegan dan sangat sering digunakan.

`ArrayList` adalah bagian dari Java Collections Framework dan merupakan implementasi dari antarmuka `List`. Ini pada dasarnya adalah "array" yang dapat tumbuh atau menyusut secara otomatis sesuai kebutuhan. Anda dapat menambah, menghapus, atau mengakses elemen dengan mudah tanpa perlu khawatir tentang manajemen memori di tingkat rendah. Karena `ArrayList` bersifat generik, Anda harus menentukan tipe data objek yang akan disimpannya, misalnya `ArrayList<String>` untuk menyimpan teks atau `ArrayList<Integer>` untuk menyimpan angka.

Operasi dasar dengan `ArrayList` sangat intuitif. Anda dapat menambahkan elemen menggunakan metode `add()`, mengambil elemen berdasarkan indeksnya menggunakan `get(index)`, dan mengetahui jumlah elemen saat ini dengan `size()`. Kemampuan untuk mengakses elemen dengan indeks membuatnya cepat untuk operasi pencarian berdasarkan posisi. Fleksibilitas ini menjadikannya pilihan yang sangat baik untuk sebagian besar skenario di mana Anda memerlukan daftar objek yang ukurannya tidak tetap.

Meskipun `ArrayList` sangat serbaguna, penting untuk diingat bahwa setiap kali Anda menambahkan elemen sehingga kapasitas internalnya terlampaui, `ArrayList` akan membuat array baru yang lebih besar dan menyalin semua elemen lama ke array baru tersebut. Proses ini mungkin memakan sedikit waktu, namun Java sudah mengoptimalkannya sedemikian rupa sehingga umumnya tidak menjadi masalah untuk sebagian besar aplikasi sehari-hari. Untuk mahasiswa semester awal, `ArrayList` adalah fondasi penting untuk memahami bagaimana data dikelola dalam skala yang lebih besar.

```
import java.util.ArrayList;

// Contoh penggunaan dalam sebuah method, misalnya main()
ArrayList<String> daftarNama = new ArrayList<>();
daftarNama.add("Alice");
daftarNama.add("Bob");
daftarNama.add("Charlie");

System.out.println("Nama pertama: " + daftarNama.get(0)); // Output: Nama pertama: Alice
System.out.println("Jumlah nama: " + daftarNama.size());   // Output: Jumlah nama: 3
```

💡 **Fun Fact:** Tahukah Anda bahwa `ArrayList` sebenarnya diimplementasikan menggunakan array biasa di balik layarnya? Ketika Anda menambahkan elemen melebihi kapasitas array yang ada, Java secara otomatis membuat array baru yang lebih besar dan menyalin semua elemen lama ke sana! Ini adalah salah satu trik di balik "array dinamis".
