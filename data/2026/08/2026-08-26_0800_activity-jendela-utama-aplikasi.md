## 🤖 Android Concept: Activity: Jendela Utama Aplikasi

**Category:** UI
**TL;DR:** Activity adalah komponen aplikasi inti yang menyediakan satu layar dengan antarmuka pengguna untuk interaksi dengan pengguna.

Dalam pengembangan Android, Activity bisa diibaratkan sebagai satu "layar" tunggal dalam aplikasi Anda. Setiap kali Anda membuka aplikasi dan melihat suatu antarmuka pengguna—misalnya, layar masuk, daftar produk, atau halaman pengaturan—kemungkinan besar Anda sedang berinteraksi dengan sebuah Activity. Activity bertanggung jawab penuh untuk menampilkan UI dan merespon interaksi pengguna, menjadikannya fondasi utama pengalaman pengguna aplikasi Android.

Setiap Activity memiliki siklus hidup (lifecycle) yang dikelola oleh sistem Android, mulai dari saat Activity dibuat hingga dihancurkan. Tahapan yang paling fundamental bagi pemula adalah `onCreate()`, yang merupakan titik di mana Activity pertama kali dibuat dan semua inisialisasi awal harus dilakukan. Di sinilah Anda biasanya mengatur tata letak (layout) UI menggunakan `setContentView()` yang merujuk pada file XML layout, serta menyiapkan komponen-komponen tampilan lainnya. Memahami siklus hidup ini sangat krusial untuk mengelola sumber daya dan perilaku aplikasi dengan benar.

Untuk membuat Activity baru, Anda perlu membuat kelas Kotlin yang mewarisi `AppCompatActivity` dan mendeklarasikannya dalam file `AndroidManifest.xml` agar sistem Android dapat mengenalinya. Saat ingin berpindah dari satu Activity ke Activity lain, Anda akan menggunakan `Intent`. Intent adalah objek pesan yang memberitahu sistem Android untuk meluncurkan Activity tujuan, atau melakukan tindakan tertentu. Ini adalah cara standar untuk navigasi antar layar dalam aplikasi Anda.

Sistem Android mengelola Activity dalam sebuah tumpukan (back stack). Ketika Activity baru dimulai, ia ditempatkan di atas tumpukan Activity sebelumnya. Saat pengguna menekan tombol kembali, Activity teratas akan dihancurkan (atau dihentikan) dan Activity yang ada di bawahnya akan kembali terlihat. Mekanisme back stack ini memastikan pengalaman navigasi yang intuitif dan sesuai ekspektasi pengguna di Android.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan layout XML ke Activity
        // Di sini Anda bisa menambahkan kode untuk inisialisasi tampilan lainnya
    }
}
```

💡 **Fun Fact:** Tahukah kamu, Activity adalah salah satu komponen inti Android yang paling tua, diperkenalkan bersamaan dengan versi Android 1.0 pada tahun 2008. Tanpanya, tidak akan ada aplikasi Android interaktif seperti yang kita kenal sekarang!
