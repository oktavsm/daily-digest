## ⚡ Competitive Programming Concept: Binary Search

**Category:** Searching
**TL;DR:** Algoritma pencarian efisien untuk menemukan nilai dalam array terurut dengan membagi rentang pencarian menjadi dua di setiap langkah.

Binary Search adalah algoritma pencarian yang sangat efisien untuk menemukan posisi sebuah nilai target dalam array atau list yang **sudah terurut**. Ide utamanya adalah terus-menerus membagi rentang pencarian menjadi dua bagian. Ini sangat berguna ketika kita berhadapan dengan data besar dan perlu menemukan sesuatu dengan cepat, atau ketika kita perlu mencari batas nilai tertentu dalam rentang yang monotonik.

Algoritma dimulai dengan menetapkan dua pointer, `low` ke indeks pertama dan `high` ke indeks terakhir dari array. Kemudian, di setiap iterasi, kita menghitung indeks `mid` sebagai `low + (high - low) / 2` (untuk mencegah overflow). Kita membandingkan elemen di `arr[mid]` dengan nilai target. Jika `arr[mid]` sama dengan target, kita telah menemukan elemen tersebut. Jika `arr[mid]` lebih kecil dari target, kita tahu bahwa target (jika ada) harus berada di sisi kanan `mid`, jadi kita set `low = mid + 1`. Sebaliknya, jika `arr[mid]` lebih besar dari target, target harus berada di sisi kiri `mid`, sehingga kita set `high = mid - 1`. Proses ini berlanjut sampai `low > high`, yang berarti target tidak ditemukan.

Keunggulan utama Binary Search terletak pada efisiensinya. Karena setiap langkah memangkas setengah dari rentang pencarian, kompleksitas waktu algoritma ini adalah **O(log N)**, di mana N adalah jumlah elemen dalam array. Ini jauh lebih cepat daripada pencarian linear O(N) untuk array besar. Selain mencari elemen spesifik, Binary Search juga sering digunakan dalam competitive programming untuk mencari "jawaban" (disebut "binary search on answer") ketika fungsi yang harus dioptimalkan bersifat monotonik, atau untuk menemukan batas bawah/atas (seperti `std::lower_bound` dan `std::upper_bound` di C++).

```
int binary_search(const std::vector<int>& arr, int target) {
    int low = 0;
    int high = arr.size() - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2; // Mencegah overflow
        if (arr[mid] == target) {
            return mid; // Ditemukan
        } else if (arr[mid] < target) {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }
    return -1; // Tidak ditemukan
}
```

💡 **Fun Fact:** Meskipun konsepnya sederhana, Binary Search seringkali ditulis dengan kesalahan implementasi yang halus, terutama dalam penentuan kondisi batas atau perhitungan indeks tengah, bahkan oleh programmer berpengalaman.
