## ⚡ Competitive Programming Concept: 0/1 Knapsack Problem

**Category:** DP
**TL;DR:** Masalah Knapsack 0/1 mencari kombinasi item dengan bobot dan nilai tertentu untuk dimasukkan ke dalam ransel berkapasitas terbatas sehingga total nilai item yang dibawa menjadi maksimal, di mana setiap item hanya bisa diambil sekali atau tidak sama sekali.

Masalah Knapsack 0/1 adalah salah satu masalah optimasi klasik dalam ilmu komputer. Anda diberikan serangkaian item, di mana setiap item memiliki bobot (weight) dan nilai (value) tertentu. Anda juga memiliki ransel dengan kapasitas bobot maksimum yang terbatas. Tujuannya adalah memilih subset item untuk dimasukkan ke dalam ransel sehingga total nilai item yang dibawa adalah yang terbesar, tanpa melebihi kapasitas ransel. Sebutan '0/1' menunjukkan bahwa untuk setiap item, kita hanya memiliki dua pilihan: mengambilnya secara utuh (1) atau tidak mengambilnya sama sekali (0); tidak ada pengambilan sebagian.

Untuk menyelesaikan masalah ini, kita dapat menggunakan pendekatan Dynamic Programming (DP). Kita dapat mendefinisikan `dp[j]` sebagai nilai maksimum yang bisa kita dapatkan dengan kapasitas ransel `j`. Ketika kita mempertimbangkan item ke-`i` dengan bobot `w_i` dan nilai `v_i`, kita memiliki dua opsi: tidak mengambil item tersebut, atau mengambilnya. Jika kita tidak mengambil item ke-`i`, nilai maksimum untuk kapasitas `j` tetap sama dengan nilai maksimum yang bisa didapatkan tanpa item ke-`i` (`dp[j]` dari iterasi sebelumnya).

Jika kita memutuskan untuk mengambil item ke-`i`, ini hanya mungkin jika kapasitas ransel `j` cukup besar (`j >= w_i`). Dalam kasus ini, nilai yang kita dapatkan adalah `v_i` ditambah nilai maksimum yang bisa kita dapatkan dari kapasitas sisa `j - w_i` (dari item-item sebelumnya). Oleh karena itu, transisi DP untuk `dp[j]` saat mempertimbangkan item ke-`i` adalah `dp[j] = max(dp[j], dp[j - w_i] + v_i)`. Penting untuk mengiterasi kapasitas `j` dari `W` (kapasitas maksimum) ke bawah (`weights[i]`) agar setiap item hanya dipertimbangkan satu kali per iterasi item.

Kompleksitas waktu dari solusi DP ini adalah O(N * W), di mana N adalah jumlah item dan W adalah kapasitas maksimum ransel. Kompleksitas ruangnya dapat dioptimalkan menjadi O(W) dengan menggunakan array 1-dimensi karena kita hanya memerlukan nilai dari iterasi item sebelumnya. Inisialisasi array `dp` dengan nol, karena ransel kosong memiliki nilai nol.

```
int knapsack(int W, const std::vector<int>& weights, const std::vector<int>& values) {
    int n = weights.size();
    std::vector<int> dp(W + 1, 0);

    for (int i = 0; i < n; ++i) {
        for (int j = W; j >= weights[i]; --j) {
            dp[j] = std::max(dp[j], dp[j - weights[i]] + values[i]);
        }
    }
    return dp[W];
}
```

💡 **Fun Fact:** Masalah Knapsack dinamakan demikian karena membayangkan seseorang yang sedang mengemas barang-barang paling berharga ke dalam ransel (knapsack) mereka sebelum melakukan perjalanan. Meskipun dalam bentuk umumnya ia adalah masalah NP-hard, solusi Dynamic Programming yang pseudo-polinomial membuatnya sangat berguna dalam praktik.
