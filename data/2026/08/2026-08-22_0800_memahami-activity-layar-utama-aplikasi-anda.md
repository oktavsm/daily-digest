## 🤖 Android Concept: Memahami Activity, Layar Utama Aplikasi Anda

**Category:** UI
**TL;DR:** Activity adalah komponen fundamental yang menyediakan satu layar antarmuka pengguna (UI) interaktif untuk interaksi pengguna dalam aplikasi Android Anda.

Activity adalah salah satu blok bangunan paling dasar di Android. Bayangkan setiap layar yang Anda lihat di aplikasi, seperti layar login, daftar belanja, atau profil pengguna — itu semua biasanya diwakili oleh sebuah Activity. Setiap Activity bertanggung jawab untuk menyediakan jendela visual di mana aplikasi Anda dapat menggambar UI dan menerima interaksi dari pengguna, fokus pada satu tugas atau tindakan yang bisa dilakukan pengguna. Sebuah aplikasi Android biasanya terdiri dari beberapa Activity yang bekerja bersama.

Setiap Activity memiliki siklus hidup (lifecycle) yang dikelola oleh sistem Android, yang mencakup berbagai status seperti `onCreate`, `onStart`, `onResume`, `onPause`, `onStop`, dan `onDestroy`. Memahami siklus hidup ini sangat krusial, karena di sinilah Anda akan menulis kode untuk mengelola sumber daya, menyimpan data aplikasi ketika Activity dihancurkan sementara (misalnya karena rotasi layar atau panggilan telepon masuk), dan memastikan aplikasi Anda berjalan efisien serta responsif. Sistem Android akan memanggil metode-metode ini pada berbagai tahapan untuk memberi tahu Activity tentang perubahan statusnya.

Secara praktis, sebuah Activity akan selalu terhubung dengan file layout XML yang mendefinisikan tampilan antarmuka penggunanya. Di dalam kelas Kotlin Activity Anda, metode `setContentView()` akan digunakan untuk 'mengikat' layout XML tersebut, sehingga tampilan visual yang Anda desain di XML dapat ditampilkan kepada pengguna. Dari titik ini, Anda dapat mulai menambahkan logika untuk merespons input pengguna, menampilkan data, dan menavigasi ke Activity lain menggunakan objek `Intent`. Activity berfungsi sebagai jembatan utama antara logika aplikasi Anda dan antarmuka yang dilihat serta diinteraksikan pengguna.

```
package com.example.aplikasiku

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        // Di sini Anda bisa mulai inisialisasi UI atau logika lainnya
    }
}
```
