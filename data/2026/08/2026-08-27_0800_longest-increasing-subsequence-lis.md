## ⚡ Competitive Programming Concept: Longest Increasing Subsequence (LIS)

**Category:** DP
**TL;DR:** Mencari subsequence terpanjang dari sebuah array di mana setiap elemen dalam subsequence tersebut lebih besar dari elemen sebelumnya.

Longest Increasing Subsequence (LIS) adalah masalah klasik dalam pemrograman dinamis yang meminta kita untuk menemukan panjang subsequence terpanjang dari sebuah array, sedemikian rupa sehingga semua elemen dalam subsequence tersebut dalam urutan menaik. Sebagai contoh, jika kita memiliki array `[10, 22, 9, 33, 21, 50, 41, 60]`, salah satu LIS adalah `[10, 22, 33, 50, 60]` dengan panjang 5. Penting untuk diingat bahwa subsequence tidak harus terdiri dari elemen-elemen yang berdekatan di array asli.

Untuk menyelesaikan masalah LIS dengan pendekatan Dynamic Programming (DP) dasar, kita dapat mendefinisikan `dp[i]` sebagai panjang LIS yang berakhir dengan elemen `arr[i]`. Setiap elemen `arr[i]` sendiri bisa membentuk LIS dengan panjang 1, jadi kita menginisialisasi semua nilai `dp[i]` dengan 1. Kemudian, kita akan membangun solusi secara iteratif.

Proses transisi untuk `dp[i]` melibatkan melihat semua elemen `arr[j]` yang muncul sebelum `arr[i]` (yaitu, `j < i`). Jika `arr[i]` lebih besar dari `arr[j]`, itu berarti `arr[i]` bisa memperpanjang LIS yang berakhir di `arr[j]`. Jadi, kita bisa memperbarui `dp[i]` dengan `max(dp[i], dp[j] + 1)`. Kita mencari `max` karena kita ingin LIS terpanjang yang mungkin berakhir di `arr[i]`. Setelah kita menghitung semua nilai `dp[i]` untuk semua `i`, panjang LIS keseluruhan adalah nilai maksimum yang ditemukan dalam array `dp`.

Algoritma DP dasar ini memiliki kompleksitas waktu O(N^2) karena kita memiliki dua loop bersarang (satu untuk `i` dan satu untuk `j`), di mana N adalah ukuran array. Kompleksitas ruangnya adalah O(N) untuk menyimpan array `dp`. Meskipun ada solusi yang lebih cepat (O(N log N) menggunakan binary search), pendekatan O(N^2) ini adalah fondasi yang bagus untuk memahami konsep DP dalam LIS.

```
std::vector<int> arr = {10, 22, 9, 33, 21, 50, 41, 60};
if (arr.empty()) { /* handle empty array */ }
std::vector<int> dp(arr.size(), 1);
int max_len = 1;
for (int i = 1; i < arr.size(); ++i) {
    for (int j = 0; j < i; ++j) {
        if (arr[i] > arr[j]) {
            dp[i] = std::max(dp[i], dp[j] + 1);
        }
    }
    max_len = std::max(max_len, dp[i]);
}
// Variabel max_len kini menyimpan panjang LIS
```

💡 **Fun Fact:** Selain solusi O(N^2) yang menggunakan dua loop, LIS juga dapat diselesaikan dalam O(N log N) menggunakan pendekatan yang menggabungkan Dynamic Programming dengan Binary Search. Solusi yang lebih efisien ini tidak secara langsung membangun subsequence, melainkan mempertahankan array 'ekor' yang merepresentasikan kemungkinan akhiran LIS terpendek dengan panjang tertentu.
