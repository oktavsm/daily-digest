## ⚡ Competitive Programming Concept: Disjoint Set Union (DSU)

**Category:** Data Structure
**TL;DR:** DSU adalah struktur data yang efisien untuk melacak partisi set elemen-elemen ke dalam sejumlah set yang tidak tumpang tindih, dengan dua operasi utama: `find` untuk mencari perwakilan set dan `union` untuk menggabungkan dua set.

Disjoint Set Union (DSU), juga dikenal sebagai Union-Find, adalah struktur data yang dirancang untuk mengelola koleksi elemen yang dibagi ke dalam sejumlah set yang tidak tumpang tindih. Dua operasi utamanya adalah `find`, yang mengidentifikasi perwakilan (root) dari set tempat suatu elemen berada, dan `union`, yang menggabungkan dua set menjadi satu. DSU sangat berguna untuk masalah yang melibatkan pengelompokan elemen dan pemeriksaan konektivitas antar elemen.

Implementasi DSU biasanya menggunakan array `parent` di mana `parent[i]` menyimpan parent dari elemen `i`. Jika `parent[i] == i`, maka `i` adalah perwakilan dari set tersebut. Untuk mengoptimalkan kinerja, DSU menggunakan dua teknik kunci: **Path Compression** pada operasi `find`, yang meratakan pohon dengan membuat semua node di jalur langsung menunjuk ke root; dan **Union by Size/Rank** pada operasi `union`, yang selalu menggabungkan pohon yang lebih kecil ke pohon yang lebih besar (atau pohon dengan rank lebih rendah ke yang lebih tinggi) untuk menjaga pohon tetap dangkal. (Contoh kode di bawah menunjukkan `find` dengan path compression dan `union` yang disederhanakan tanpa optimasi size/rank untuk ringkasan).

Dengan optimisasi ini, DSU menjadi sangat efisien. Operasi `find` dan `union` memiliki kompleksitas waktu amortisasi yang hampir konstan, dilambangkan dengan O(α(N)), di mana α adalah fungsi Ackermann terbalik. Fungsi Ackermann terbalik tumbuh sangat lambat, sehingga untuk ukuran input praktis (N hingga 10^18), α(N) nilainya kurang dari 5. Hal ini membuat DSU ideal untuk masalah seperti menentukan komponen terhubung dalam graf, algoritma Kruskal untuk Minimum Spanning Tree (MST), atau melacak konektivitas jaringan secara dinamis.

```
vector<int> parent; // Asumsi diinisialisasi: parent[i] = i untuk semua i

int find_set(int v) {
    if (v == parent[v])
        return v;
    return parent[v] = find_set(parent[v]); // Path compression
}

void union_sets(int a, int b) {
    a = find_set(a);
    b = find_set(b);
    if (a != b)
        parent[b] = a; // Union sederhana, tanpa optimasi rank/size
}
```

💡 **Fun Fact:** Fungsi Ackermann terbalik (inverse Ackermann function), yang mendefinisikan kompleksitas waktu DSU, tumbuh sangat lambat sehingga untuk setiap input praktis, nilainya kurang dari 5. Ini berarti DSU adalah salah satu struktur data yang paling efisien secara teoritis.
