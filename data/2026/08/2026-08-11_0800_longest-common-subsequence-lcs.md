## ⚡ Competitive Programming Concept: Longest Common Subsequence (LCS)

**Category:** DP
**TL;DR:** LCS adalah masalah mencari subsequence terpanjang yang sama dari dua string, diselesaikan secara efisien menggunakan Dynamic Programming.

Longest Common Subsequence (LCS) adalah masalah klasik dalam ilmu komputer yang bertujuan untuk menemukan subsequence terpanjang yang muncul di dua atau lebih string. Perlu diingat bahwa *subsequence* tidak harus berurutan secara *contiguous* (berdampingan) seperti *substring*, melainkan hanya perlu menjaga urutan relatif karakternya. Misalnya, 'ACE' adalah subsequence dari 'ABCDE', tetapi 'AEC' bukan. Masalah ini memiliki banyak aplikasi, termasuk dalam biologi komputasi (perbandingan DNA), sistem kontrol versi (diff tool), dan deteksi plagiarisme.

LCS dapat diselesaikan secara efisien menggunakan Dynamic Programming (DP) karena memenuhi dua properti utama DP: *overlapping subproblems* dan *optimal substructure*. Kita bisa mendefinisikan `dp[i][j]` sebagai panjang LCS dari prefiks string pertama `s1` sepanjang `i` karakter dan prefiks string kedua `s2` sepanjang `j` karakter. Relasi rekursifnya bergantung pada apakah karakter `s1[i-1]` dan `s2[j-1]` (menggunakan 0-indeks) sama atau berbeda.

Jika `s1[i-1] == s2[j-1]`, berarti kedua karakter terakhir sama dan bisa menjadi bagian dari LCS. Maka, `dp[i][j] = 1 + dp[i-1][j-1]`. Ini berarti kita mengambil LCS dari prefiks sebelumnya dan menambahkan satu karakter yang cocok. Namun, jika `s1[i-1] != s2[j-1]`, maka kita tidak bisa menyertakan kedua karakter tersebut secara bersamaan. Kita harus mengambil maksimum dari dua kemungkinan: `dp[i-1][j]` (mengabaikan `s1[i-1]`) atau `dp[i][j-1]` (mengabaikan `s2[j-1]`). Base case-nya adalah `dp[i][0] = 0` dan `dp[0][j] = 0` untuk semua `i` dan `j`, karena LCS dengan string kosong selalu 0.

Kita mengisi tabel `dp` berukuran `(m+1) x (n+1)` (dimana `m` dan `n` adalah panjang `s1` dan `s2`) secara iteratif. Setiap sel membutuhkan waktu `O(1)` untuk dihitung. Oleh karena itu, kompleksitas waktu keseluruhan adalah `O(m * n)`. Kompleksitas ruang juga `O(m * n)` untuk menyimpan tabel DP. Dengan sedikit optimasi, kompleksitas ruang bisa dikurangi menjadi `O(min(m, n))` dengan hanya menyimpan dua baris atau kolom terakhir dari tabel.

```
int longestCommonSubsequence(const std::string& s1, const std::string& s2) {
    int m = s1.length(), n = s2.length();
    std::vector<std::vector<int>> dp(m + 1, std::vector<int>(n + 1, 0));

    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (s1[i-1] == s2[j-1]) {
                dp[i][j] = 1 + dp[i-1][j-1];
            } else {
                dp[i][j] = std::max(dp[i-1][j], dp[i][j-1]);
            }
        }
    }
    return dp[m][n];
}
```

💡 **Fun Fact:** LCS adalah dasar dari algoritma `diff` yang digunakan dalam Git dan banyak sistem kontrol versi lainnya untuk menunjukkan perubahan antara dua versi file. Selain itu, ada varian LCS yang disebut 'LCS untuk banyak string', yang merupakan masalah NP-hard untuk jumlah string yang tidak terbatas, berbeda dengan LCS dua string yang merupakan polinomial.
