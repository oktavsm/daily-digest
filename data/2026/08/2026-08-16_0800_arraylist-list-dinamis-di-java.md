## ☕ Java Concept: ArrayList: List Dinamis di Java

**Category:** Collections
**TL;DR:** ArrayList adalah implementasi List yang paling sering digunakan, memungkinkan kita menyimpan urutan elemen dinamis yang dapat tumbuh atau menyusut sesuai kebutuhan tanpa harus menentukan ukurannya di awal.

ArrayList adalah salah satu kelas yang paling sering digunakan dalam Java Collections Framework, dirancang untuk menyimpan kumpulan objek yang berurutan. Berbeda dengan array standar di Java yang memiliki ukuran tetap setelah dibuat, ArrayList menyediakan array yang ukurannya dapat berubah secara dinamis (dynamically-sized array). Ini sangat berguna ketika Anda tidak tahu persis berapa banyak elemen yang akan Anda simpan selama program berjalan, karena ArrayList akan otomatis menyesuaikan kapasitasnya.

Cara kerja ArrayList cukup sederhana: di balik layar, ia sebenarnya menggunakan sebuah array biasa untuk menyimpan elemen-elemennya. Ketika Anda menambahkan elemen baru dan array internal sudah penuh, ArrayList akan secara otomatis membuat array baru yang lebih besar (misalnya, 1.5 kali ukuran sebelumnya), lalu menyalin semua elemen dari array lama ke array baru tersebut. Proses ini memungkinkan Anda untuk terus menambahkan elemen tanpa khawatir kehabisan ruang, meskipun perlu diingat bahwa proses penyalinan ini bisa memakan sedikit waktu.

Untuk menggunakan ArrayList, Anda perlu mengimpornya dari paket `java.util`. Deklarasinya menggunakan Generics, yang memungkinkan Anda menentukan tipe data spesifik dari objek yang akan disimpan, misalnya `ArrayList<String>` untuk menyimpan teks atau `ArrayList<Integer>` untuk angka bulat. Operasi dasar meliputi `add()` untuk menambah elemen, `get(index)` untuk mengambil elemen pada posisi tertentu, `remove(index)` atau `remove(object)` untuk menghapus elemen, dan `size()` untuk mengetahui jumlah elemen saat ini.

ArrayList sangat cocok digunakan ketika Anda membutuhkan daftar yang dapat diakses dengan cepat berdasarkan indeks (seperti array), dan Anda sering menambahkan atau menghapus elemen, terutama di bagian akhir daftar. Kelebihannya dalam fleksibilitas ukuran membuatnya menjadi pilihan utama dibandingkan array statis untuk banyak skenario, memberikan kemudahan dalam manajemen data berurutan.

```
import java.util.ArrayList;
import java.util.List;

public class ContohArrayList {
    public static void main(String[] args) {
        List<String> daftarNama = new ArrayList<>(); // Deklarasi & Inisialisasi
        daftarNama.add("Alice"); // Menambah elemen
        daftarNama.add("Bob");
        System.out.println("Daftar: " + daftarNama); // Output: [Alice, Bob]
        System.out.println("Pertama: " + daftarNama.get(0)); // Output: Alice
        daftarNama.remove(0); // Menghapus elemen pertama
        System.out.println("Daftar sekarang: " + daftarNama); // Output: [Bob]
    }
}
```

💡 **Fun Fact:** ArrayList menyimpan elemen-elemennya dalam sebuah array biasa di balik layar. Ketika kapasitas array internalnya penuh, ArrayList akan secara otomatis membuat array baru yang lebih besar (biasanya sekitar 1.5 kali ukuran semula) dan menyalin semua elemen lama ke array baru tersebut, yang terkadang bisa menjadi operasi yang relatif mahal.
