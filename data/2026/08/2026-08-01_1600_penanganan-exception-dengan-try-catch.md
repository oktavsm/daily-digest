## ☕ Java Concept: Penanganan Exception dengan try-catch

**Category:** Exception
**TL;DR:** Blok `try-catch` digunakan untuk menangani kesalahan (exceptions) yang mungkin terjadi saat program berjalan, mencegahnya dari crash secara tiba-tiba.

Dalam pemrograman Java, *exception* adalah sebuah peristiwa tak terduga yang mengganggu jalannya program secara normal. Bayangkan ketika program Anda mencoba membagi angka dengan nol, mengakses elemen di luar batas array, atau membaca file yang tidak ada – ini semua adalah contoh-contoh *exception*. Jika exception ini tidak ditangani, program Anda akan berhenti (crash) dan menampilkan pesan kesalahan yang tidak ramah pengguna. Penanganan exception adalah praktik penting untuk membangun aplikasi yang kokoh dan dapat diandalkan.

Untuk menangani situasi ini, Java menyediakan blok `try-catch`. Bagian kode yang berpotensi menimbulkan exception diletakkan di dalam blok `try`. Jika sebuah exception benar-benar terjadi di dalam blok `try`, eksekusi kode di `try` akan segera dihentikan, dan kontrol akan dialihkan ke blok `catch` yang sesuai. Blok `catch` inilah yang bertanggung jawab untuk "menangkap" exception tersebut dan menjalankan kode pemulihan atau penanganan yang telah Anda definisikan.

Setiap blok `catch` dirancang untuk menangani tipe exception tertentu (misalnya, `ArithmeticException`, `NumberFormatException`, `IOException`). Ini memungkinkan Anda untuk menulis logika penanganan yang spesifik untuk setiap jenis masalah. Dengan menggunakan `try-catch`, Anda tidak hanya mencegah program dari crash, tetapi juga dapat memberikan umpan balik yang informatif kepada pengguna, mencatat kesalahan untuk analisis lebih lanjut, atau bahkan mencoba melakukan pemulihan dari kesalahan tersebut agar program dapat terus berjalan dengan semestinya.

```
public class PembagianAman {
    public static void main(String[] args) {
        int angka1 = 10;
        int angka2 = 0; // Ini akan menyebabkan ArithmeticException

        try {
            int hasil = angka1 / angka2;
            System.out.println("Hasil pembagian: " + hasil);
        } catch (ArithmeticException e) {
            System.err.println("Terjadi kesalahan: " + e.getMessage());
            System.err.println("Tidak dapat melakukan pembagian dengan nol!");
        }
    }
}
```

💡 **Fun Fact:** Java adalah salah satu bahasa pemrograman awal yang mengimplementasikan konsep exception handling secara ekstensif, bahkan membedakan antara *checked exceptions* (yang wajib ditangani atau dideklarasikan) dan *unchecked exceptions* (runtime exceptions yang tidak wajib ditangani secara eksplisit), sebuah fitur yang dirancang untuk meningkatkan robustitas kode.
