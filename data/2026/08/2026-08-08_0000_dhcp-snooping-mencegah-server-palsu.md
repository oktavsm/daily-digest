## 🌐 Networking Concept: DHCP Snooping: Mencegah Server Palsu

**Category:** Security
**TL;DR:** Fitur keamanan pada switch untuk mencegah server DHCP palsu dan memastikan klien hanya menerima alamat IP dari sumber yang terpercaya.

Dalam jaringan modern, Dynamic Host Configuration Protocol (DHCP) sangat vital untuk otomatisasi alokasi alamat IP. Namun, kerentanan DHCP dapat dieksploitasi oleh aktor jahat yang mencoba menyebarkan server DHCP palsu (rogue DHCP server). Server palsu ini dapat memberikan alamat IP, gateway, atau DNS server yang salah kepada klien, mengarahkan lalu lintas melalui perangkat penyerang (man-in-the-middle) atau bahkan menyebabkan denial-of-service dengan menyebarkan alamat IP yang tidak valid.

DHCP Snooping adalah fitur keamanan Layer 2 yang diimplementasikan pada switch untuk memerangi ancaman ini. Cara kerjanya adalah dengan memantau lalu lintas DHCP dan mengklasifikasikan port switch menjadi dua jenis: 'trusted' dan 'untrusted'. Port 'trusted' adalah port yang terhubung ke server DHCP yang sah atau ke switch lain yang juga terpercaya. Sedangkan port 'untrusted' adalah port yang terhubung ke perangkat pengguna akhir. Switch hanya akan mengizinkan paket DHCP server (offer, ack) untuk masuk melalui port 'trusted' dan akan memblokir paket-paket serupa yang datang dari port 'untrusted', sehingga mencegah server DHCP palsu.

Selain memblokir server DHCP ilegal, DHCP Snooping juga membangun dan memelihara DHCP Snooping Binding Database. Database ini adalah tabel yang mencatat MAC address, alamat IP yang diberikan, nomor VLAN, dan port switch dari setiap perangkat yang sah menerima konfigurasi DHCP. Informasi ini sangat berharga dan dapat digunakan oleh fitur keamanan Layer 2 lainnya seperti Dynamic ARP Inspection (DAI) dan IP Source Guard untuk memberikan lapisan perlindungan tambahan terhadap serangan ARP spoofing atau IP spoofing.

Dengan mengimplementasikan DHCP Snooping, administrator jaringan dapat memastikan integritas dan ketersediaan layanan DHCP. Ini mencegah penyerang mengambil alih kontrol konfigurasi IP klien, melindungi klien dari pengalihan lalu lintas yang tidak sah, dan meminimalkan risiko serangan berbasis alamat IP, menjadikan jaringan lebih aman dan stabil.

```
ip dhcp snooping trust
```

💡 **Fun Fact:** DHCP Snooping adalah bagian penting dari strategi pertahanan keamanan Layer 2, sering kali diimplementasikan bersama dengan Dynamic ARP Inspection (DAI) dan IP Source Guard untuk menciptakan perlindungan berlapis terhadap berbagai jenis serangan berbasis alamat.
