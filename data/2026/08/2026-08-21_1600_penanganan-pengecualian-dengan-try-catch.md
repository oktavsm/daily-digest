## ☕ Java Concept: Penanganan Pengecualian dengan try-catch

**Category:** Exception
**TL;DR:** Pengecualian (exceptions) adalah kejadian tak terduga yang mengganggu aliran normal program, dan kita menanganinya menggunakan blok `try-catch` untuk mencegah program crash serta membuatnya lebih robust.

Dalam pemrograman Java, tidak jarang terjadi situasi di mana sesuatu berjalan tidak sesuai rencana, seperti mencoba membuka file yang tidak ada, membagi angka dengan nol, atau mengakses elemen array di luar batas indeksnya. Kejadian tak terduga inilah yang kita sebut sebagai 'pengecualian' atau 'exceptions'. Jika tidak ditangani, pengecualian akan menyebabkan program Anda berhenti secara paksa (crash), memberikan pengalaman yang buruk bagi pengguna.

Untuk mengatasi hal ini, Java menyediakan mekanisme penanganan pengecualian menggunakan blok `try-catch`. Blok `try` digunakan untuk membungkus kode yang berpotensi menimbulkan pengecualian. Jika sebuah pengecualian terjadi di dalam blok `try`, eksekusi kode di dalam blok `try` akan dihentikan, dan kontrol akan segera dialihkan ke blok `catch` yang sesuai. Blok `catch` sendiri berisi kode yang akan dijalankan untuk menangani pengecualian tersebut, misalnya dengan menampilkan pesan error kepada pengguna atau melakukan logging kesalahan.

Dengan menggunakan `try-catch`, kita dapat 'menangkap' dan mengelola pengecualian yang terjadi, alih-alih membiarkan program crash. Ini memungkinkan program untuk pulih dari kesalahan, menampilkan pesan yang informatif, atau bahkan mencoba alternatif lain, sehingga program menjadi lebih tangguh (robust) dan mudah digunakan. Penanganan pengecualian adalah praktik fundamental untuk membangun aplikasi Java yang stabil dan andal.

```
public class DivideSafely {
    public static void main(String[] args) {
        int num = 10;
        int div = 0; // Ini akan menyebabkan ArithmeticException

        try {
            int result = num / div;
            System.out.println("Hasil: " + result);
        } catch (ArithmeticException e) {
            System.err.println("Error: Tidak bisa membagi dengan nol!");
        }
        System.out.println("Program berlanjut.");
    }
}
```

💡 **Fun Fact:** Java memiliki dua jenis pengecualian utama: 'checked' (harus ditangani secara eksplisit oleh programmer) dan 'unchecked' (tidak wajib ditangani). Desain ini, terutama untuk checked exceptions, bertujuan untuk mendorong penulisan kode yang lebih robust, meskipun terkadang dianggap menambah verbositas.
