## 🌐 Networking Concept: Redundansi Gateway dengan HSRP

**Category:** Routing
**TL;DR:** HSRP menyediakan redundansi gateway default untuk host di LAN, memastikan konektivitas jaringan tetap berjalan meskipun router utama gagal.

Selamat pagi, mahasiswa sekalian! Hari ini, tanggal 12 Agustus 2026, kita akan menjelajahi konsep krusial untuk menjaga ketersediaan jaringan, yaitu Hot Standby Router Protocol (HSRP). Dalam desain jaringan standar, host biasanya hanya memiliki satu alamat IP sebagai gateway default untuk keluar dari subnet lokal. Jika router gateway tunggal tersebut mengalami kegagalan, maka seluruh host di subnet tersebut akan kehilangan konektivitas ke jaringan eksternal, menyebabkan downtime yang signifikan. HSRP hadir sebagai solusi cerdas untuk mengatasi single point of failure ini dengan menyediakan mekanisme failover otomatis.

HSRP adalah protokol redundansi gateway layer 3 yang dikembangkan secara proprietary oleh Cisco. Cara kerjanya melibatkan sekelompok router yang bekerja sama untuk mempresentasikan satu alamat IP virtual dan satu alamat MAC virtual yang sama sebagai gateway default kepada host-host di LAN. Di antara grup router tersebut, satu router akan diidentifikasi sebagai router "Active", yang bertanggung jawab untuk meneruskan semua traffic yang ditujukan ke gateway virtual. Router lainnya menjadi "Standby", yang siap siaga untuk mengambil alih peran Active jika router Active saat ini mengalami kegagalan.

Router Active dan Standby saling berkomunikasi secara teratur melalui pesan Hello untuk memantau status satu sama lain. Dengan HSRP, ketika router Active mengalami kegagalan (misalnya, karena mati atau interface-nya down), router Standby secara otomatis dan cepat akan mengambil alih peran Active, menggunakan alamat IP dan MAC virtual yang sama. Proses failover ini terjadi secara transparan bagi host di jaringan; host tidak menyadari adanya perubahan pada router fisik yang melayani mereka, sehingga konektivitas tetap terjaga tanpa gangguan signifikan.

Konfigurasi HSRP dalam Cisco Packet Tracer cukup sederhana, melibatkan penentuan nomor grup standby, alamat IP virtual yang akan digunakan sebagai gateway default, dan prioritas pada setiap router. Router dengan prioritas tertinggi dalam grup yang sama akan menjadi Active secara default. Kita juga bisa mengkonfigurasi preemption, yang memungkinkan router dengan prioritas lebih tinggi yang baru pulih dari kegagalan untuk kembali mengambil alih peran Active. Ini adalah protokol fundamental untuk membangun jaringan yang tangguh dan selalu tersedia, sangat penting dalam lingkungan bisnis modern.

```
standby 1 ip 192.168.1.254
```

💡 **Fun Fact:** HSRP adalah protokol eksklusif milik Cisco Systems. Jika Anda membutuhkan protokol redundansi gateway yang bersifat standar terbuka (vendor-agnostic), Anda akan menggunakan Virtual Router Redundancy Protocol (VRRP), yang memiliki fungsi dan cara kerja yang sangat mirip dengan HSRP.
