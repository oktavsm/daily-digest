## 🤖 Android Concept: Activity Lifecycle

**Category:** Architecture
**TL;DR:** Memahami Activity Lifecycle membantu kita mengelola bagaimana Activity dibuat, dihentikan, dan dihancurkan, memastikan aplikasi berjalan efisien dan bebas bug.

Setiap kali Anda membuka sebuah aplikasi atau berpindah antar layar di Android, Anda berinteraksi dengan sebuah komponen yang disebut `Activity`. `Activity` adalah satu layar tunggal dalam aplikasi Anda, seperti layar login, layar daftar produk, atau layar detail. Sama seperti kehidupan manusia, sebuah `Activity` juga memiliki siklus hidup (lifecycle) dari mulai "lahir" (dibuat), "hidup" (terlihat dan interaktif), "berhenti sementara", hingga akhirnya "mati" (dihancurkan). Memahami siklus hidup ini sangat krusial untuk membangun aplikasi Android yang stabil dan responsif.

Siklus hidup `Activity` diatur oleh serangkaian metode callback yang dipanggil oleh sistem Android pada tahapan tertentu. Beberapa callback penting meliputi `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()`. Misalnya, `onCreate()` dipanggil hanya sekali ketika `Activity` pertama kali dibuat, cocok untuk inisialisasi awal seperti mengatur layout dan mengikat data. `onStart()` dipanggil saat Activity akan menjadi terlihat bagi pengguna, sedangkan `onResume()` dipanggil saat Activity benar-benar di latar depan dan siap untuk interaksi.

Mengapa ini penting? Dengan memahami kapan masing-masing metode callback dipanggil, Anda dapat menempatkan logika aplikasi Anda pada tempat yang tepat. Contohnya, Anda mungkin ingin menghentikan pemutaran video di `onPause()` agar tidak menghabiskan sumber daya saat pengguna beralih ke aplikasi lain, dan melanjutkannya di `onResume()`. Kesalahan dalam mengelola siklus hidup Activity dapat menyebabkan memory leak, crash aplikasi, atau pengalaman pengguna yang buruk. Ini adalah dasar yang kokoh untuk pengembangan Android lebih lanjut.

```
import android.os.Bundle
import android.util.Log
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {

    private val TAG = "MainActivity"

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        Log.d(TAG, "onCreate: Activity created.")
    }

    override fun onStart() {
        super.onStart()
        Log.d(TAG, "onStart: Activity is visible.")
    }
}
```

💡 **Fun Fact:** Pada tahun-tahun awal Android, manajemen Activity Lifecycle sering menjadi sumber bug yang sulit dilacak. Munculnya ViewModel dari Android Jetpack di kemudian hari sangat membantu memisahkan logika UI dari siklus hidup Activity, membuat pengembangan lebih mudah dan robust.
