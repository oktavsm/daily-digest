## ⚡ Competitive Programming Concept: Segment Tree: Query & Update Rentang

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data pohon yang memungkinkan query dan update pada rentang (range) dengan efisien, seringkali dalam waktu logaritmik.

Kompleksitas waktu untuk membangun Segment Tree adalah O(N), di mana N adalah ukuran array. Baik operasi query maupun update memiliki kompleksitas waktu O(log N) karena pada setiap langkah rekursi, kita membagi rentang menjadi dua dan hanya melintasi sejumlah kecil cabang pohon. Kompleksitas ruang Segment Tree adalah O(N), karena dalam implementasi berbasis array, biasanya dibutuhkan sekitar 4N ruang untuk menyimpan semua node.

```
/* Asumsi: 'tree' adalah global/class vector<int> berukuran 4*N,
'arr' adalah array asli. Fungsi build(1, 0, N-1) dipanggil sekali. */
int query(int node, int s, int e, int L, int R) {
    if (R < s || e < L) return 0; // No overlap
    if (L <= s && e <= R) return tree[node]; // Complete overlap
    int mid = (s + e) / 2;
    return query(2*node, s, mid, L, R) + query(2*node+1, mid+1, e, L, R);
}
void update(int node, int s, int e, int idx, int val) {
    if (s == e) { tree[node] = val; return; } // Found leaf
    int mid = (s + e) / 2;
    if (idx <= mid) update(2*node, s, mid, idx, val);
    else update(2*node+1, mid+1, e, idx, val);
    tree[node] = tree[2*node] + tree[2*node+1]; // Update parent
}
```

💡 **Fun Fact:** Segment Tree sangat serbaguna dan dapat diadaptasi untuk mendukung berbagai jenis query (sum, min, max, XOR, GCD) dan bahkan update lebih kompleks seperti *lazy propagation* untuk update rentang besar, menjadikannya salah satu struktur data yang paling fundamental dan sering muncul dalam competitive programming.
