## ☕ Java Concept: Kelas dan Objek: Fondasi OOP

**Category:** OOP
**TL;DR:** Kelas adalah cetak biru (blueprint) untuk membuat objek, yang merupakan instance nyata dari kelas tersebut dengan data dan perilaku spesifik.

Dalam pemrograman berorientasi objek (OOP) seperti Java, konsep "Kelas" dan "Objek" adalah inti fundamental yang harus dipahami. Bayangkan sebuah "Kelas" sebagai cetak biru atau resep untuk membuat sesuatu; ia mendefinisikan karakteristik (data atau atribut) dan tindakan (perilaku atau metode) apa yang dimiliki oleh entitas tersebut, tetapi belum menjadi sesuatu yang nyata. Misalnya, kelas `Mobil` mungkin mendefinisikan bahwa setiap mobil memiliki `warna`, `merk`, dan `tahun`, serta kemampuan untuk `start()` atau `rem()`.

"Objek" adalah perwujudan nyata atau instance dari sebuah kelas. Menggunakan analogi cetak biru, jika `Mobil` adalah cetak birunya, maka mobil `Honda Civic Merah tahun 2023` adalah sebuah objek. Objek ini memiliki nilai-nilai spesifik untuk karakteristik yang didefinisikan oleh kelasnya (misalnya, `warna="Merah"`, `merk="Honda Civic"`, `tahun=2023`) dan dapat melakukan tindakan yang ditentukan (seperti `start()` atau `rem()`). Setiap objek dibuat dari kelas dan memiliki identitasnya sendiri.

Pentingnya kelas dan objek terletak pada kemampuannya untuk mengorganisir kode secara logis dan modular. Mereka mempromosikan prinsip enkapsulasi, di mana data (variabel anggota atau atribut) dan metode (fungsi atau perilaku) yang beroperasi pada data tersebut dibungkus bersama dalam satu unit. Ini membuat kode lebih mudah dikelola, dipahami, dan digunakan kembali, karena kita dapat membuat banyak objek dari satu kelas tanpa perlu menulis ulang logikanya.

```
public class Kucing {
    String nama;
    String ras;

    public Kucing(String namaKucing, String rasKucing) {
        this.nama = namaKucing;
        this.ras = rasKucing;
    }

    public void meong() {
        System.out.println(nama + " berbunyi meong!");
    }

    public static void main(String[] args) {
        Kucing myCat = new Kucing("Milo", "Persia");
        System.out.println("Nama: " + myCat.nama + ", Ras: " + myCat.ras);
        myCat.meong();
    }
}
```

💡 **Fun Fact:** Java dijuluki sebagai bahasa "Pure Object-Oriented" pada awalnya karena hampir semua hal, kecuali tipe data primitif, direpresentasikan sebagai objek. Filosofi "Write Once, Run Anywhere" Java juga sangat didukung oleh cara objek berinteraksi dalam Java Virtual Machine (JVM).
