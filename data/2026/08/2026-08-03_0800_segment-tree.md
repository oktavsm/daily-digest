## ⚡ Competitive Programming Concept: Segment Tree

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data pohon biner yang efisien untuk melakukan query pada rentang (range query) dan update pada titik atau rentang (point/range update) dalam sebuah array.

Segment Tree adalah struktur data pohon biner yang kuat, dirancang untuk menyimpan informasi agregat tentang interval atau segmen dari sebuah array. Konsep utamanya adalah membagi array asli menjadi segmen-segmen yang lebih kecil secara rekursif, dengan setiap node dalam pohon merepresentasikan suatu segmen. Tujuan utama Segment Tree adalah memungkinkan operasi query (misalnya, mencari sum, min, atau max dalam suatu rentang) dan operasi update (mengubah nilai pada satu indeks atau dalam suatu rentang) dilakukan dengan sangat efisien.

Setiap node di Segment Tree mewakili suatu rentang indeks dari array asli. Node root mencakup seluruh rentang array, sedangkan node daun (leaf nodes) merepresentasikan elemen tunggal dari array. Node internal menyimpan hasil agregasi (misalnya, jumlah, nilai minimum) dari rentang yang diwakili oleh kedua anak-anaknya. Proses pembangunan pohon (build) dilakukan secara rekursif dengan pendekatan "divide and conquer", di mana setiap node membagi rentangnya menjadi dua sub-rentang untuk anak kiri dan kanan, lalu menggabungkan hasilnya.

Ada dua operasi utama: query dan update. Saat melakukan query untuk suatu rentang [L, R], pohon Segment Tree akan dilalui secara rekursif. Jika rentang yang diwakili oleh suatu node sepenuhnya berada dalam [L, R], kita langsung menggunakan nilai agregat yang tersimpan di node tersebut. Jika tidak, pencarian dilanjutkan ke anak-anaknya. Proses serupa berlaku untuk operasi update. Kedua operasi ini memiliki kompleksitas waktu O(log N), di mana N adalah ukuran array asli.

Pembangunan pohon awal membutuhkan O(N) waktu untuk mengisi semua node dengan nilai agregat yang benar. Ruang yang dibutuhkan oleh Segment Tree adalah O(N) karena pohon dapat memiliki hingga 4N node untuk array berukuran N, yang memastikan bahwa setiap segmen dapat direpresentasikan.

```
vector<long long> tree_data; // Stores segment sums
vector<long long> original_arr; // The array we're building from
int N_size;

void build_tree(int node, int start, int end) {
    if (start == end) {
        tree_data[node] = original_arr[start];
    } else {
        int mid = (start + end) / 2;
        build_tree(2 * node, start, mid);
        build_tree(2 * node + 1, mid + 1, end);
        tree_data[node] = tree_data[2 * node] + tree_data[2 * node + 1];
    }
}
// Usage: N_size = arr.size(); tree_data.resize(4 * N_size); build_tree(1, 0, N_size - 1);
```

💡 **Fun Fact:** Segment Tree sering dianggap sebagai salah satu struktur data "fundamental" yang harus dikuasai untuk kompetisi programming, karena menjadi dasar bagi banyak solusi masalah yang lebih kompleks atau varian seperti Lazy Segment Tree.
