## ⚡ Competitive Programming Concept: Segment Tree: Range Query Update

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data pohon yang efisien untuk melakukan operasi query dan update pada rentang (range) indeks dalam array.

Segment Tree adalah struktur data pohon biner yang digunakan untuk menyimpan informasi tentang rentang atau segmen dari sebuah array. Struktur ini sangat efisien untuk melakukan dua jenis operasi utama: "range query" (misalnya, mencari jumlah, minimum, atau maksimum dalam sebuah rentang indeks) dan "point/range update" (mengubah nilai pada satu indeks atau dalam sebuah rentang). Segment Tree mengatasi keterbatasan array biasa yang memerlukan O(N) untuk query rentang atau update rentang, menjadikannya alat penting dalam competitive programming.

Pembangunan Segment Tree dimulai dengan membagi array asli menjadi segmen-segmen yang lebih kecil secara rekursif hingga setiap segmen hanya berisi satu elemen (node daun). Setiap node dalam pohon merepresentasikan suatu rentang dalam array asli. Node induk akan menyimpan hasil operasi (misalnya, jumlah) dari rentang yang dicakup oleh kedua anak-anaknya. Proses pembangunan ini umumnya dimulai dari node daun yang merepresentasikan elemen array asli, lalu bergerak ke atas mengisi node induk hingga root pohon terbentuk, yang merepresentasikan seluruh array.

Operasi query pada Segment Tree bekerja dengan mencari node-node yang rentangnya sepenuhnya tercakup dalam rentang query yang diminta. Jika sebuah node rentangnya sepenuhnya tercakup, nilainya langsung diambil. Jika tidak, operasi akan dilanjutkan ke anak-anak node tersebut. Hasil dari semua node yang relevan kemudian digabungkan. Operasi update (misalnya, mengubah nilai pada satu indeks) melibatkan traversi dari root ke node daun yang sesuai, mengubah nilai di sana, lalu memperbarui nilai pada semua node induk di jalur kembali ke root untuk memastikan konsistensi.

Kompleksitas waktu untuk membangun sebuah Segment Tree adalah O(N), di mana N adalah ukuran array asli, karena setiap elemen array dan setiap node di pohon dikunjungi sekali. Untuk operasi query dan update, kompleksitasnya adalah O(log N). Ini karena dalam setiap langkah traversi, kita membuang separuh dari ruang pencarian, mirip dengan binary search. Kompleksitas ruang yang dibutuhkan oleh Segment Tree adalah O(N) karena pohon biner lengkap yang mencakup N daun akan memiliki sekitar 2N-1 node, seringkali diimplementasikan dengan array berukuran 4N untuk kemudahan indexing.

```
// Contoh skema dasar Segment Tree (untuk build)
// N_MAX adalah ukuran maksimum array
struct Node { /* Data yang disimpan, misal sum/min/max */ };
Node tree[4 * N_MAX]; // Array untuk menyimpan node tree

void build(int node, int start, int end, const int arr[]) {
    if (start == end) {
        tree[node] = /* inisialisasi dengan arr[start] */;
    } else {
        int mid = (start + end) / 2;
        build(2 * node, start, mid, arr);
        build(2 * node + 1, mid + 1, end, arr);
        tree[node] = /* gabungkan tree[2*node] & tree[2*node+1] */;
    }
}
```

💡 **Fun Fact:** Segment Tree dapat diperluas dengan teknik Lazy Propagation untuk menangani operasi update pada rentang yang lebih besar (range update) dengan kompleksitas O(log N), bukan hanya point update.
