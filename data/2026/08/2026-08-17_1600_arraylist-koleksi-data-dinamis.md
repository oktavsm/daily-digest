## ☕ Java Concept: `ArrayList`: Koleksi Data Dinamis

**Category:** Collections
**TL;DR:** `ArrayList` adalah implementasi dari antarmuka `List` yang menyediakan array yang dapat tumbuh dan menyusut secara dinamis, memungkinkan Anda menyimpan dan mengelola daftar objek tanpa perlu menentukan ukuran awal secara tetap.

Sebagai mahasiswa semester awal, Anda mungkin sudah akrab dengan array di Java yang memiliki ukuran tetap. Artinya, setelah Anda mendeklarasikan sebuah array dengan ukuran tertentu, Anda tidak bisa lagi mengubah ukurannya. Namun, dalam banyak aplikasi nyata, kita sering kali perlu menyimpan data yang jumlahnya tidak pasti atau bisa bertambah dan berkurang seiring waktu. Di sinilah `ArrayList` hadir sebagai solusi.

`ArrayList` adalah bagian dari Java Collections Framework dan merupakan salah satu kelas koleksi yang paling sering digunakan. Ia bertindak seperti array, tetapi dengan kemampuan untuk mengubah ukurannya secara otomatis. Ketika Anda menambahkan elemen baru dan `ArrayList` mencapai kapasitas maksimumnya, ia akan secara otomatis membuat array internal yang lebih besar dan menyalin semua elemen lama ke array baru tersebut. Hal yang sama berlaku saat Anda menghapus elemen, kapasitasnya akan disesuaikan.

Kelebihan utama `ArrayList` adalah kemudahan penggunaannya untuk operasi umum seperti menambah (`add`), mengambil (`get`), menghapus (`remove`), dan mencari elemen. Ia menyimpan elemen-elemen dalam urutan penyisipan dan memungkinkan adanya duplikasi. Meskipun `ArrayList` menyimpan objek (bukan tipe data primitif secara langsung), Java memiliki fitur 'autoboxing' yang secara otomatis mengonversi tipe data primitif seperti `int` menjadi objek `Integer` saat ditambahkan ke `ArrayList`, sehingga penggunaannya terasa lebih fleksibel.

```
import java.util.ArrayList;

ArrayList<String> daftarNama = new ArrayList<>(); // Deklarasi & inisialisasi
daftarNama.add("Budi Santoso"); // Menambah elemen
daftarNama.add("Citra Kirana");
daftarNama.add("Andi Wijaya");

System.out.println("Nama pertama: " + daftarNama.get(0)); // Mengambil elemen pada indeks 0
daftarNama.remove(1); // Menghapus elemen pada indeks 1 (Citra Kirana)
System.out.println("Daftar sekarang: " + daftarNama); // Mencetak seluruh daftar
System.out.println("Jumlah elemen: " + daftarNama.size()); // Mengecek ukuran ArrayList
```

💡 **Fun Fact:** Secara internal, `ArrayList` di Java menggunakan array biasa sebagai dasar penyimpanannya. Saat `ArrayList` penuh dan perlu menampung lebih banyak elemen, ia akan membuat array baru yang lebih besar (biasanya 1.5 kali ukuran lama) dan menyalin semua elemen lama ke array baru tersebut. Proses ini disebut 'resizing' atau 'reallocation'.
