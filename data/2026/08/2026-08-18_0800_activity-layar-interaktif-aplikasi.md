## 🤖 Android Concept: Activity: Layar Interaktif Aplikasi

**Category:** UI
**TL;DR:** Activity adalah komponen fundamental Android yang menyediakan satu layar antarmuka pengguna (UI) tempat pengguna dapat berinteraksi dengan aplikasi Anda.

Activity merupakan salah satu komponen inti dari aplikasi Android. Bayangkan Activity sebagai satu "layar" dalam aplikasi Anda. Setiap kali Anda membuka aplikasi dan melihat sesuatu di layar, kemungkinan besar itu sedang ditampilkan oleh sebuah Activity. Activity bertanggung jawab untuk mengelola UI dan merespons interaksi pengguna pada layar tersebut, menjadikannya titik awal bagi sebagian besar pengalaman pengguna aplikasi.

Setiap Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, mulai dari dibuat, ditampilkan, di-pause, dihentikan, hingga dihancurkan. Metode paling dasar yang akan sering Anda temui adalah `onCreate()`, di mana Anda biasanya melakukan inisialisasi awal, seperti mengatur tata letak (layout) UI yang akan ditampilkan. Tata letak ini biasanya didefinisikan dalam file XML yang terpisah, memungkinkan Anda mendesain tampilan aplikasi secara deklaratif.

Sebuah aplikasi Android dapat terdiri dari satu atau lebih Activity. Misalnya, satu Activity untuk layar login, satu Activity untuk daftar produk, dan satu lagi untuk detail produk. Kita berpindah antar Activity menggunakan Intent, yang bertindak sebagai pesan untuk meminta sistem Android memulai komponen aplikasi lain. Intent bisa eksplisit (menentukan Activity mana yang akan dibuka secara spesifik) atau implisit (meminta sistem untuk menemukan Activity yang bisa melakukan tindakan tertentu, seperti membuka URL).

Memahami Activity adalah langkah pertama yang krusial karena hampir semua interaksi visual dalam aplikasi Android melibatkan Activity. Ini menjadi fondasi untuk mempelajari komponen UI lain dan bagaimana mereka disatukan dalam sebuah aplikasi.

```
import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan layout XML
    }
}
```

💡 **Fun Fact:** Android Activity adalah konsep yang ada sejak awal Android, dan merupakan tulang punggung bagaimana aplikasi menampilkan antarmuka. Anda bahkan bisa memulai Activity dari aplikasi lain, memungkinkan interaksi antar-aplikasi yang kaya dan terintegrasi!
