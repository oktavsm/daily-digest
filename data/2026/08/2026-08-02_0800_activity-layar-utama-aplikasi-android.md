## 🤖 Android Concept: Activity: Layar Utama Aplikasi Android

**Category:** UI
**TL;DR:** Activity adalah komponen dasar yang mewakili satu layar tunggal dengan antarmuka pengguna dalam aplikasi Android Anda.

Setiap aplikasi Android yang kita gunakan sehari-hari, dari aplikasi chat hingga game, dibangun di atas pondasi yang disebut Activity. Anggap saja Activity ini seperti sebuah 'halaman' atau 'layar' yang bisa kita lihat dan interaksi di dalam aplikasi Anda. Misalnya, layar login, layar daftar produk, atau layar pengaturan, itu semua biasanya direpresentasikan oleh Activity yang berbeda. Activity inilah yang menjadi wadah bagi elemen-elemen UI seperti tombol, teks, gambar, dan lain-lain.

Activity memiliki siklus hidup (lifecycle) yang penting untuk dipahami. Ini adalah serangkaian metode callback yang dipanggil oleh sistem Android saat Activity berpindah status, misalnya saat dibuat, terlihat, tidak terlihat, atau dihancurkan. Metode yang paling sering dan pertama kita gunakan adalah `onCreate()`, di mana kita melakukan inisialisasi awal seperti mengaitkan layout XML dengan Activity kita menggunakan `setContentView()`. Memahami lifecycle ini krusial untuk mengelola sumber daya dan perilaku aplikasi dengan benar.

Saat Anda membuat Activity baru, biasanya akan ada file Kotlin yang berisi logika (misalnya `MainActivity.kt`) dan file layout XML yang mendefinisikan tampilan antarmuka pengguna (misalnya `activity_main.xml`). Di dalam metode `onCreate()`, kita memanggil `setContentView(R.layout.activity_main)` untuk "menggambar" layout tersebut di layar. Setelah layout terhubung, kita bisa mulai berinteraksi dengan komponen UI di dalamnya melalui ID mereka.

Aplikasi modern jarang hanya memiliki satu layar. Kita bisa berpindah dari satu Activity ke Activity lain menggunakan `Intent`. `Intent` adalah objek yang menjelaskan "maksud" untuk melakukan sesuatu, seperti memulai Activity baru. Ini memungkinkan alur navigasi yang mulus dalam aplikasi Anda, misalnya dari layar login ke layar utama setelah autentikasi berhasil. Ini adalah fundamental yang akan sering Anda gunakan.

```
package com.example.myapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Mengaitkan layout XML
    }
}
```

💡 **Fun Fact:** Konsep Activity telah ada sejak versi Android 1.0. Meskipun arsitektur modern sering melibatkan Fragment dan ViewModel, Activity tetap menjadi fondasi utama yang menghosting semua komponen UI lainnya dalam sebuah aplikasi Android.
