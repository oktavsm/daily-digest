## ☕ Java Concept: Menggunakan ArrayList (Daftar Dinamis)

**Category:** Collections
**TL;DR:** ArrayList adalah struktur data dinamis di Java yang memungkinkan kita menyimpan dan mengelola daftar objek dengan ukuran yang dapat berubah sesuai kebutuhan.

Sebagai programmer Java, Anda pasti akan sering berhadapan dengan kebutuhan untuk menyimpan dan mengelola kumpulan data. Array standar di Java sangat bagus untuk ini, tetapi memiliki satu keterbatasan utama: ukurannya tetap setelah dibuat. Bagaimana jika kita tidak tahu berapa banyak item yang perlu kita simpan di awal, atau jika jumlahnya bisa berubah sepanjang waktu? Di sinilah ArrayList menjadi penyelamat.

ArrayList adalah bagian dari Java Collections Framework, sebuah kumpulan antarmuka dan kelas untuk merepresentasikan dan memanipulasi koleksi objek. Berbeda dengan array biasa, ArrayList dapat tumbuh atau menyusut secara otomatis saat kita menambah atau menghapus elemen. Ini membuatnya sangat fleksibel untuk situasi di mana ukuran daftar data kita tidak tetap atau sering berubah. Secara internal, ArrayList sebenarnya masih menggunakan array, tetapi Java mengelola proses perubahan ukuran array di balik layar untuk kita, sehingga kita tidak perlu repot memikirkannya.

Anda dapat menganggap ArrayList seperti sebuah 'kotak' ajaib yang bisa menyimpan banyak benda sejenis. Anda bisa menambahkan benda baru ke dalamnya (`add()`), mengambil benda dari posisi tertentu (`get()`), mengetahui berapa banyak benda di dalamnya (`size()`), atau bahkan menghapus benda (`remove()`). Semua operasi ini dilakukan dengan mudah berkat metode-metode yang disediakan oleh kelas ArrayList. Karena sifatnya yang menjaga urutan dan memungkinkan duplikasi elemen, ArrayList sangat cocok untuk membangun daftar sederhana, riwayat transaksi, atau antrean.

Saat membuat ArrayList, kita biasanya menentukan tipe data objek yang akan disimpan di dalamnya menggunakan Generics (misalnya, `ArrayList<String>` untuk menyimpan daftar string, atau `ArrayList<Integer>` untuk bilangan bulat). Penggunaan Generics ini sangat penting untuk memastikan 'type safety' di kode Anda, artinya kompiler akan membantu mencegah Anda menyimpan tipe data yang salah ke dalam ArrayList, sehingga mengurangi potensi kesalahan saat program berjalan.

```
import java.util.ArrayList;

ArrayList<String> daftarMahasiswa = new ArrayList<>();

daftarMahasiswa.add("Budi"); // Menambah elemen
daftarMahasiswa.add("Ani");
daftarMahasiswa.add("Cahyo");

System.out.println("Mahasiswa pertama: " + daftarMahasiswa.get(0)); // Mengambil elemen
System.out.println("Total mahasiswa: " + daftarMahasiswa.size()); // Ukuran ArrayList
```

💡 **Fun Fact:** Meskipun 'list' yang kita gunakan di ArrayList bisa menyimpan berbagai tipe data, secara internal ia mengelola semuanya sebagai objek. Ini berarti jika Anda menyimpan tipe primitif seperti `int` atau `double`, Java akan secara otomatis melakukan 'autoboxing' (mengonversinya menjadi objek `Integer` atau `Double`) untuk Anda.
