## 🤖 Android Concept: Siklus Hidup Activity

**Category:** Architecture
**TL;DR:** Memahami berbagai tahapan yang dilewati sebuah Activity dari dibuat hingga dihancurkan sangat penting untuk mengelola UI dan data aplikasi dengan benar.

Activity adalah salah satu komponen fundamental dalam aplikasi Android, yang bertanggung jawab untuk menyediakan satu layar tunggal untuk berinteraksi dengan pengguna. Setiap kali Anda melihat sebuah layar di aplikasi, seperti daftar email, formulir login, atau halaman detail produk, Anda sedang berinteraksi dengan sebuah Activity. Activity berfungsi sebagai titik masuk utama bagi pengguna untuk berinteraksi dengan aplikasi dan tempat utama untuk menampilkan antarmuka pengguna (UI) Anda.

Setiap Activity memiliki "siklus hidup" atau LifeCycle, serangkaian tahapan yang dilaluinya dari saat pertama kali dibuat, menjadi terlihat oleh pengguna, berinteraksi dengan pengguna, hingga akhirnya dihancurkan. Sistem Android secara otomatis mengelola siklus hidup ini, dan akan memanggil berbagai metode *callback* (seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, `onDestroy()`) pada Activity Anda saat berpindah antar tahapan. Memahami tahapan ini sangat krusial untuk membangun aplikasi yang stabil dan responsif.

Dengan mengimplementasikan metode *callback* siklus hidup ini, Anda dapat mengelola sumber daya aplikasi dengan sangat efisien. Misalnya, Anda mungkin ingin memulai pemutaran video atau koneksi jaringan aktif hanya saat Activity terlihat oleh pengguna (misalnya, di `onStart()`), dan menghentikan atau menghentikannya saat Activity tidak lagi terlihat (di `onStop()`) untuk menghemat baterai dan data. Ini juga sangat penting untuk menyimpan dan mengembalikan status UI serta data ketika terjadi perubahan konfigurasi (seperti rotasi layar) atau ketika sistem menghentikan Activity Anda untuk membebaskan memori.

Metode `onCreate()` adalah tempat utama untuk melakukan inisialisasi awal Activity, seperti mengatur tata letak (layout) dan mengikat data awal. `onResume()` dipanggil saat Activity siap berinteraksi dengan pengguna. `onPause()` dipanggil saat Activity sebagian tertutup (misalnya, dialog muncul di atasnya), dan `onStop()` dipanggil saat Activity tidak lagi terlihat sama sekali. Terakhir, `onDestroy()` dipanggil sebelum Activity dihancurkan secara permanen. Penting juga untuk memahami `onSaveInstanceState()` dan `onRestoreInstanceState()` untuk mempertahankan data penting saat Activity dibuat ulang.

```
import android.os.Bundle
import android.util.Log
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        Log.d("Lifecycle", "onCreate dipanggil")
    }

    override fun onResume() {
        super.onResume()
        Log.d("Lifecycle", "onResume dipanggil")
    }

    override fun onPause() {
        super.onPause()
        Log.d("Lifecycle", "onPause dipanggil")
    }

    override fun onDestroy() {
        super.onDestroy()
        Log.d("Lifecycle", "onDestroy dipanggil")
    }
}
```
