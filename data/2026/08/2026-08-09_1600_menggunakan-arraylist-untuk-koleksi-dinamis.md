## ☕ Java Concept: Menggunakan ArrayList untuk Koleksi Dinamis

**Category:** Collections
**TL;DR:** ArrayList adalah struktur data dinamis dari Java Collections Framework yang dapat menyimpan urutan objek dan secara otomatis menyesuaikan ukurannya.

Selamat pagi, teman-teman mahasiswa! Hari ini kita akan menyelami salah satu struktur data paling sering digunakan di Java, yaitu `ArrayList`. Bayangkan Anda ingin menyimpan daftar nama mahasiswa, tetapi Anda tidak tahu persis berapa banyak mahasiswa yang akan mendaftar. Jika kita menggunakan array biasa, kita harus menentukan ukurannya di awal dan tidak bisa mengubahnya. Nah, di sinilah `ArrayList` menjadi penyelamat!

`ArrayList` adalah implementasi dari antarmuka `List` dalam Java Collections Framework yang memungkinkan kita menyimpan daftar objek dengan ukuran yang bisa berubah-ubah (dinamis) selama program berjalan. Ini berarti Anda bisa menambah atau mengurangi jumlah elemen tanpa perlu khawatir tentang kapasitas awal. Untuk menggunakannya, kita perlu mengimpornya dari package `java.util`.

Deklarasi `ArrayList` mirip dengan array, tetapi kita menggunakan tanda `<>` untuk menentukan tipe objek yang akan disimpan – ini disebut Generics, yang membantu mencegah kesalahan tipe data saat kompilasi. Setelah dibuat, kita bisa menambahkan elemen menggunakan metode `add()`. Misalnya, `mahasiswa.add("Budi")` akan menambahkan nama "Budi" ke daftar. `ArrayList` menjaga urutan elemen, artinya elemen yang ditambahkan pertama akan berada di indeks 0, yang kedua di indeks 1, dan seterusnya.

Mengakses elemen di `ArrayList` dilakukan dengan metode `get()` menggunakan indeks, mirip seperti array, misalnya `mahasiswa.get(0)`. Jika Anda ingin menghapus elemen, Anda bisa menggunakan `remove()` baik berdasarkan indeks atau berdasarkan objeknya. Untuk mengetahui berapa banyak elemen yang ada di dalam `ArrayList`, kita bisa menggunakan metode `size()`. Kemampuan untuk menambah, mengurangi, dan mengakses elemen dengan mudah serta ukurannya yang dinamis membuat `ArrayList` sangat praktis untuk berbagai skenario, seperti menyimpan daftar belanja, log peristiwa, atau data pengguna.

```
import java.util.ArrayList;

public class DaftarMahasiswa {
    public static void main(String[] args) {
        ArrayList<String> namaMahasiswa = new ArrayList<>(); // Membuat ArrayList
        namaMahasiswa.add("Alice"); // Menambah elemen
        namaMahasiswa.add("Bob");
        namaMahasiswa.add("Charlie");

        System.out.println("Mahasiswa pertama: " + namaMahasiswa.get(0)); // Mengakses elemen
        System.out.println("Jumlah mahasiswa: " + namaMahasiswa.size()); // Ukuran ArrayList

        namaMahasiswa.remove("Bob"); // Menghapus elemen
        System.out.println("Jumlah mahasiswa setelah Bob dihapus: " + namaMahasiswa.size());
    }
}
```

💡 **Fun Fact:** Tahukah Anda bahwa `ArrayList` sebenarnya menggunakan array biasa di balik layarnya untuk menyimpan elemen? Ketika `ArrayList` penuh dan perlu menampung elemen baru, ia akan secara otomatis membuat array baru yang lebih besar (biasanya 1.5 kali ukuran semula) dan menyalin semua elemen lama ke array baru tersebut. Proses ini disebut 'resizing' atau 'reallocation'.
