## ☕ Java Concept: Memahami ArrayList di Java

**Category:** Collections
**TL;DR:** ArrayList adalah koleksi dinamis yang sangat berguna untuk menyimpan daftar objek yang ukurannya bisa berubah-ubah saat program berjalan.

ArrayList adalah salah satu implementasi dari antarmuka List dalam kerangka kerja Collections di Java. Berbeda dengan array standar yang ukurannya tetap setelah dibuat, ArrayList menyediakan struktur data yang dinamis, artinya Anda dapat menambah atau mengurangi jumlah elemen di dalamnya kapan saja selama program berjalan. Ini sangat berguna ketika Anda tidak tahu persis berapa banyak item yang perlu Anda simpan, misalnya daftar mahasiswa yang mendaftar atau item dalam keranjang belanja.

Penggunaan ArrayList sangat intuitif dan fleksibel. Anda dapat menambahkan elemen baru menggunakan metode `add()`, mengambil elemen pada posisi tertentu dengan `get(index)`, dan menghapus elemen dengan `remove(index)` atau `remove(object)`. Seperti array tradisional, elemen ArrayList diindeks mulai dari 0, yang berarti elemen pertama berada di indeks 0, elemen kedua di indeks 1, dan seterusnya. Praktik terbaik adalah menggunakannya dengan tipe generik (misalnya `ArrayList<String>`) untuk memastikan keamanan tipe (type-safety) dan menghindari masalah `ClassCastException`.

Keuntungan utama ArrayList adalah kemudahan dan fleksibilitasnya dalam mengelola koleksi data yang jumlahnya berubah-ubah tanpa perlu pusing memikirkan kapasitas awal. Secara internal, ArrayList menggunakan array biasa, dan ketika kapasitasnya penuh, ia akan membuat array baru yang lebih besar dan menyalin semua elemen lama ke array baru tersebut. Ini membuatnya sangat efisien untuk operasi akses acak (mengambil elemen berdasarkan indeks), menjadikannya pilihan yang sangat populer untuk banyak kebutuhan penyimpanan data di Java.

```
import java.util.ArrayList;
import java.util.List;

public class DemoArrayList {
    public static void main(String[] args) {
        List<String> daftarBuah = new ArrayList<>(); // Membuat ArrayList
        daftarBuah.add("Apel"); // Menambah elemen
        daftarBuah.add("Pisang");
        daftarBuah.add("Mangga");

        System.out.println("Buah pertama: " + daftarBuah.get(0)); // Mengambil elemen

        daftarBuah.remove("Pisang"); // Menghapus elemen

        System.out.println("Jumlah buah sekarang: " + daftarBuah.size());
        System.out.println("Daftar lengkap: " + daftarBuah); // Mencetak semua
    }
}
```

💡 **Fun Fact:** ArrayList adalah salah satu kelas koleksi yang paling banyak digunakan di Java karena kesederhanaan dan fleksibilitasnya. Di balik layar, ArrayList sebenarnya menggunakan array biasa yang ukurannya diubah secara otomatis saat diperlukan, memberikan ilusi array dinamis kepada pengembang.
