## 🌐 Networking Concept: IP SLA untuk Failover Routing Dinamis

**Category:** Routing
**TL;DR:** Menggunakan IP Service Level Agreement (SLA) untuk memantau konektivitas dan secara dinamis mengubah rute jika jalur utama gagal, meningkatkan ketahanan jaringan.

IP Service Level Agreement (SLA) adalah fitur canggih pada perangkat Cisco yang memungkinkan kita untuk mengukur dan memverifikasi kinerja jaringan, seperti ketersediaan jalur, waktu respons (latency), dan jitter. Lebih dari sekadar pemantauan pasif, IP SLA dapat diintegrasikan secara aktif dengan mekanisme routing untuk menciptakan sistem failover yang otomatis dan dinamis. Konsepnya adalah mendeteksi kegagalan jalur primer secara real-time dan secara otomatis mengalihkan lalu lintas ke jalur cadangan tanpa campur tangan administrator.

Prosesnya dimulai dengan mengkonfigurasi operasi IP SLA, misalnya, dengan mengirimkan paket ICMP Echo (ping) secara berkala ke sebuah alamat IP tujuan yang dapat dijangkau melalui jalur utama Anda. Jika router tidak menerima balasan ping dalam periode waktu tertentu, operasi IP SLA akan dianggap gagal. Hasil dari operasi IP SLA ini kemudian dikaitkan dengan sebuah "tracking object" yang statusnya akan berubah menjadi "down" ketika operasi SLA gagal dan "up" ketika berhasil.

Tracking object inilah yang menjadi kunci integrasi dengan routing. Kita dapat mengkonfigurasi sebuah static route agar hanya aktif dalam tabel routing selama tracking object berstatus "up". Jika tracking object berubah menjadi "down" (menandakan jalur utama terputus), rute statis tersebut akan secara otomatis dihapus dari tabel routing. Pada saat yang sama, sebuah rute statis cadangan dengan administrative distance yang lebih tinggi (atau rute dari protokol routing dinamis) yang mengarah ke jalur alternatif akan secara otomatis menjadi aktif. 

Dengan demikian, lalu lintas jaringan Anda akan secara instan dialihkan ke jalur cadangan, memastikan konektivitas yang tidak terputus dan meminimalkan downtime. Penerapan IP SLA untuk failover routing ini sangat krusial untuk bisnis yang memerlukan ketersediaan jaringan tinggi, seperti data center atau koneksi internet utama perusahaan.

```
ip sla 1 icmp-echo 8.8.8.8 source-interface GigabitEthernet0/1
```

💡 **Fun Fact:** Banyak ISP dan perusahaan besar tidak hanya menggunakan IP SLA untuk failover, tetapi juga untuk secara proaktif mengukur performa jaringan mereka dan memverifikasi apakah mereka memenuhi janji Service Level Agreement (SLA) yang ditawarkan kepada pelanggan.
