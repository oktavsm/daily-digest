## 🤖 Android Concept: Activity: Fondasi Aplikasi Android

**Category:** Architecture
**TL;DR:** Activity adalah komponen aplikasi Android yang menyediakan layar tunggal untuk berinteraksi dengan pengguna, seperti sebuah jendela pada aplikasi desktop.

Activity merepresentasikan satu layar dengan antarmuka pengguna (UI) dalam sebuah aplikasi Android. Pikirkan Activity sebagai sebuah halaman dalam peramban web atau jendela di aplikasi desktop. Hampir setiap aplikasi memiliki beberapa Activity, masing-masing didesain untuk tugas spesifik, misalnya layar login, daftar item, atau tampilan detail. Saat Anda berpindah-pindah dalam aplikasi, seringkali Anda berpindah antar Activity atau Fragment yang di-host di dalamnya.

Activity memiliki siklus hidup (lifecycle) yang dikelola oleh sistem Android. Siklus hidup ini mencakup status-status seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()`. Memahami metode callback ini sangat penting untuk mengelola sumber daya, menyimpan status, dan memastikan aplikasi Anda berperilaku benar saat pengguna berinteraksi (misalnya, memutar perangkat, menerima panggilan telepon, atau beralih ke aplikasi lain).

Activity biasanya diluncurkan menggunakan objek `Intent`. `Intent` adalah objek pesan yang dapat Anda gunakan untuk meminta suatu tindakan dari komponen aplikasi lain. Misalnya, Anda dapat menggunakan `Intent` untuk memulai Activity lain dalam aplikasi Anda sendiri, meluncurkan aplikasi eksternal (seperti kamera atau peramban web), atau bahkan meneruskan data antar Activity. Mekanisme ini memungkinkan modularitas dan integrasi yang mulus baik di dalam maupun antar aplikasi.

Antarmuka pengguna yang ditampilkan oleh sebuah Activity didefinisikan menggunakan berkas layout, biasanya ditulis dalam XML. XML ini menjelaskan struktur dan elemen-elemen (seperti tombol, tampilan teks, gambar) yang muncul di layar. Metode `setContentView()` dalam Activity menghubungkan berkas layout XML ini dengan instance Activity, sehingga membuatnya terlihat oleh pengguna.

```
package com.example.aplikasiku

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        // Kode inisialisasi UI atau data lainnya bisa ditambahkan di sini
    }
}
```

💡 **Fun Fact:** Aplikasi Android pertama yang dirilis untuk publik pada tahun 2008, seperti Google Maps dan YouTube, dibangun sepenuhnya menggunakan konsep Activity sebagai unit antarmuka utama. Ini menunjukkan betapa fundamentalnya Activity dalam sejarah Android.
