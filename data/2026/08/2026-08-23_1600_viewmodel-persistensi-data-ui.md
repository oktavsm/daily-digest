## 🤖 Android Concept: ViewModel: Persistensi Data UI

**Category:** Architecture
**TL;DR:** ViewModel adalah komponen Jetpack yang dirancang untuk menyimpan dan mengelola data terkait UI dengan cara yang sadar siklus hidup, memastikan data tidak hilang saat konfigurasi perangkat berubah.

Pernahkah kamu membangun aplikasi, lalu saat layar dirotasi dari portrait ke landscape (atau sebaliknya), semua data di layar tiba-tiba hilang atau ter-reset? Ini adalah masalah umum bagi pemula, karena Activity atau Fragment yang menangani UI akan dihancurkan dan dibuat ulang saat terjadi perubahan konfigurasi seperti rotasi. Menyimpan dan mengembalikan state UI secara manual bisa menjadi rumit dan rentan kesalahan.

Di sinilah `ViewModel` datang sebagai penyelamat. `ViewModel` adalah bagian dari Android Jetpack Architecture Components yang dirancang khusus untuk menyimpan dan mengelola data terkait UI dengan cara yang *lifecycle-aware*. Ini berarti, meskipun `Activity` atau `Fragment` yang terkait dengannya dihancurkan dan dibuat ulang karena perubahan konfigurasi (misalnya rotasi layar), instance `ViewModel` akan tetap hidup dan utuh. `Activity` atau `Fragment` yang baru dibuat akan menerima instance `ViewModel` yang sama, beserta data yang sudah ada di dalamnya.

Dengan menggunakan `ViewModel`, kamu bisa memisahkan logika bisnis (seperti mengambil data dari server, melakukan perhitungan) dari logika tampilan (misalnya menampilkan data di `TextView` atau `RecyclerView`). `Activity` atau `Fragment` cukup berinteraksi dengan `ViewModel` untuk mendapatkan data dan memperbarui UI. Pemisahan ini membuat kode lebih bersih, lebih mudah diuji (karena `ViewModel` tidak bergantung langsung pada konteks Android), dan yang paling penting, datamu aman dari perubahan konfigurasi, memberikan pengalaman pengguna yang lebih mulus.

```
import androidx.lifecycle.ViewModel
import androidx.lifecycle.MutableLiveData

class CounterViewModel : ViewModel() {
    val count: MutableLiveData<Int> = MutableLiveData(0)

    fun incrementCount() {
        count.value = (count.value ?: 0) + 1
    }
}
```

💡 **Fun Fact:** Sebelum ViewModel diperkenalkan, pengembang sering menggunakan `onSaveInstanceState()` atau bahkan menyimpan data di objek retained Fragment untuk mengatasi masalah rotasi. ViewModel menyederhanakan proses ini secara signifikan dan menjadi fondasi untuk pola arsitektur modern seperti MVVM.
