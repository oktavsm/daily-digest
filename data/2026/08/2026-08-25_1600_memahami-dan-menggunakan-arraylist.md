## ☕ Java Concept: Memahami dan Menggunakan ArrayList

**Category:** Collections
**TL;DR:** ArrayList memungkinkan kita menyimpan koleksi objek yang ukurannya bisa berubah-ubah secara dinamis, jauh lebih fleksibel daripada array biasa.

Di Java, array standar memiliki ukuran yang tetap setelah dibuat, yang sering kali menyulitkan jika kita tidak tahu berapa banyak data yang akan disimpan selama program berjalan. `ArrayList` datang sebagai solusi, menawarkan struktur data yang bisa tumbuh atau menyusut secara otomatis sesuai kebutuhan. Ini seperti wadah serbaguna yang ukurannya bisa menyesuaikan diri, memungkinkan kita untuk menambah atau mengurangi elemen tanpa perlu khawatir tentang kapasitas awal.

`ArrayList` adalah bagian penting dari Java Collections Framework dan merupakan implementasi dari interface `List`. Kita bisa menambahkan elemen ke dalamnya menggunakan metode `add()`, mengambil elemen dengan `get()` (berdasarkan indeks), mengetahui jumlah elemen dengan `size()`, dan menghapus elemen dengan `remove()`. Penting untuk diingat bahwa `ArrayList` menyimpan objek, jadi tipe data primitif seperti `int` atau `double` akan secara otomatis "dibungkus" menjadi objek `Integer` atau `Double` (proses yang disebut autoboxing).

Untuk memastikan keamanan tipe (type safety) dan menghindari kesalahan saat mengambil data, kita selalu menggunakan `ArrayList` dengan tipe generik (misalnya, `ArrayList<String>` atau `ArrayList<Mahasiswa>`). Dengan generik, kompiler akan memastikan kita hanya menyimpan tipe data yang sesuai dan tidak perlu melakukan casting manual saat mengambil elemen. Ini membuat kode lebih bersih, lebih aman, dan terhindar dari `ClassCastException` yang bisa terjadi di runtime.

`ArrayList` adalah salah satu koleksi yang paling sering digunakan dalam pengembangan aplikasi Java, mulai dari menyimpan daftar nama siswa, item di keranjang belanja, hingga data hasil query dari database. Fleksibilitas dan kemudahan penggunaannya menjadikannya pilihan utama untuk sebagian besar skenario yang membutuhkan daftar objek yang dinamis.

```
import java.util.ArrayList;

public class ContohArrayList {
    public static void main(String[] args) {
        ArrayList<String> daftarMahasiswa = new ArrayList<>();

        daftarMahasiswa.add("Budi");
        daftarMahasiswa.add("Citra");
        daftarMahasiswa.add("Dian");

        System.out.println("Mahasiswa pertama: " + daftarMahasiswa.get(0));
        System.out.println("Jumlah mahasiswa: " + daftarMahasiswa.size());

        daftarMahasiswa.remove("Citra"); // Menghapus berdasarkan objek

        System.out.println("Jumlah setelah dihapus: " + daftarMahasiswa.size());
    }
}
```

💡 **Fun Fact:** Meskipun `ArrayList` sangat populer dan tampak dinamis, di baliknya ia menggunakan array biasa sebagai implementasi dasarnya. Ketika `ArrayList` mencapai kapasitas maksimumnya, ia akan membuat array baru yang lebih besar (biasanya 1.5 kali ukuran sebelumnya), lalu menyalin semua elemen lama ke array baru tersebut — sebuah operasi yang bisa memakan waktu, terutama untuk daftar yang sangat besar.
