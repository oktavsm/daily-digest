## ☕ Java Concept: Kelas dan Objek: Pilar OOP Java

**Category:** OOP
**TL;DR:** Kelas adalah cetak biru untuk membuat objek, yang merupakan instans nyata dari kelas dan memiliki atribut serta perilaku.

Dalam pemrograman Java, yang merupakan bahasa berorientasi objek (OOP), konsep 'Kelas' (Class) dan 'Objek' (Object) adalah fondasi utamanya. Anda bisa membayangkan sebuah Kelas sebagai sebuah cetak biru, rancangan, atau prototipe. Kelas mendefinisikan struktur, seperti variabel (disebut atribut atau *fields*) yang akan menyimpan data, dan fungsi (disebut metode atau *methods*) yang akan melakukan aksi atau perilaku tertentu. Sebagai contoh, Anda bisa membuat kelas 'Mobil' yang mendefinisikan bahwa setiap mobil memiliki atribut seperti warna, merek, dan metode seperti 'jalankan' atau 'rem'.

Setelah kita memiliki cetak biru (Kelas), kita bisa mulai membuat 'Objek' darinya. Objek adalah instans nyata dari sebuah kelas. Jika kelas adalah resep kue, maka objek adalah kue yang sudah jadi. Dari kelas 'Mobil' yang sama, kita bisa membuat banyak objek mobil yang berbeda: satu mobil berwarna merah merek Honda, mobil lain berwarna biru merek Toyota, dan seterusnya. Setiap objek memiliki nilai atributnya sendiri yang unik (misalnya, warna mobil saya merah, warna mobil teman biru), tetapi mereka semua memiliki kemampuan untuk melakukan perilaku yang sama (misalnya, kedua mobil bisa 'jalankan').

Untuk membuat objek dari sebuah kelas, kita menggunakan kata kunci `new`. Misalnya, `Mobil mobilSaya = new Mobil();` akan menciptakan sebuah objek 'Mobil' baru bernama `mobilSaya`. Setelah objek dibuat, kita bisa mengakses atribut dan metode-nya menggunakan operator titik (.). Misalnya, `mobilSaya.warna = "Merah";` untuk mengatur atribut warna, atau `mobilSaya.jalankan();` untuk memanggil metode jalankan. Memahami Kelas dan Objek sangat penting karena hampir semua yang Anda lakukan di Java akan melibatkan interaksi antara objek-objek yang dibuat dari kelas-kelas.

```
public class Kucing {
    String nama;
    String ras;

    public void bersuara() {
        System.out.println(nama + " berbunyi Meong!");
    }
}

// Cara penggunaan (misal di method main):
// Kucing kucingSaya = new Kucing();
// kucingSaya.nama = "Luna";
// kucingSaya.ras = "Persia";
// kucingSaya.bersuara(); // Output: Luna berbunyi Meong!
```

💡 **Fun Fact:** Java adalah salah satu bahasa pemrograman paling populer yang sepenuhnya berorientasi objek (kecuali untuk tipe data primitif). Pendekatan OOP dengan Kelas dan Objek membuat Java sangat modular, mudah dikelola, dan skalabel untuk proyek-proyek besar!
