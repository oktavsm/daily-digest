## ☕ Java Concept: Penanganan Error dengan `try-catch`

**Category:** Exception
**TL;DR:** Penanganan error dengan `try-catch` adalah mekanisme Java untuk mengelola kesalahan runtime agar program tidak crash dan dapat memberikan respons yang lebih baik kepada pengguna.

Sebuah 'exception' dalam Java adalah kejadian tak terduga yang mengganggu alur normal eksekusi program. Ini bisa berupa percobaan pembagian dengan nol, akses indeks array di luar batas, atau upaya membuka file yang tidak ada. Tanpa penanganan yang tepat, program Anda akan berhenti secara paksa (crash) dan menampilkan pesan error yang mungkin tidak informatif bagi pengguna. Ini tentu bukan pengalaman yang baik untuk pengguna aplikasi Anda.

Blok `try-catch` adalah solusi fundamental untuk masalah ini. Blok `try` digunakan untuk membungkus kode yang berpotensi melempar exception (memunculkan error). Jika sebuah exception terjadi di dalam blok `try`, eksekusi kode di dalam blok `try` akan segera dihentikan, dan kendali program akan dialihkan ke blok `catch` yang relevan. Blok `catch` berfungsi untuk 'menangkap' exception dari jenis tertentu dan menyediakan kode untuk menanganinya, seperti mencetak pesan kesalahan yang lebih jelas, mencatat error untuk debugging, atau melakukan tindakan pemulihan.

Dengan menggunakan `try-catch`, Anda memberikan 'kesempatan kedua' bagi program Anda untuk melanjutkan eksekusi meskipun ada kesalahan. Daripada berhenti total, program Anda dapat memberitahu pengguna tentang apa yang salah dan, jika memungkinkan, kembali ke keadaan stabil. Ini adalah langkah krusial dalam membangun aplikasi Java yang tangguh, stabil, dan memberikan pengalaman pengguna yang baik. Memahami dan menerapkan `try-catch` adalah keterampilan dasar yang harus dikuasai setiap programmer Java.

```
public class SimpleExceptionHandling {
    public static void main(String[] args) {
        try {
            int num1 = 10;
            int num2 = 0;
            // Baris ini akan menyebabkan ArithmeticException (pembagian dengan nol)
            int result = num1 / num2;
            System.out.println("Hasil pembagian: " + result);
        } catch (ArithmeticException e) {
            // Blok ini akan dieksekusi jika terjadi ArithmeticException
            System.err.println("Terjadi kesalahan aritmatika: Tidak dapat membagi angka dengan nol!");
            System.err.println("Pesan sistem: " + e.getMessage());
        }
        System.out.println("Program tetap berjalan setelah penanganan error.");
    }
}
```

💡 **Fun Fact:** Java adalah salah satu bahasa pemrograman pertama yang memperkenalkan mekanisme penanganan exception yang terstruktur (menggunakan `try-catch-finally`) sebagai fitur inti bahasanya, menjadikannya standar emas untuk membangun aplikasi yang tangguh dan aman.
