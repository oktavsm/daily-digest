## ☕ Java Concept: ArrayList: Koleksi Dinamis Data

**Category:** Collections
**TL;DR:** `ArrayList` adalah struktur data dinamis yang memungkinkan kita menyimpan dan mengelola daftar objek dengan ukuran yang bisa berubah-ubah.

Pada perkuliahan hari ini, kita akan mempelajari `ArrayList`, sebuah konsep fundamental dalam Java Collections Framework yang sangat sering digunakan. Berbeda dengan array biasa yang ukurannya sudah harus ditentukan di awal dan tidak bisa diubah, `ArrayList` menawarkan fleksibilitas yang lebih besar. Ia adalah implementasi dari antarmuka `List`, yang berarti elemen-elemennya disimpan dalam urutan tertentu dan memungkinkan adanya elemen duplikat.

Keunggulan utama `ArrayList` terletak pada kemampuannya untuk beradaptasi dengan jumlah data yang terus bertambah atau berkurang. Bayangkan Anda perlu menyimpan daftar nama siswa, barang belanjaan, atau catatan transaksi yang jumlahnya tidak Anda ketahui secara pasti di awal. Menggunakan array biasa akan merepotkan karena Anda harus membuat array baru setiap kali kapasitasnya tidak mencukupi. `ArrayList` mengatasi masalah ini dengan otomatis menyesuaikan ukurannya di belakang layar, memudahkan programmer untuk fokus pada logika bisnis.

Untuk menggunakan `ArrayList`, kita perlu membuat objeknya dan menentukan tipe data objek yang akan disimpan menggunakan Generics (misalnya, `ArrayList<String>` untuk menyimpan String). Setelah itu, kita bisa menambahkan elemen menggunakan metode `add()`, mengakses elemen berdasarkan indeksnya dengan `get()`, atau menghapus elemen dengan `remove()`. Konsep ini sangat praktis dan akan menjadi pondasi kuat untuk mengelola koleksi data di berbagai aplikasi Java.

```
import java.util.ArrayList;

public class DemoArrayList {
    public static void main(String[] args) {
        ArrayList<String> daftarNama = new ArrayList<>();
        daftarNama.add("Budi");
        daftarNama.add("Ani");
        daftarNama.add("Cahyo");
        System.out.println("Nama pertama: " + daftarNama.get(0));
        daftarNama.remove("Ani");
        System.out.println("Daftar nama sekarang: " + daftarNama);
    }
}
```

💡 **Fun Fact:** Secara internal, `ArrayList` menggunakan array biasa. Ketika `ArrayList` penuh dan perlu menampung lebih banyak elemen, ia akan membuat array baru yang lebih besar (biasanya 1.5 kali ukuran semula) dan menyalin semua elemen dari array lama ke array baru, sebuah proses yang dikenal sebagai 'resizing'.
