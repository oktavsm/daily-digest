## ☕ Java Concept: Penanganan Exception dengan try-catch

**Category:** Exception
**TL;DR:** Penanganan exception menggunakan `try-catch` adalah mekanisme Java untuk mengelola error tak terduga yang terjadi saat program berjalan, mencegah program crash dan menjaga agar tetap berjalan dengan baik.

Dalam pengembangan perangkat lunak, program tidak selalu berjalan mulus. Terkadang, kondisi tak terduga bisa terjadi saat program dieksekusi, seperti mencoba membagi sebuah angka dengan nol, mengakses elemen di luar batas array, atau mencoba membaca file yang tidak ada. Kondisi-kondisi bermasalah inilah yang kita sebut sebagai "exception" atau pengecualian. Tanpa penanganan yang tepat, exception akan menyebabkan program berhenti mendadak (crash), yang tentu saja sangat tidak diinginkan dari sudut pandang pengguna.

Penanganan exception adalah fondasi untuk membangun aplikasi yang kokoh dan dapat diandalkan (robust). Dengan mengantisipasi dan mengelola exception, kita bisa memastikan bahwa program kita tidak akan berhenti secara tiba-tiba, melainkan dapat "pulih" dari kesalahan atau setidaknya memberikan pesan yang informatif kepada pengguna, lalu menghentikan program dengan anggun. Ini meningkatkan pengalaman pengguna dan kemudahan perawatan program.

Java menyediakan blok `try` dan `catch` sebagai inti dari mekanisme penanganan exception. Kita menempatkan kode yang berpotensi menimbulkan exception di dalam blok `try`. Jika sebuah exception terjadi di dalam blok `try`, Java akan segera menghentikan eksekusi kode di dalam `try` tersebut dan mencari blok `catch` yang cocok untuk menanganinya. Setiap blok `catch` dirancang untuk menangani jenis exception tertentu, yang didefinisikan oleh tipe parameter exception-nya.

Ketika exception yang cocok ditemukan, kendali program akan dialihkan ke blok `catch` tersebut. Di dalam blok `catch`, kita dapat menulis logika untuk merespons exception, misalnya dengan menampilkan pesan kesalahan yang user-friendly ke konsol, mencatat detail kesalahan ke file log, atau bahkan mencoba memperbaiki masalah secara otomatis. Setelah blok `catch` selesai dieksekusi, program akan melanjutkan eksekusi dari kode setelah blok `try-catch` tersebut, memastikan bahwa program tetap berjalan meskipun ada masalah di bagian tertentu.

```
int numerator = 10;
int denominator = 0;
try {
    int result = numerator / denominator;
    System.out.println("Hasil: " + result);
} catch (ArithmeticException e) {
    System.err.println("Kesalahan: " + e.getMessage());
    System.out.println("Pembagian dengan nol tidak diizinkan.");
}
System.out.println("Aplikasi tetap berjalan.");
```

💡 **Fun Fact:** Tahukah Anda? Mekanisme `try-catch` Java adalah salah satu fitur paling fundamental yang membuat aplikasi Java dikenal sangat tangguh dan jarang crash mendadak di tangan pengguna.
