## ⚡ Competitive Programming Concept: 0/1 Knapsack Problem

**Category:** DP
**TL;DR:** Memilih subset item dengan berat dan nilai tertentu untuk memaksimalkan total nilai, tanpa melebihi kapasitas tas, di mana setiap item hanya bisa diambil seluruhnya atau tidak sama sekali.

The 0/1 Knapsack Problem adalah salah satu masalah klasik dalam pemrograman dinamis (DP). Anda diberikan sejumlah item, di mana setiap item memiliki berat (weight) dan nilai (value) tertentu. Anda juga diberikan sebuah kapasitas maksimum (capacity) untuk sebuah "tas" (knapsack). Tujuan Anda adalah memilih subset item yang total beratnya tidak melebihi kapasitas knapsack, sambil memaksimalkan total nilai dari item-item yang dipilih. Nama "0/1" menunjukkan bahwa setiap item hanya bisa dipilih seluruhnya (1) atau tidak sama sekali (0) – tidak bisa mengambil sebagian.

Masalah ini dapat diselesaikan dengan DP. Kita bisa mendefinisikan `dp[w]` sebagai nilai maksimum yang bisa dicapai dengan kapasitas `w`. Untuk setiap item, kita mempertimbangkan dua kemungkinan: tidak mengambil item tersebut, atau mengambil item tersebut. Jika kita tidak mengambil item ke-`i`, nilai maksimum `dp[w]` tidak berubah. Jika kita mengambil item ke-`i`, kita harus memastikan kapasitas yang tersisa cukup (`w - weight[i] >= 0`), lalu kita mengupdate `dp[w]` menjadi `max(dp[w], dp[w - weight[i]] + value[i])`.

Pendekatan DP dua dimensi `dp[i][j]` (nilai max menggunakan `i` item pertama dengan kapasitas `j`) dapat dioptimalkan menjadi satu dimensi `dp[j]` (nilai max dengan kapasitas `j`). Saat memproses item ke-`k`, kita perlu mengupdate `dp[j]` dari nilai `dp[j]` sebelumnya dan `dp[j - weight[k]]` (yang merujuk ke status *sebelum* item ke-`k` diproses). Untuk memastikan ini, iterasi untuk `j` harus bergerak mundur dari `capacity` hingga `weight[k]`. Ini mencegah item yang sama diambil lebih dari sekali dalam satu iterasi item.

Kompleksitas waktu untuk solusi ini adalah O(N * W), di mana N adalah jumlah item dan W adalah kapasitas maksimum knapsack. Kompleksitas ruang adalah O(W) jika menggunakan optimasi satu dimensi, atau O(N * W) jika menggunakan array DP dua dimensi. Batasan N dan W biasanya sekitar 100-2000 untuk N dan 10^4 - 10^5 untuk W, membuat solusi O(N*W) layak.

```
int solve_knapsack(int W, const std::vector<int>& weights, const std::vector<int>& values) {
    int N = weights.size();
    std::vector<int> dp(W + 1, 0);

    for (int i = 0; i < N; ++i) { // Untuk setiap item
        for (int w = W; w >= weights[i]; --w) { // Iterasi kapasitas mundur
            dp[w] = std::max(dp[w], dp[w - weights[i]] + values[i]);
        }
    }
    return dp[W];
}
```

💡 **Fun Fact:** Masalah knapsack memiliki banyak aplikasi di dunia nyata, mulai dari alokasi sumber daya optimal, perencanaan investasi, hingga pemotongan bahan industri. Konsepnya pertama kali dideskripsikan secara formal pada akhir abad ke-19.
