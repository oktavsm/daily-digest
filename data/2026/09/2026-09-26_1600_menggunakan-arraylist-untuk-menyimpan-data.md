## ☕ Java Concept: Menggunakan ArrayList untuk Menyimpan Data

**Category:** Collections
**TL;DR:** ArrayList adalah struktur data dinamis yang fleksibel untuk menyimpan dan mengelola banyak objek, ukurannya bisa berubah saat program berjalan.

Sebagai mahasiswa semester awal, kalian mungkin sudah familiar dengan array, struktur data untuk menyimpan banyak elemen dengan tipe yang sama. Namun, array memiliki batasan: ukurannya tetap setelah dibuat. Bagaimana jika kita tidak tahu berapa banyak data yang akan kita simpan? Di sinilah `ArrayList` datang sebagai solusi. `ArrayList` adalah bagian dari Java Collections Framework, yang memungkinkan kita menyimpan koleksi objek dan ukurannya dapat bertambah atau berkurang secara dinamis sesuai kebutuhan.

Untuk mulai menggunakan `ArrayList`, kita perlu mengimpor kelasnya dari paket `java.util`. Deklarasi `ArrayList` mirip dengan array, tetapi kita menggunakan tanda kurung siku (`<>`) untuk menentukan tipe objek yang akan disimpan – ini disebut Generics. Misalnya, `ArrayList<String>` berarti kita akan menyimpan koleksi objek `String`. Setelah dibuat, kita bisa menambahkan elemen menggunakan metode `add()`, yang akan menempatkan objek di akhir daftar.

`ArrayList` menyediakan banyak metode berguna untuk mengelola datanya. Kita bisa mengakses elemen pada indeks tertentu menggunakan `get()`, menghapus elemen dengan `remove()` (berdasarkan indeks atau objek itu sendiri), dan mengetahui berapa banyak elemen yang ada di dalamnya dengan `size()`. `ArrayList` sangat fleksibel dan sering digunakan karena kemudahan penggunaannya dibandingkan mengelola array biasa secara manual.

Penting untuk diingat bahwa `ArrayList` menyimpan objek, jadi untuk tipe data primitif seperti `int` atau `double`, Java akan secara otomatis 'membungkusnya' menjadi objek (`Integer`, `Double`) melalui proses yang disebut autoboxing. Kemudahan dan efisiensi `ArrayList` menjadikannya salah satu struktur data paling sering digunakan dalam pengembangan aplikasi Java.

```
import java.util.ArrayList;

public class MahasiswaApp {
    public static void main(String[] args) {
        ArrayList<String> daftarNama = new ArrayList<>(); // Membuat ArrayList untuk String
        daftarNama.add("Budi"); // Menambah elemen
        daftarNama.add("Ani");
        daftarNama.add("Cici");

        System.out.println("Nama mahasiswa pertama: " + daftarNama.get(0)); // Mengakses elemen
        System.out.println("Jumlah mahasiswa saat ini: " + daftarNama.size()); // Ukuran ArrayList

        daftarNama.remove(1); // Menghapus elemen "Ani" (berada di indeks 1)
        System.out.println("Daftar setelah Ani dihapus: " + daftarNama);
    }
}
```

💡 **Fun Fact:** Secara internal, `ArrayList` diimplementasikan menggunakan array biasa. Saat `ArrayList` penuh, ia akan membuat array baru yang lebih besar (biasanya 1.5 kali ukuran semula) dan menyalin semua elemen lama ke array baru tersebut secara otomatis, sehingga kamu tidak perlu pusing memikirkan kapasitas!
