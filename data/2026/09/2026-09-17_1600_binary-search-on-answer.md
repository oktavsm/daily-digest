## ⚡ Competitive Programming Concept: Binary Search on Answer

**Category:** Searching
**TL;DR:** Mencari nilai optimal (minimum atau maksimum) dari suatu jawaban yang mungkin dengan binary search pada rentang nilai tersebut, ketika kondisi validitas jawaban bersifat monoton.

Binary Search on Answer (BSOA) adalah teknik powerful yang digunakan ketika kita perlu mencari nilai minimum atau maksimum yang memenuhi suatu kondisi tertentu, di mana kondisi tersebut memiliki sifat monoton. Artinya, jika suatu nilai `X` memenuhi kondisi, maka semua nilai yang lebih besar (atau lebih kecil, tergantung masalahnya) dari `X` juga akan memenuhi kondisi, atau sebaliknya. Contoh klasik termasuk "mencari nilai minimum `X` agar semua objek bisa diselesaikan dalam `K` operasi" atau "mencari nilai maksimum `Y` sehingga `N` sumber daya cukup untuk `Y` unit".

Cara kerjanya mirip binary search biasa, namun kita tidak mencari elemen dalam array terurut, melainkan mencari *nilai jawaban itu sendiri* dalam rentang nilai yang mungkin. Pertama, tentukan rentang `[low, high]` yang sangat lebar untuk nilai jawaban yang mungkin. Kemudian, di setiap iterasi, hitung `mid = low + (high - low) / 2`. Pada `mid` ini, kita akan memanggil sebuah fungsi `check(mid)` yang dirancang khusus untuk masalah tersebut. Fungsi `check(mid)` ini akan mengembalikan `true` jika `mid` adalah jawaban yang valid/memenuhi kondisi, dan `false` jika tidak.

Berdasarkan hasil `check(mid)`, kita perbarui rentang pencarian: jika `check(mid)` benar (dan kita mencari nilai minimum), artinya `mid` bisa menjadi jawaban, jadi kita simpan `mid` sebagai kandidat dan mencoba mencari nilai yang lebih kecil di `[low, mid-1]`. Jika `check(mid)` salah, artinya `mid` terlalu kecil, jadi kita perlu mencari di rentang `[mid+1, high]`. Proses ini berlanjut sampai `low > high`. Kompleksitas waktu BSOA adalah `O(log(Range) * T_check)`, di mana `Range` adalah ukuran rentang `[low, high]` awal, dan `T_check` adalah kompleksitas waktu dari fungsi `check`.

```
bool check(long long val) {
    // Implementasi logika pengecekan untuk 'val'
    // return true jika 'val' memenuhi kondisi, false jika tidak
    return true;
}

void solve() {
    long long low = 0, high = 2e18; // Sesuaikan rentang jawaban
    long long ans = high; // Untuk mencari nilai minimum X

    while (low <= high) {
        long long mid = low + (high - low) / 2;
        if (check(mid)) {
            ans = mid;
            high = mid - 1; // Coba cari yang lebih kecil
        } else {
            low = mid + 1; // 'mid' terlalu kecil, perlu yang lebih besar
        }
    }
    // 'ans' akan berisi nilai optimal
}
```

💡 **Fun Fact:** Berbeda dengan binary search biasa yang mencari elemen dalam array terurut, Binary Search on Answer mencari nilai *itu sendiri* dalam rentang jawaban yang mungkin. Teknik ini sangat fleksibel dan sering menjadi solusi untuk masalah yang kelihatannya tidak ada hubungannya dengan binary search.
