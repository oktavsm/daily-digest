## 🤖 Android Concept: Activity: Jendela Utama Aplikasi Anda

**Category:** UI
**TL;DR:** Activity adalah komponen dasar yang menyediakan satu layar antarmuka pengguna untuk interaksi dengan aplikasi Anda.

Dalam pengembangan Android, Activity adalah salah satu blok bangunan paling fundamental. Secara sederhana, Activity mewakili satu layar dengan antarmuka pengguna (UI) tempat pengguna dapat berinteraksi dengan aplikasi Anda. Misalnya, layar masuk, layar daftar item, atau layar detail produk, semuanya adalah contoh dari Activity. Setiap aplikasi Android setidaknya memiliki satu Activity, dan sebagian besar aplikasi memiliki beberapa Activity untuk menangani berbagai tampilan dan fungsionalitas.

Setiap Activity memiliki siklus hidup (lifecycle) yang jelas, dari mulai dibuat, ditampilkan, dihentikan sementara, hingga dihancurkan. Siklus hidup ini diatur oleh sistem Android dan memiliki metode callback seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()`. Metode `onCreate()` adalah tempat utama untuk melakukan inisialisasi awal Activity, seperti mengatur tata letak (layout) UI dari file XML dan mengikat data.

Navigasi antar Activity dalam aplikasi biasanya dilakukan menggunakan Intent, sebuah objek pesan yang digunakan untuk meminta tindakan dari komponen lain. Selain itu, setiap Activity yang Anda buat harus dideklarasikan dalam file `AndroidManifest.xml` aplikasi Anda. Ini memberitahu sistem Android tentang keberadaan Activity tersebut dan bagaimana Activity itu dapat diluncurkan, serta izin atau konfigurasi spesifik yang mungkin dibutuhkan.

```
package com.example.aplikasipemula

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan file layout XML
        // Kode inisialisasi UI atau logika awal lainnya di sini
    }
}
```

💡 **Fun Fact:** Sistem Android menjaga setiap Activity dalam 'back stack' (tumpukan belakang). Ini memungkinkan pengguna untuk menavigasi mundur melalui layar-layar yang mereka kunjungi sebelumnya dalam aplikasi atau bahkan antar aplikasi lain.
