## 🤖 Android Concept: Memahami Activity di Android

**Category:** UI
**TL;DR:** Activity adalah blok bangunan dasar setiap layar interaktif di aplikasi Android Anda, merepresentasikan satu UI yang bisa berinteraksi dengan pengguna.

Activity adalah komponen fundamental di setiap aplikasi Android, merepresentasikan satu layar antarmuka pengguna (UI) yang dapat berinteraksi dengan pengguna. Pikirkan setiap layar di aplikasi yang Anda gunakan – daftar email, layar pengaturan, atau tampilan detail produk – kemungkinan besar setiap layar tersebut diimplementasikan sebagai Activity.

Setiap aplikasi Android setidaknya memiliki satu Activity utama sebagai titik masuk. Activity bertanggung jawab untuk menggambar layout di layar, merespons interaksi pengguna, dan mengelola siklus hidupnya sendiri. Misalnya, ketika Anda membuka aplikasi, Activity utama akan dibuat dan ditampilkan.

Activity memiliki "siklus hidup" (lifecycle) dengan beberapa tahapan penting seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()`. Memahami ini krusial karena Anda akan menempatkan kode sesuai tahapan ini. `onCreate()` adalah tempat paling umum untuk inisialisasi awal UI dan data saat Activity pertama kali dibuat.

Aplikasi Android umumnya terdiri dari banyak Activity. Anda berpindah dari satu Activity ke Activity lain menggunakan objek `Intent`, yang bertindak seperti pesan untuk sistem Android, memberitahunya Activity mana yang harus diluncurkan atau tindakan apa yang harus dilakukan.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        // Di sini Anda bisa mulai menambahkan logika UI atau inisialisasi
    }
}
```

💡 **Fun Fact:** Setiap kali Anda berpindah antar aplikasi atau beralih layar di satu aplikasi, Anda sebenarnya sedang berinteraksi dengan Activity-activity yang berbeda, yang dikelola oleh sistem Android dalam sebuah 'task' atau tumpukan (back stack).
