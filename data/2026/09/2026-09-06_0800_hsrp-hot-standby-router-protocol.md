## 🌐 Networking Concept: HSRP (Hot Standby Router Protocol)

**Category:** Routing
**TL;DR:** HSRP memastikan redundansi default gateway untuk host di LAN dengan menggunakan satu alamat IP virtual yang dibagi oleh dua atau lebih router fisik, sehingga mencegah single point of failure.

Bayangkan sebuah jaringan lokal di mana semua host bergantung pada satu router sebagai gateway default mereka. Jika router ini mati, seluruh jaringan tidak bisa keluar, meskipun ada router cadangan lain yang siap sedia. Di sinilah Hot Standby Router Protocol (HSRP) hadir. HSRP adalah protokol redundansi first-hop yang dirancang untuk mengatasi single point of failure pada default gateway, memastikan ketersediaan jaringan yang tinggi tanpa interupsi bagi end-user.

HSRP bekerja dengan mengelompokkan dua atau lebih router ke dalam sebuah 'kelompok standby'. Dalam setiap kelompok, satu router ditetapkan sebagai router 'aktif' dan satu lainnya sebagai router 'standby', sementara router lain (jika ada) berada dalam kondisi 'listen'. Semua router dalam kelompok ini berbagi satu alamat IP virtual dan alamat MAC virtual. Host di LAN dikonfigurasi untuk menggunakan alamat IP virtual ini sebagai default gateway mereka. Router aktif yang akan merespons permintaan ARP untuk alamat IP virtual tersebut dan meneruskan lalu lintas.

Jika router aktif mengalami kegagalan (misalnya, interface-nya mati atau router itu sendiri down), router standby akan secara otomatis mengambil alih peran sebagai router aktif. Proses failover ini terjadi secara transparan bagi host, yang bahkan tidak menyadari bahwa default gateway fisik mereka telah berubah. Ini karena mereka terus menggunakan alamat IP dan MAC virtual yang sama. Anda dapat mendemonstrasikan ini dengan mudah di Cisco Packet Tracer dengan mematikan interface pada router aktif dan mengamati bagaimana router standby segera mengambil alih, menjaga konektivitas tetap berjalan.

```
standby 1 ip 192.168.1.254
```

💡 **Fun Fact:** HSRP adalah protokol milik Cisco Systems. Untuk mencapai tujuan yang sama di lingkungan multi-vendor, Anda akan menggunakan Virtual Router Redundancy Protocol (VRRP), yang merupakan standar terbuka (RFC 3768).
