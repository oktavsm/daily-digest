## ⚡ Competitive Programming Concept: 0/1 Knapsack Problem

**Category:** DP
**TL;DR:** Mencari subset item dengan total nilai maksimum yang dapat dimasukkan ke dalam knapsack berkapasitas terbatas, di mana setiap item hanya bisa diambil satu kali.

Konsep 0/1 Knapsack Problem adalah salah satu masalah klasik dalam pemrograman dinamis (Dynamic Programming). Dalam masalah ini, kita diberikan sejumlah N item, di mana setiap item memiliki berat (weight) dan nilai (value) tertentu. Kita juga memiliki sebuah knapsack (tas) dengan kapasitas berat maksimum W. Tujuan kita adalah memilih subset item yang dapat dimasukkan ke dalam knapsack sedemikian rupa sehingga total berat item tidak melebihi W, dan total nilai item yang dipilih adalah maksimum. "0/1" mengacu pada fakta bahwa setiap item hanya dapat diambil *seluruhnya* (1) atau *tidak sama sekali* (0); tidak ada pilihan untuk mengambil sebagian item.

Pendekatan Dynamic Programming (DP) sangat cocok untuk masalah ini. Kita dapat mendefinisikan sebuah tabel DP dua dimensi, `dp[i][w]`, yang merepresentasikan nilai maksimum yang dapat kita capai dengan mempertimbangkan `i` item pertama (dari 0 hingga `i-1`) dan kapasitas knapsack sebesar `w`. Tabel ini akan diisi secara bottom-up. Baris `i` dalam tabel DP akan dihitung berdasarkan baris `i-1`, item sebelumnya, dan kapasitas saat ini.

Untuk setiap item `i` (dari 1 hingga N) dan setiap kapasitas `w` (dari 0 hingga W), ada dua kemungkinan:
1.  **Tidak mengambil item ke-`i`**: Dalam kasus ini, nilai maksimum yang bisa dicapai sama dengan nilai maksimum saat mempertimbangkan `i-1` item pertama dengan kapasitas `w`. Jadi, `dp[i][w] = dp[i-1][w]`.
2.  **Mengambil item ke-`i`**: Ini hanya mungkin jika berat item ke-`i` (`weights[i-1]`) tidak melebihi kapasitas `w`. Jika kita mengambilnya, nilai yang didapat adalah `values[i-1]` ditambah nilai maksimum yang bisa dicapai dari `i-1` item pertama dengan sisa kapasitas `w - weights[i-1]`. Jadi, `dp[i][w] = values[i-1] + dp[i-1][w - weights[i-1]]`.
Kita akan mengambil nilai maksimum dari kedua opsi ini.

Kasus dasar (base cases) adalah ketika `i=0` (tidak ada item) atau `w=0` (kapasitas nol), di mana `dp[0][w]` dan `dp[i][0]` akan selalu 0. Setelah tabel terisi penuh, `dp[N][W]` akan berisi jawaban akhir. Kompleksitas waktu untuk pendekatan ini adalah **O(N * W)**, di mana N adalah jumlah item dan W adalah kapasitas knapsack. Kompleksitas ruang juga **O(N * W)**, meskipun bisa dioptimalkan menjadi **O(W)** jika kita hanya menggunakan dua baris atau bahkan satu baris DP dengan iterasi terbalik untuk kapasitas.

```
#include <vector>
#include <algorithm>

int knapsack(int W, const std::vector<int>& weights, const std::vector<int>& values) {
    int n = weights.size();
    std::vector<std::vector<int>> dp(n + 1, std::vector<int>(W + 1, 0));

    for (int i = 1; i <= n; ++i) {
        for (int w = 1; w <= W; ++w) {
            if (weights[i-1] <= w) {
                dp[i][w] = std::max(dp[i-1][w], values[i-1] + dp[i-1][w - weights[i-1]]);
            } else {
                dp[i][w] = dp[i-1][w];
            }
        }
    }
    return dp[n][W];
}
```

💡 **Fun Fact:** Masalah 0/1 Knapsack adalah salah satu dari 21 masalah NP-lengkap pertama yang diidentifikasi oleh Richard Karp pada tahun 1972, yang berarti tidak ada algoritma waktu polinomial yang diketahui untuk menyelesaikannya secara umum. Namun, algoritma pemrograman dinamis ini efisien karena kapasitas W biasanya tidak terlalu besar, sehingga disebut sebagai "pseudopolynomial".
