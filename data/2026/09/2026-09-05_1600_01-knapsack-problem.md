## ⚡ Competitive Programming Concept: 0/1 Knapsack Problem

**Category:** DP
**TL;DR:** Masalah 0/1 Knapsack mencari nilai maksimum barang yang dapat dimasukkan ke dalam tas dengan kapasitas terbatas, di mana setiap barang hanya bisa dipilih sekali atau tidak sama sekali.

Masalah 0/1 Knapsack adalah salah satu masalah klasik dalam pemrograman dinamis (DP). Anda diberikan sejumlah N barang, di mana setiap barang `i` memiliki berat `w_i` dan nilai `v_i`. Anda juga memiliki sebuah tas (knapsack) dengan kapasitas maksimum `C`. Tujuan Anda adalah memilih subset barang-barang yang dapat dimasukkan ke dalam tas sehingga total berat barang tidak melebihi kapasitas `C`, dan total nilai barang yang terpilih adalah maksimum. Nama "0/1" menunjukkan bahwa setiap barang hanya bisa diambil secara utuh (1) atau tidak sama sekali (0), tidak ada pilihan mengambil sebagian.

Untuk menyelesaikan masalah ini dengan DP, kita bisa mendefinisikan `dp[j]` sebagai nilai maksimum yang bisa kita capai dengan kapasitas tas `j`. Inisialisasi `dp[0]` dengan 0 (kapasitas 0, nilai 0) dan semua `dp[j]` lainnya dengan 0. Kemudian, kita akan mengiterasi melalui setiap barang. Untuk setiap barang `i` dengan berat `w_i` dan nilai `v_i`, kita mempertimbangkan apakah akan memasukkan barang ini ke dalam tas atau tidak. Untuk mencegah sebuah barang dihitung lebih dari sekali (yang akan terjadi jika kita mengiterasi kapasitas dari kecil ke besar), kita harus mengiterasi kapasitas `w` dari `C` (kapasitas maksimum) menurun hingga `w_i` (berat barang saat ini).

Transisi DP-nya adalah: `dp[w] = max(dp[w], dp[w - weights[i]] + values[i])`. Ini berarti, untuk kapasitas `w`, nilai maksimum yang bisa kita dapatkan adalah maksimum dari dua pilihan: (1) tidak memasukkan barang `i`, sehingga nilainya tetap `dp[w]` dari iterasi barang sebelumnya, atau (2) memasukkan barang `i`, yang berarti kita mengambil nilai `values[i]` ditambah nilai maksimum yang bisa didapat dari kapasitas sisa `w - weights[i]` (yaitu `dp[w - weights[i]]`). Dengan mengiterasi kapasitas dari `C` turun, kita memastikan bahwa `dp[w - weights[i]]` merujuk pada hasil dari _barang-barang sebelumnya_, bukan dari barang `i` yang sama di iterasi saat ini. Kompleksitas waktu untuk solusi ini adalah O(N * C), di mana N adalah jumlah barang dan C adalah kapasitas tas.

Solusi DP ini memiliki kompleksitas ruang O(C) karena kita hanya membutuhkan satu array 1D. Meskipun efisien untuk kapasitas tas yang tidak terlalu besar, perlu diingat bahwa jika kapasitas `C` sangat besar, O(N * C) mungkin masih terlalu lambat. Ini adalah tradeoff yang sering ditemui dalam masalah DP. Namun, ini adalah dasar yang kuat untuk memahami banyak variasi masalah knapsack lainnya serta konsep DP secara umum.

```
int knapsack01(int capacity, const std::vector<int>& weights, const std::vector<int>& values) {
    int n = weights.size();
    std::vector<int> dp(capacity + 1, 0);

    for (int i = 0; i < n; ++i) { // Iterasi setiap barang
        for (int w = capacity; w >= weights[i]; --w) { // Iterasi kapasitas dari max turun
            dp[w] = std::max(dp[w], dp[w - weights[i]] + values[i]);
        }
    }
    return dp[capacity];
}
```

💡 **Fun Fact:** Masalah Knapsack ini merupakan salah satu dari 21 masalah NP-lengkap pertama yang diidentifikasi oleh Richard Karp pada tahun 1972, yang menunjukkan betapa sulitnya menemukan solusi optimal secara cepat untuk kasus umum. Namun, untuk batasan tertentu (seperti kapasitas), ia dapat diselesaikan secara efisien dengan pemrograman dinamis.
