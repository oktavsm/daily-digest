## ☕ Java Concept: Penanganan Exception (Exception Handling)

**Category:** Exception
**TL;DR:** Mempelajari cara program Java mengelola error atau kondisi tak terduga yang terjadi saat runtime agar aplikasi tetap berjalan stabil.

Dalam pengembangan perangkat lunak, tidak jarang terjadi kondisi di luar dugaan yang dapat menyebabkan program berhenti bekerja secara tiba-tiba atau 'crash'. Kondisi tak terduga ini disebut sebagai 'exception'. Penanganan exception (Exception Handling) adalah mekanisme penting dalam Java yang memungkinkan kita untuk mengidentifikasi, menangkap, dan merespons kondisi error ini dengan cara yang terkontrol, sehingga aplikasi tetap stabil dan memberikan pengalaman yang lebih baik bagi pengguna.

Mekanisme dasar untuk menangani exception di Java adalah dengan menggunakan blok `try-catch`. Kode yang berpotensi memicu exception diletakkan di dalam blok `try`. Jika sebuah exception terjadi di dalam blok `try`, eksekusi kode akan segera berpindah ke blok `catch` yang sesuai, yang kemudian akan menangani exception tersebut. Blok `catch` mendefinisikan jenis exception yang ingin ditangkap dan tindakan apa yang harus dilakukan ketika exception tersebut terjadi, seperti menampilkan pesan error atau melakukan logging.

Selain `try-catch`, kita juga sering menemukan blok `finally`. Blok `finally` akan selalu dieksekusi, terlepas dari apakah exception terjadi atau tidak di dalam blok `try`. Ini sangat berguna untuk membersihkan sumber daya yang digunakan, seperti menutup koneksi database atau stream file, memastikan bahwa sumber daya tersebut dibebaskan dengan benar bahkan jika terjadi error. Java memiliki berbagai jenis exception, yang secara umum dibagi menjadi 'checked exceptions' (yang harus dideklarasikan atau ditangkap) dan 'unchecked exceptions' (biasanya akibat kesalahan pemrograman dan tidak harus dideklarasikan).

Memahami dan menerapkan penanganan exception yang baik adalah kunci untuk membangun aplikasi Java yang tangguh dan dapat diandalkan, karena membantu kita untuk mengantisipasi dan merespons berbagai skenario kegagalan tanpa menghentikan seluruh program.

```
public class ExceptionDemo {
    public static void main(String[] args) {
        String inputAngka = "seratus"; // Contoh input tidak valid
        try {
            int angka = Integer.parseInt(inputAngka);
            System.out.println("Angka yang di-parse: " + angka);
        } catch (NumberFormatException e) {
            System.err.println("Error: Input bukan format angka yang valid!");
        } finally {
            System.out.println("Proses penanganan exception selesai.");
        }
    }
}
```

💡 **Fun Fact:** Java adalah salah satu bahasa pertama yang mempopulerkan konsep 'checked exceptions', di mana kompilator memaksa programmer untuk secara eksplisit menangani atau mendeklarasikan potensi error, yang tujuannya adalah menciptakan kode yang lebih robust (tangguh).
