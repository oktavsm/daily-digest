## ⚡ Competitive Programming Concept: Dynamic Programming: 0/1 Knapsack

**Category:** DP
**TL;DR:** Dynamic Programming adalah teknik untuk memecah masalah kompleks menjadi sub-masalah yang lebih kecil, menyimpan hasil sub-masalah untuk menghindari perhitungan berulang, dan membangun solusi akhir secara optimal, seperti yang diilustrasikan oleh masalah 0/1 Knapsack.

Dynamic Programming (DP) adalah metode yang kuat dalam competitive programming untuk menyelesaikan masalah optimasi dengan memecahnya menjadi sub-masalah yang lebih kecil yang saling tumpang tindih (overlapping subproblems) dan memiliki struktur optimal (optimal substructure). Salah satu contoh klasik yang mengilustrasikan DP adalah masalah 0/1 Knapsack. Dalam masalah ini, kita diberikan sejumlah item, masing-masing dengan berat dan nilai tertentu, serta sebuah kapasitas maksimum knapsack. Tujuan kita adalah memilih subset item yang total beratnya tidak melebihi kapasitas knapsack, sambil memaksimalkan total nilai item yang dibawa.

Masalah 0/1 Knapsack dinamakan demikian karena setiap item hanya bisa dipilih seluruhnya (1) atau tidak sama sekali (0). Pendekatan DP melibatkan pembuatan tabel (biasanya 2D) `dp[i][w]`, yang merepresentasikan nilai maksimum yang bisa didapat dengan menggunakan `i` item pertama dan kapasitas knapsack `w`. Ketika mempertimbangkan item ke-`i`, kita memiliki dua pilihan: tidak memasukkan item tersebut (nilai tetap `dp[i-1][w]`) atau memasukkannya (jika berat item `berat[i-1]` tidak melebihi `w`, maka nilainya adalah `nilai[i-1] + dp[i-1][w - berat[i-1]`). Kita memilih opsi yang memberikan nilai maksimum dari kedua pilihan tersebut.

Hubungan rekurensi untuk `dp[i][w]` adalah sebagai berikut: Jika `berat[i-1] > w`, maka `dp[i][w] = dp[i-1][w]`. Jika `berat[i-1] <= w`, maka `dp[i][w] = max(dp[i-1][w], nilai[i-1] + dp[i-1][w - berat[i-1]])`. Basis kasusnya adalah `dp[0][w] = 0` untuk semua `w`, dan `dp[i][0] = 0` untuk semua `i`. Tabel DP diisi secara iteratif. Kompleksitas waktu untuk solusi ini adalah `O(N * W)`, di mana `N` adalah jumlah item dan `W` adalah kapasitas maksimum knapsack. Kompleksitas ruangnya juga `O(N * W)`, meskipun dapat dioptimalkan menjadi `O(W)` menggunakan array 1D.

```
vector<vector<int>> dp(N + 1, vector<int>(W + 1, 0));
for (int i = 1; i <= N; ++i) {
    for (int w = 1; w <= W; ++w) {
        if (weights[i-1] <= w) {
            dp[i][w] = max(dp[i-1][w], values[i-1] + dp[i-1][w - weights[i-1]]);
        } else {
            dp[i][w] = dp[i-1][w];
        }
    }
}
// Hasil maksimum ada di dp[N][W]
```

💡 **Fun Fact:** 0/1 Knapsack adalah masalah NP-hard jika diselesaikan secara umum, tetapi dapat dipecahkan dalam waktu pseudo-polinomial menggunakan Dynamic Programming karena keterbatasan kapasitas knapsack dan jumlah item. Ini menunjukkan bagaimana kendala tertentu dapat memungkinkan solusi efisien.
