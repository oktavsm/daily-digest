## ☕ Java Concept: Classes dan Objek

**Category:** OOP
**TL;DR:** Classes adalah blueprint untuk membuat objek, yang merupakan instansi dari class tersebut dengan properti dan perilaku uniknya sendiri.

Dalam pemrograman berorientasi objek (OOP) seperti Java, Class adalah konsep fundamental yang berfungsi sebagai cetak biru (blueprint) atau template untuk membuat objek. Sebuah Class mendefinisikan struktur dan perilaku yang akan dimiliki oleh objek-objek yang dibuat darinya. Struktur ini berupa variabel yang disebut atribut (atau properti), sedangkan perilakunya berupa fungsi yang disebut method.

Objek adalah instansi konkret atau wujud nyata dari sebuah Class. Jika Class adalah cetak biru sebuah mobil, maka objek adalah mobil-mobil nyata yang diproduksi dari cetak biru tersebut (misalnya, 'mobilToyota' atau 'mobilHonda'). Setiap objek yang dibuat dari Class yang sama akan memiliki atribut dan method yang sama, namun setiap objek dapat memiliki nilai atribut yang berbeda secara independen. Ini memungkinkan kita untuk memodelkan entitas dunia nyata dalam program kita.

Ketika Anda membuat sebuah objek dari suatu Class, Anda sedang melakukan 'instansiasi'. Objek yang terinstansiasi akan menempati memori dan dapat berinteraksi satu sama lain atau dengan bagian lain dari program melalui method-nya. Konsep Class dan Objek sangat penting untuk membuat kode yang terstruktur, modular, mudah dikelola, dan dapat merepresentasikan kompleksitas dunia nyata secara efektif dalam aplikasi Java.

```
class Kucing { // Definisi Class
    String nama; // Atribut (properti)
    String warna;

    void mengeong() { // Method (perilaku)
        System.out.println(nama + " berwarna " + warna + " mengeong: Meow!");
    }
}
/* Cara membuat Objek di method main():
Kucing siMolly = new Kucing();
siMolly.nama = "Molly";
siMolly.warna = "Putih";
siMolly.mengeong();
*/
```

💡 **Fun Fact:** Java secara fundamental adalah bahasa berorientasi objek, di mana hampir semua hal yang kita kerjakan melibatkan Class dan Objek. Bahkan, method `main()` yang sering kita tulis pun berada di dalam sebuah Class!
