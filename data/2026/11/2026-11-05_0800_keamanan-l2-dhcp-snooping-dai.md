## 🌐 Networking Concept: Keamanan L2: DHCP Snooping & DAI

**Category:** Security
**TL;DR:** Melindungi jaringan dari serangan DHCP spoofing dan ARP poisoning menggunakan fitur keamanan Layer 2 pada switch.

Jaringan lokal (Layer 2) seringkali dianggap aman, padahal rentan terhadap berbagai serangan, terutama dari dalam jaringan itu sendiri. Dua serangan umum yang sering terjadi adalah DHCP spoofing, di mana server DHCP palsu mencoba mendistribusikan alamat IP dan informasi gateway yang salah, serta ARP poisoning (atau ARP spoofing), di mana penyerang memanipulasi cache ARP host lain untuk mengalihkan lalu lintas data melalui dirinya (Man-in-the-Middle). Untuk mengatasi kerentanan ini, switch modern menawarkan fitur keamanan canggih seperti DHCP Snooping dan Dynamic ARP Inspection (DAI).

**DHCP Snooping** adalah fitur keamanan yang diaktifkan pada switch untuk memfilter pesan DHCP. Switch akan mengklasifikasikan port-portnya sebagai "trusted" (port yang terhubung ke server DHCP yang sah atau switch lain) atau "untrusted" (port yang terhubung ke end device atau server DHCP yang tidak sah). Pesan DHCP server hanya diizinkan masuk melalui port trusted. Ketika DHCP Snooping diaktifkan, switch membangun sebuah database (disebut DHCP Snooping Binding Table) yang berisi pasangan MAC address, IP address, nomor VLAN, port, dan waktu lease untuk setiap host yang mendapatkan alamat IP secara sah. Tabel ini menjadi dasar validasi untuk fitur keamanan lain.

**Dynamic ARP Inspection (DAI)** bekerja sama dengan DHCP Snooping untuk melindungi dari serangan ARP poisoning. DAI akan memeriksa setiap paket ARP yang melewati switch dan memvalidasinya terhadap informasi yang ada di DHCP Snooping Binding Table. Jika sebuah paket ARP mengklaim asosiasi IP-MAC yang tidak cocok dengan entri di tabel binding yang sah, atau jika ada upaya untuk melakukan ARP spoofing, switch akan memblokir paket ARP tersebut. Seperti DHCP Snooping, DAI juga menggunakan konsep port trusted dan untrusted, di mana validasi hanya dilakukan pada port untrusted.

Kombinasi DHCP Snooping dan DAI memberikan lapisan keamanan pertama yang kuat pada jaringan Layer 2. DHCP Snooping memastikan bahwa host mendapatkan alamat IP dari server yang sah dan membangun tabel binding yang akurat. DAI kemudian menggunakan tabel ini untuk secara aktif mencegah serangan ARP poisoning, sehingga melindungi integritas komunikasi dan mencegah serangan Man-in-the-Middle di tingkat lokal. Mengimplementasikan kedua fitur ini sangat penting untuk membangun jaringan yang lebih resilien terhadap ancaman internal.

```
ip dhcp snooping trust
```

💡 **Fun Fact:** DHCP Snooping tidak hanya mencegah DHCP spoofing, tetapi tabel binding yang dihasilkannya juga dapat digunakan oleh fitur keamanan lain seperti IP Source Guard untuk mencegah host menggunakan alamat IP statis yang tidak sah atau mencuri alamat IP host lain.
