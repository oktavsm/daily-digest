## ☕ Java Concept: Menggunakan ArrayList untuk Koleksi Dinamis

**Category:** Collections
**TL;DR:** ArrayList adalah struktur data dinamis di Java yang memungkinkan kita menyimpan dan mengelola koleksi objek yang ukurannya bisa berubah saat program berjalan, berbeda dengan array biasa yang ukurannya tetap.

Dalam pemrograman, seringkali kita perlu menyimpan sekumpulan data, seperti daftar nama mahasiswa atau daftar produk. Cara paling dasar adalah menggunakan array. Namun, array di Java memiliki keterbatasan utama: ukurannya sudah ditentukan sejak awal dan tidak bisa diubah. Jika kita awalnya membuat array dengan 10 slot, kita tidak bisa tiba-tiba menambahkannya menjadi 15 slot atau menguranginya menjadi 5 slot saat program berjalan, yang seringkali merepotkan ketika kita tidak tahu pasti berapa banyak data yang akan disimpan.

Untuk mengatasi keterbatasan array statis ini, Java menyediakan `ArrayList` sebagai bagian dari Java Collections Framework. `ArrayList` adalah implementasi dari antarmuka `List` yang menawarkan fungsionalitas array tetapi dengan kemampuan untuk mengubah ukurannya secara dinamis. Ini berarti Anda bisa menambah atau menghapus elemen sesuka hati, dan `ArrayList` akan secara otomatis menyesuaikan kapasitasnya di belakang layar. Saat mendeklarasikan `ArrayList`, Anda harus menentukan tipe data objek yang akan disimpan di dalamnya menggunakan Generics, misalnya `ArrayList<String>` untuk menyimpan teks atau `ArrayList<Integer>` untuk angka.

Menggunakan `ArrayList` sangat intuitif. Anda dapat menambahkan elemen baru menggunakan metode `add()`, mengambil elemen pada indeks tertentu dengan `get(index)`, mengetahui jumlah elemen yang ada saat ini dengan `size()`, dan menghapus elemen dengan `remove(index)` atau `remove(object)`. Dengan kemampuan-kemampuan ini, `ArrayList` menjadi salah satu struktur data yang paling sering digunakan dalam pengembangan aplikasi Java karena fleksibilitas dan kemudahannya dalam mengelola koleksi data yang dinamis.

```
import java.util.ArrayList;

public class DaftarMahasiswa {
    public static void main(String[] args) {
        ArrayList<String> namaMahasiswa = new ArrayList<>();

        namaMahasiswa.add("Budi Santoso");
        namaMahasiswa.add("Siti Aminah");
        namaMahasiswa.add("Andi Wijaya");

        System.out.println("Jumlah mahasiswa: " + namaMahasiswa.size());
        System.out.println("Mahasiswa pertama: " + namaMahasiswa.get(0));

        namaMahasiswa.remove("Siti Aminah"); 
        System.out.println("Jumlah setelah dihapus: " + namaMahasiswa.size());
    }
}
```

💡 **Fun Fact:** Meskipun `ArrayList` tampak seperti array yang bisa tumbuh, di balik layarnya, `ArrayList` sebenarnya diimplementasikan menggunakan array biasa. Ketika `ArrayList` mencapai kapasitas maksimumnya, ia akan membuat array baru yang lebih besar (biasanya 1.5 kali ukuran semula), lalu menyalin semua elemen dari array lama ke array baru tersebut.
