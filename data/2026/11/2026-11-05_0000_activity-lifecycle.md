## 🤖 Android Concept: Activity Lifecycle

**Category:** Architecture
**TL;DR:** Siklus hidup Activity menjelaskan tahapan-tahapan yang dilalui sebuah layar di aplikasi Android, dari dibuat hingga dihancurkan.

Setiap layar di aplikasi Android Anda disebut Activity. Activity Lifecycle adalah serangkaian tahapan yang dilalui oleh setiap Activity, mulai dari saat ia dibuat, tampil di layar, berpindah ke latar belakang, hingga akhirnya dihancurkan dari memori. Memahami siklus ini sangat penting untuk mengelola sumber daya aplikasi dengan baik, seperti menyimpan data saat aplikasi berhenti sementara atau memastikan UI selalu menampilkan informasi yang benar.

Tahapan kunci dalam Activity Lifecycle meliputi `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()`. `onCreate()` adalah tempat utama untuk melakukan inisialisasi awal, seperti mengatur tata letak (layout) dan mengikat view. Setelah `onCreate()`, Activity akan berlanjut ke `onStart()` dan kemudian `onResume()`, yang menandakan Activity kini sepenuhnya interaktif bagi pengguna.

Ketika pengguna beralih ke aplikasi lain atau Activity lain di aplikasi Anda, Activity saat ini akan melalui `onPause()` dan mungkin `onStop()`. Di sinilah Anda harus menyimpan data state yang penting atau melepaskan sumber daya yang hanya diperlukan saat Activity aktif. Terakhir, `onDestroy()` dipanggil ketika Activity akan dihapus sepenuhnya dari memori, misalnya saat pengguna menekan tombol back berulang kali atau sistem perlu mengosongkan memori. Dengan memahami kapan metode-metode ini dipanggil, Anda bisa menulis kode yang lebih efisien dan responsif terhadap interaksi pengguna serta peristiwa sistem.

```
import android.os.Bundle
import android.util.Log
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    private val TAG = "MainActivity"

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        Log.d(TAG, "onCreate: Activity created.")
    }

    override fun onResume() {
        super.onResume()
        Log.d(TAG, "onResume: Activity resumed, fully interactive.")
    }

    override fun onPause() {
        super.onPause()
        Log.d(TAG, "onPause: Activity paused, going to background.")
    }

    override fun onDestroy() {
        super.onDestroy()
        Log.d(TAG, "onDestroy: Activity destroyed.")
    }
}
```

💡 **Fun Fact:** Tahukah Anda bahwa Android akan otomatis mencoba menyimpan dan memulihkan UI state Activity Anda saat terjadi perubahan konfigurasi (misalnya rotasi layar) secara default? Namun, mengimplementasikan `onSaveInstanceState()` dan `onRestoreInstanceState()` adalah praktik terbaik untuk data yang lebih kompleks.
