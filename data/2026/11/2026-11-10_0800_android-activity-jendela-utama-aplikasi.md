## 🤖 Android Concept: Android Activity: Jendela Utama Aplikasi

**Category:** UI
**TL;DR:** Activity adalah komponen fundamental dalam aplikasi Android yang merepresentasikan satu layar antarmuka pengguna (UI) tempat pengguna dapat berinteraksi.

Setiap aplikasi Android terdiri dari satu atau lebih Activity. Anggap saja Activity sebagai satu "layar" dalam aplikasi Anda, seperti layar login, layar daftar produk, atau layar detail pengaturan. Ketika Anda membuka aplikasi dan melihat antarmuka, apa yang Anda lihat dan interaksikan adalah sebuah Activity yang sedang berjalan. Activity bertanggung jawab untuk menyediakan jendela di mana UI aplikasi digambar dan untuk merespons interaksi pengguna.

Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, yang diwakili oleh serangkaian metode callback seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()`. Metode-metode ini dipanggil oleh sistem Android pada berbagai tahapan saat Activity dibuat, dimulai, dijeda, dihentikan, atau dihancurkan. Memahami siklus hidup ini sangat krusial untuk mengelola sumber daya aplikasi dengan benar dan memberikan pengalaman pengguna yang mulus, misalnya menyimpan data saat aplikasi dijeda atau membebaskan memori saat Activity tidak lagi terlihat.

Untuk membuat Activity baru, Anda perlu membuat kelas Kotlin yang mewarisi dari `AppCompatActivity` atau `ComponentActivity` (untuk proyek Compose). Di dalam kelas ini, Anda akan menimpa metode `onCreate()` yang merupakan tempat utama untuk melakukan inisialisasi awal Activity Anda. Di sinilah Anda biasanya mengatur tata letak antarmuka pengguna menggunakan `setContentView()` yang merujuk ke file layout XML Anda, dan menginisialisasi View-View yang ada di dalamnya.

Navigasi antar Activity biasanya dilakukan menggunakan `Intent`, sebuah objek yang digunakan untuk "meminta" sistem Android untuk memulai Activity lain atau melakukan operasi tertentu. Activity adalah fondasi dari setiap aplikasi Android yang berinteraksi dengan pengguna, dan penguasaannya adalah langkah pertama yang krusial bagi setiap developer Android pemula untuk membangun aplikasi yang fungsional dan responsif.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan dengan layout XML
    }
}
```

💡 **Fun Fact:** Sebelum Kotlin menjadi bahasa resmi untuk pengembangan Android, sebagian besar aplikasi Android ditulis dalam Java. Meskipun demikian, konsep dasar Activity tetap sama, menunjukkan betapa sentralnya komponen ini dalam arsitektur Android.
