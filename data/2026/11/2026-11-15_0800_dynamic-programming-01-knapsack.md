## ⚡ Competitive Programming Concept: Dynamic Programming: 0/1 Knapsack

**Category:** DP
**TL;DR:** Metode untuk memecahkan masalah optimasi dengan memecahkannya menjadi submasalah yang lebih kecil dan menyimpan hasilnya untuk menghindari komputasi ulang.

Dynamic Programming (DP) adalah metode kuat dalam competitive programming untuk menyelesaikan masalah optimasi dengan memecahkannya menjadi submasalah yang lebih kecil dan saling tumpang tindih (overlapping subproblems), lalu menyimpan hasil dari submasalah tersebut (memoization atau tabulation) untuk menghindari perhitungan ulang. Ini sangat efektif untuk masalah yang memiliki struktur optimal (optimal substructure), di mana solusi optimal dari masalah besar dapat dibangun dari solusi optimal submasalahnya.

Salah satu contoh klasik penerapan DP adalah masalah 0/1 Knapsack. Diberikan sejumlah N barang, di mana setiap barang `i` memiliki berat `w[i]` dan nilai `v[i]`, serta sebuah tas (knapsack) dengan kapasitas maksimum `W`. Tujuan kita adalah memilih subset barang sedemikian rupa sehingga total berat barang yang dipilih tidak melebihi `W`, dan total nilai barang yang dipilih adalah maksimum. "0/1" menunjukkan bahwa setiap barang hanya dapat dipilih satu kali (diambil atau tidak sama sekali).

Masalah ini dapat diselesaikan dengan DP menggunakan tabel `dp[i][j]`, yang menyatakan nilai maksimum yang dapat diperoleh dari `i` barang pertama dengan kapasitas tas `j`. Rekurensi untuk `dp[i][j]` adalah sebagai berikut: jika berat barang `i` (`w[i-1]`) lebih besar dari kapasitas `j`, maka `dp[i][j] = dp[i-1][j]`. Jika tidak, `dp[i][j] = max(dp[i-1][j], values[i-1] + dp[i-1][j - weights[i-1]])`. Nilai akhir yang dicari adalah `dp[N][W]`.

Pendekatan DP ini memiliki kompleksitas waktu `O(N * W)` dan kompleksitas ruang `O(N * W)`, di mana `N` adalah jumlah barang dan `W` adalah kapasitas knapsack. Kompleksitas ruang dapat dioptimalkan menjadi `O(W)` dengan hanya menyimpan dua baris (atau bahkan satu baris jika iterasi dilakukan dengan benar) dari tabel DP, karena `dp[i][j]` hanya bergantung pada nilai dari baris sebelumnya (`i-1`).

```
int knapsack(int W, const std::vector<int>& weights, const std::vector<int>& values) {
    int N = weights.size();
    std::vector<std::vector<int>> dp(N + 1, std::vector<int>(W + 1, 0));
    for (int i = 1; i <= N; ++i) {
        for (int j = 1; j <= W; ++j) {
            if (weights[i-1] <= j) {
                dp[i][j] = std::max(dp[i-1][j], values[i-1] + dp[i-1][j - weights[i-1]]);
            } else {
                dp[i][j] = dp[i-1][j];
            }
        }
    }
    return dp[N][W];
}
```

💡 **Fun Fact:** Istilah Dynamic Programming diciptakan oleh Richard Bellman pada tahun 1950-an. Ia memilih 'dynamic' karena terdengar lebih menarik di mata sponsor penelitiannya, dan 'programming' merujuk pada 'planning' atau 'scheduling' (bukan pemrograman komputer dalam arti modern).
