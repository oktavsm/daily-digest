## 🤖 Android Concept: Android Activity Lifecycle

**Category:** Architecture
**TL;DR:** Activity adalah komponen UI dasar yang merepresentasikan satu layar di aplikasi Anda, dan memiliki siklus hidup yang mengatur kapan dan bagaimana Activity berperilaku selama aplikasi berjalan.

Activity adalah salah satu komponen fundamental dan paling sering digunakan di Android. Setiap kali pengguna melihat layar di aplikasi Anda dan berinteraksi dengannya, kemungkinan besar itu adalah sebuah Activity. Activity bertanggung jawab untuk menyediakan jendela visual di mana aplikasi dapat menggambar UI-nya dan merespons input pengguna, pada dasarnya mewakili satu layar dengan satu fokus tunggal.

Namun, sebuah Activity tidak selalu berada dalam kondisi yang sama sepanjang waktu. Saat pengguna membuka aplikasi, berpindah antar layar, atau bahkan menerima panggilan telepon, Activity akan berpindah dari satu 'state' ke state lainnya. Perpindahan antar state inilah yang kita sebut sebagai Android Activity Lifecycle, yang diwakili oleh serangkaian method callback seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()`.

Memahami siklus hidup ini sangat krusial. Sistem operasi Android dapat menghentikan atau bahkan mematikan Activity Anda untuk menghemat sumber daya, terutama saat perangkat kekurangan memori. Dengan mengimplementasikan method-method callback siklus hidup ini, Anda dapat memastikan bahwa aplikasi Anda berperilaku dengan benar, menyimpan data penting saat Activity dihentikan, dan melepaskan sumber daya yang tidak diperlukan seperti koneksi jaringan atau database yang terbuka.

Sebagai contoh, `onCreate()` adalah tempat Anda melakukan inisialisasi awal seperti mengatur layout atau mengikat data ke UI. `onResume()` dipanggil saat Activity Anda siap berinteraksi penuh dengan pengguna. Sebaliknya, `onPause()` adalah tempat yang baik untuk menyimpan perubahan data pengguna yang belum disimpan, karena Activity Anda mungkin akan dihentikan atau beralih ke background setelahnya. Mengelola siklus hidup dengan benar akan membuat aplikasi Anda lebih stabil, efisien, dan memberikan pengalaman pengguna yang lebih baik.

```
import android.os.Bundle
import android.util.Log
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Mengatur layout UI
        Log.d("Lifecycle", "onCreate: Activity dibuat dan layout diatur.")
    }
    override fun onResume() {
        super.onResume()
        Log.d("Lifecycle", "onResume: Activity siap berinteraksi dengan user.")
    }
    // Masih banyak callback lain seperti onPause(), onStop(), onDestroy()
}
```

💡 **Fun Fact:** Did you know bahwa Activity adalah salah satu dari empat komponen inti Android, bersama dengan Services (untuk operasi di background), Broadcast Receivers (untuk merespons event sistem), dan Content Providers (untuk mengelola data bersama)?
