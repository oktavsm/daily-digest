## ☕ Java Concept: Kelas dan Objek dalam Java

**Category:** OOP
**TL;DR:** Kelas adalah cetak biru untuk membuat objek, yang merupakan instansi nyata dari kelas dengan data dan perilaku uniknya.

Di Java, kelas (class) adalah konsep fundamental yang berfungsi sebagai cetak biru atau template. Bayangkan Anda ingin membangun banyak rumah yang serupa; Anda memerlukan denah atau desain arsitektur. Denah inilah analogi dari sebuah kelas. Kelas mendefinisikan struktur data (atribut atau *fields*) dan perilaku (metode atau *methods*) yang akan dimiliki oleh objek-objek yang dibuat darinya. Kelas itu sendiri bukanlah objek, melainkan deskripsi bagaimana objek seharusnya terlihat dan bertindak.

Objek (object) adalah instansi nyata dari sebuah kelas. Mengikuti analogi denah rumah, objek adalah rumah fisik yang telah dibangun berdasarkan denah tersebut. Setiap objek memiliki nilai unik untuk atribut-atributnya (disebut *state*) dan dapat melakukan tindakan sesuai dengan metode yang didefinisikan dalam kelasnya (disebut *behavior*). Anda bisa membuat banyak objek dari satu kelas yang sama, dan masing-masing objek akan memiliki kehidupannya sendiri yang terpisah.

Hubungan antara kelas dan objek adalah satu-ke-banyak; satu kelas bisa digunakan untuk membuat banyak objek. Di Java, semua program berorientasi objek (OOP), yang berarti sebagian besar kode yang Anda tulis akan melibatkan pembuatan dan interaksi antara objek-objek. Pemahaman yang kuat tentang kelas dan objek sangat penting karena ini adalah fondasi untuk membangun aplikasi yang modular, mudah dikelola, dan dapat digunakan kembali (*reusable*). Konsep ini juga menjadi dasar untuk prinsip OOP lainnya seperti *inheritance* dan *polymorphism*.

```
public class Sepeda { // Ini adalah definisi Kelas
    String merk;       // Ini adalah Atribut (data)

    void genjot() {    // Ini adalah Metode (perilaku)
        System.out.println("Sepeda " + merk + " digenjot!");
    }

    public static void main(String[] args) {
        Sepeda sepedaKu = new Sepeda(); // Ini adalah pembuatan Objek 'sepedaKu'
        sepedaKu.merk = "Polygon";      // Mengatur nilai atribut objek
        sepedaKu.genjot();              // Memanggil metode objek
    }
}
```

💡 **Fun Fact:** Java dirancang dengan filosofi 'everything is an object' (kecuali tipe data primitif), menjadikan pemahaman kelas dan objek sangat krusial. Konsep ini membantu developer dalam memodelkan masalah dunia nyata ke dalam kode program.
