## 🤖 Android Concept: Memahami Android Activity

**Category:** UI
**TL;DR:** Activity adalah komponen dasar yang menyediakan layar tunggal untuk berinteraksi dengan pengguna di aplikasi Android.

Activity adalah salah satu komponen fundamental dalam setiap aplikasi Android. Bayangkan Activity sebagai satu layar atau antarmuka tunggal yang dilihat dan berinteraksi dengan pengguna. Misalnya, layar login, layar daftar produk, atau layar pengaturan, masing-masing biasanya diwakili oleh sebuah Activity. Setiap aplikasi Android terdiri dari satu atau lebih Activity yang saling terkait, dan Activity adalah titik masuk utama pengguna ke dalam aplikasi Anda.

Setiap Activity memiliki "siklus hidup" (lifecycle) yang dikelola oleh sistem Android. Ini berarti ada serangkaian metode callback yang dipanggil pada berbagai tahap keberadaan Activity, seperti saat dibuat, dimulai, dilanjutkan, dihentikan, atau dihancurkan. Bagi pemula, metode `onCreate()` adalah yang paling penting. Metode ini dipanggil saat Activity pertama kali dibuat dan merupakan tempat utama untuk melakukan inisialisasi, seperti mengaitkan layout UI dari file XML dengan `setContentView()` dan inisialisasi variabel-variabel penting.

Untuk membuat Activity, Anda cukup membuat kelas Kotlin yang mewarisi dari `AppCompatActivity` (atau `ComponentActivity` untuk pendekatan yang lebih modern). Setelah itu, Anda perlu mendaftarkan Activity tersebut dalam file `AndroidManifest.xml` agar sistem Android mengetahuinya dan bisa meluncurkannya. Deklarasi di manifest juga mencakup `<intent-filter>` jika Activity tersebut adalah titik masuk utama aplikasi Anda, menjadikannya 'launcher activity' yang akan terlihat di daftar aplikasi pengguna.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Mengaitkan layout XML
        // Logika inisialisasi lainnya di sini
    }
}
```

💡 **Fun Fact:** Setiap aplikasi Android harus memiliki setidaknya satu Activity yang ditetapkan sebagai 'launcher' agar bisa muncul di daftar aplikasi pengguna dan diluncurkan dari sana.
