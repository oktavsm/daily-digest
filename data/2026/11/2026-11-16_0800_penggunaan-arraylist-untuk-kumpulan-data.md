## ☕ Java Concept: Penggunaan `ArrayList` untuk Kumpulan Data

**Category:** Collections
**TL;DR:** `ArrayList` adalah struktur data dinamis di Java untuk menyimpan koleksi objek yang ukurannya dapat berubah sesuai kebutuhan.

Sebagai mahasiswa pemrograman, Anda pasti pernah berhadapan dengan array, yaitu kumpulan data yang ukurannya sudah ditentukan sejak awal. Namun, bagaimana jika Anda perlu menyimpan daftar data yang jumlahnya tidak Anda ketahui pasti saat program dimulai, dan bisa bertambah atau berkurang sewaktu-waktu? Di sinilah `ArrayList` menjadi sangat berguna. `ArrayList` adalah salah satu implementasi dari antarmuka `List` dalam Java Collections Framework, yang memungkinkan Anda membuat daftar objek yang ukurannya dapat disesuaikan (dinamis).

Untuk menggunakan `ArrayList`, Anda harus mengimpornya dari paket `java.util`. Deklarasinya sedikit berbeda dari array biasa; Anda perlu menentukan jenis data (tipe generik) yang akan disimpan di dalamnya, misalnya `<String>` untuk teks atau `<Integer>` untuk angka. Setelah `ArrayList` dibuat, Anda bisa menambahkan elemen baru menggunakan metode `add()`. Setiap elemen akan ditambahkan di akhir daftar secara berurutan, dan `ArrayList` akan otomatis menyesuaikan kapasitasnya jika diperlukan.

Mengakses elemen di `ArrayList` sama mudahnya. Anda dapat mengambil elemen pada posisi (indeks) tertentu menggunakan metode `get()`, mirip dengan array standar (ingat, indeks dimulai dari 0!). Jika Anda ingin mengganti elemen yang sudah ada dengan elemen baru, gunakan metode `set()`. Untuk menghapus elemen, `ArrayList` menyediakan metode `remove()` yang bisa menerima indeks atau objek yang ingin dihapus. Selain itu, Anda bisa mengetahui berapa banyak elemen yang ada di dalam `ArrayList` saat ini dengan menggunakan metode `size()`.

Memahami dan mahir menggunakan `ArrayList` adalah keterampilan dasar yang sangat penting dalam pengembangan aplikasi Java. Anda akan sering menemukannya digunakan untuk menyimpan daftar item belanja, data dari database, input pengguna, atau objek-objek lain yang jumlahnya tidak statis. Ini adalah fondasi yang kokoh untuk mempelajari struktur data lain yang lebih kompleks dan membangun aplikasi yang lebih dinamis dan interaktif.

```
import java.util.ArrayList;

// Dalam metode main() Anda:
ArrayList<String> daftarMahasiswa = new ArrayList<>(); // Membuat ArrayList
daftarMahasiswa.add("Budi"); // Menambah elemen
daftarMahasiswa.add("Siti");
daftarMahasiswa.add("Joko");

System.out.println("Elemen ke-0: " + daftarMahasiswa.get(0)); // Output: Budi
daftarMahasiswa.set(1, "Ani"); // Mengubah Siti menjadi Ani
daftarMahasiswa.remove("Joko"); // Menghapus Joko

System.out.println("Isi ArrayList: " + daftarMahasiswa); // Output: [Budi, Ani]
System.out.println("Jumlah elemen: " + daftarMahasiswa.size()); // Output: 2
```

💡 **Fun Fact:** Java Collections Framework, tempat `ArrayList` berada, pertama kali diperkenalkan pada Java 1.2 di tahun 1998. Desainnya terinspirasi dari beberapa struktur data di C++ Standard Template Library (STL), tetapi dengan pendekatan yang lebih berorientasi objek khas Java.
