## 🤖 Android Concept: Dasar-Dasar Android Activity

**Category:** UI
**TL;DR:** Activity adalah komponen fundamental dalam aplikasi Android yang merepresentasikan satu layar tunggal dengan antarmuka pengguna untuk berinteraksi dengan pengguna.

Setiap aplikasi Android terdiri dari satu atau lebih Activity. Anggap saja setiap Activity sebagai satu "layar" dalam aplikasi Anda. Misalnya, ketika Anda membuka aplikasi WhatsApp, daftar chat adalah satu Activity, dan ketika Anda mengklik salah satu chat, layar chat itu adalah Activity lain. Activity menyediakan tempat bagi Anda untuk menampilkan UI, merespons interaksi pengguna, dan mengelola logika bisnis yang terkait dengan layar tersebut.

Activity memiliki daur hidup (lifecycle) yang terdefinisi dengan baik, yang mencakup berbagai status seperti `Created`, `Started`, `Resumed`, `Paused`, `Stopped`, dan `Destroyed`. Sistem Android akan memanggil metode-metode tertentu (seperti `onCreate()`, `onStart()`, `onResume()`, dll.) ketika Activity berpindah antar status ini. Memahami daur hidup ini sangat penting untuk mengelola sumber daya dengan benar dan memastikan pengalaman pengguna yang lancar, misalnya, menyimpan data saat aplikasi di-background atau melepaskan listener.

Untuk membuat Activity, Anda cukup membuat kelas Kotlin yang mewarisi dari `AppCompatActivity` dan mengimplementasikan metode `onCreate()`. Di dalam `onCreate()`, Anda biasanya akan memanggil `setContentView()` untuk mengaitkan layout XML dengan Activity Anda. Setiap Activity juga harus dideklarasikan dalam file `AndroidManifest.xml` agar sistem Android dapat mengenalinya dan meluncurkannya.

Meskipun Activity dapat menjadi entry point utama, aplikasi seringkali memiliki banyak Activity dan perlu berpindah antar mereka. Anda dapat memulai Activity lain menggunakan `Intent`. `Intent` adalah objek pesan yang dapat Anda gunakan untuk meminta tindakan dari komponen aplikasi lain, seperti meluncurkan Activity baru, mengirim data, atau memanggil layanan. Ini memungkinkan navigasi yang mulus antar layar dalam aplikasi Anda.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
    }
}
```

💡 **Fun Fact:** Activity pertama kali diperkenalkan pada API level 1 (Android 1.0) pada tahun 2008 dan tetap menjadi fondasi utama dalam pengembangan aplikasi Android hingga saat ini, meskipun konsep seperti Fragment dan Jetpack Compose telah menambah cara baru untuk membangun UI.
