## ☕ Java Concept: Menggunakan ArrayList untuk Koleksi Dinamis

**Category:** Collections
**TL;DR:** ArrayList memungkinkan kita menyimpan dan mengelola daftar objek yang ukurannya bisa berubah secara dinamis, jauh lebih fleksibel daripada array biasa.

Dalam pemrograman, seringkali kita perlu menyimpan sekumpulan data. Array adalah salah satu cara untuk melakukannya, namun array memiliki batasan ukuran yang tetap setelah dibuat, sehingga kita tidak bisa dengan mudah menambah atau mengurangi elemen di dalamnya. Di sinilah `ArrayList` hadir sebagai solusi yang sangat praktis dan sering digunakan. `ArrayList` adalah bagian dari Java Collections Framework yang menyediakan implementasi daftar (list) yang ukurannya dapat berubah secara dinamis.

`ArrayList` dirancang untuk menyimpan objek, bukan tipe data primitif secara langsung (misalnya `int` harus menjadi `Integer`). Untuk mendeklarasikan dan menginisialisasi sebuah `ArrayList`, kita perlu menentukan tipe objek yang akan disimpan di dalamnya, seperti `ArrayList<String>` untuk daftar nama atau `ArrayList<Integer>` untuk daftar angka. Setelah dibuat, kita dapat menambahkan elemen baru menggunakan metode `add()`, dan `ArrayList` akan secara otomatis menyesuaikan ukurannya untuk menampung elemen tersebut tanpa perlu kita khawatirkan.

Untuk mengakses elemen dalam `ArrayList`, kita bisa menggunakan metode `get()` dengan indeks posisi elemen (dimulai dari 0, sama seperti array). Jika kita ingin menghapus elemen, ada metode `remove()` yang bisa menghapus berdasarkan indeks atau berdasarkan objek itu sendiri. Kita juga bisa mengetahui berapa banyak elemen yang ada di dalam `ArrayList` menggunakan metode `size()`. Fleksibilitas ini membuat `ArrayList` menjadi pilihan utama saat kita tidak tahu persis berapa banyak data yang akan kita tangani.

Secara ringkas, `ArrayList` adalah struktur data yang sangat berguna karena menggabungkan kemudahan akses berdasarkan indeks seperti array, namun dengan keunggulan adaptasi ukuran yang dinamis. Ini adalah alat fundamental untuk mengelola koleksi data yang jumlahnya tidak tetap, menjadikannya salah satu kelas yang paling sering Anda temui dan gunakan dalam aplikasi Java sehari-hari.

```
import java.util.ArrayList;

public class DaftarMahasiswa {
    public static void main(String[] args) {
        ArrayList<String> namaMahasiswa = new ArrayList<>(); // Membuat ArrayList
        namaMahasiswa.add("Budi Santoso"); // Menambah elemen
        namaMahasiswa.add("Siti Aminah");
        namaMahasiswa.add("Joko Susilo");

        System.out.println("Jumlah mahasiswa: " + namaMahasiswa.size());
        System.out.println("Mahasiswa pertama: " + namaMahasiswa.get(0));

        namaMahasiswa.remove(1); // Menghapus Siti Aminah (indeks 1)
        System.out.println("Jumlah mahasiswa setelah dihapus: " + namaMahasiswa.size());
        System.out.println("Daftar terbaru: " + namaMahasiswa);
    }
}
```

💡 **Fun Fact:** Tahukah Anda bahwa `ArrayList` adalah salah satu implementasi paling populer dari antarmuka `List` dalam Java Collections Framework? Struktur dasarnya sebenarnya menggunakan array biasa di balik layar, namun Java mengelola peningkatan ukurannya secara otomatis saat Anda menambahkan lebih banyak elemen.
