## ⚡ Competitive Programming Concept: Dynamic Programming (DP)

**Category:** DP
**TL;DR:** Sebuah teknik algoritma yang memecah masalah kompleks menjadi sub-masalah yang lebih kecil, menyimpan solusi dari sub-masalah tersebut untuk menghindari perhitungan berulang dan mencapai solusi optimal.

Dynamic Programming (DP) adalah metode yang sangat ampuh dalam competitive programming untuk menyelesaikan masalah optimasi atau perhitungan yang melibatkan sub-masalah yang saling tumpang tindih (overlapping subproblems) dan memiliki struktur optimal (optimal substructure). Dua properti kunci ini berarti bahwa solusi optimal dari masalah yang lebih besar dapat dibangun dari solusi optimal sub-masalahnya, dan sub-masalah yang sama akan muncul berkali-kali jika dipecahkan secara rekursif tanpa penyimpanan.

Ada dua pendekatan utama dalam implementasi DP: memoization (top-down) dan tabulation (bottom-up). Memoization melibatkan rekursi di mana hasil dari setiap pemanggilan fungsi disimpan dalam sebuah 'memo' (biasanya array atau map) setelah dihitung pertama kali. Jika pemanggilan fungsi dengan parameter yang sama terjadi lagi, hasilnya langsung diambil dari memo tanpa perlu menghitung ulang. Tabulation, di sisi lain, bersifat iteratif, membangun solusi dari kasus dasar hingga mencapai solusi masalah utama, mengisi tabel DP secara berurutan.

Dengan memanfaatkan penyimpanan hasil sub-masalah, DP secara drastis mengurangi kompleksitas waktu dari eksponensial menjadi polinomial. Misalnya, masalah seperti menghitung bilangan Fibonacci ke-N atau menemukan jalur terpendek di Directed Acyclic Graph (DAG) dapat diselesaikan secara efisien. Kompleksitas waktu DP seringkali berkisar O(N) atau O(N*M), tergantung pada dimensi 'state' atau jumlah sub-masalah yang perlu dihitung.

Langkah-langkah umum dalam menerapkan DP meliputi mendefinisikan 'state' DP (apa yang direpresentasikan oleh setiap entri tabel DP), merumuskan relasi rekursif atau transisi antar state, menentukan kasus dasar (base cases), dan memilih antara pendekatan memoization atau tabulation untuk implementasinya.

```
/* memerlukan #include <vector> */
std::vector<int> memo;

int fib_dp(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib_dp(n-1) + fib_dp(n-2);
}
// Cara memanggil: memo.assign(N+1, -1); int result = fib_dp(N);
```

💡 **Fun Fact:** Richard Bellman, penemu istilah "Dynamic Programming", memilih nama tersebut pada tahun 1950-an untuk menyamarkan penelitian matematikanya dari atasannya yang skeptis di RAND Corporation, karena kata "dynamic" terdengar lebih impresif dan relevan secara militer.
