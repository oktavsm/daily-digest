## ☕ Java Concept: ArrayList: List Dinamis

**Category:** Collections
**TL;DR:** ArrayList adalah implementasi dari antarmuka List yang menyediakan array yang ukurannya dapat berubah secara dinamis, memungkinkan kita menyimpan dan mengelola kumpulan objek.

Sebelumnya, Anda mungkin sudah akrab dengan array biasa di Java. Array sangat berguna untuk menyimpan kumpulan data dengan tipe yang sama, tetapi memiliki satu keterbatasan utama: ukurannya tetap setelah dibuat. Bagaimana jika kita tidak tahu berapa banyak data yang akan kita simpan di awal? Di sinilah `ArrayList` datang sebagai solusi. `ArrayList` adalah bagian dari Java Collections Framework yang menyediakan "array yang dapat diubah ukurannya" (`resizable-array`), memungkinkan Anda untuk menambahkan atau menghapus elemen kapan saja tanpa perlu khawatir tentang kapasitas awal.

Menggunakan `ArrayList` cukup mudah. Anda perlu mengimpornya dari package `java.util`. Saat membuat objek `ArrayList`, kita juga menentukan tipe data objek yang akan disimpan di dalamnya menggunakan *generics* (misalnya `<String>` untuk menyimpan teks, atau `<Integer>` untuk angka). Untuk menambahkan elemen, kita menggunakan metode `add()`. Metode ini akan menempatkan elemen baru di akhir list.

Setelah elemen ditambahkan, Anda dapat mengaksesnya menggunakan metode `get()` dengan indeks elemen yang diinginkan (ingat, indeks dimulai dari 0). Anda juga bisa menghapus elemen dengan `remove()` (berdasarkan indeks atau objeknya), atau mengubah elemen yang sudah ada dengan `set()`. Untuk mengetahui berapa banyak elemen yang ada di `ArrayList`, gunakan metode `size()`. Iterasi melalui `ArrayList` bisa dilakukan dengan loop `for` biasa atau *enhanced for loop* (for-each).

`ArrayList` sangat cocok digunakan ketika Anda membutuhkan list yang elemennya sering diakses berdasarkan indeks, dan ketika Anda sering menambahkan elemen di akhir list. Karena sifatnya yang mirip array, akses acak (mengambil elemen berdasarkan indeks) sangat cepat. Namun, jika Anda sering melakukan operasi penambahan atau penghapusan di awal atau tengah list, performa `ArrayList` bisa menurun karena memerlukan penggeseran semua elemen setelahnya, yang bisa menjadi mahal untuk list yang sangat besar.

```
import java.util.ArrayList;

public class MahasiswaApp {
    public static void main(String[] args) {
        ArrayList<String> daftarNama = new ArrayList<>(); // Membuat ArrayList
        daftarNama.add("Budi"); // Menambah elemen
        daftarNama.add("Ani");
        daftarNama.add("Cici");

        System.out.println("Nama pertama: " + daftarNama.get(0)); // Mengakses elemen
        daftarNama.set(1, "Doni"); // Mengubah elemen

        System.out.println("Daftar nama saat ini:");
        for (String nama : daftarNama) { // Iterasi
            System.out.println(nama);
        }
    }
}
```

💡 **Fun Fact:** ArrayList menggunakan array internal sebagai penyimpanan. Ketika ArrayList penuh dan Anda mencoba menambahkan elemen baru, ia akan secara otomatis membuat array internal baru yang lebih besar (biasanya 1.5 kali ukuran semula) dan menyalin semua elemen lama ke array baru tersebut. Proses ini disebut "resizing".
