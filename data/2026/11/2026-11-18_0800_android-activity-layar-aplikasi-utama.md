## 🤖 Android Concept: Android Activity: Layar Aplikasi Utama

**Category:** UI
**TL;DR:** Activity adalah komponen dasar yang merepresentasikan layar tunggal dengan antarmuka pengguna dalam aplikasi Android.

Setiap kali Anda membuka aplikasi Android dan melihat sebuah layar, kemungkinan besar itu adalah sebuah Activity. Activity adalah komponen aplikasi inti yang menyediakan wadah untuk antarmuka pengguna (UI) tempat pengguna dapat berinteraksi. Bayangkan Activity sebagai satu "halaman" atau "layar" dalam buku aplikasi Anda, di mana setiap layar memiliki tujuan dan fungsionalitasnya sendiri.

Sebuah Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, mulai dari dibuat, aktif, terhenti, hingga dihancurkan. Metode-metode seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()` dipanggil oleh sistem Android pada tahapan yang berbeda. `onCreate()` adalah titik masuk paling penting, di mana Anda biasanya melakukan inisialisasi awal, seperti mengatur tata letak (layout) dan mengikat komponen UI.

Untuk membuat Activity, Anda perlu membuat kelas Kotlin yang mewarisi dari `AppCompatActivity` (atau `Activity` dasar) dan mendeklarasikannya di dalam file `AndroidManifest.xml`. Deklarasi ini memberi tahu sistem Android bahwa kelas tersebut adalah bagian dari aplikasi Anda dan dapat diluncurkan. Biasanya, setiap Activity akan dihubungkan dengan satu atau lebih file layout XML yang mendefinisikan tampilan antarmuka penggunanya.

Interaksi antar Activity juga merupakan konsep penting. Anda bisa memulai Activity lain dari Activity saat ini menggunakan `Intent`. Misalnya, ketika pengguna mengklik tombol "Detail Produk" di layar daftar produk, Anda akan meluncurkan Activity Detail Produk menggunakan `Intent`, yang juga bisa membawa data dari satu Activity ke Activity lainnya.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan layout XML
        // Di sini Anda bisa inisialisasi UI atau logic lain
    }
}
```

💡 **Fun Fact:** Activity telah menjadi pondasi UI Android sejak versi pertamanya. Google pernah mencoba mengganti atau melengkapi konsep ini dengan Fragments untuk modularitas, tetapi Activity tetap menjadi kontainer utama untuk sebagian besar pengalaman pengguna.
