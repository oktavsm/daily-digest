## ☕ Java Concept: Menggunakan ArrayList untuk Koleksi Data

**Category:** Collections
**TL;DR:** `ArrayList` adalah struktur data dinamis yang memungkinkan kita menyimpan dan mengelola daftar objek yang ukurannya dapat berubah secara fleksibel selama program berjalan.

Dalam pemrograman Java, seringkali kita perlu menyimpan sekumpulan data yang jumlahnya tidak kita ketahui secara pasti di awal, atau yang jumlahnya bisa bertambah dan berkurang. Array standar Java memiliki ukuran yang tetap setelah dibuat, yang bisa menjadi batasan. Di sinilah `ArrayList` dari paket `java.util` menjadi sangat berguna. `ArrayList` adalah implementasi dari antarmuka `List`, yang menyediakan array berukuran dinamis. Ini berarti kita dapat dengan mudah menambah atau menghapus elemen tanpa khawatir tentang kapasitas awal.

Untuk menggunakan `ArrayList`, kita perlu mengimpornya terlebih dahulu. Pembuatannya sangat mirip dengan objek lain, namun kita harus menentukan tipe data objek yang akan disimpannya (menggunakan Generics, misalnya `<String>` untuk menyimpan teks atau `<Integer>` untuk angka). Setelah `ArrayList` dibuat, kita bisa menambahkan elemen menggunakan metode `add()`. Elemen akan ditambahkan di akhir daftar secara berurutan, dan `ArrayList` akan otomatis mengatur ulang kapasitasnya jika diperlukan.

`ArrayList` menyediakan berbagai metode untuk mengelola datanya. Kita bisa mendapatkan elemen pada indeks tertentu menggunakan `get()`, mengubah elemen pada indeks tertentu dengan `set()`, dan menghapus elemen baik berdasarkan objeknya (`remove(Object)`) maupun berdasarkan indeksnya (`remove(int)`). Ukuran `ArrayList` saat ini bisa diketahui dengan metode `size()`. Kemampuan untuk mengakses elemen berdasarkan indeks membuatnya efisien untuk operasi pencarian dan akses langsung. `ArrayList` adalah salah satu kelas koleksi paling sering digunakan dalam pengembangan aplikasi Java karena fleksibilitas dan kemudahan penggunaannya dibandingkan array tradisional.

```
import java.util.ArrayList;

public class ContohArrayList {
    public static void main(String[] args) {
        ArrayList<String> daftarMahasiswa = new ArrayList<>(); // Inisialisasi
        daftarMahasiswa.add("Siti");      // Tambah elemen
        daftarMahasiswa.add("Bagus");
        daftarMahasiswa.add("Dewi");

        System.out.println("Mahasiswa pertama: " + daftarMahasiswa.get(0)); // Akses
        daftarMahasiswa.set(1, "Adi"); // Ubah elemen kedua

        System.out.println("Daftar lengkap: " + daftarMahasiswa); // Cetak seluruh list
        daftarMahasiswa.remove(0); // Hapus elemen pertama
        System.out.println("Setelah dihapus: " + daftarMahasiswa); // Cetak lagi
    }
}
```

💡 **Fun Fact:** `ArrayList` diimplementasikan di balik layar menggunakan array biasa. Ketika `ArrayList` mencapai kapasitas maksimumnya, ia akan membuat array baru yang lebih besar (biasanya 1.5 kali ukuran semula) dan menyalin semua elemen lama ke array baru tersebut. Proses inilah yang membuatnya tampak "dinamis".
