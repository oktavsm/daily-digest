## ⚡ Competitive Programming Concept: Disjoint Set Union (DSU)

**Category:** Data Structure
**TL;DR:** DSU adalah struktur data yang efisien untuk melacak partisi set elemen-elemen ke dalam sejumlah set yang tidak tumpang tindih, mendukung operasi penggabungan set dan pencarian representatif set secara cepat.

DSU, atau Disjoint Set Union, adalah struktur data yang dirancang untuk mengelola koleksi elemen-elemen yang terbagi menjadi beberapa set yang saling lepas (disjoint). Tujuan utamanya adalah untuk secara efisien melakukan dua operasi: `find(x)` yang mengembalikan representatif (biasanya root) dari set yang mengandung elemen `x`, dan `union(x, y)` yang menggabungkan set yang mengandung `x` dan set yang mengandung `y` menjadi satu set tunggal. DSU sangat berguna dalam masalah yang melibatkan konektivitas, seperti di graf atau pengelompokan elemen.

Implementasi dasar DSU menggunakan array `parent`, di mana `parent[i]` menyimpan parent dari elemen `i`. Jika `parent[i] == i`, maka `i` adalah root atau representatif dari setnya. Operasi `find` akan menelusuri rantai parent hingga menemukan root. Untuk meningkatkan efisiensi, teknik `path compression` digunakan: selama `find`, setiap node yang dikunjungi akan langsung menunjuk ke root, membuat pohon lebih datar.

Operasi `union` menggabungkan dua set dengan membuat root salah satu set menunjuk ke root set lainnya. Untuk mencegah pohon menjadi terlalu tinggi dan tidak seimbang, teknik `union by rank` atau `union by size` diterapkan. `Union by rank` menggabungkan pohon dengan rank (tinggi) yang lebih kecil ke pohon dengan rank yang lebih besar, sementara `union by size` menggabungkan pohon dengan ukuran (jumlah node) yang lebih kecil ke pohon yang lebih besar. Kombinasi `path compression` dan `union by rank/size` adalah implementasi standar yang sangat efisien.

Dengan kedua optimasi ini, kompleksitas waktu untuk setiap operasi `find` atau `union` menjadi hampir konstan. Secara teoritis, kompleksitasnya adalah O(α(N)), di mana α adalah fungsi invers Ackermann. Fungsi ini tumbuh sangat lambat sehingga untuk semua N yang praktis, α(N) kurang dari 5, menjadikannya performa yang sangat mendekati O(1) amortized. Initialisasi DSU untuk N elemen membutuhkan O(N) waktu.

```
vector<int> parent; // diasumsikan telah diinisialisasi: parent[i] = i

int find(int i) {
    if (parent[i] == i) return i;
    return parent[i] = find(parent[i]); // Path compression
}

void unite(int i, int j) {
    int root_i = find(i);
    int root_j = find(j);
    if (root_i != root_j) {
        parent[root_j] = root_i; // Simple union (tanpa rank/size)
    }
}
```

💡 **Fun Fact:** Penemu DSU adalah Bernard A. Galler dan Michael J. Fischer pada tahun 1964. Struktur data ini awalnya disebut "Union-Find Algorithm".
