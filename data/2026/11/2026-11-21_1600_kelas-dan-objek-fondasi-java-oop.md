## ☕ Java Concept: Kelas dan Objek: Fondasi Java OOP

**Category:** OOP
**TL;DR:** Di Java, kelas adalah blueprint untuk membuat objek, yang merupakan instansi dari kelas dengan perilaku dan data uniknya sendiri.

Dalam pemrograman Java, `Kelas` (Class) bisa diibaratkan sebagai sebuah cetak biru atau 'blueprint'. Ia mendefinisikan struktur dan perilaku yang akan dimiliki oleh objek-objek yang dibuat dari kelas tersebut. Sebuah kelas bukan objek itu sendiri, melainkan hanya sebuah template yang menjelaskan jenis data (atribut atau *fields*) apa yang akan dimiliki oleh objek, serta aksi atau fungsi apa saja yang bisa dilakukan oleh objek tersebut (metode atau *methods*).

Sebaliknya, `Objek` (Object) adalah instansi nyata dari sebuah kelas. Jika kelas adalah cetak biru rumah, maka objek adalah rumah yang sudah jadi berdasarkan cetak biru tersebut. Setiap objek memiliki data (nilai atribut) dan perilaku (metode) uniknya sendiri, meskipun dibuat dari kelas yang sama. Anda dapat membuat banyak objek dari satu kelas, dan setiap objek tersebut akan beroperasi secara independen.

Konsep kelas dan objek adalah inti dari Pemrograman Berorientasi Objek (OOP) di Java. Mereka memungkinkan kita untuk memodelkan entitas dunia nyata ke dalam kode program dengan cara yang terstruktur dan mudah dikelola. Dengan menggunakan kelas dan objek, kode menjadi lebih modular, mudah dipahami, dapat digunakan kembali (reusable), dan lebih mudah untuk di-debug atau diperbaiki, menjadikannya fondasi utama dalam mengembangkan aplikasi Java yang kompleks dan efisien.

```
class Mobil {
    String merk;
    void nyalakan() {
        System.out.println(merk + " menyala.");
    }
}

public class Demo {
    public static void main(String[] args) {
        Mobil mobilSaya = new Mobil(); // Membuat objek
        mobilSaya.merk = "Toyota";     // Mengisi atribut
        mobilSaya.nyalakan();          // Memanggil metode
    }
}
```

💡 **Fun Fact:** Bahkan program 'Hello World' sederhana di Java pun harus berada di dalam sebuah kelas, menunjukkan betapa fundamentalnya konsep kelas dalam bahasa ini.
