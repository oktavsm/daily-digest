## 🤖 Android Concept: Activity: Layar Utama Aplikasi Android

**Category:** Architecture
**TL;DR:** Activity adalah komponen inti Android yang merepresentasikan satu layar antarmuka pengguna, mengelola siklus hidupnya, dan menyediakan tempat bagi pengguna untuk berinteraksi dengan aplikasi.

Setiap kali Anda membuka aplikasi Android dan melihat satu layar interaktif, kemungkinan besar Anda sedang berinteraksi dengan sebuah Activity. Activity adalah salah satu blok bangunan paling fundamental dalam pengembangan aplikasi Android, bertindak sebagai pintu gerbang utama ke interaksi pengguna dan fungsionalitas aplikasi. Ia bertanggung jawab untuk menyediakan jendela visual di mana aplikasi Anda menggambar antarmuka pengguna (UI) dan tempat pengguna dapat berinteraksi.

Sebuah Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, mulai dari dibuat, aktif, dijeda, dihentikan, hingga dihancurkan. Memahami siklus hidup ini sangat krusial, karena di sinilah Anda akan menentukan kapan kode Anda harus berjalan — misalnya, saat Activity pertama kali dibuat (`onCreate`), saat kembali ke latar depan (`onResume`), atau saat akan dihentikan sementara (`onPause`). Metode `onCreate()` adalah yang paling penting bagi pemula, karena di sinilah Activity diinisialisasi, layout di-inflate, dan komponen UI pertama kali disiapkan.

Untuk membuat Activity, Anda perlu mendefinisikan sebuah kelas Kotlin yang mewarisi dari `AppCompatActivity` (atau `Activity` dasar) dan mendeklarasikannya dalam file `AndroidManifest.xml` aplikasi Anda. Deklarasi di manifest memberi tahu sistem Android tentang keberadaan Activity ini dan bagaimana cara meluncurkannya. Setiap aplikasi Android setidaknya memiliki satu Activity utama yang bertindak sebagai titik masuk saat aplikasi diluncurkan dari launcher.

Antarmuka pengguna yang ditampilkan oleh sebuah Activity biasanya didefinisikan dalam sebuah file layout XML terpisah. Activity kemudian menggunakan metode `setContentView()` untuk 'mengaitkan' layout XML tersebut ke jendela visualnya, mengubah definisi layout menjadi elemen UI yang bisa dilihat dan diinteraksi oleh pengguna. Ini memisahkan logika aplikasi dari desain UI, membuat kode lebih bersih dan mudah dikelola.

```
package com.example.myapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Mengaitkan layout XML
        // Di sini kita bisa inisialisasi View atau data lain
    }
}
```

💡 **Fun Fact:** Tahukah Anda bahwa Android 1.0 tidak memiliki Fragment? Activity adalah satu-satunya cara untuk membuat layar aplikasi saat itu. Fragment baru diperkenalkan di Android 3.0 (Honeycomb) untuk membantu menangani ukuran layar yang lebih besar seperti tablet.
