## ⚡ Competitive Programming Concept: Disjoint Set Union (DSU)

**Category:** Data Structure
**TL;DR:** DSU adalah struktur data yang efisien untuk melacak partisi set elemen ke dalam himpunan-himpunan yang tidak tumpang tindih dan menggabungkannya.

Disjoint Set Union (DSU), atau sering juga disebut Union-Find, adalah struktur data yang digunakan untuk mengelola partisi dari sebuah set elemen ke dalam himpunan-himpunan (set) yang tidak tumpang tindih. Dua operasi utamanya adalah `find(i)` yang mengembalikan representasi (biasanya "root" atau elemen kanonis) dari himpunan tempat elemen `i` berada, dan `union(i, j)` yang menggabungkan dua himpunan yang mengandung elemen `i` dan `j` menjadi satu himpunan. Konsep ini sangat berguna dalam masalah yang melibatkan pengelompokan elemen atau pelacakan komponen terhubung dalam sebuah graf.

Implementasi DSU biasanya menggunakan sebuah array `parent[]` di mana `parent[i]` menyimpan parent dari elemen `i`. Jika `parent[i] == i`, maka `i` adalah root dari himpunannya. Operasi `find(i)` bekerja dengan melintasi rantai parent sampai menemukan root. Untuk efisiensi, teknik `path compression` digunakan: selama melintasi rantai, setiap elemen yang dikunjungi akan langsung menunjuk ke root, memipihkan struktur pohon. Operasi `union(i, j)` pertama-tama menemukan root dari `i` dan `j`, katakanlah `root_i` dan `root_j`. Jika keduanya berbeda, `root_j` dijadikan anak dari `root_i` (atau sebaliknya).

Untuk lebih meningkatkan performa operasi `union`, kita dapat menggunakan teknik `union by size` atau `union by rank`. `Union by size` memastikan bahwa root dari pohon yang lebih kecil selalu menjadi anak dari root pohon yang lebih besar, menjaga pohon tetap dangkal. `Union by rank` melakukan hal serupa berdasarkan perkiraan tinggi pohon. Dengan kombinasi `path compression` dan `union by size/rank`, kompleksitas waktu amortized untuk kedua operasi `find` dan `union` menjadi O(α(N)), di mana α adalah fungsi Ackermann invers. Fungsi ini tumbuh sangat lambat, sehingga dalam praktiknya, kompleksitasnya hampir konstan.

DSU memiliki banyak aplikasi di competitive programming, seperti menemukan komponen terhubung dalam graf, mendeteksi siklus dalam graf tidak berarah (jika menambahkan edge yang menghubungkan dua node dalam komponen yang sama berarti ada siklus), dan merupakan bagian fundamental dari algoritma Kruskal untuk mencari Minimum Spanning Tree (MST). DSU juga bisa diadaptasi untuk masalah-masalah yang lebih kompleks seperti DSU on trees atau Dynamic Connectivity.

```
vector<int> parent; // parent[i] stores parent of i

int find_set(int v) {
    if (v == parent[v])
        return v;
    return parent[v] = find_set(parent[v]); // Path compression
}

void union_sets(int a, int b) {
    a = find_set(a);
    b = find_set(b);
    if (a != b) {
        parent[b] = a; // Simple union (without size/rank for brevity)
    }
}
```

💡 **Fun Fact:** Fungsi Ackermann invers (α) yang muncul dalam kompleksitas DSU tumbuh sangat lambat. Untuk setiap N yang bisa kita bayangkan (bahkan lebih besar dari jumlah atom di alam semesta), nilai α(N) selalu kurang dari 5.
