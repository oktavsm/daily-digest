## 🌐 Networking Concept: HSRP: Redundansi Gateway Jaringan

**Category:** Protocol
**TL;DR:** HSRP menyediakan redundancy gateway default untuk host di jaringan lokal dengan memungkinkan beberapa router berbagi satu alamat IP virtual, mencegah titik kegagalan tunggal.

Dalam topologi jaringan modern, ketersediaan adalah kunci. Salah satu titik kegagalan tunggal yang paling umum adalah gateway default (router) yang menghubungkan subnet lokal ke jaringan yang lebih luas. Jika router ini down, semua host di subnet tersebut akan kehilangan konektivitas ke dunia luar, menghentikan operasional bisnis atau layanan. Di sinilah Hot Standby Router Protocol (HSRP) dari Cisco berperan penting sebagai salah satu First Hop Redundancy Protocols (FHRPs).

HSRP mengatasi masalah ini dengan memungkinkan dua atau lebih router pada segmen LAN yang sama untuk berbagi satu alamat IP virtual dan alamat MAC virtual. Alamat IP virtual inilah yang akan dikonfigurasi sebagai gateway default pada semua host di subnet tersebut. Salah satu router akan ditetapkan sebagai router 'Active', yang bertanggung jawab untuk meneruskan lalu lintas secara aktif. Router lain akan menjadi router 'Standby', yang terus memantau status router Active dan siap mengambil alih peran penerusan lalu lintas jika router Active gagal atau tidak lagi dapat dijangkau.

Proses failover dari Active ke Standby ini terjadi secara otomatis dan transparan bagi host di jaringan, yang tidak perlu mengubah konfigurasi gateway mereka. Ini memastikan kontinuitas layanan dan meningkatkan ketersediaan jaringan secara signifikan, menghilangkan titik kegagalan tunggal pada lapisan akses. Dalam Packet Tracer, kita bisa mensimulasikan kegagalan router Active dan mengamati bagaimana router Standby segera mengambil alih, menjaga konektivitas tetap berjalan. Konfigurasi HSRP melibatkan penugasan group ID yang sama dan alamat IP virtual, serta prioritas untuk menentukan siapa yang menjadi Active atau Standby.

```
standby 1 ip 192.168.1.254
```

💡 **Fun Fact:** HSRP adalah protokol eksklusif (proprietary) milik Cisco. Versi standar terbuka yang memiliki tujuan serupa dan bisa digunakan di perangkat dari vendor lain disebut VRRP (Virtual Router Redundancy Protocol).
