## ⚡ Competitive Programming Concept: Dasar Dynamic Programming

**Category:** DP
**TL;DR:** Dynamic Programming (DP) adalah metode untuk memecahkan masalah kompleks dengan memecahnya menjadi sub-masalah yang lebih kecil, menyimpan hasil sub-masalah untuk menghindari komputasi berulang.

Dynamic Programming (DP) adalah paradigma algoritma yang sangat efektif untuk memecahkan masalah yang memiliki dua properti kunci: *overlapping subproblems* dan *optimal substructure*. *Overlapping subproblems* berarti masalah yang lebih besar dapat dipecah menjadi sub-masalah yang sama yang muncul berulang kali. *Optimal substructure* berarti solusi optimal dari masalah yang lebih besar dapat dibangun dari solusi optimal sub-masalahnya, mirip dengan prinsip divide and conquer, namun dengan penekanan pada penggunaan kembali hasil perhitungan.

Ada dua pendekatan utama dalam DP: *memoization* (top-down) dan *tabulation* (bottom-up). Pendekatan *memoization* adalah rekursi dengan caching, di mana hasil dari setiap pemanggilan fungsi disimpan dalam memori (misalnya array atau map) sehingga ketika pemanggilan yang sama terjadi lagi, hasilnya langsung diambil tanpa perlu dihitung ulang. Pendekatan *tabulation* membangun solusi secara iteratif dari kasus dasar ke atas, mengisi tabel (biasanya array) dengan solusi sub-masalah secara sistematis, memastikan semua prasyarat telah dihitung.

DP sangat sering digunakan dalam masalah seperti menghitung deret Fibonacci, masalah knapsack, longest common subsequence (LCS), shortest path pada Directed Acyclic Graph (DAG), dan banyak lagi. Kunci untuk mengidentifikasi masalah DP adalah mencari pola di mana keputusan saat ini bergantung pada hasil keputusan sebelumnya, dan ada banyak cara untuk mencapai solusi akhir. Kompleksitas waktu DP umumnya adalah jumlah state dikalikan dengan biaya transisi antar state, seringkali O(N*M) atau O(N) tergantung definisi state dan dimensinya.

```
#include <vector>

long long fib_tab(int n) {
    if (n <= 1) return n;
    std::vector<long long> dp(n + 1);
    dp[0] = 0;
    dp[1] = 1;
    for (int i = 2; i <= n; ++i) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```

💡 **Fun Fact:** Richard Bellman, yang menciptakan istilah Dynamic Programming, memilih nama itu untuk menyamarkan pekerjaannya yang bersifat matematis murni agar terdengar lebih 'bisnis' dan penting bagi sponsor militernya pada saat itu.
