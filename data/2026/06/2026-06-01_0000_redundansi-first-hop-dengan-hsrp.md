## 🌐 Networking Concept: Redundansi First-Hop dengan HSRP

**Category:** Routing
**TL;DR:** Memastikan ketersediaan gateway jaringan dengan dua router atau lebih berbagi satu IP virtual untuk mencegah titik kegagalan tunggal.

Dalam jaringan modern, ketersediaan adalah kunci. Salah satu titik kegagalan tunggal yang sering terabaikan adalah router gateway default untuk sebuah subnet. Jika router utama ini mengalami masalah, seluruh perangkat dalam subnet tersebut akan kehilangan konektivitas ke luar jaringan, menghentikan operasional bisnis yang vital. Konsep hari ini akan membahas bagaimana kita mengatasi masalah ini secara efektif menggunakan Cisco Packet Tracer.

Hot Standby Router Protocol (HSRP) adalah protokol redundansi first-hop milik Cisco yang dirancang untuk menyediakan ketersediaan gateway yang tinggi. HSRP memungkinkan dua atau lebih router untuk bekerja sama dalam suatu grup, berbagi satu alamat IP virtual dan alamat MAC virtual yang bertindak sebagai gateway default untuk host-host di jaringan lokal. Salah satu router akan menjadi router 'Aktif' yang menangani semua lalu lintas, sementara router lain akan berada dalam mode 'Standby' yang siap mengambil alih kapan saja.

Ketika router Aktif mengalami kegagalan—misalnya, karena mati, interface down, atau masalah perangkat lunak—router Standby akan secara otomatis dan cepat mendeteksi kegagalan tersebut. Setelah mendeteksi kegagalan, router Standby akan segera mengambil alih peran Aktif, mulai merespons ARP request untuk IP virtual, dan meneruskan lalu lintas. Proses failover ini transparan bagi perangkat-perangkat host, karena mereka tetap menggunakan alamat IP gateway virtual yang sama tanpa perlu konfigurasi ulang.

Dengan HSRP, kita dapat memastikan bahwa meskipun ada kegagalan pada salah satu perangkat keras router fisik, konektivitas jaringan tetap terjaga dengan minimal gangguan. Ini adalah solusi penting untuk membangun infrastruktur jaringan yang tangguh dan selalu tersedia, sangat relevan untuk skenario di mana downtime bukanlah pilihan dalam lingkungan perusahaan.

```
standby 1 ip 192.168.1.254
```

💡 **Fun Fact:** HSRP adalah protokol proprietary Cisco, sedangkan VRRP (Virtual Router Redundancy Protocol) adalah standar terbuka yang menjalankan fungsi serupa. Pilihlah sesuai ekosistem perangkat Anda!
