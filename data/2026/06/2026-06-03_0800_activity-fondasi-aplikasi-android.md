## 🤖 Android Concept: Activity: Fondasi Aplikasi Android

**Category:** UI
**TL;DR:** Activity adalah komponen utama yang menyediakan satu layar untuk interaksi pengguna dalam aplikasi Android.

Dalam pengembangan Android, Activity adalah salah satu blok bangunan paling fundamental. Bayangkan Activity sebagai sebuah 'layar' atau 'jendela' tunggal yang dilihat pengguna saat berinteraksi dengan aplikasi Anda. Misalnya, layar login, daftar produk, atau detail item, masing-masing umumnya diwakili oleh sebuah Activity terpisah. Ini berarti setiap kali pengguna berpindah antar tampilan utama di aplikasi, kemungkinan besar mereka berpindah dari satu Activity ke Activity lainnya.

Sebuah Activity bertanggung jawab penuh untuk mengelola antarmuka pengguna (UI) dan menangani interaksi pengguna pada layar tersebut. Di sinilah Anda meletakkan berbagai elemen UI seperti tombol (Button), teks (TextView), gambar (ImageView), dan input teks (EditText). Activity bertindak sebagai kontainer untuk semua View ini, mengatur bagaimana mereka ditampilkan dan bagaimana mereka merespons sentuhan atau input dari pengguna.

Setiap Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, yang terdiri dari serangkaian metode callback yang dipanggil oleh sistem Android pada berbagai tahapan. Yang paling penting untuk pemula adalah metode `onCreate()`. Metode ini adalah yang pertama kali dipanggil saat Activity dibuat dan menjadi tempat utama untuk melakukan inisialisasi awal, seperti mengatur tata letak (layout) dan menginisialisasi komponen UI.

Untuk menghubungkan Activity Anda dengan tata letak visual, Anda akan menggunakan file XML yang disebut layout. Di dalam metode `onCreate()`, Anda akan memanggil `setContentView()` dan meneruskan ID layout XML Anda. Ini memberi tahu Activity layout mana yang harus ditampilkan di layar, menggabungkan logika Kotlin Anda dengan desain UI yang telah Anda buat di XML.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan Activity dengan layout XML
    }
}
```

💡 **Fun Fact:** Nama 'Activity' dipilih untuk menggambarkan bahwa komponen ini adalah 'aktivitas' atau tindakan yang sedang dilakukan pengguna dalam aplikasi, mirip dengan bagaimana setiap pekerjaan memiliki aktivitas utamanya.
