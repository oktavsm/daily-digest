## ☕ Java Concept: Mengelola Kumpulan Data dengan `ArrayList`

**Category:** Collections
**TL;DR:** `ArrayList` adalah struktur data dinamis dari Java Collections Framework yang sangat fleksibel untuk menyimpan dan mengelola kumpulan objek yang ukurannya dapat berubah. 

Saat kita baru belajar pemrograman, kita sering menggunakan *array* untuk menyimpan banyak data dengan tipe yang sama. Namun, array memiliki batasan utama: ukurannya tetap setelah dibuat. Jika kita perlu menyimpan lebih banyak data dari yang diperkirakan, atau menghapus data di tengah jalan, kita akan kesulitan. Di sinilah `ArrayList` hadir sebagai solusi yang elegan dan powerful.

`ArrayList` adalah salah satu kelas paling populer dari Java Collections Framework. Ia mengimplementasikan antarmuka `List`, yang berarti ia dapat menyimpan urutan elemen berdasarkan indeks, mirip seperti array, namun dengan kemampuan untuk menambah atau menghapus elemen secara dinamis. Anda tidak perlu khawatir tentang ukuran maksimal; `ArrayList` akan mengelolanya secara otomatis. Penting untuk diingat bahwa `ArrayList` hanya dapat menyimpan objek, bukan tipe data primitif secara langsung (misalnya, `int` harus diubah menjadi `Integer`).

Untuk menggunakan `ArrayList`, Anda perlu mengimpornya (`import java.util.ArrayList;`). Ketika membuat `ArrayList`, Anda harus menentukan tipe objek yang akan disimpannya menggunakan *generics* (misalnya, `<String>` untuk menyimpan teks, atau `<Integer>` untuk angka bulat). Metode-metode dasar yang akan sering Anda gunakan adalah `add()` untuk menambahkan elemen, `get()` untuk mengakses elemen berdasarkan indeks, `size()` untuk mengetahui jumlah elemen, dan `remove()` untuk menghapus elemen. Dengan `ArrayList`, pengelolaan koleksi data menjadi jauh lebih mudah dan efisien.

```
import java.util.ArrayList;

ArrayList<String> namaMahasiswa = new ArrayList<>();
namaMahasiswa.add("Alice");
namaMahasiswa.add("Bob");
System.out.println("Ukuran list: " + namaMahasiswa.size());
System.out.println("Elemen ke-0: " + namaMahasiswa.get(0));
namaMahasiswa.remove(0);
System.out.println("Ukuran baru: " + namaMahasiswa.size());
```

💡 **Fun Fact:** `ArrayList` secara internal menggunakan array biasa. Ketika `ArrayList` Anda kehabisan ruang, ia akan secara otomatis membuat array baru yang lebih besar (biasanya 1.5 kali ukuran semula) dan menyalin semua elemen lama ke array baru tersebut.
