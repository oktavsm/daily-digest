## ☕ Java Concept: Java ArrayList: Koleksi Data Dinamis

**Category:** Collections
**TL;DR:** ArrayList adalah implementasi array dinamis yang memungkinkan Anda menyimpan dan mengelola koleksi objek dengan ukuran yang bisa berubah secara otomatis.

Di Java, `ArrayList` adalah salah satu struktur data yang paling sering digunakan dari Java Collections Framework. Bayangkan Anda perlu menyimpan daftar mahasiswa, daftar nilai, atau daftar barang belanjaan, tetapi Anda tidak tahu persis berapa jumlahnya di awal. Array biasa memiliki ukuran tetap setelah dibuat, yang bisa merepotkan jika jumlah data berubah. Di sinilah `ArrayList` bersinar, menyediakan array dinamis yang bisa membesar dan mengecil secara otomatis sesuai kebutuhan.

Keunggulan utama `ArrayList` adalah fleksibilitas ukurannya. Anda bisa dengan mudah menambahkan elemen baru atau menghapus elemen yang sudah ada tanpa perlu khawatir tentang manajemen memori di balik layar. Ia bekerja berdasarkan indeks, mirip array tradisional, sehingga akses elemen (mengambil atau mengubah) berdasarkan indeks sangat cepat, menjadikannya pilihan ideal untuk skenario di mana Anda sering mengakses elemen berdasarkan posisinya.

Secara internal, `ArrayList` sebenarnya menggunakan array biasa. Ketika `ArrayList` penuh dan Anda mencoba menambahkan elemen baru, ia akan secara otomatis membuat array internal yang lebih besar, menyalin semua elemen lama ke array baru tersebut, dan kemudian menambahkan elemen baru. Fitur Generics (`<E>`) memastikan bahwa `ArrayList` hanya dapat menyimpan tipe data tertentu, mencegah kesalahan tipe saat kompilasi dan membuat kode lebih aman serta mudah dibaca.

Dari mengelola daftar item di aplikasi e-commerce hingga menyimpan histori aktivitas pengguna, `ArrayList` adalah solusi serbaguna yang sangat fundamental. Ia memungkinkan pengembang untuk fokus pada logika bisnis inti daripada pusing memikirkan manajemen memori tingkat rendah, yang sangat membantu mahasiswa di awal pembelajaran pemrograman Java.

```
import java.util.ArrayList;
import java.util.List;

// Contoh penggunaan dasar ArrayList
List<String> daftarNilai = new ArrayList<>(); // Membuat ArrayList
daftarNilai.add("A");   // Menambah elemen
daftarNilai.add("B+");
System.out.println("Nilai pertama: " + daftarNilai.get(0)); // Mengakses elemen
daftarNilai.remove("A"); // Menghapus elemen
System.out.println("Ukuran daftar: " + daftarNilai.size()); // Mendapatkan ukuran
```

💡 **Fun Fact:** Tahukah Anda bahwa secara internal, ketika sebuah `ArrayList` penuh dan perlu diperbesar, ia biasanya akan menambah kapasitasnya sekitar 50% dari ukuran sebelumnya untuk mengurangi frekuensi operasi resizing yang mahal?
