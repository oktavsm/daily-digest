## ☕ Java Concept: ArrayList: Koleksi Dinamis Data

**Category:** Collections
**TL;DR:** ArrayList adalah struktur data di Java yang memungkinkan kita menyimpan koleksi objek dengan ukuran yang bisa berubah secara dinamis sesuai kebutuhan program.

Di Java, kita sering perlu menyimpan banyak data yang sejenis, misalnya daftar nama mahasiswa atau barang belanjaan. Arrays (larik) adalah pilihan dasar, namun ukurannya tetap setelah dibuat, yang bisa merepotkan jika kita tidak tahu pasti berapa banyak data yang akan disimpan. Di sinilah `ArrayList` hadir sebagai solusi, menyediakan "array yang bisa tumbuh" yang sangat fleksibel.

`ArrayList` adalah bagian dari Java Collections Framework dan berada di package `java.util`. Berbeda dengan array biasa, Anda tidak perlu menentukan kapasitas awal `ArrayList` saat membuatnya; ia akan menyesuaikan ukurannya secara otomatis saat Anda menambah atau menghapus elemen. Anda dapat menambahkan elemen menggunakan metode `add()`, mengambil elemen dengan `get(index)`, mengetahui jumlah elemen saat ini dengan `size()`, dan menghapus elemen dengan `remove(index)` atau `remove(object)`.

Keuntungan utama menggunakan `ArrayList` adalah kemudahan dalam mengelola koleksi data yang ukurannya tidak pasti atau sering berubah. Misalnya, dalam aplikasi keranjang belanja, Anda tidak tahu berapa banyak barang yang akan ditambahkan pengguna. Dengan `ArrayList`, Anda bisa dengan mudah menambah atau mengurangi barang tanpa harus khawatir tentang kapasitas. Di balik layar, `ArrayList` diimplementasikan menggunakan array biasa, tetapi Java mengelola logika di baliknya untuk memperbesar atau memperkecil array internalnya secara efisien saat diperlukan.

```
import java.util.ArrayList;

public class ContohArrayList {
    public static void main(String[] args) {
        ArrayList<String> daftarNama = new ArrayList<>();
        daftarNama.add("Alice");
        daftarNama.add("Bob");
        System.out.println("Ukuran: " + daftarNama.size()); // Output: Ukuran: 2
        System.out.println("Elemen pertama: " + daftarNama.get(0)); // Output: Elemen pertama: Alice
        daftarNama.remove(0); // Hapus Alice
        System.out.println("Elemen setelah hapus: " + daftarNama.get(0)); // Output: Elemen setelah hapus: Bob
    }
}
```

💡 **Fun Fact:** `ArrayList` diimplementasikan menggunakan array biasa di belakang layar; ketika kapasitasnya penuh, ia akan membuat array baru yang lebih besar (biasanya 1.5 kali ukuran lama) dan menyalin semua elemen lama ke array baru tersebut, sebuah proses yang dikenal sebagai "resizing".
