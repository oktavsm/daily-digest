## ☕ Java Concept: Penanganan Exception dengan try-catch

**Category:** Exception
**TL;DR:** `try-catch` adalah mekanisme Java untuk menangani kesalahan atau kejadian tak terduga (exception) yang terjadi saat program berjalan, mencegah aplikasi crash dan memungkinkan penanganan yang elegan.

Dalam pemrograman, seringkali kita dihadapkan pada situasi yang tidak terduga saat program sedang berjalan, seperti mencoba membagi angka dengan nol, mengakses elemen array di luar batas, atau mencoba membuka file yang tidak ada. Kejadian-kejadian abnormal ini disebut "exception". Jika tidak ditangani, exception dapat menyebabkan program kita berhenti secara paksa (crash), memberikan pengalaman buruk bagi pengguna.

Untuk mengatasi hal ini, Java menyediakan mekanisme "exception handling" menggunakan blok `try-catch`. Blok `try` berisi kode yang berpotensi menimbulkan exception. Jika sebuah exception terjadi di dalam blok `try`, eksekusi kode di dalam blok `try` akan segera dihentikan, dan kendali program akan dialihkan ke blok `catch` yang sesuai.

Blok `catch` berfungsi untuk "menangkap" dan "menangani" exception tersebut. Di sinilah Anda bisa menulis kode untuk merespons kesalahan, misalnya dengan menampilkan pesan error yang ramah pengguna, mencatat error ke dalam log, atau bahkan mencoba memperbaiki situasi. Anda bisa memiliki beberapa blok `catch` untuk menangani jenis exception yang berbeda, memberikan fleksibilitas dalam penanganan. Dengan `try-catch`, meskipun terjadi kesalahan, program dapat melanjutkan eksekusi setelah blok `catch` selesai, atau setidaknya keluar dengan graceful, bukan crash mendadak.

```
public class ExceptionDemo {
    public static void main(String[] args) {
        try {
            int numerator = 10;
            int denominator = 0; // Ini akan menyebabkan ArithmeticException
            int result = numerator / denominator;
            System.out.println("Hasil: " + result);
        } catch (ArithmeticException e) {
            System.err.println("Terjadi kesalahan aritmatika: " + e.getMessage());
            System.err.println("Tidak bisa membagi dengan nol! Harap periksa input Anda.");
        }
        System.out.println("Program tetap berjalan setelah penanganan error.");
    }
}
```

💡 **Fun Fact:** Konsep "Checked Exceptions" di Java, yang mengharuskan developer untuk secara eksplisit menangani atau mendeklarasikan bahwa sebuah method melempar exception, adalah fitur yang cukup unik dan kontroversial. Tujuannya adalah untuk memaksa developer untuk memikirkan skenario kegagalan, meskipun beberapa orang merasa ini membuat kode menjadi lebih bertele-tele.
