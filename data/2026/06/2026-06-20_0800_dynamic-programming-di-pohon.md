## ⚡ Competitive Programming Concept: Dynamic Programming di Pohon

**Category:** DP
**TL;DR:** Menerapkan Dynamic Programming pada struktur pohon dengan menggunakan traversal DFS untuk mengkomputasi solusi submasalah dari anak-anak ke induk.

Dynamic Programming (DP) di pohon adalah teknik penting untuk menyelesaikan masalah pada struktur data pohon. Ini memanfaatkan sifat rekursif pohon di mana solusi untuk sebuah node seringkali dapat dibangun dari solusi anak-anaknya. Mirip dengan DP biasa, teknik ini menghindari perhitungan berulang pada subpohon yang sama, menjadikannya efisien untuk masalah-masalah yang memiliki substruktur optimal dan submasalah tumpang tindih.

Implementasinya biasanya melibatkan Depth-First Search (DFS). Saat DFS mengunjungi sebuah node `u`, pertama-tama ia akan memanggil dirinya sendiri secara rekursif untuk semua anak `v` dari `u`. Setelah semua anak selesai diproses dan nilai DP mereka diketahui, barulah nilai DP untuk `u` dapat dihitung menggunakan nilai-nilai yang telah dihitung dari anak-anaknya. Pendekatan "bottom-up" dalam konteks pohon ini memastikan semua dependensi terpenuhi, yaitu nilai anak dihitung sebelum nilai induk.

Contoh masalah yang dapat diselesaikan dengan DP di pohon antara lain menghitung ukuran subtree, jumlah nilai di subtree, mencari diameter pohon, atau menemukan Maximum Independent Set. Karena setiap node dan setiap edge dikunjungi tepat sekali selama traversal DFS, kompleksitas waktunya umumnya O(N) di mana N adalah jumlah node dalam pohon. Ini menjadikannya metode yang sangat efisien untuk memecahkan banyak masalah yang berkaitan dengan pohon.

```
vector<int> adj[N]; // Adjacency list
int values[N]; // Nilai setiap node
long long dp_sum[N]; // dp_sum[u] = total nilai di subtree u

void dfs_sum_subtree(int u, int p) {
    dp_sum[u] = values[u]; // Inisialisasi dengan nilai node saat ini
    for (int v : adj[u]) {
        if (v == p) continue; // Hindari kembali ke parent
        dfs_sum_subtree(v, u); // Rekursi untuk anak
        dp_sum[u] += dp_sum[v]; // Tambahkan hasil dari anak
    }
}
```

💡 **Fun Fact:** Pohon adalah salah satu struktur data yang paling sering muncul di Competitive Programming karena sifatnya yang hirarkis dan banyak masalah dunia nyata dapat dimodelkan sebagai pohon, seperti struktur file sistem atau silsilah keluarga.
