## 🤖 Android Concept: Memahami Activity Android

**Category:** UI
**TL;DR:** Activity adalah komponen dasar yang menyediakan satu layar antarmuka pengguna, memungkinkan interaksi dengan pengguna dalam aplikasi Android Anda.

Setiap aplikasi Android yang Anda lihat terdiri dari satu atau beberapa `Activity`. Bayangkan `Activity` sebagai satu "layar" yang bisa dilihat dan berinteraksi dengan pengguna. Misalnya, saat Anda membuka aplikasi WhatsApp, daftar chat adalah satu `Activity`. Saat Anda mengetuk chat tertentu dan masuk ke percakapan, itu adalah `Activity` lain. Ini adalah fondasi utama yang menampilkan elemen UI seperti tombol, teks, gambar, dan bidang input.

Untuk menampilkan antarmuka pengguna, sebuah `Activity` biasanya terhubung dengan file layout XML. File XML ini mendefinisikan struktur visual dari layar Anda. Di dalam `Activity` Anda (kode Kotlin), Anda memuat layout ini menggunakan metode `setContentView()`, biasanya di dalam metode `onCreate()`. Ini adalah cara sistem mengetahui apa yang harus ditampilkan di layar ketika `Activity` tersebut aktif.

Sama seperti makhluk hidup, `Activity` memiliki siklus hidupnya sendiri (lifecycle). Dimulai saat ia dibuat (`onCreate`), aktif dan terlihat oleh pengguna (`onResume`), bisa dijeda (`onPause`), berhenti (`onStop`), hingga dihancurkan (`onDestroy`). Sistem Android secara otomatis mengelola siklus hidup ini, memastikan `Activity` menggunakan sumber daya dengan efisien dan menangani perubahan seperti rotasi layar atau navigasi antar aplikasi. Memahami ini penting untuk membangun aplikasi yang stabil.

Sebagai developer, Anda akan sering memulai dari sebuah `Activity`. Ini adalah titik masuk utama bagi pengguna untuk berinteraksi dengan aplikasi Anda. Dari `Activity` inilah Anda bisa meluncurkan `Activity` lain, berinteraksi dengan data, atau menjalankan logika bisnis yang lebih kompleks. Ini adalah "rumah" bagi sebagian besar interaksi pengguna yang terjadi dalam aplikasi Android Anda.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan ke layout XML
    }
}
```

💡 **Fun Fact:** Nama `Activity` sebenarnya mencerminkan fungsi utamanya sebagai "aktivitas" atau "tugas" tunggal yang dapat dilakukan pengguna dalam aplikasi, mirip dengan bagaimana jendela program bekerja di sistem operasi desktop.
