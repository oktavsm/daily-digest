## ☕ Java Concept: Menangani Error dengan Exception Handling

**Category:** Exception
**TL;DR:** Exception Handling adalah mekanisme Java untuk mengelola error runtime agar program tidak crash dan tetap berjalan dengan gracefully.

Penggunaan exception handling sangat penting untuk membuat aplikasi yang tangguh dan ramah pengguna. Dengan menangani exception, kita bisa memastikan bahwa program tidak crash karena input yang salah, masalah jaringan, atau file yang tidak ditemukan. Ini adalah fondasi penting dalam membangun perangkat lunak yang andal dan profesional, memastikan pengalaman pengguna yang lebih baik meskipun ada hal tak terduga yang terjadi.

```
public class DemoException {
    public static void main(String[] args) {
        try {
            int angka1 = 10;
            int angka2 = 0;
            int hasil = angka1 / angka2; // Ini akan menyebabkan ArithmeticException
            System.out.println("Hasil pembagian: " + hasil);
        } catch (ArithmeticException e) {
            System.err.println("Terjadi error aritmatika: " + e.getMessage());
            System.err.println("Tidak bisa membagi dengan nol!");
        }
        System.out.println("Program selesai.");
    }
}
```

💡 **Fun Fact:** Konsep "exception" bukan hanya ada di Java; banyak bahasa pemrograman modern lainnya juga memiliki mekanisme serupa. Uniknya, di Java, semua exception adalah objek dari kelas `Throwable`, yang memungkinkan kita untuk mendapatkan informasi detail tentang error tersebut secara terprogram.
