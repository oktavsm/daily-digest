## ⚡ Competitive Programming Concept: Segment Tree

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data berbasis pohon biner yang efisien untuk melakukan operasi query pada rentang (range query) dan pembaruan (update) pada array.

Segment Tree adalah struktur data berbasis pohon biner yang sangat efisien untuk mengelola array. Tujuan utamanya adalah melakukan operasi *range query* (misalnya mencari jumlah, minimum, atau maksimum dalam suatu rentang indeks) dan *point/range update* (mengubah nilai pada satu indeks atau seluruh rentang indeks) dengan cepat. Setiap node pada Segment Tree merepresentasikan sebuah segmen atau rentang indeks dari array asli, dan node root merepresentasikan seluruh array.

Pembangunan Segment Tree biasanya dilakukan secara rekursif dalam waktu `O(N)`, di mana N adalah ukuran array. Setiap node parent menyimpan hasil agregasi dari kedua node anaknya. Misalnya, untuk range sum, node parent akan menyimpan jumlah dari node anak kirinya dan anak kanannya. Operasi *query* untuk mencari nilai pada rentang `[L, R]` juga dilakukan secara rekursif, dengan memecah rentang menjadi sub-rentang yang cocok dengan node-node di pohon. Jika sebuah node sepenuhnya berada di dalam rentang query, nilainya langsung digunakan; jika tidak, query dilanjutkan ke anak-anaknya. Kompleksitas waktu untuk query adalah `O(logN)`.

Operasi *update* (misalnya mengubah nilai pada indeks `i`) juga dilakukan secara rekursif. Kita menelusuri jalur dari root menuju daun yang merepresentasikan indeks `i`, mengubah nilainya, lalu memperbarui nilai pada semua node parent di jalur tersebut hingga ke root. Ini juga membutuhkan waktu `O(logN)`. Untuk kasus yang lebih kompleks seperti *range update* (mengubah nilai pada seluruh rentang `[L, R]`), Segment Tree dapat diperluas dengan teknik *lazy propagation*, yang menunda penerapan update pada node-node tertentu sampai benar-benar dibutuhkan.

```
int tree[4 * N]; // N adalah ukuran array

// Contoh fungsi query untuk mencari total sum dalam rentang [l, r]
int query(int node, int start, int end, int l, int r) {
    if (r < start || end < l) return 0; // Rentang tidak overlap
    if (l <= start && end <= r) return tree[node]; // Rentang query sepenuhnya di dalam node
    int mid = (start + end) / 2;
    int p1 = query(2 * node, start, mid, l, r);
    int p2 = query(2 * node + 1, mid + 1, end, l, r);
    return p1 + p2; // Gabungkan hasil dari kedua anak
}
```

💡 **Fun Fact:** Segment Tree dapat dilihat sebagai perpanjangan dari konsep prefix sums, namun dengan kemampuan untuk melakukan pembaruan (update) poin atau rentang secara efisien, tidak hanya query statis. Ini membuatnya sangat fleksibel untuk berbagai masalah interaktif.
