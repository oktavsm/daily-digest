## ⚡ Competitive Programming Concept: Longest Common Subsequence (LCS)

**Category:** DP
**TL;DR:** Mencari subsequence terpanjang yang sama dari dua buah string menggunakan Dynamic Programming.

Longest Common Subsequence (LCS) adalah masalah klasik dalam Dynamic Programming (DP) yang bertujuan untuk menemukan subsequence terpanjang yang dimiliki oleh dua buah string. Subsequence adalah urutan karakter yang dapat diperoleh dari string asli dengan menghapus nol atau lebih karakter yang tersisa, tanpa mengubah urutan karakter yang tidak dihapus. Misalnya, jika string pertama adalah "ABCBDAB" dan string kedua adalah "BDCABA", maka LCS-nya adalah "BCBA" (panjang 4).

Untuk menyelesaikan masalah LCS, kita dapat menggunakan tabel DP dua dimensi, `dp[i][j]`, yang menyimpan panjang LCS dari prefix string pertama sepanjang `i` karakter (yaitu `s1[0...i-1]`) dan prefix string kedua sepanjang `j` karakter (yaitu `s2[0...j-1]`). Basis kasus untuk tabel ini adalah ketika salah satu prefix kosong, di mana panjang LCS-nya adalah 0. Artinya, `dp[0][j] = 0` untuk semua `j`, dan `dp[i][0] = 0` untuk semua `i`.

Aturan transisi untuk mengisi tabel `dp[i][j]` adalah sebagai berikut: Jika karakter terakhir dari kedua prefix sama (yaitu `s1[i-1] == s2[j-1]`), maka karakter tersebut pasti menjadi bagian dari LCS. Dalam kasus ini, `dp[i][j]` akan menjadi `1 + dp[i-1][j-1]`. Namun, jika karakter terakhirnya berbeda, maka karakter tersebut tidak bisa secara bersamaan menjadi bagian dari LCS. Kita harus memilih yang terbaik dari dua kemungkinan: LCS dari `s1[0...i-2]` dengan `s2[0...j-1]` (yaitu `dp[i-1][j]`), atau LCS dari `s1[0...i-1]` dengan `s2[0...j-2]` (yaitu `dp[i][j-1]`). Jadi, `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`.

Setelah seluruh tabel DP terisi, nilai `dp[N][M]` (di mana `N` dan `M` adalah panjang string `s1` dan `s2` secara berturut-turut) akan memberikan panjang LCS dari kedua string. Kompleksitas waktu algoritma ini adalah O(N*M) karena kita mengisi tabel N x M, dan setiap pengisian membutuhkan waktu konstan. Kompleksitas ruangnya juga O(N*M) untuk menyimpan tabel DP.

```
int n = text1.length();
int m = text2.length();
std::vector<std::vector<int>> dp(n + 1, std::vector<int>(m + 1, 0));

for (int i = 1; i <= n; ++i) {
    for (int j = 1; j <= m; ++j) {
        if (text1[i-1] == text2[j-1]) {
            dp[i][j] = 1 + dp[i-1][j-1];
        } else {
            dp[i][j] = std::max(dp[i-1][j], dp[i][j-1]);
        }
    }
}
return dp[n][m];
```

💡 **Fun Fact:** LCS memiliki banyak aplikasi praktis, seperti dalam bioinformatika untuk membandingkan urutan DNA atau RNA, serta dalam sistem kontrol versi seperti 'diff' untuk mendeteksi perbedaan antara dua file atau versi kode.
