## 🤖 Android Concept: Memahami Activity: Blok Bangunan Utama

**Category:** Architecture
**TL;DR:** Activity adalah komponen aplikasi Android yang menyediakan layar tempat pengguna dapat berinteraksi, berfungsi sebagai titik masuk utama bagi sebagian besar pengalaman pengguna.

Setiap aplikasi Android dibangun dari berbagai komponen, dan salah satu yang paling fundamental adalah `Activity`. Bayangkan sebuah `Activity` sebagai satu layar tunggal dalam aplikasi Anda. Misalnya, ketika Anda membuka aplikasi email, Anda mungkin melihat `Activity` daftar email, lalu ketika Anda mengetuk salah satu email, `Activity` lain akan terbuka untuk menampilkan detail email tersebut. Setiap `Activity` bertanggung jawab untuk menyediakan jendela untuk menggambar antarmuka pengguna (UI) dan mengelola interaksi pengguna.

`Activity` memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, yang diatur oleh sistem operasi Android. Ini berarti `Activity` Anda akan melewati berbagai status seperti dibuat (`onCreate`), dimulai (`onStart`), dapat berinteraksi (`onResume`), dijeda (`onPause`), dihentikan (`onStop`), hingga dihancurkan (`onDestroy`). Memahami siklus hidup ini sangat penting agar aplikasi Anda berperilaku benar, misalnya menyimpan data saat pengguna meninggalkan layar atau melepaskan sumber daya yang tidak terpakai.

Saat Anda membuat aplikasi Android baru, secara default Anda akan memiliki setidaknya satu `Activity`, seringkali dinamakan `MainActivity`. `Activity` ini biasanya merupakan titik masuk pertama yang dilihat pengguna. Untuk membuat `Activity`, Anda perlu membuat sebuah kelas Kotlin yang meng-extend `AppCompatActivity` dan mengimplementasikan metode `onCreate()`, di mana Anda akan mengatur tata letak (layout) UI dengan memanggil `setContentView()`.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        // Di sini Anda bisa menambahkan logika atau inisialisasi UI lainnya
    }
}
```

💡 **Fun Fact:** Ketika Anda meluncurkan `Activity` baru, `Activity` tersebut ditempatkan di atas 'back stack'. Ketika pengguna menekan tombol kembali, `Activity` teratas dikeluarkan dari stack dan `Activity` sebelumnya akan ditampilkan kembali.
