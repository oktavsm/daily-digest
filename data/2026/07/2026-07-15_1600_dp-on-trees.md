## ⚡ Competitive Programming Concept: DP on Trees

**Category:** DP
**TL;DR:** Metode pemrograman dinamis yang diaplikasikan pada struktur data pohon, seringkali menggunakan Depth First Search (DFS) untuk menghitung nilai state dari anak-anak ke orang tua.

DP on Trees, atau Tree DP, adalah teknik pemrograman dinamis yang memanfaatkan struktur hierarkis sebuah pohon. Konsep utamanya adalah menghitung nilai DP untuk setiap node, yang biasanya bergantung pada nilai DP dari node-node anaknya (sub-tree-nya). Proses ini umumnya dilakukan dengan traversi DFS dari root ke daun, lalu menghitung nilai DP saat kembali dari daun ke root.

Setiap node dalam pohon akan memiliki state DP yang perlu dihitung. Saat fungsi DFS mengunjungi sebuah node `u`, ia akan secara rekursif memanggil DFS untuk semua anaknya. Setelah semua anak `v` dari `u` telah memproses sub-pohonnya dan mengembalikan nilai DP masing-masing, node `u` kemudian menggunakan nilai-nilai tersebut untuk menghitung nilai DP-nya sendiri. Ini memastikan bahwa saat kita menghitung DP untuk sebuah node, semua informasi yang dibutuhkan dari sub-pohon anaknya sudah tersedia.

Contoh umum dari DP on Trees termasuk menghitung ukuran subtree, jumlah nilai di subtree, mencari jalur terpanjang di sebuah pohon, atau menemukan diameter pohon. Kompleksitas waktu untuk DP on Trees biasanya O(N), di mana N adalah jumlah node dalam pohon. Ini karena setiap node dan setiap edge dikunjungi tepat sekali selama traversi DFS dan setiap perhitungan DP di sebuah node membutuhkan waktu konstan atau linear terhadap derajat node tersebut, yang secara agregat menjadi O(N+M) = O(N) untuk pohon (M=N-1 edges).

Penting untuk mendefinisikan state DP dengan benar dan transisi antar state. Basis kasus biasanya adalah node daun, di mana nilai DP-nya dapat dihitung secara langsung tanpa bergantung pada anak-anak. Contoh implementasi melibatkan penggunaan adjacency list untuk merepresentasikan pohon dan fungsi DFS rekursif yang melewati node saat ini dan parent-nya untuk menghindari traversi ke atas.

```
vector<vector<int>> adj;
vector<long long> dp_subtree_sum;
vector<int> node_values;

void dfs(int u, int p) {
    dp_subtree_sum[u] = node_values[u];
    for (int v : adj[u]) {
        if (v == p) continue;
        dfs(v, u);
        dp_subtree_sum[u] += dp_subtree_sum[v];
    }
}
```

💡 **Fun Fact:** Tree DP seringkali menjadi fondasi untuk teknik yang lebih canggih seperti Rerooting DP (atau Tree DP dua kali), di mana nilai DP dihitung untuk setiap node seolah-olah node tersebut adalah root dari pohon.
