## ☕ Java Concept: ArrayList: List Dinamis di Java

**Category:** Collections
**TL;DR:** ArrayList adalah implementasi antarmuka List di Java yang menyediakan array yang ukurannya dapat berubah secara dinamis, sangat berguna untuk menyimpan koleksi objek yang jumlahnya tidak tetap.

ArrayList adalah salah satu struktur data yang paling sering digunakan di Java untuk menyimpan koleksi objek. Berbeda dengan array biasa yang ukurannya sudah tetap saat dibuat, ArrayList bersifat dinamis, artinya ukurannya bisa bertambah atau berkurang sesuai kebutuhan program. Ini sangat praktis ketika Anda tidak tahu persis berapa banyak elemen yang akan Anda simpan di awal program, misalnya daftar nama pelanggan atau item belanja.

Untuk menggunakan ArrayList, Anda perlu mengimpor `java.util.ArrayList` dan biasanya mendeklarasikannya menggunakan antarmuka `List`. Contohnya: `List<String> namaMahasiswa = new ArrayList<>();`. Tanda `<String>` adalah Generic, yang menentukan bahwa ArrayList ini hanya boleh menyimpan objek bertipe `String`, mencegah kesalahan tipe data. Anda bisa menambahkan elemen dengan metode `add()`, seperti `namaMahasiswa.add("Budi");`, dan mengambil elemen dengan `get(indeks)`, misalnya `namaMahasiswa.get(0)` untuk elemen pertama.

ArrayList juga menyediakan metode mudah untuk mengelola elemennya. Anda bisa menghapus elemen berdasarkan indeks atau objeknya dengan `remove()`, misalnya `namaMahasiswa.remove(1)` atau `namaMahasiswa.remove("Budi")`. Untuk mengetahui berapa banyak elemen yang ada di ArrayList, gunakan metode `size()`. Anda juga bisa memperbarui elemen di indeks tertentu menggunakan `set(indeks, nilaiBaru)`. Mengiterasi seluruh elemen juga mudah, seringkali menggunakan *enhanced for-loop* (`for (String nama : namaMahasiswa) { ... }`).

Keunggulan utama ArrayList adalah fleksibilitas ukurannya yang dinamis, membuatnya sangat cocok untuk banyak skenario sehari-hari. Ia juga cepat dalam mengakses elemen berdasarkan indeks. Namun, perlu diingat bahwa menambahkan atau menghapus elemen di tengah ArrayList bisa sedikit kurang efisien karena semua elemen setelahnya harus digeser. Meskipun demikian, untuk kebanyakan aplikasi semester awal, ArrayList adalah pilihan yang sangat solid dan merupakan fondasi penting untuk memahami struktur data koleksi lainnya.

```
import java.util.ArrayList;
import java.util.List;

public class ContohArrayList {
    public static void main(String[] args) {
        List<String> daftarBelanja = new ArrayList<>();
        daftarBelanja.add("Apel");
        daftarBelanja.add("Pisang");
        System.out.println("Daftar: " + daftarBelanja);
        daftarBelanja.remove("Apel");
        System.out.println("Sisa: " + daftarBelanja.size() + " item.");
    }
}
```

💡 **Fun Fact:** Sebelum Java 5, ArrayList tidak menggunakan Generics, sehingga seringkali perlu melakukan *casting* secara manual dan rentan *runtime error* jika tipe data yang disimpan tidak konsisten. Generics membuat ArrayList jauh lebih aman dan mudah digunakan.
