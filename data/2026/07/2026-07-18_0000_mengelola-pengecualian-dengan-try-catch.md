## ☕ Java Concept: Mengelola Pengecualian dengan try-catch

**Category:** Exception
**TL;DR:** Konsep ini memungkinkan program Anda mengelola dan merespons kesalahan tak terduga (exceptions) agar tidak berhenti secara mendadak.

Dalam pemrograman Java, `Exception` adalah peristiwa yang mengganggu alur normal eksekusi program. Ini bukan kesalahan sintaksis yang terdeteksi saat kompilasi, melainkan masalah yang muncul saat program sedang berjalan (runtime). Contoh umum termasuk mencoba membagi angka dengan nol (`ArithmeticException`), mengakses elemen di luar batas array (`ArrayIndexOutOfBoundsException`), atau mencoba membuka file yang tidak ada (`FileNotFoundException`).

Jika `exception` tidak ditangani, program akan berhenti secara paksa (crash) dan menampilkan pesan kesalahan teknis (stack trace) yang mungkin membingungkan pengguna akhir. Penanganan `exception` memungkinkan program untuk "menangkap" kesalahan tersebut, meresponsnya dengan cara yang terkontrol, dan melanjutkan eksekusi atau mengakhiri dengan cara yang lebih ramah pengguna, bukan sekadar berhenti tiba-tiba.

Java menyediakan blok `try-catch-finally` untuk menangani `exception`. Kode yang berpotensi menimbulkan `exception` diletakkan di dalam blok `try`. Jika `exception` terjadi di dalam blok `try`, eksekusi akan segera berpindah ke blok `catch` yang sesuai. Blok `catch` mendefinisikan jenis `exception` apa yang ditanganinya dan tindakan apa yang harus diambil. Blok `finally` bersifat opsional dan akan selalu dieksekusi, terlepas dari apakah `exception` terjadi atau tidak, sering digunakan untuk membersihkan sumber daya seperti menutup koneksi database atau file.

```
public class ContohPengecualian {
    public static void main(String[] args) {
        try {
            int hasil = 10 / 0; // Ini memicu ArithmeticException
            System.out.println("Hasil: " + hasil);
        } catch (ArithmeticException e) {
            System.err.println("Kesalahan: Tidak bisa membagi dengan nol!");
        } finally {
            System.out.println("Operasi selesai.");
        }
    }
}
```

💡 **Fun Fact:** Java adalah salah satu bahasa pertama yang secara ketat menerapkan "checked exceptions", yaitu jenis `exception` tertentu yang harus secara eksplisit ditangani atau dideklarasikan oleh metode. Hal ini mendorong developer untuk mempertimbangkan skenario kegagalan sejak awal desain program.
