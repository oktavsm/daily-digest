## ☕ Java Concept: Penanganan Error dengan try-catch

**Category:** Exception
**TL;DR:** Belajar cara mengelola error runtime di Java menggunakan blok `try-catch` agar program tidak crash dan tetap berjalan mulus.

Dalam pemrograman Java, terkadang ada situasi di mana program kita menghadapi kondisi yang tidak terduga saat berjalan (runtime), seperti mencoba membaca file yang tidak ada, membagi angka dengan nol, atau mengonversi teks yang bukan angka menjadi bilangan bulat. Kondisi tak terduga ini disebut sebagai 'exception' atau pengecualian. Jika tidak ditangani, exception dapat menyebabkan program berhenti secara tiba-tiba (crash), yang tentu saja bukanlah pengalaman yang baik bagi pengguna.

Untuk mengatasi masalah ini, Java menyediakan mekanisme 'exception handling' menggunakan blok `try-catch`. Blok `try` digunakan untuk membungkus kode yang berpotensi menimbulkan exception. Artinya, jika ada baris kode di dalam blok `try` yang menyebabkan exception, eksekusi kode di dalam blok `try` akan segera dihentikan, dan kontrol akan dialihkan ke blok `catch` yang sesuai.

Blok `catch` berfungsi sebagai penangkap exception. Setelah exception terjadi di blok `try`, Java akan mencari blok `catch` yang bisa menangani jenis exception tersebut. Di dalam blok `catch`, kita bisa menuliskan logika untuk merespons exception, misalnya dengan menampilkan pesan error yang lebih ramah kepada pengguna, mencatat detail error untuk debugging, atau bahkan mencoba melakukan pemulihan agar program bisa melanjutkan eksekusi. Ini membuat program kita lebih robust dan user-friendly, karena tidak akan berhenti tiba-tiba di hadapan masalah.

Penggunaan `try-catch` adalah praktik yang sangat penting dalam pengembangan aplikasi nyata. Dengan menanganinya, kita bisa mengontrol bagaimana program bereaksi terhadap kondisi yang tidak ideal, mencegahnya crash, dan memastikan pengalaman pengguna yang lebih baik. Ini adalah salah satu fondasi untuk membangun aplikasi Java yang stabil dan andal.

```
public class DemoExceptionHandling {
    public static void main(String[] args) {
        try {
            String teksAngka = "seratus";
            int angka = Integer.parseInt(teksAngka); // Ini akan memicu NumberFormatException
            System.out.println("Angka yang dikonversi: " + angka);
        } catch (NumberFormatException e) {
            System.err.println("Error: Tidak bisa mengonversi teks menjadi angka!");
            System.err.println("Pesan detail: " + e.getMessage());
        } finally {
            System.out.println("Program selesai dijalankan, baik ada error maupun tidak.");
        }
    }
}
```

💡 **Fun Fact:** Java adalah salah satu bahasa pertama yang mewajibkan penanganan beberapa jenis pengecualian (yang dikenal sebagai 'checked exceptions') pada waktu kompilasi. Hal ini mendorong developer untuk menulis kode yang lebih robust karena compiler akan memberi tahu jika ada potensi error yang belum ditangani.
