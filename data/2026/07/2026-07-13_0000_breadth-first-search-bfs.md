## ⚡ Competitive Programming Concept: Breadth-First Search (BFS)

**Category:** Graph
**TL;DR:** BFS adalah algoritma penelusuran graf yang menjelajahi semua simpul pada 'level' yang sama dari titik awal sebelum beralih ke 'level' berikutnya.

Breadth-First Search (BFS) adalah algoritma penelusuran graf yang menjelajahi simpul-simpul dalam graf secara "level by level". Dimulai dari sebuah simpul awal, BFS akan terlebih dahulu mengunjungi semua tetangga langsungnya (level 1), kemudian semua tetangga dari tetangga-tetangga tersebut (level 2), dan seterusnya. Pendekatan ini memastikan bahwa simpul-simpul yang lebih dekat ke simpul awal akan selalu dikunjungi terlebih dahulu, membuatnya sangat cocok untuk menemukan jalur terpendek dalam graf yang tidak berbobot.

Untuk mengimplementasikan BFS, kita umumnya menggunakan struktur data antrean (queue). Proses dimulai dengan menambahkan simpul awal ke antrean dan menandainya sebagai sudah dikunjungi. Kemudian, selama antrean tidak kosong, kita mengambil (dequeue) sebuah simpul dari depan antrean, memprosesnya, dan menambahkan semua tetangga yang belum dikunjungi ke antrean, sambil segera menandai mereka sebagai sudah dikunjungi. Menandai simpul segera setelah mereka dimasukkan ke antrean mencegah kunjungan berulang dan loop tak terbatas.

BFS memiliki banyak aplikasi dalam competitive programming. Selain menemukan jalur terpendek pada graf tidak berbobot, ia juga digunakan untuk menemukan semua komponen terhubung dalam graf, melakukan traversal level-order pada pohon, dan menyelesaikan teka-teki labirin atau permainan yang melibatkan pergerakan di grid. Fleksibilitas dan sifat penelusurannya yang menyeluruh menjadikannya algoritma fundamental yang harus dikuasai.

Kompleksitas waktu BFS adalah O(V + E) ketika graf direpresentasikan menggunakan daftar ketetanggaan (adjacency list), di mana V adalah jumlah simpul (vertices) dan E adalah jumlah sisi (edges). Jika menggunakan matriks ketetanggaan (adjacency matrix), kompleksitasnya menjadi O(V^2). Kompleksitas ruangnya adalah O(V) untuk menyimpan status kunjungan simpul dan antrean.

```
void bfs(int start, int N, const std::vector<std::vector<int>>& adj) {
    std::vector<bool> visited(N + 1, false);
    std::queue<int> q;

    visited[start] = true;
    q.push(start);

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        // std::cout << u << " "; // Proses simpul u

        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
        }
    }
}
```

💡 **Fun Fact:** BFS sering diibaratkan seperti menjatuhkan batu ke dalam kolam dan melihat riak-riak air menyebar secara merata. Ini mencerminkan bagaimana algoritma menjelajahi graf secara progresif dari titik awal.
