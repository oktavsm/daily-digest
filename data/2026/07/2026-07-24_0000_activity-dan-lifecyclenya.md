## 🤖 Android Concept: Activity dan Lifecyclenya

**Category:** Architecture
**TL;DR:** Activity adalah komponen utama yang menyediakan layar interaksi pengguna dan memiliki siklus hidup yang terdefinisi untuk mengelola sumber daya.

Dalam pengembangan Android, Activity adalah fondasi dari setiap interaksi pengguna dengan aplikasi Anda. Bayangkan Activity sebagai satu layar individual yang Anda lihat di aplikasi, seperti layar login, daftar produk, atau detail item. Setiap aplikasi Android setidaknya memiliki satu Activity, yang seringkali menjadi titik masuk utama saat aplikasi diluncurkan. Activity ini bertanggung jawab untuk menggambar antarmuka pengguna (UI) dan merespons interaksi pengguna.

Hal paling krusial dari Activity adalah 'siklus hidup' atau Lifecycle-nya. Ini adalah serangkaian status yang dilalui Activity dari saat dibuat hingga dihancurkan. Siklus hidup ini diatur oleh sistem Android dan Activity akan memanggil beberapa metode callback seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()` saat berpindah antar status. Memahami metode-metode ini memungkinkan kita untuk menjalankan kode pada waktu yang tepat.

Memahami Lifecycle Activity sangat penting untuk membangun aplikasi yang stabil dan efisien. Dengan mengetahui kapan Activity berada di status tertentu, Anda dapat mengelola sumber daya dengan benar, misalnya, memulai kamera di `onStart()` dan menghentikannya di `onStop()`, atau menyimpan data yang belum disimpan di `onPause()` untuk mencegah kehilangan saat aplikasi berpindah ke latar belakang atau ditutup. Ini membantu mencegah kebocoran memori, crash aplikasi, dan memastikan pengalaman pengguna yang mulus.

```
package com.example.myapp

import android.os.Bundle
import android.util.Log
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    private val TAG = "MainActivity" // Untuk logging

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan Activity dengan layout XML
        Log.d(TAG, "onCreate: Activity baru saja dibuat!")
    }

    override fun onPause() {
        super.onPause()
        Log.d(TAG, "onPause: Activity akan tidak aktif sementara.")
    }
}
```

💡 **Fun Fact:** Sebelum Kotlin menjadi bahasa utama, Activity ditulis dengan Java. Konsep Lifecycle Activity adalah salah satu pilar utama yang sudah ada sejak Android versi awal dirilis, memungkinkan aplikasi untuk berperilaku adaptif di berbagai kondisi perangkat dan interaksi pengguna.
