## ☕ Java Concept: Penanganan Exception: try-catch

**Category:** Exception
**TL;DR:** Memastikan program tetap berjalan stabil dan elegan dengan menangani kesalahan tak terduga menggunakan blok `try` dan `catch`.

Dalam pengembangan perangkat lunak, tidak semua hal berjalan sesuai rencana. Ada kalanya program menghadapi kondisi tak terduga, seperti pembagian dengan nol, mencoba mengakses file yang tidak ada, atau input pengguna yang tidak valid. Kondisi-kondisi ini, jika tidak ditangani, dapat menyebabkan program berhenti secara mendadak (crash) dan memberikan pengalaman buruk bagi pengguna. Di Java, kondisi tak terduga yang dapat mengganggu alur normal program ini disebut sebagai "Exception" (pengecualian).

Untuk mencegah program crash dan memastikan ia tetap berjalan secara elegan, Java menyediakan mekanisme penanganan exception melalui blok `try` dan `catch`. Blok `try` adalah tempat kita menempatkan kode yang berpotensi menimbulkan exception. Jika sebuah exception terjadi di dalam blok `try`, eksekusi kode di dalam `try` akan segera dihentikan, dan kendali program akan dialihkan ke blok `catch` yang sesuai.

Blok `catch` berfungsi untuk "menangkap" exception yang terjadi. Setiap blok `catch` didefinisikan untuk tipe exception tertentu, memungkinkan kita untuk memberikan respons yang spesifik tergantung pada jenis kesalahan yang terjadi. Misalnya, kita bisa menampilkan pesan error yang lebih informatif kepada pengguna, melakukan logging, atau mencoba operasi alternatif. Dengan begitu, program tidak berhenti tiba-tiba tetapi dapat pulih atau setidaknya memberikan umpan balik yang jelas.

Penggunaan `try-catch` sangat fundamental dalam membangun aplikasi Java yang robust (tangguh) dan user-friendly. Bayangkan sebuah aplikasi kalkulator: jika pengguna memasukkan teks alih-alih angka, tanpa `try-catch`, program akan error. Dengan `try-catch`, kita bisa "menangkap" kesalahan format input (`NumberFormatException`) dan meminta pengguna memasukkan ulang, membuat aplikasi lebih stabil dan mudah digunakan.

```
public class ExceptionDemo {
    public static void main(String[] args) {
        String inputAngka = "seratus"; // Contoh input yang salah
        try {
            int angka = Integer.parseInt(inputAngka);
            System.out.println("Angka yang dimasukkan: " + angka);
        } catch (NumberFormatException e) {
            System.err.println("Kesalahan: Input \'" + inputAngka + "\' bukan angka yang valid!");
            // e.printStackTrace(); // Untuk debugging, menampilkan jejak kesalahan
        }
        System.out.println("Program tetap berjalan setelah penanganan error.");
    }
}
```

💡 **Fun Fact:** Java adalah salah satu bahasa pemrograman pertama yang secara komprehensif mengintegrasikan mekanisme penanganan exception sebagai bagian inti dari bahasanya, bukan sekadar sebuah fitur tambahan. Pendekatan ini mendorong developer untuk menulis kode yang lebih robust dan andal sejak awal, menjadikannya standar dalam pengembangan software modern.
