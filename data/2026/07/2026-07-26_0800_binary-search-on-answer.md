## ⚡ Competitive Programming Concept: Binary Search on Answer

**Category:** Searching
**TL;DR:** Teknik mencari nilai optimal (minimum atau maksimum) dari suatu jawaban yang memenuhi kondisi tertentu, dengan memanfaatkan sifat monotonik dari fungsi pengecekan.

Binary Search on Answer (BSA) adalah sebuah teknik powerful untuk memecahkan masalah di mana kita perlu mencari nilai minimum atau maksimum dari suatu hasil yang memenuhi properti tertentu. Kunci penggunaannya adalah ketika kita bisa merumuskan sebuah fungsi `check(X)` yang mengembalikan `true` jika `X` adalah jawaban yang valid (atau lebih baik), dan `false` jika tidak, dan fungsi ini memiliki sifat monotonik. Artinya, jika `check(X)` benar, maka `check(Y)` juga benar untuk semua `Y > X` (atau `Y < X`, tergantung masalahnya).

Alih-alih mencari elemen dalam array, BSA mencari "nilai" itu sendiri. Kita menentukan rentang jawaban yang mungkin, yaitu `low` dan `high`. Di setiap iterasi, kita mengambil `mid = low + (high - low) / 2`. Kita panggil `check(mid)`. Jika `check(mid)` benar, berarti `mid` mungkin adalah jawabannya atau kita bisa mencari jawaban yang lebih baik di rentang `[low, mid-1]` (jika mencari minimum), atau `[mid+1, high]` (jika mencari maksimum). Jika `check(mid)` salah, berarti `mid` terlalu kecil/besar, dan kita harus mencari di rentang `[mid+1, high]` atau `[low, mid-1]` yang sesuai. Proses ini berlanjut hingga `low` dan `high` bertemu.

Teknik ini sangat efisien. Jika rentang jawaban adalah `R` (misalnya dari 1 hingga 10^18) dan kompleksitas fungsi `check(X)` adalah `O(C)`, maka total kompleksitas waktu adalah `O(C * log R)`. BSA sering muncul pada masalah yang meminta "nilai minimum `X` agar pekerjaan selesai dalam `T` waktu," atau "nilai maksimum `Y` sehingga `K` kondisi terpenuhi." Contoh klasik termasuk mencari waktu minimum untuk menyelesaikan semua tugas, kapasitas maksimum, atau nilai ambang batas optimal.

```
long long solve() {
    long long low = 1, high = 1e18, ans = high; // Sesuaikan rentang jawaban
    while (low <= high) {
        long long mid = low + (high - low) / 2;
        if (check(mid)) { // fungsi check(mid) mengembalikan true jika mid adalah jawaban yang valid/lebih baik
            ans = mid; // Simpan mid sebagai jawaban potensial
            high = mid - 1; // Coba cari jawaban yang lebih kecil/baik
        } else {
            low = mid + 1; // mid terlalu kecil, perlu nilai yang lebih besar
        }
    }
    return ans;
}

// bool check(long long val) { /* Implementasi fungsi pengecekan */ }
```

💡 **Fun Fact:** Meskipun dinamakan 'Binary Search', teknik ini lebih sering digunakan pada rentang nilai jawaban yang mungkin daripada pada array yang sudah terurut, menjadikannya 'meta-algoritma' yang sangat fleksibel.
