## 🤖 Android Concept: Activity: Layar Utama Aplikasi Anda

**Category:** Architecture
**TL;DR:** Activity adalah komponen fundamental dalam aplikasi Android yang menyediakan satu layar dengan antarmuka pengguna untuk interaksi pengguna.

Dalam pengembangan aplikasi Android, Activity adalah salah satu blok bangunan paling mendasar. Bayangkan setiap "layar" yang Anda lihat di aplikasi (misalnya, layar utama, layar detail produk, atau layar pengaturan) sebagai sebuah Activity. Setiap Activity bertugas untuk menampilkan antarmuka pengguna (UI) tertentu dan merespons interaksi pengguna pada layar tersebut. Ini adalah titik awal utama di mana pengguna berinteraksi langsung dengan aplikasi Anda.

Sebuah Activity biasanya dihubungkan dengan sebuah file layout XML yang mendefinisikan tampilan UI-nya. Saat Activity dibuat, metode `onCreate()` adalah tempat di mana Anda akan melakukan sebagian besar inisialisasi awal. Di sinilah Anda biasanya mengaitkan file layout XML dengan Activity Anda menggunakan `setContentView(R.layout.nama_layout_anda)`, dan mulai menyiapkan komponen UI seperti tombol, teks, atau gambar. Meskipun Activity memiliki siklus hidup yang lebih kompleks, `onCreate()` adalah titik penting yang perlu dipahami oleh pemula.

Setiap Activity yang Anda buat harus dideklarasikan di file `AndroidManifest.xml` aplikasi Anda. Manifest ini memberi tahu sistem Android tentang keberadaan Activity tersebut dan bagaimana Activity tersebut harus dioperasikan. Aplikasi Android dapat memiliki banyak Activity, dan pengguna dapat berpindah dari satu Activity ke Activity lain, misalnya, dari layar daftar ke layar detail, menggunakan mekanisme yang disebut `Intent`.

Memahami Activity adalah langkah pertama yang krusial karena hampir setiap aplikasi Android pasti memiliki setidaknya satu Activity. Ini adalah fondasi tempat Anda akan membangun seluruh interaksi visual dan logika presentasi aplikasi Anda. Tanpa Activity, tidak ada layar yang bisa Anda tampilkan kepada pengguna.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan layout XML
        // Di sini Anda bisa inisialisasi Views lain
    }
}
```

💡 **Fun Fact:** Saat Anda membuka aplikasi dan berpindah antar layar, Android mengelola "Activity stack" atau tumpukan Activity. Activity baru didorong ke atas tumpukan, dan ketika Anda menekan tombol kembali, Activity teratas akan dihapus dari tumpukan, menampilkan Activity sebelumnya.
