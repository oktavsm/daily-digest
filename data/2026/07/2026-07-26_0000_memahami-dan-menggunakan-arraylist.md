## ☕ Java Concept: Memahami dan Menggunakan ArrayList

**Category:** Collections
**TL;DR:** ArrayList adalah struktur data dinamis yang memungkinkan kita menyimpan dan mengelola daftar objek dengan mudah, dengan kemampuan untuk berubah ukuran secara otomatis.

Dalam pemrograman Java, terkadang kita perlu menyimpan sekumpulan data yang jumlahnya tidak kita ketahui secara pasti di awal, atau yang jumlahnya mungkin berubah selama program berjalan. Di sinilah `ArrayList` sangat berguna. Berbeda dengan array tradisional yang memiliki ukuran tetap setelah dibuat, `ArrayList` menawarkan fleksibilitas karena ia dapat membesar atau mengecil secara otomatis sesuai kebutuhan. Ini membuatnya ideal untuk skenario di mana Anda sering menambahkan atau menghapus elemen.

Untuk mulai menggunakan `ArrayList`, kita perlu mengimpornya dari paket `java.util`. Saat membuat objek `ArrayList`, kita juga perlu menentukan tipe data objek yang akan disimpannya (misalnya, `ArrayList<String>` untuk string, atau `ArrayList<Integer>` untuk bilangan bulat). Ini dikenal sebagai Generics, yang membantu Java memastikan konsistensi tipe data dalam daftar tersebut. Setelah dibuat, Anda dapat menambahkan elemen menggunakan metode `add()`, yang akan menempatkan elemen baru di akhir daftar.

Mengelola data dalam `ArrayList` juga cukup mudah. Anda bisa mengambil elemen pada indeks tertentu menggunakan metode `get(int index)`, mirip seperti array biasa. Jika Anda perlu mengetahui berapa banyak elemen yang ada di dalam daftar, Anda bisa menggunakan metode `size()`. Untuk menghapus elemen, Anda dapat menggunakan `remove(int index)` atau `remove(Object obj)`. `ArrayList` juga sangat cocok untuk diulang (iterasi) menggunakan perulangan `for-each` yang sederhana dan mudah dibaca, memungkinkan Anda memproses setiap elemen dalam daftar.

Singkatnya, `ArrayList` adalah pilihan yang sangat praktis dan sering digunakan ketika Anda membutuhkan sebuah 'daftar' di mana jumlah elemennya tidak tetap dan Anda sering melakukan operasi penambahan, pengambilan, atau penghapusan data. Ini adalah salah satu struktur data paling dasar dan penting untuk dikuasai di Java.

```
import java.util.ArrayList;

public class ContohArrayList {
    public static void main(String[] args) {
        // Membuat ArrayList untuk menyimpan nama mahasiswa (tipe String)
        ArrayList<String> daftarNama = new ArrayList<>();

        // Menambahkan beberapa nama ke ArrayList
        daftarNama.add("Budi");
        daftarNama.add("Ani");
        daftarNama.add("Citra");

        // Mengakses elemen pertama dan mencetaknya
        System.out.println("Mahasiswa pertama: " + daftarNama.get(0));

        // Mencetak jumlah total mahasiswa
        System.out.println("Total mahasiswa: " + daftarNama.size());

        // Mengiterasi (mengunjungi) dan mencetak setiap nama
        System.out.println("Daftar lengkap:");
        for (String nama : daftarNama) {
            System.out.println("- " + nama);
        }
    }
}
```

💡 **Fun Fact:** Secara internal, `ArrayList` di Java sebenarnya menggunakan array biasa sebagai dasar penyimpanannya. Ketika kapasitas array internalnya penuh saat Anda menambahkan elemen baru, `ArrayList` akan secara otomatis membuat array baru yang lebih besar (biasanya berkapasitas 1.5 kali ukuran semula) dan menyalin semua elemen lama ke array baru tersebut.
