## ☕ Java Concept: Kelas dan Objek di Java

**Category:** OOP
**TL;DR:** Kelas adalah cetak biru (blueprint) untuk membuat objek, yang merupakan entitas nyata dengan data dan perilaku yang didefinisikan oleh kelasnya.

Dalam pemrograman Java, konsep Kelas dan Objek adalah pondasi utama dari Paradigma Berorientasi Objek (OOP). Bayangkan sebuah kelas sebagai cetak biru atau template. Ia mendefinisikan struktur (data yang akan dimiliki, disebut atribut atau field) dan perilaku (aksi yang bisa dilakukan, disebut method) yang akan dimiliki oleh objek-objek yang dibuat darinya. Kelas sendiri bukanlah sesuatu yang "hidup" atau bisa berinteraksi secara langsung; ia hanya sebuah definisi abstrak.

Objek, di sisi lain, adalah instance nyata dari sebuah kelas. Jika kelas adalah cetak biru mobil, maka objek adalah mobil-mobil fisik yang dibuat berdasarkan cetak biru tersebut—setiap mobil memiliki warna, model, dan nomor rangka sendiri, namun semuanya mengikuti desain dasar yang sama. Setiap objek memiliki nilai unik untuk atribut-atributnya (disebut "state") dan bisa menjalankan method yang didefinisikan oleh kelasnya. Proses membuat objek dari sebuah kelas disebut instansiasi.

Untuk membuat sebuah objek dari kelas, kita menggunakan kata kunci `new`. Misalnya, jika kita memiliki kelas `Mahasiswa`, kita bisa membuat objek `Mahasiswa` dengan `Mahasiswa mhs1 = new Mahasiswa();`. Objek `mhs1` ini kemudian dapat mengakses dan mengubah nilai atributnya (`mhs1.nama = "Budi"`) serta memanggil method-method yang ada di kelas `Mahasiswa` (`mhs1.perkenalkanDiri()`). Memahami bagaimana kelas dan objek saling berinteraksi adalah langkah pertama yang krusial dalam menguasai pemrograman Java.

```
class Mahasiswa {
    String nama;
    String nim;

    void perkenalkanDiri() {
        System.out.println("Halo, saya " + nama + " dengan NIM " + nim);
    }
}

public class MainApp {
    public static void main(String[] args) {
        Mahasiswa mhs1 = new Mahasiswa(); // Membuat objek
        mhs1.nama = "Budi Santoso";
        mhs1.nim = "2023001";
        mhs1.perkenalkanDiri(); // Memanggil method
    }
}
```

💡 **Fun Fact:** Java adalah salah satu dari sedikit bahasa pemrograman yang hampir sepenuhnya berorientasi objek; bahkan program 'Hello World' Anda sudah beroperasi dalam konteks kelas, menunjukkan seberapa fundamental konsep ini bagi Java.
