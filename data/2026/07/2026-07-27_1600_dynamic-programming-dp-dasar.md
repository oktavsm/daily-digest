## ⚡ Competitive Programming Concept: Dynamic Programming (DP) Dasar

**Category:** DP
**TL;DR:** Memecahkan masalah kompleks dengan memecahnya menjadi sub-masalah yang lebih kecil dan menyimpan hasilnya untuk menghindari perhitungan berulang.

Dynamic Programming (DP) adalah metode yang sangat kuat untuk memecahkan masalah kompleks dengan memecahnya menjadi sub-masalah yang lebih kecil dan menyimpan hasil dari sub-masalah tersebut agar tidak dihitung ulang. Dua karakteristik utama yang harus dipenuhi agar masalah dapat diselesaikan dengan DP adalah *overlapping subproblems* (sub-masalah yang sama muncul berulang kali) dan *optimal substructure* (solusi optimal dari masalah dapat dibangun dari solusi optimal sub-masalahnya). Metode ini sangat efektif untuk masalah yang memiliki struktur rekursif tetapi dengan banyak perhitungan duplikat, seperti masalah rute terpendek, knapsack, atau longest common subsequence.

Ada dua pendekatan utama dalam DP: *Memoization* (top-down) dan *Tabulation* (bottom-up). Memoization dimulai dari masalah utama dan secara rekursif memanggil sub-masalah. Hasil dari setiap sub-masalah disimpan dalam "memo" (misalnya array atau map) setelah dihitung pertama kali. Jika sub-masalah yang sama dipanggil lagi, hasilnya langsung diambil dari memo. Sebaliknya, Tabulation membangun solusi dari sub-masalah terkecil hingga masalah utama secara iteratif, mengisi tabel DP (biasanya array multidimensi) dengan hasil sub-masalah secara berurutan.

Keuntungan utama menggunakan DP adalah peningkatan efisiensi yang signifikan. Banyak masalah yang jika diselesaikan dengan rekursi naif akan memiliki kompleksitas waktu eksponensial karena perhitungan berulang. Dengan menyimpan hasil sub-masalah, DP dapat mengurangi kompleksitas waktu menjadi polinomial. Contoh klasik adalah menghitung bilangan Fibonacci ke-N; rekursi naif memiliki kompleksitas O(2^N), sedangkan dengan DP (baik memoization maupun tabulation) kompleksitasnya menjadi O(N) karena setiap sub-masalah hanya dihitung satu kali.

Pemilihan antara memoization dan tabulation seringkali tergantung pada preferensi pribadi atau struktur spesifik masalah. Memoization lebih intuitif jika masalah awalnya dirumuskan secara rekursif, karena ia mengikuti alur rekursi alami. Sementara itu, tabulation seringkali lebih efisien dalam penggunaan memori dan menghindari overhead panggilan fungsi rekursif. Memahami kapan dan bagaimana menerapkan kedua pendekatan ini adalah kunci untuk menguasai Dynamic Programming di competitive programming.

```
#include <vector>

// Contoh: Menghitung Fibonacci ke-N dengan DP (Tabulation)
int fibonacci_dp(int n) {
    if (n <= 1) return n;
    std::vector<int> dp(n + 1);
    dp[0] = 0;
    dp[1] = 1;
    for (int i = 2; i <= n; ++i) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
```
