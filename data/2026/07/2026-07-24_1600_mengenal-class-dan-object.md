## ☕ Java Concept: Mengenal Class dan Object

**Category:** OOP
**TL;DR:** Class adalah blueprint untuk membuat object, sedangkan object adalah instance nyata dari class yang memiliki state dan behavior.

Class dalam Java adalah sebuah cetak biru (blueprint) atau template yang mendefinisikan struktur dan perilaku objek. Ibaratnya, jika Anda ingin membangun banyak rumah dengan desain yang sama, Anda memerlukan denah arsitek; denah inilah 'class'. Sebuah class tidak menempati memori secara langsung; ia hanya mendefinisikan seperti apa objek yang akan dibuat nanti. Di dalamnya, Anda akan menemukan atribut (variabel) yang mendeskripsikan karakteristik objek dan metode (fungsi) yang mendeskripsikan apa yang bisa dilakukan objek tersebut.

Object adalah instance (wujud nyata) dari sebuah class. Jika class adalah denah rumah, maka object adalah rumah-rumah yang sudah dibangun berdasarkan denah tersebut. Setiap object memiliki identitas, state (nilai dari atributnya), dan behavior (apa yang bisa dilakukannya melalui metodenya). Kita bisa membuat banyak object dari satu class yang sama, dan setiap object akan memiliki state-nya sendiri-sendiri yang independen. Untuk membuat object, kita menggunakan operator `new`, contohnya `Mobil mobilSaya = new Mobil();`.

Hubungan antara class dan object adalah fundamental dalam pemrograman berorientasi objek (OOP). Class mendefinisikan 'apa' suatu entitas, sementara object adalah manifestasi 'itu'. Konsep ini memungkinkan kita untuk memodelkan entitas dunia nyata ke dalam kode program, membuat kode lebih terstruktur, modular, dan mudah dipelihara. Dengan memisahkan definisi (class) dari implementasi (object), kita dapat membuat program yang lebih fleksibel dan skalabel dalam menghadapi perubahan.

```
public class Kucing { // Class: cetak biru
    String nama; // Atribut (state)
    void bersuara() { // Method (behavior)
        System.out.println(nama + " mengeong!");
    }

    public static void main(String[] args) {
        Kucing myKucing = new Kucing(); // Object: wujud nyata
        myKucing.nama = "Milo";
        myKucing.bersuara(); // Panggil method
    }
}
```

💡 **Fun Fact:** Bahkan method `main` di Java pun harus berada di dalam sebuah class, menegaskan bahwa Java sangat berorientasi objek dan hampir semua hal berputar pada konsep class dan object.
