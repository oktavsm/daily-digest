## 🤖 Android Concept: Memahami Android Activity

**Category:** UI
**TL;DR:** Activity adalah komponen utama yang menyediakan layar untuk interaksi pengguna dalam aplikasi Android.

Activity merupakan salah satu blok bangunan fundamental dalam pengembangan aplikasi Android, berfungsi sebagai titik masuk utama untuk interaksi pengguna. Sederhananya, setiap layar yang Anda lihat di aplikasi Android Anda, seperti layar login, daftar produk, atau halaman pengaturan, biasanya diimplementasikan sebagai sebuah Activity. Ia menyediakan jendela di mana aplikasi Anda menggambar antarmuka pengguna (UI) dan tempat pengguna dapat berinteraksi dengan aplikasi tersebut.

Setiap Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, mulai dari dibuat hingga dihancurkan. Metode kunci dalam lifecycle ini meliputi `onCreate()`, tempat inisialisasi awal seperti pengaturan layout dilakukan; `onStart()`, saat Activity mulai terlihat oleh pengguna; `onResume()`, ketika Activity berada di latar depan dan siap untuk berinteraksi; `onPause()`, saat Activity sebagian tertutup; `onStop()`, saat Activity tidak lagi terlihat; dan `onDestroy()`, ketika Activity sepenuhnya dihancurkan.

Ketika Anda ingin menampilkan sebuah Activity, Anda akan menggunakan objek `Intent` untuk memulai Activity baru dari Activity yang sudah ada. Di dalam metode `onCreate()`, Anda biasanya memanggil `setContentView(R.layout.activity_main)` untuk menghubungkan Activity dengan file layout XML yang mendefinisikan tampilan antarmukanya. Ini memungkinkan Anda merancang UI secara deklaratif menggunakan XML dan mengelola logikanya di kelas Kotlin Activity.

Memahami Activity lifecycle sangat krusial untuk membangun aplikasi yang responsif dan efisien. Aplikasi harus dapat mengelola state-nya dengan baik saat Activity berpindah antar status, misalnya ketika pengguna menerima panggilan telepon atau merotasi layar perangkat. Manajemen lifecycle yang tepat akan mencegah kebocoran memori dan memastikan pengalaman pengguna yang mulus.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan layout XML
        // Inisialisasi komponen UI lainnya di sini
    }
}
```
