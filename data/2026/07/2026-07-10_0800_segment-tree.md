## ⚡ Competitive Programming Concept: Segment Tree

**Category:** Data Structure
**TL;DR:** Segment Tree adalah struktur data pohon yang efisien untuk melakukan query pada rentang (range) dan update elemen dalam waktu logaritmis.

Segment Tree adalah struktur data pohon biner yang sangat efisien untuk menyelesaikan berbagai masalah yang melibatkan query pada sebuah *range* (misalnya, mencari sum, minimum, atau maksimum dalam sebuah subarray) dan *update* nilai pada sebuah posisi atau range tertentu. Dalam competitive programming, seringkali kita perlu melakukan operasi ini berkali-kali pada array besar, di mana pendekatan naïf O(N) untuk setiap query/update akan terlalu lambat. Segment Tree hadir untuk mengatasi masalah ini dengan kompleksitas waktu yang jauh lebih baik.

Secara konseptual, Segment Tree merepresentasikan sebuah array sebagai pohon biner di mana setiap node internal menyimpan informasi gabungan dari *range* yang dicakup oleh anak-anaknya. Node daun (leaf nodes) merepresentasikan elemen tunggal dari array asli. Misalnya, jika kita ingin mencari sum, sebuah node internal akan menyimpan total sum dari range yang diwakilinya, yang merupakan jumlah sum dari anak kiri dan anak kanannya. Struktur ini memungkinkan kita 'melompati' bagian-bagian array yang tidak relevan saat melakukan query.

Proses pembangunan (build) Segment Tree membutuhkan waktu **O(N)**, di mana N adalah ukuran array asli, karena setiap elemen perlu diproses satu kali untuk mengisi node-node pohon. Setelah dibangun, baik operasi query (misalnya, mencari sum di sebuah range) maupun update (misalnya, mengubah nilai di satu indeks) dapat dilakukan dalam waktu **O(log N)**. Efisiensi ini berasal dari sifat pohon biner yang tingginya logaritmis terhadap jumlah jumlah elemen dalam array.

Keunggulan Segment Tree terletak pada fleksibilitasnya; ia bisa diadaptasi untuk berbagai operasi seperti sum, min, max, GCD, dan lainnya, asalkan operasi tersebut asosiatif. Namun, ia memerlukan memori **O(N)** (tepatnya sekitar 4N) dan bisa menjadi kompleks untuk operasi *range update* yang membutuhkan teknik *lazy propagation*. Meskipun demikian, kemampuan query dan update yang cepat membuatnya menjadi salah satu struktur data paling fundamental dan sering digunakan.

```
vector<int> tree; // Assume declared globally/member. Size ~4*N
vector<int> arr;  // Original array. Assume declared globally/member.

void build(int node, int start, int end) {
    if (start == end) {
        tree[node] = arr[start];
    } else {
        int mid = (start + end) / 2;
        build(2*node, start, mid);
        build(2*node+1, mid+1, end);
        tree[node] = tree[2*node] + tree[2*node+1]; // Example: sum operation
    }
}
```

💡 **Fun Fact:** Meskipun namanya 'segment tree', struktur ini awalnya dirancang untuk masalah geometris segment-intersection namun kini jauh lebih sering digunakan sebagai alat serbaguna untuk masalah query range pada array.
