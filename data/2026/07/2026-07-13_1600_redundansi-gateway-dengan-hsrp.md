## 🌐 Networking Concept: Redundansi Gateway dengan HSRP

**Category:** Routing
**TL;DR:** HSRP memastikan ketersediaan gateway default yang tinggi dengan memungkinkan beberapa router berbagi alamat IP virtual, mencegah satu titik kegagalan.

Dalam jaringan modern, ketersediaan adalah segalanya. Salah satu titik kegagalan tunggal yang paling umum adalah router yang berfungsi sebagai gateway default untuk segmen LAN. Jika router ini gagal, semua perangkat di segmen tersebut akan kehilangan konektivitas ke luar jaringan, mengganggu operasional dan produktivitas. Skenario seperti ini tidak dapat diterima dalam lingkungan bisnis yang membutuhkan konektivitas tanpa henti.

Untuk mengatasi masalah fundamental ini, kita akan mempelajari Hot Standby Router Protocol (HSRP), sebuah protokol redundansi first-hop milik Cisco. HSRP memungkinkan dua atau lebih router untuk secara kolektif menyediakan satu alamat IP dan MAC address virtual. Salah satu router akan bertindak sebagai router 'Aktif' yang memproses semua lalu lintas, sementara router lainnya menjadi 'Standby' yang siap mengambil alih peran aktif jika router utama gagal, memastikan transisi yang mulus dan transparan bagi pengguna akhir.

Konsep inti HSRP adalah pengelompokan (group). Setiap kelompok HSRP memiliki alamat IP virtual dan MAC address virtualnya sendiri. Perangkat klien di LAN dikonfigurasi untuk menggunakan alamat IP virtual ini sebagai gateway default mereka. Router aktif secara teratur mengirimkan pesan 'Hello' ke router standby. Jika router standby tidak menerima pesan ini dalam interval waktu yang ditentukan, ia akan mengasumsikan router aktif telah gagal dan segera mengambil alih peran aktif. Proses failover ini terjadi tanpa memerlukan konfigurasi ulang pada perangkat klien.

Dengan Cisco Packet Tracer, kita dapat mensimulasikan implementasi HSRP dengan menyiapkan dua router yang terhubung ke segmen LAN yang sama. Setelah mengkonfigurasi HSRP pada antarmuka masing-masing router yang terhubung ke LAN, kita dapat mengamati secara langsung bagaimana failover terjadi ketika kita mematikan router aktif. Ini adalah cara yang sangat praktis untuk memahami pentingnya redundansi dalam desain jaringan dan bagaimana HSRP secara efektif memastikan konektivitas yang tidak terputus bahkan saat terjadi kegagalan perangkat.

```
standby 1 ip 192.168.1.254
```

💡 **Fun Fact:** HSRP menggunakan MAC address virtual khusus (0000.0C07.ACxx, di mana xx adalah nomor grup HSRP dalam heksadesimal) agar perangkat klien tidak perlu memperbarui tabel ARP mereka saat terjadi failover, membuat transisi benar-benar transparan.
