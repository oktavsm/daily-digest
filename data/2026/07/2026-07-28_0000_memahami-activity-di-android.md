## 🤖 Android Concept: Memahami Activity di Android

**Category:** Architecture
**TL;DR:** Activity adalah komponen dasar yang menyediakan layar untuk interaksi pengguna dalam aplikasi Android.

Dalam pengembangan aplikasi Android, Activity adalah salah satu blok bangunan paling fundamental. Bayangkan Activity sebagai satu layar atau jendela dalam aplikasi Anda. Setiap kali pengguna melihat sesuatu di layar (misalnya daftar email, detail produk, atau formulir pendaftaran), kemungkinan besar itu diwakili oleh sebuah Activity. Activity bertanggung jawab untuk mengelola antarmuka pengguna (UI) dan berinteraksi dengan pengguna. Setiap aplikasi Android setidaknya memiliki satu Activity utama, dan seringkali lebih banyak lagi untuk berbagai fungsi atau tampilan.

Setiap Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, mulai dari dibuat (created), terlihat (started), berinteraksi (resumed), hingga dihancurkan (destroyed). Metode utama yang harus Anda pahami adalah `onCreate()`, tempat Anda melakukan inisialisasi awal seperti mengaitkan layout XML dengan Activity menggunakan `setContentView(R.layout.nama_layout_anda)`. Selain itu, ada juga metode seperti `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()` yang dipanggil pada berbagai tahapan siklus hidup Activity, memungkinkan Anda mengelola sumber daya aplikasi secara efisien.

Untuk berpindah dari satu Activity ke Activity lainnya, kita menggunakan objek `Intent`. Intent bertindak sebagai pesan yang digunakan untuk meminta sistem Android melakukan sesuatu, seperti memulai Activity baru. Anda dapat membuat `Intent` eksplisit (menentukan Activity tujuan secara langsung) atau implisit (menentukan tindakan yang ingin dilakukan sistem). Setelah membuat Intent, Anda memanggil `startActivity(intent)` untuk meluncurkan Activity tujuan.

Memahami Activity adalah kunci untuk membangun aplikasi Android yang terstruktur dan responsif. Ia tidak hanya menjadi wadah bagi UI, tetapi juga pusat koordinasi untuk berbagai operasi seperti manajemen state, penanganan input pengguna, dan navigasi antar layar. Menguasai konsep Activity akan menjadi fondasi yang kuat sebelum melangkah ke komponen Android yang lebih kompleks seperti Fragment atau ViewModel.

```
class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        val myButton: Button = findViewById(R.id.my_button)
        myButton.setOnClickListener {
            val intent = Intent(this, DetailActivity::class.java)
            startActivity(intent)
        }
    }
}
```

💡 **Fun Fact:** Tahukah Anda bahwa nama 'Activity' dipilih karena setiap layar dalam aplikasi merepresentasikan sebuah 'aktivitas' yang sedang dilakukan pengguna? Konsep ini sudah ada sejak Android versi awal dan masih menjadi tulang punggung navigasi dan struktur aplikasi hingga kini.
