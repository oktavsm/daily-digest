## ⚡ Competitive Programming Concept: Segment Tree (Pohon Segmen)

**Category:** Data Structure
**TL;DR:** Struktur data pohon yang efisien untuk melakukan query rentang (range query) dan update elemen tunggal atau rentang pada array, dengan kompleksitas waktu logaritmik.

Segment Tree, atau Pohon Segmen, adalah struktur data berbasis pohon biner yang sangat efisien untuk menangani query pada rentang (range query) dan update pada elemen tunggal atau rentang pada sebuah array. Sering digunakan dalam kompetisi pemrograman untuk masalah yang melibatkan pencarian nilai minimum/maksimum dalam rentang, penjumlahan rentang, atau operasi lain yang bersifat asosiatif (misalnya, XOR, GCD). Keunggulan utamanya adalah kemampuannya untuk melakukan operasi-operasi ini jauh lebih cepat daripada iterasi linear pada array, terutama ketika ada banyak query dan update.

Secara konseptual, Segment Tree merepresentasikan sebuah array sebagai pohon biner. Setiap node dalam pohon merepresentasikan suatu "segmen" atau sub-rentang dari array asli. Node akar (root) merepresentasikan seluruh rentang array, sedangkan node daun (leaf nodes) merepresentasikan elemen tunggal dari array. Setiap node internal merepresentasikan gabungan dari rentang yang diwakili oleh kedua anak-anaknya. Misalnya, jika sebuah node merepresentasikan rentang `[L, R]`, anak kirinya mungkin merepresentasikan `[L, (L+R)/2]` dan anak kanannya `[(L+R)/2 + 1, R]`.

Ada tiga operasi utama pada Segment Tree: `build`, `update`, dan `query`. Operasi `build` membangun pohon dari array asli, mengisi nilai-nilai agregat pada setiap node. Operasi `update` mengubah nilai pada indeks tertentu di array dan kemudian memperbarui nilai-nilai pada node-node yang relevan di jalur dari node daun ke akar. Operasi `query` mengambil nilai agregat (misalnya, jumlah, minimum, maksimum) untuk rentang tertentu dengan memecah rentang query menjadi beberapa segmen yang sudah dihitung sebelumnya dalam pohon. Semua operasi ini biasanya diimplementasikan secara rekursif, memanfaatkan struktur pohon biner.

Kompleksitas waktu untuk membangun Segment Tree dari array berukuran `N` adalah **O(N)**, karena setiap node dikunjungi sekali. Untuk operasi `update` dan `query` pada rentang atau elemen tunggal, kompleksitas waktunya adalah **O(log N)**. Hal ini karena dalam setiap operasi, kita hanya perlu menelusuri jalur dari akar ke daun (untuk update) atau beberapa jalur yang mencakup rentang query (untuk query), dan panjang jalur ini logaritmik terhadap ukuran array. Ini membuatnya sangat efisien untuk masalah dengan banyak query dan update, seringkali lebih unggul dari array biasa atau Fenwick Tree dalam skenario tertentu.

```
const int N_MAX = 100005;
int tree[4 * N_MAX]; // Array untuk menyimpan pohon segmen

// Contoh operasi point update untuk range sum
void update(int node, int start, int end, int idx, int val) {
    if (start == end) { tree[node] = val; return; }
    int mid = (start + end) / 2;
    if (idx <= mid) update(2*node, start, mid, idx, val);
    else update(2*node+1, mid+1, end, idx, val);
    tree[node] = tree[2*node] + tree[2*node+1]; // Gabungkan hasil anak
}
```

💡 **Fun Fact:** Segment Tree dinamakan demikian karena setiap node merepresentasikan 'segmen' atau rentang dari array asli, bukan karena bentuk fisiknya menyerupai segmen. Konsep serupa juga dapat diperluas untuk data multidimensi, menghasilkan Segment Tree multidimensi yang lebih kompleks.
