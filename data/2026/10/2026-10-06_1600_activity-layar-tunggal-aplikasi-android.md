## 🤖 Android Concept: Activity: Layar Tunggal Aplikasi Android

**Category:** UI
**TL;DR:** Activity adalah komponen dasar aplikasi Android yang menyediakan satu layar visual untuk berinteraksi dengan pengguna.

Di dunia Android, Activity adalah fondasi utama dari interaksi pengguna. Bayangkan Activity sebagai satu "layar" dalam aplikasi Anda. Setiap kali Anda membuka aplikasi, melihat daftar item, atau mengisi formulir, kemungkinan besar Anda sedang berinteraksi dengan sebuah Activity. Activity bertanggung jawab untuk menyediakan jendela visual tempat antarmuka pengguna (UI) digambar, dan di sinilah pengguna dapat melihat serta berinteraksi dengan aplikasi Anda.

Setiap Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, mulai dari dibuat (`onCreate`), tampil di layar (`onStart`, `onResume`), hingga dihancurkan (`onDestroy`). Memahami siklus hidup ini sangat krusial untuk mengelola sumber daya dengan benar dan memastikan aplikasi Anda berjalan efisien tanpa kebocoran memori. Fungsi `onCreate()` adalah tempat paling umum untuk melakukan inisialisasi awal, seperti mengatur tata letak (layout) dan mengikat komponen UI.

Untuk membuat Activity, Anda biasanya membuat kelas Kotlin yang mewarisi dari `AppCompatActivity` dan mengimplementasikan metode `onCreate()`. Di dalam `onCreate()`, Anda akan memanggil `setContentView()` untuk mengaitkan Activity dengan file layout XML yang mendefinisikan tampilan UI-nya. Activity juga dapat berkomunikasi dengan Activity lain menggunakan `Intent`, memungkinkan transisi antar layar dan berbagi data sederhana.

Singkatnya, Activity adalah "rumah" bagi UI Anda dan titik masuk utama bagi pengguna untuk berinteraksi. Penguasaan konsep Activity, termasuk siklus hidupnya dan cara kerjanya dengan layout dan Intent, adalah langkah pertama yang paling fundamental dalam perjalanan Anda sebagai pengembang Android.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Mengaitkan dengan layout XML
        // Di sini Anda bisa inisialisasi UI komponen lain
    }
}
```

💡 **Fun Fact:** Activity adalah salah satu komponen asli Android yang sudah ada sejak versi pertama platform ini dirilis pada tahun 2008, menjadikannya tulang punggung bagi sebagian besar pengalaman pengguna selama lebih dari satu dekade.
