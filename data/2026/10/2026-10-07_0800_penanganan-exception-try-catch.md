## ☕ Java Concept: Penanganan Exception (Try-Catch)

**Category:** Exception
**TL;DR:** Konsep penanganan exception di Java memungkinkan program Anda untuk mengelola dan merespon kesalahan tak terduga dengan cara yang terkontrol, mencegah aplikasi crash dan meningkatkan keandalan.

Selamat pagi, mahasiswa! Hari ini kita akan membahas salah satu aspek krusial dalam pemrograman Java: **Penanganan Exception**. Dalam dunia nyata, program tidak selalu berjalan mulus. Ada kalanya terjadi hal-hal tak terduga, seperti pengguna memasukkan teks padahal diharapkan angka, mencoba membuka file yang tidak ada, atau bahkan membagi angka dengan nol. Kejadian-kejadian inilah yang dalam Java kita sebut sebagai "exception" atau pengecualian. Tanpa penanganan yang tepat, sebuah exception akan menyebabkan program Anda berhenti secara mendadak (crash), yang tentu saja merupakan pengalaman buruk bagi pengguna.

Maka dari itu, Java menyediakan mekanisme khusus untuk "menangkap" dan "menangani" exception ini, yaitu melalui blok `try-catch`. Blok `try` digunakan untuk mengapit kode yang berpotensi menimbulkan exception. Jika sebuah exception terjadi di dalam blok `try`, eksekusi kode di dalam blok `try` akan segera dihentikan, dan kendali akan dialihkan ke blok `catch` yang relevan. Ini memungkinkan program Anda untuk tidak berhenti total, melainkan memberikan kesempatan untuk memulihkan diri atau setidaknya memberikan pesan kesalahan yang informatif kepada pengguna.

Blok `catch` berfungsi sebagai "penangkap" exception. Setiap blok `catch` dapat dikaitkan dengan jenis exception tertentu (misalnya, `ArithmeticException` untuk kesalahan pembagian, atau `IOException` untuk masalah input/output). Saat exception tertangkap, kode di dalam blok `catch` akan dieksekusi, di mana Anda bisa menentukan bagaimana program harus bereaksi: apakah itu mencetak pesan kesalahan, melakukan logging, meminta input ulang dari pengguna, atau melakukan tindakan pembersihan lainnya. Dengan demikian, `try-catch` adalah fondasi untuk membangun aplikasi Java yang tangguh dan ramah pengguna, karena ia memastikan bahwa program dapat terus berjalan bahkan ketika menghadapi situasi di luar dugaan.

```
public class ExceptionDemo {
    public static void main(String[] args) {
        try {
            int numerator = 10;
            int denominator = 0; // Akan menyebabkan ArithmeticException
            int result = numerator / denominator;
            System.out.println("Hasil: " + result);
        } catch (ArithmeticException e) {
            System.err.println("Error: Tidak bisa membagi dengan nol!");
            System.err.println("Detail: " + e.getMessage());
        }
        System.out.println("Program selesai.");
    }
}
```

💡 **Fun Fact:** Tahukah Anda bahwa semua exception di Java adalah objek? Mereka semua merupakan subclass dari kelas `java.lang.Throwable`. Konsep ini memungkinkan Anda untuk memperlakukan exception seperti data lain dalam program Anda, memberikan fleksibilitas tinggi dalam cara penanganannya.
