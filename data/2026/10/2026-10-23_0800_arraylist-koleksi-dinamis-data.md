## ☕ Java Concept: ArrayList: Koleksi Dinamis Data

**Category:** Collections
**TL;DR:** ArrayList adalah implementasi antarmuka List yang memungkinkan kita menyimpan dan mengelola urutan objek dengan ukuran yang bisa berubah secara dinamis.

Sebagai mahasiswa semester awal, kalian mungkin sudah akrab dengan array. Array memang sangat berguna untuk menyimpan sekumpulan data dengan tipe yang sama. Namun, array memiliki satu keterbatasan utama: ukurannya tetap setelah dibuat. Jika kita perlu menyimpan data yang jumlahnya tidak pasti atau akan sering bertambah dan berkurang, array "biasa" menjadi kurang fleksibel. Di sinilah ArrayList hadir sebagai solusi.

ArrayList adalah bagian dari Java Collections Framework, yang merupakan sekumpulan antarmuka dan kelas untuk merepresentasikan dan memanipulasi koleksi objek. Berbeda dengan array, ArrayList dapat tumbuh atau menyusut secara otomatis sesuai kebutuhan. Ini membuatnya sangat praktis untuk banyak skenario, misalnya saat kita ingin menyimpan daftar nama pelanggan, nilai ujian, atau item belanja yang jumlahnya bisa berubah-ubah selama program berjalan.

Untuk menggunakan ArrayList, kita perlu mengimpornya dari package `java.util`. Pembuatannya sangat mudah: kita cukup menentukan tipe data objek yang ingin disimpan (misalnya, `String` atau `Integer`) menggunakan fitur Generics (yang akan kita pelajari lebih lanjut nanti). Kemudian, kita bisa menambahkan elemen menggunakan metode `add()`, mengambil elemen menggunakan `get()` dengan indeksnya, menghapus elemen dengan `remove()`, dan mengetahui jumlah elemen dengan `size()`.

Keunggulan utama ArrayList adalah fleksibilitas ukurannya dan kemudahan penggunaannya. Namun, penting untuk diingat bahwa karena ia adalah "list", mengakses elemen berdasarkan indeks (`get()`) sangat cepat, tetapi menambahkan atau menghapus elemen di tengah list bisa sedikit lebih lambat karena membutuhkan penggeseran elemen-elemen lain. Meskipun demikian, untuk sebagian besar aplikasi sehari-hari, ArrayList adalah pilihan koleksi yang sangat efisien dan paling sering digunakan.

```
import java.util.ArrayList;

public class ContohArrayList {
    public static void main(String[] args) {
        // Membuat ArrayList untuk menyimpan nama-nama (tipe String)
        ArrayList<String> daftarNama = new ArrayList<>();
        
        // Menambahkan elemen ke ArrayList
        daftarNama.add("Alice");
        daftarNama.add("Bob");
        daftarNama.add("Charlie");

        // Mengakses elemen berdasarkan indeks
        System.out.println("Nama pertama: " + daftarNama.get(0)); // Output: Alice
        
        // Mendapatkan jumlah elemen
        System.out.println("Jumlah nama: " + daftarNama.size()); // Output: 3

        // Menghapus elemen
        daftarNama.remove("Bob"); // Menghapus "Bob"
        
        // Menampilkan seluruh isi ArrayList
        System.out.println("Daftar setelah Bob dihapus: " + daftarNama); // Output: [Alice, Charlie]
    }
}
```

💡 **Fun Fact:** Tahukah kamu bahwa di balik layar, `ArrayList` sebenarnya menggunakan array biasa? Saat `ArrayList` penuh dan membutuhkan lebih banyak ruang, ia akan membuat array baru yang lebih besar (biasanya 1.5 kali ukuran semula) dan menyalin semua elemen lama ke array baru tersebut. Proses inilah yang membuatnya terlihat memiliki "ukuran dinamis"!
