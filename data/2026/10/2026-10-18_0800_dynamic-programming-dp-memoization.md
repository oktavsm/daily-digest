## ⚡ Competitive Programming Concept: Dynamic Programming (DP) - Memoization

**Category:** DP
**TL;DR:** DP dengan memoization (top-down) menyelesaikan masalah dengan memecahnya menjadi sub-masalah yang tumpang tindih dan menyimpan hasil sub-masalah untuk menghindari perhitungan ulang.

Dynamic Programming (DP) adalah teknik yang sangat ampuh dalam competitive programming, digunakan untuk menyelesaikan masalah optimasi atau pencacahan yang memiliki dua karakteristik utama: *optimal substructure* (solusi optimal dari masalah dapat dibangun dari solusi optimal sub-masalahnya) dan *overlapping subproblems* (sub-masalah yang sama dihitung berkali-kali). Ada dua pendekatan utama DP: top-down (memoization) dan bottom-up (tabulation). Konsep ini akan fokus pada pendekatan top-down atau memoization.

Pendekatan top-down bekerja secara rekursif. Ketika kita mencoba menyelesaikan masalah utama, kita memecahnya menjadi sub-masalah yang lebih kecil. Sebelum menghitung solusi untuk suatu sub-masalah, kita memeriksa apakah solusi untuk sub-masalah tersebut sudah pernah dihitung dan disimpan sebelumnya. Jika ya, kita langsung mengembalikan nilai yang tersimpan (inilah 'memoization'). Jika belum, kita hitung solusinya, menyimpannya di 'memo' (biasanya array atau map), lalu mengembalikannya. Proses ini memastikan setiap sub-masalah hanya dihitung sekali.

Keuntungan utama dari memoization adalah kita hanya menghitung sub-masalah yang benar-benar dibutuhkan untuk mencapai solusi masalah utama. Ini berbeda dengan pendekatan bottom-up yang mungkin menghitung semua sub-masalah hingga ukuran tertentu, meskipun beberapa di antaranya tidak relevan dengan solusi akhir. Struktur rekursif dari memoization juga seringkali lebih intuitif untuk dirancang karena langsung mencerminkan definisi rekursif dari masalah.

Kompleksitas waktu dari DP dengan memoization biasanya ditentukan oleh jumlah unik sub-masalah dikalikan dengan waktu yang dibutuhkan untuk menghitung setiap sub-masalah (setelah semua sub-sub-masalahnya sudah diketahui). Misalnya, untuk masalah seperti Fibonacci, jumlah unik sub-masalah adalah O(N) dan waktu untuk menghitung setiap sub-masalah adalah O(1), sehingga total kompleksitas waktunya adalah O(N). Untuk masalah lain seperti Knapsack, kompleksitas bisa menjadi O(N*W) di mana N adalah jumlah item dan W adalah kapasitas knapsack.

```
std::vector<int> memo;

int fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib(n - 1) + fib(n - 2);
}

```

Ia memilih nama 'dynamic programming' karena kedengarannya lebih impresif dan 'ilmiah' untuk mendapatkan pendanaan dari militer AS, bukan karena ada hubungannya dengan 'dinamis' dalam pengertian umum.
