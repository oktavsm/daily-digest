## ☕ Java Concept: Memahami dan Menggunakan ArrayList

**Category:** Collections
**TL;DR:** ArrayList adalah struktur data dinamis yang memungkinkan kita menyimpan dan mengelola kumpulan objek dengan fleksibel, berbeda dengan array biasa yang ukurannya tetap.

Selamat pagi, mahasiswa! Hari ini, kita akan mempelajari salah satu konsep paling praktis dan sering dipakai dalam pemrograman Java, yaitu `ArrayList`. Bayangkan kamu perlu menyimpan daftar nama teman, nilai-nilai ujian, atau data produk. Jika menggunakan array biasa, kamu harus menentukan ukurannya di awal, dan itu bisa menjadi masalah jika jumlah data berubah-ubah. Nah, `ArrayList` hadir sebagai solusinya.

`ArrayList` adalah bagian dari Java Collections Framework yang bertindak seperti 'array dinamis'. Artinya, kamu tidak perlu khawatir tentang ukuran. Ia dapat tumbuh dan menyusut secara otomatis sesuai kebutuhan. Ini membuatnya sangat ideal untuk skenario di mana kamu tidak tahu berapa banyak elemen yang akan kamu miliki, atau ketika jumlah elemen sering berubah selama eksekusi program. `ArrayList` secara internal menggunakan array biasa, namun ia mengelola sendiri proses resizing-nya agar kamu tidak perlu pusing.

Untuk menggunakan `ArrayList`, kamu perlu mengimpornya dari paket `java.util`. Saat membuat objek `ArrayList`, sangat disarankan untuk menggunakan _generics_ (misalnya `ArrayList<String>`) untuk menentukan tipe data objek yang akan disimpan. Ini penting untuk keamanan tipe (_type safety_) dan mencegah kesalahan saat kompilasi. Kamu bisa menambahkan elemen menggunakan metode `add()`, mengambil elemen dengan `get(indeks)`, mengetahui jumlah elemen dengan `size()`, dan bahkan menghapus elemen dengan `remove(indeks)` atau `remove(objek)`.

Memahami `ArrayList` akan sangat membantumu dalam berbagai proyek, mulai dari menyimpan data sementara hingga berinteraksi dengan basis data. Ia adalah fondasi penting untuk bekerja dengan koleksi data di Java. Dengan kemudahan dan fleksibilitasnya, `ArrayList` akan menjadi teman baikmu dalam perjalanan pemrograman Java!

```
import java.util.ArrayList;

public class DaftarMahasiswa {
    public static void main(String[] args) {
        // Membuat ArrayList untuk menyimpan nama-nama mahasiswa
        ArrayList<String> namaMahasiswa = new ArrayList<>();

        // Menambahkan elemen ke ArrayList
        namaMahasiswa.add("Budi Santoso");
        namaMahasiswa.add("Siti Aminah");
        namaMahasiswa.add("Joko Susanto");

        // Mengakses dan menampilkan elemen pertama
        System.out.println("Mahasiswa pertama: " + namaMahasiswa.get(0));

        // Menampilkan semua elemen menggunakan enhanced for loop
        System.out.println("\nDaftar Mahasiswa Lengkap:");
        for (String nama : namaMahasiswa) {
            System.out.println("- " + nama);
        }
    }
}
```

💡 **Fun Fact:** Tahukah kamu, di balik layar, `ArrayList` sebenarnya menggunakan array biasa (fixed-size array) sebagai penyimpanan internalnya? Ketika kapasitasnya penuh, ia akan membuat array baru yang lebih besar (biasanya 1.5 kali ukuran semula) dan menyalin semua elemen lama ke array baru tersebut secara otomatis!
