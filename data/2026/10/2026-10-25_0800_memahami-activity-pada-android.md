## 🤖 Android Concept: Memahami Activity pada Android

**Category:** Architecture
**TL;DR:** Activity adalah komponen fundamental yang menyediakan satu layar antarmuka pengguna, menjadi titik interaksi utama pengguna dengan aplikasi.

Dalam pengembangan Android, Activity adalah salah satu komponen inti yang paling sering Anda temui. Secara sederhana, setiap layar yang Anda lihat dan berinteraksi di aplikasi Android Anda diwakili oleh sebuah Activity. Ini adalah kelas dasar yang menyediakan jendela di mana aplikasi Anda dapat menggambar antarmuka penggunanya dan tempat interaksi pengguna terjadi. Setiap aplikasi umumnya memiliki satu atau lebih Activity yang saling terkait.

Activity bertindak sebagai pintu gerbang utama bagi pengguna untuk berinteraksi dengan aplikasi Anda. Misalnya, ketika Anda membuka aplikasi pesan, layar daftar obrolan adalah sebuah Activity. Ketika Anda mengetuk salah satu obrolan dan berpindah ke layar percakapan, itu adalah Activity lain. Activity memiliki daur hidup (lifecycle) yang terdefinisi dengan baik, mulai dari `onCreate()`, `onStart()`, `onResume()`, hingga `onPause()`, `onStop()`, dan `onDestroy()`. Memahami daur hidup ini sangat krusial untuk mengelola sumber daya dan perilaku aplikasi secara efisien.

Ketika Anda membuat proyek Android baru, Android Studio secara otomatis akan membuat `MainActivity` untuk Anda. Activity ini umumnya mewarisi kelas `AppCompatActivity` (bagian dari Android Jetpack) yang menyediakan kompatibilitas fitur untuk berbagai versi Android. Fungsi `onCreate()` adalah tempat utama untuk menginisialisasi Activity Anda, seperti menentukan layout XML apa yang akan ditampilkan (menggunakan `setContentView()`) dan melakukan pengaturan awal lainnya. Ini adalah titik awal eksekusi kode Anda untuk Activity tersebut.

```
package com.example.myfirstapp

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
        // Kode inisialisasi lainnya bisa ditambahkan di sini
    }
}
```

💡 **Fun Fact:** Tahukah Anda, pada versi awal Android, Activity adalah satu-satunya cara untuk menampilkan UI. Konsep Fragment baru diperkenalkan di Android 3.0 (Honeycomb) untuk membantu menangani tata letak yang lebih fleksibel, terutama di tablet.
