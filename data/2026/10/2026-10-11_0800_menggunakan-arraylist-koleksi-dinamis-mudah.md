## ☕ Java Concept: Menggunakan ArrayList: Koleksi Dinamis Mudah

**Category:** Collections
**TL;DR:** ArrayList adalah struktur data dinamis yang memungkinkan Anda menyimpan daftar objek dengan ukuran yang dapat berubah secara otomatis saat Anda menambah atau menghapus elemen.

Java menawarkan berbagai cara untuk menyimpan kumpulan data, dan salah satu yang paling sering digunakan adalah `ArrayList`. Berbeda dengan array standar yang memiliki ukuran tetap setelah dibuat, `ArrayList` adalah implementasi dari antarmuka `List` yang memungkinkan Anda membuat "daftar" objek dengan ukuran yang dapat bertambah atau berkurang sesuai kebutuhan. Ini sangat praktis ketika Anda tidak tahu persis berapa banyak data yang akan Anda simpan di awal program, seperti daftar belanja, daftar nama mahasiswa, atau hasil pencarian.

Untuk menggunakan `ArrayList`, Anda perlu mengimpornya dari package `java.util`. Anda mendeklarasikan `ArrayList` dengan tipe data objek yang ingin Anda simpan (misalnya, `ArrayList<String>` untuk menyimpan teks atau `ArrayList<Integer>` untuk angka). Setelah dibuat, Anda bisa menambahkan elemen menggunakan metode `add()`, mengakses elemen berdasarkan indeks menggunakan `get()`, dan mengetahui jumlah elemen saat ini dengan `size()`. `ArrayList` juga menangani secara otomatis memori yang dibutuhkan, jadi Anda tidak perlu pusing memikirkan pengalokasian ulang array secara manual.

Kemudahan penggunaan dan fleksibilitas `ArrayList` menjadikannya pilihan utama bagi banyak pengembang Java. Anda dapat dengan mudah menambahkan, menghapus, atau memodifikasi elemen di dalamnya tanpa khawatir tentang batasan ukuran array tradisional. Fitur ini sangat berharga dalam aplikasi nyata, di mana jumlah data seringkali tidak dapat diprediksi dan perlu ditangani secara dinamis, menjadikan kode Anda lebih ringkas dan mudah dipelihara.

```
import java.util.ArrayList;

public class DaftarMahasiswa {
    public static void main(String[] args) {
        ArrayList<String> namaMahasiswa = new ArrayList<>();
        namaMahasiswa.add("Budi");
        namaMahasiswa.add("Ani");
        namaMahasiswa.add("Cici");
        System.out.println("Jumlah mahasiswa: " + namaMahasiswa.size());
        System.out.println("Mahasiswa pertama: " + namaMahasiswa.get(0));
        namaMahasiswa.add("Dodi"); // Tambah lagi
        System.out.println("Semua mahasiswa: " + namaMahasiswa);
    }
}
```

💡 **Fun Fact:** Meskipun `ArrayList` sangat fleksibel, di balik layarnya ia sebenarnya menggunakan array biasa. Ketika `ArrayList` Anda penuh, ia akan secara otomatis membuat array baru yang lebih besar, menyalin semua elemen lama ke array baru tersebut, dan membuang array lama. Proses ini disebut "resizing" dan dirancang untuk menyeimbangkan efisiensi penambahan elemen dengan penggunaan memori.
