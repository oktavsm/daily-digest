## 🤖 Android Concept: Android Activity: Pondasi Aplikasi Anda

**Category:** Architecture
**TL;DR:** Activity adalah komponen dasar yang menyediakan layar interaktif tunggal tempat pengguna dapat berinteraksi dengan aplikasi Anda.

Di dunia Android, Activity bisa diibaratkan sebagai satu "layar" dalam aplikasi Anda. Setiap kali Anda membuka sebuah aplikasi dan melihat sesuatu — apakah itu daftar email, detail produk, atau sebuah game — kemungkinan besar Anda sedang berinteraksi dengan sebuah Activity. Activity bertanggung jawab untuk mengelola antarmuka pengguna (UI) dan menyediakan ruang bagi pengguna untuk berinteraksi, menampilkan data, dan menerima input.

Setiap Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, yang diwakili oleh serangkaian callback method seperti `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()`. Memahami lifecycle ini sangat krusial, karena di sinilah Anda akan melakukan inisialisasi UI di `onCreate()`, mengambil data saat Activity terlihat, atau menyimpan state penting sebelum Activity dimatikan. Sistem Android mengelola siklus hidup ini secara otomatis berdasarkan interaksi pengguna dan kondisi perangkat.

Untuk membuat sebuah Activity, Anda cukup membuat kelas Kotlin yang mewarisi dari `AppCompatActivity` dan mengimplementasikan method `onCreate()`. Di dalam `onCreate()`, Anda akan memanggil `setContentView()` untuk mengaitkan layout XML yang telah Anda desain sebagai tampilan visual Activity tersebut. Setiap Activity juga harus dideklarasikan dalam file `AndroidManifest.xml` agar sistem Android dapat mengenalinya dan meluncurkannya.

Dengan menguasai Activity, Anda membangun fondasi yang kokoh untuk mengembangkan aplikasi Android. Anda akan belajar bagaimana menavigasi antar Activity, bagaimana mengirim data dari satu Activity ke Activity lain, dan bagaimana mengelola berbagai skenario yang terjadi selama penggunaan aplikasi, seperti rotasi layar atau menerima panggilan telepon. Ini adalah langkah pertama yang esensial dalam perjalanan Anda sebagai developer Android.

```
import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Mengaitkan layout XML
        // Di sini Anda bisa inisialisasi view, set listener, dll.
    }
}
```

💡 **Fun Fact:** Android memiliki 'task stack' untuk mengelola Activity, mirip tumpukan piring. Ketika Anda membuka Activity baru, ia diletakkan di atas tumpukan; saat Anda menekan tombol kembali, Activity teratas dikeluarkan dari tumpukan.
