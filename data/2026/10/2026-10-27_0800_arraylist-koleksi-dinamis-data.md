## ☕ Java Concept: ArrayList: Koleksi Dinamis Data

**Category:** Collections
**TL;DR:** `ArrayList` adalah implementasi array dinamis di Java yang memungkinkan kita menyimpan dan mengelola urutan objek dengan ukuran yang dapat berubah secara otomatis.

Pada pemrograman, kita seringkali perlu menyimpan banyak data yang sejenis. Array adalah struktur data dasar untuk ini, namun array memiliki batasan ukuran yang tetap setelah dibuat. Artinya, jika Anda membuat array dengan 10 slot, Anda tidak bisa menambah atau menguranginya. Di sinilah `ArrayList` hadir sebagai solusi yang elegan. `ArrayList` adalah bagian dari Java Collections Framework, yang bertindak seperti "array pintar" yang ukurannya bisa bertambah atau berkurang sesuai kebutuhan.

`ArrayList` menyediakan cara yang fleksibel untuk bekerja dengan daftar objek. Anda bisa dengan mudah menambahkan elemen baru menggunakan metode `add()`, mengambil elemen pada posisi tertentu dengan `get(index)`, mengetahui jumlah elemen saat ini dengan `size()`, dan bahkan menghapus elemen menggunakan `remove(index)` atau `remove(object)`. Semua operasi ini ditangani secara internal oleh `ArrayList`, membebaskan Anda dari manajemen memori manual yang rumit.

Untuk menjaga keamanan tipe (type safety), `ArrayList` menggunakan *generics*. Ini berarti Anda bisa menentukan tipe data objek yang akan disimpan di dalamnya, misalnya `ArrayList<String>` untuk menyimpan teks, atau `ArrayList<Integer>` untuk angka. Hal ini sangat membantu mencegah kesalahan pada saat *runtime* karena compiler akan memeriksa tipe data yang dimasukkan. Di balik layar, `ArrayList` sebenarnya menggunakan array biasa, tetapi ketika array tersebut penuh, ia akan membuat array baru yang lebih besar dan menyalin semua elemen lama ke dalamnya, sehingga memberikan ilusi ukuran yang dinamis.

Menguasai `ArrayList` sangatlah penting karena ia adalah salah satu koleksi yang paling sering digunakan dalam aplikasi Java sehari-hari. Ia sangat cocok digunakan ketika Anda tidak tahu berapa banyak elemen yang akan Anda simpan, atau ketika jumlah elemen sering berubah selama program berjalan. Pemahaman `ArrayList` juga akan menjadi jembatan untuk mempelajari koleksi lain yang lebih kompleks seperti `LinkedList` atau `HashMap`.

```
import java.util.ArrayList;

public class MahasiswaApp {
    public static void main(String[] args) {
        ArrayList<String> daftarMahasiswa = new ArrayList<>();

        daftarMahasiswa.add("Budi");
        daftarMahasiswa.add("Ani");
        daftarMahasiswa.add("Cici");

        System.out.println("Jumlah mahasiswa: " + daftarMahasiswa.size());
        System.out.println("Mahasiswa pertama: " + daftarMahasiswa.get(0));

        daftarMahasiswa.remove(1); // Menghapus Ani
        System.out.println("Jumlah mahasiswa setelah dihapus: " + daftarMahasiswa.size());
        System.out.println("Daftar mahasiswa: " + daftarMahasiswa); // Output: [Budi, Cici]
    }
}
```

💡 **Fun Fact:** Ketika sebuah `ArrayList` perlu memperluas ukurannya, secara default ia akan membuat array baru yang berukuran sekitar 50% lebih besar dari kapasitas sebelumnya. Ini adalah strategi untuk menyeimbangkan antara penggunaan memori dan frekuensi operasi penyalinan data.
