## 🤖 Android Concept: Memahami Activity di Android

**Category:** UI
**TL;DR:** Activity adalah komponen dasar yang menyediakan layar tunggal untuk berinteraksi dengan pengguna, menampilkan antarmuka dan mengelola daur hidupnya.

Dalam pengembangan aplikasi Android, Activity adalah salah satu komponen inti yang paling sering Anda temui. Bayangkan Activity sebagai satu "layar" tunggal dalam aplikasi Anda. Misalnya, saat Anda membuka aplikasi dan melihat halaman login, daftar produk, atau detail profil, kemungkinan besar itu semua diwakili oleh Activity yang berbeda. Setiap Activity bertanggung jawab untuk menyediakan antarmuka pengguna (UI) dan berinteraksi dengan user melalui elemen-elemen seperti tombol, teks, dan gambar.

Setiap Activity memiliki siklus hidup (lifecycle) yang terdefinisi dengan baik, mulai dari dibuat hingga dihancurkan. Beberapa metode penting dalam lifecycle ini adalah `onCreate()`, `onStart()`, `onResume()`, `onPause()`, `onStop()`, dan `onDestroy()`. Metode `onCreate()` adalah tempat utama Anda melakukan inisialisasi awal, seperti menghubungkan layout XML Anda ke Activity. `onResume()` menandakan Activity berada di latar depan dan siap berinteraksi, sementara `onPause()` berarti Activity sebagian atau sepenuhnya tertutup oleh Activity lain. Memahami lifecycle ini sangat penting untuk mengelola resource aplikasi secara efisien dan menyimpan/mengembalikan status user.

Untuk menampilkan antarmuka pengguna, sebuah Activity biasanya dihubungkan dengan file layout XML melalui metode `setContentView()`. File XML ini mendefinisikan tata letak visual komponen-komponen UI. Selain itu, Activity juga bertindak sebagai orkestrator yang merespons input pengguna, memproses logika bisnis sederhana, dan menavigasi ke Activity lain menggunakan objek `Intent`. Activity adalah fondasi utama yang memungkinkan interaksi dan alur kerja dalam aplikasi Android Anda.

```
class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main) // Menghubungkan layout XML
        // Lakukan inisialisasi UI atau logika dasar di sini
    }
}
```
