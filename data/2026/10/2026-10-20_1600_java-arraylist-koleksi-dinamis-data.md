## ☕ Java Concept: Java ArrayList: Koleksi Dinamis Data

**Category:** Collections
**TL;DR:** `ArrayList` adalah implementasi struktur data array yang ukurannya dapat berubah secara dinamis, memungkinkan penambahan atau penghapusan elemen setelah dibuat.

Para mahasiswa pasti sudah akrab dengan array biasa di Java. Array sangat berguna, tetapi memiliki batasan utama: ukurannya tetap setelah dibuat. Artinya, jika Anda membuat array dengan 5 elemen, Anda tidak bisa menambahkan elemen keenam tanpa membuat array baru yang lebih besar dan menyalin semua isinya.

Di sinilah `ArrayList` dari paket `java.util` menjadi penyelamat. `ArrayList` menyediakan array yang "dapat diresize", yang berarti ia dapat secara otomatis menumbuhkan atau menyusutkan kapasitasnya saat Anda menambah atau menghapus elemen. Ini membuatnya sangat fleksibel untuk situasi di mana Anda tidak tahu persis berapa banyak data yang akan Anda simpan. `ArrayList` adalah bagian dari Java Collections Framework, yang menyediakan berbagai struktur data umum.

Secara internal, `ArrayList` masih menggunakan array biasa. Ketika Anda menambahkan elemen dan kapasitas array internal habis, `ArrayList` akan membuat array baru yang lebih besar (biasanya 1.5 kali ukuran semula), menyalin semua elemen lama ke array baru tersebut, lalu menambahkan elemen baru Anda. Meskipun proses ini terjadi secara otomatis di belakang layar, penting untuk memahami bahwa ada sedikit overhead kinerja saat `ArrayList` perlu diresize.

Beberapa metode penting `ArrayList` yang akan sering Anda gunakan meliputi `add()` untuk menambahkan elemen, `get()` untuk mengambil elemen berdasarkan indeks, `set()` untuk mengubah elemen pada indeks tertentu, `remove()` untuk menghapus elemen, dan `size()` untuk mendapatkan jumlah elemen saat ini. Karena `ArrayList` adalah kelas generik, Anda bisa menentukan tipe data elemen yang akan disimpannya (misalnya, `ArrayList<String>`).

```
import java.util.ArrayList;

public class KoleksiMahasiswa {
    public static void main(String[] args) {
        ArrayList<String> namaMahasiswa = new ArrayList<>(); // Membuat ArrayList

        namaMahasiswa.add("Budi"); // Menambah elemen
        namaMahasiswa.add("Siti");
        namaMahasiswa.add("Andi");

        System.out.println("Jumlah mahasiswa: " + namaMahasiswa.size()); // Mendapatkan ukuran

        System.out.println("Mahasiswa pertama: " + namaMahasiswa.get(0)); // Mengambil elemen

        namaMahasiswa.remove(1); // Menghapus elemen pada indeks 1 (Siti)

        System.out.println("Setelah dihapus, daftar: " + namaMahasiswa);
    }
}
```

💡 **Fun Fact:** `ArrayList` bukan satu-satunya implementasi antarmuka `List` di Java; ada juga `LinkedList`! Meskipun keduanya mengimplementasikan fungsionalitas `List` yang sama, `ArrayList` lebih cepat untuk akses acak (menggunakan `get(index)`) sementara `LinkedList` lebih efisien untuk operasi penambahan atau penghapusan di tengah daftar.
